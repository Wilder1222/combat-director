# 18秒演武：白鸽 × 沈砚

白鸽以中位旋踢开场，被沈砚逼近木柱后主动换线，再用短暂单手撑地衔接高位斜踢；沈砚始终以斜步、拨接和探掌争取近身。双方试出距离便停手，最后拱手。

**创作假设：**另一位练习者为本次原创的成年虚构人物“沈砚”；白鸽亦按成年虚构角色呈现。采用16:9、自然日光、布衣与木地板的可见材质，无台词。白鸽穿灰白短衣、深色长裤，沈砚穿靛蓝短衣、黑裤，均穿软底练功鞋；这些外观只是本稿区分人物的临时设计。

**规则与空间：**18秒包含收势，全程正常速度，允许切镜，空手，无能量、残影或夸张击飞。只轻触前臂，躯干探掌和高踢都可主动避开；掌心朝下的放手动作是双方约定的停止信号。开场白鸽在厅中偏西，沈砚在东，间距约1.6米；木柱在白鸽西北后方，南侧有至少3米宽的空地。摄影机始终在两人南侧，切镜后白鸽仍在画面左、沈砚在右。柱子会限制白鸽向北扩大旋身的空间，双方因此转入南侧空地。
