这段争夺的转折放在船身向西侧倾：甲也会脚滑，只是左手的绳索让他多一个支点；乙继续夺袋就无法扶栏，于是主动松手保住平衡。结尾保留两人喘息和船体摇晃，不补击倒。

创作假设：16:9，阴天自然光下的木船甲板，两名普通成年人物，便于辨认的深灰上衣甲、褐色上衣乙；无台词、无武器、无超自然能力。18秒包含起止余量，全程正常速度、一个连续镜头。

**空间与手部约束**

西侧栏杆和东侧桅杆开场同时入画。甲在桅杆以西约0.8米，距西栏约1.3米；乙在甲西侧约0.6米，位于甲与栏杆之间。甲初始面向西，乙面向东。两人脚下留出短步移动的空处，不添加绊脚杂物。

绳索一端牢系桅杆，斜向甲左手；甲以屈肘握住已有绳段，起始只有少量松弛，侧倾时绳索可绷紧承力，不允许无限伸长。甲右手始终抓紧皮袋收口，右前臂将袋压向胸腹、再收进右肋，袋底始终可见。两只手都不额外抓人、出拳或扶栏。

乙有两个阶段：先用手抢袋，再清楚地解除接触、抓栏稳身。栏杆不因镜头移动改变位置。

18秒，16:9，普通成年人的木船甲板夺袋争执。阴天自然光，湿木板、积水、受风贴身的衣服、真实受力的皮革与粗绳。甲穿深灰上衣，乙穿褐色上衣。全程正常播放速度，一个连续镜头，无切镜、跳切、黑场、遮挡转场、慢动作或定格。无台词，无武器，无超自然能力。

<动作> 船轻摇，两人都屈膝调整重心。乙先右手试探，再向东短进约0.2米抓袋底。甲不松左手的绳，右肘往内收，身体略向西北侧开，将袋从身前压入右肋。乙指尖擦过袋底但未握牢，收回少许，仍在近处寻找露出的袋角。

<动作> 乙向东北补半个短步，左掌抵住甲右前臂外侧，右手抓到袋底折边，朝自己短拉。甲抓紧袋口、右前臂夹袋，左手继续抓绳。袋身起褶，两人短暂僵持，袋没有换手。

<情绪> 甲保住皮袋，乙稳住自己，争夺就此停止。
