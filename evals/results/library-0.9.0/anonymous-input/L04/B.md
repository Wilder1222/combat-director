# 绯雪·火焰｜雨夜石桥，16 秒

采用资料库的**火焰版绯雪**：以单刀连续前压争取通路。她要从西端走到东端，成年持棍守门者要把她拦在桥西；结尾只完成越过，两人都站稳、持械。

本片创作假设：16:9，两名成年角色，无台词、无血腥；桥面内宽约四米，北侧有一条粗糙石缝带，中央积着薄水。绯雪穿便于迈步的暗红短外袍，守门者穿深灰短衣。绯雪全程右手握同一把实体单刀，左手空着；守门者双手持同一根约一人高的实木长棍。

火焰只贴在实体刀刃上，刃根暗赤、刃缘火红，接触时局部转亮；不延长刀锋、不离刃成波、不增加兵器数量。绯雪以步法和腕肘改变棍路，火焰不替她推开对手。雨滴触刃只出少量短促白汽，湿木棍不持续燃烧。反震仍由右肩、肘与落脚承担。14 秒后刀焰随收势逐渐熄灭。

## 六轨导演时间轴

全片只有镜头 S01。摄影机在桥面南半侧，与人物保持可见距离，沿西向东连续跟移；动作主要发生在中线及北半侧。始终保留两人的脚、持械手与兵器接触区，不越到北侧、不借遮挡剪辑。所有时间段均为正常速度，包含起步和结尾余势。

| 11–14 秒：从北侧通过 | 绯雪左脚承重后，右脚向东跨出，沿北侧空隙越过守门者站位。右手刀继续放在两人之间，等棍头完全收离才把刀降向右胯外。守门者双手收棍贴近胸前，随右脚转身朝东北，再向东横移半步想补位；绯雪已经过了他的东侧，未被拦回。 | 她下颌微收，侧目确认棍已撤回后看向出口；守门者绷紧的嘴角松开一瞬，马上抬眼追踪，仍有继续行动的意图。 | 平滑跟到二人南侧偏东的位置，保持同一侧视线；她从其西北侧到东北侧的整段路程完整可见。 | 刀焰降低，仍只在刃缘；没有绕身火圈或背后爆炸。 | 她外袍下摆甩下雨水；守门者转身时先踩稳再挪步，两人都没有滑倒、碰栏或跪地。 | 脚步由交错变成前后两组；木棍收回掠衣一声，火焰声减弱。 |
| 14–16 秒：继续前行 | 绯雪继续向东走出两步，右手仍握实体刀，刀尖斜向地面，左手自然回到身侧。守门者留在她身后约两步多的位置，转正朝东，双脚站稳，长棍横护胸前；没有倒地、丢械或被火焰定住。 | 她呼出一口气，眼神仍在前路；守门者胸口起伏、视线追随，握棍保持警戒。 | 继续轻缓向东跟随，画面同时保留前行的绯雪和后方站立的守门者，16 秒自然结束，不定格、不收黑。 | 刀焰从刃尖向刃根缩小，至约15.5秒熄灭，实体钢刀持续可见。 | 雨水重新流过脚印；木棍的浅痕与焦褐点仍在，桥面无爆坑和燃烧。 | 火声消退，留下雨、河水、绯雪前行的脚步与守门者呼吸。 |

**关键连续性：**绯雪的路线是西侧中线 → 沿中线前压 → 东北踏步进入北侧石缝带 → 从守门者北侧走到其东侧 → 继续向东。守门者是东侧中线 → 向东退 → 向东南卸步 → 原地收棍转向东北、再向东补半步；摄影机始终位于两人南侧。右手单刀、双手木棍、木杆浅痕与焦褐点全部延续，双方没有换手、弃械或重置站位。
