# 18秒甲板争袋：抓绳保物，放手求稳

核心转折是第二次西倾：甲靠已握住的桅杆绳索和屈膝落脚保住皮袋；乙意识到继续拉扯会让自己失衡，主动松袋、抓住西侧栏杆。两人都受船体摇晃影响，甲不额外腾手施招，乙也不是被打飞到栏杆边。

## 设计卡与空间

- **确定约束**：18秒、正常速度、一镜到底；两名普通成年人；湿滑甲板、风浪、船体侧倾；甲左手全程握桅杆绳，右手全程护袋；乙徒手争夺；结尾甲保袋、乙主动抓栏杆站稳。
- **创作补充**：16:9，阴天自然光，湿木板、粗纤维绳、深褐皮袋，甲深灰上衣、乙浅褐上衣以便辨认；无台词、无兵器、无超自然能力。皮袋没有长肩带，甲右拳攥住袋口，右前臂把袋身压在右侧肋部。这些外观不是用户已定设定。
- **强度**：近身伸手、压臂与一次短促拉袋；没有腾空、踢腿、投摔或击伤。甲的动作特征是收肘护袋、双脚小幅调位；乙是盯袋前探，失衡后及时转向支撑物。
- **场地锚点**：北为船首，西栏杆在画面左侧。桅杆为原点，栏杆约在其西侧1.8米；甲在桅杆西南约半米处、朝南略偏西；乙在甲的西南前方、距甲约0.75米，朝北略偏东。两人之间没有箱桶或绳圈。甲左侧靠近桅杆，绳索从左拳斜向桅杆约胸高的固定结，始终可见。
- **绳索状态**：甲左肘起初微屈，绳段近乎拉直，允许靠伸肘和身体靠近固定点做小幅调整；绳不缠腕、不换手、不绕人。它承担部分侧向拉力，甲的双脚持续着地，不能表现成单臂悬吊。
- **船体节奏**：0—6秒小幅起伏；6—10秒短暂回近水平；10—14秒明确西侧下沉，积水和双方脚步一起向西偏移；14—18秒倾斜减缓但船仍轻晃。两人不会凭空停止惯性。

**连续机位 S01**：摄影机在两人南侧略偏东，朝北略偏西，保持能看见两人的全身、甲左拳到桅杆的绳段、皮袋和西栏杆。0—10秒缓慢横移向西约0.4米并靠近约0.2米；10—14秒继续向西跟半步并略后撤，让栏杆与乙的双脚留在画内；14—18秒停下平移，保持同侧观察。镜头不绕到人物背后、不穿桅杆、不借人物遮挡切镜。船体倾斜主要由桅杆、栏杆相对海平线的变化表现，不靠摄影机猛甩代替人物失衡。

<声音>浪声增强、连续鞋底擦水声、乙急吸气和左掌拍握栏杆的钝响。

<环境反馈>乙双手撑握栏杆、双脚留在甲板；甲靠绳与落脚维持稳定；积水继续西流，船仍微晃。
