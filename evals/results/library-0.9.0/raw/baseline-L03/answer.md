# 白鸽与顾岑：18秒木柱练功厅演武

采用人物级试招结构：**顾岑试掌 → 白鸽弹腿回攻 → 柱边改线 → 白鸽旋踢、顾岑退接 → 示停拱手**。

创作假设：白鸽与顾岑均为成年虚构人物；顾岑是本稿新设练习者，以短掌试探、跟步压距和退接护架为动作特点。16:9，正常速度，允许切镜，无台词、空手、无能量。双方知情演武，仅允许掌臂与护架轻触，不击打头颈、关节，不分胜负。约定摊开左掌为停止信号。

白鸽穿灰白窄袖练功服，顾岑穿靛蓝练功服，均为软底鞋。干燥木地板，北墙前排列木柱，南侧中央留出开阔区，侧窗自然光。开场白鸽在西、顾岑在东，相对约一腿距离；一根木柱在白鸽西北方，提前入画。白鸽第一次斜退后接近柱边，完整旋踢空间受限，必须先向南移入开阔区。摄影机始终在南侧，白鸽保持画面左侧、顾岑保持右侧。

**关键连续性：**白鸽先左脚支撑、右腿弹击，收腿后右脚落前；南移完成后仍由右脚支撑，左腿旋踢；左脚收回落稳后才示停。双方全程空手，掌臂接触解除后才移位。6–9秒共同向南移动，之后白鸽仍在西、顾岑仍在东，不交换画面左右。柱子只限制路线，不被碰撞或破坏。旋踢若没有展开空间，白鸽直接收膝退距，不强行完成；对手没有到达护架接触位置时按扫空回收处理。
