# 凛羽 × 冰女｜20秒院落对练

采用资料库的“人物级攻防”结构：**直进试手 → 抓控续攻 → 硬冰改路 → 绕端再接 → 双方停手、障碍消退**。正常速度，两个镜头，全部入点和收势包含在20秒内。

**创作假设**：成年虚构角色、非正史试招、16:9、无台词、点到即止；外貌与服装沿用角色已有设定。本稿只设计动作和声音，不代表已有成片或平台实测。

## 设计与空间

- **凛羽**：徒手，直线进攻结合圆步换角；一次短暂抓腕必须接回掌击。没有能量、冰雾、寒气、冰晶、残影或超常位移。
- **冰女**：徒手短促硬攻与稳定桥手，使用唯一一块硬冰改变直进路线。冰不能接触、包裹或冻结人体；没有冰甲、冰刃、冰刺、飞射物或第二块冰。
- **对练目的**：凛羽练习“打进去、抓到后继续打”；冰女练习“挡住攻击、改变路线、跟转承接”。允许掌与前臂的轻接触，不追求击倒；一方举起空掌后，双方结束交手。
- **院落**：平整干燥石地。以中央一块浅色方砖为锚点，北侧为低墙，南侧为摄影机通道。凛羽从西向东，冰女从东向西；开场相距约1.6米。中央方砖南北两侧都可绕行，不把开阔院落表现成死胡同。
- **唯一冰障碍**：位于中央方砖，长边南北向，约长1.2米、厚0.3米、高0.45米，最高到膝部；钝边、半透明蓝白硬冰。形成前双方先退出这块空地。两端各保留至少1米可通行的干燥地面。

**冰的触发、代价与解除均为本次补写**：8–11秒，冰女站稳后右掌朝向中央空砖，冰只从这块地面向上长出，10.5秒成形；施术期间右手离开护架，暂时不能用右手进攻。冰成形后保持原位和原尺寸，冰女收手恢复护架。17秒双方停手后，她重新面向障碍翻掌放松，18–19.5秒冰从上缘向下融退，成为原占地内的一小片浅水；19.5秒已无硬冰。全程没有弥散冰雾，双方不踏入融水。

| 6–8秒 | 凛羽先松开左手，左掌回到胸前，借刚取得的侧角，以右掌从腰侧短促穿向冰女上胸。冰女左前臂接住并引开掌线，同时向东后撤；凛羽在接触后收右掌，向西南退回中央方砖西侧。冰女退至方砖东侧，双方重新拉开约2.4米，中间空地完全让出。 | 凛羽出掌时吐气，掌被接住后不追压；冰女一直看着来掌，后撤落稳才松下颌。两人保持试招的克制。 | 镜头1略放宽，完整看到松手、续掌和双方退开，不省略复位步。 | 无。 | 只有鞋底摩擦；中央方砖保持空置。 | 一次掌臂轻碰、两组分开的后撤脚步。 |

| 11–14秒 | 凛羽从西侧向北走两步，再沿障碍北端外的干地弧线向东转进，身体始终不穿冰、不踩冰。冰女看见绕行便沿自身东侧向东北短步横移，转身持续面对凛羽，守住北端出口。到14秒，双方都在障碍北端之外，凛羽偏西、冰女偏东，相距约一臂加半步。 | 凛羽目光落在冰女肩线，绕行时不低头盯脚；冰女用目光和胸口朝向跟随，呼吸稳定，双手保持可接招的位置。 | **镜头2，11–20秒**：切到同在南侧、稍高的双人全身中远景，能俯见障碍北端与脚步；缓慢向东平移，不越轴。 | 冰块静止，尺寸、数量、位置不变；凛羽始终无特效。 | 所有脚步落在北端外的干石上；冰不沿脚底扩散。 | 绕行脚步从疏到近，衣料摆动；不添加高速破空轰鸣。 |

## 关键连续性

| 时点 | 必须继承的状态 |
|---|---|
| 4秒 | 凛羽左掌刚被引低、右手护胸；冰女仍站稳，右手可发动下一拍。 |
| 6秒 | 凛羽已向北让线，**左手确实扣住冰女右腕**，右手未占用；冰女屈肘跟转，没有僵直或冻结。 |
| 8秒 | 左腕抓控已解除，续掌已收回；双方通过可见退步来到方砖西、东两侧，造冰区无人。 |
| 11秒切点 | 冰恰为一块、膝高、南北向；凛羽西、冰女东。镜头2继承这一位置和姿势，不跳到已绕过障碍的状态。 |
| 14秒 | 凛羽经“西侧→北端外→向东”的真实路径绕行；冰女经“东侧→东北”跟转。两人都在冰北端以外，没有隔着冰进行徒手接触。 |
| 17–20秒 | 17秒发出停手信号后不再攻击；18秒才开始解除冰，19.5秒冰已消退。没有武器、伤口、服装破损；原冰块底面留下浅水。 |

抓控失败的处理原则：本稿选择“接触成立”的一条动作链。如果画面中左手未接到右腕，就只能收手护线和退出，不能继续表现“已控制对方”或凭空牵动对手。
