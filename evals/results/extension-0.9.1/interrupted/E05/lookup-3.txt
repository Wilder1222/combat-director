# 六轨编排与连续性

先写目标、能力边界、空间锚点和结尾，再写行动。正式剧情继承人物设定；缺少关键事实时只做注明假设的测试方案，不写入正史。

角色的距离偏好、起手、回应和恢复应有可辨差异，见[动作档案与名招转译](action-design.md)。涉及多人、远程、追逐、体型差或演武时，再读[场面调度](combat-modes.md)，不将所有场面压成双人轮流接招。

## 六轨

| 轨道 | 必须解决的问题 |
| --- | --- |
| 人物攻防 | 双方各要什么，谁发起、如何回应、接触或避让怎样改变局面 |
| 表演情绪 | 双方的视线目标、呼吸、下颌、手指张力、重心；非人角色用朝向、灯光、迟滞表现 |
| 摄影机 | 景别、机位侧、运动路径、接触是否可见；相机移动不代替人物移动 |
| 特效 | 从何处触发、归属谁、沿什么路径、何时消散；不能抹掉关键动作 |
| 环境反馈 | 尘土、擦痕、兵器掉落、破坏等结果留存，不无故复位 |
| 声音 | 对应可见事件的先后与轻重；未实听素材的声音只是设计建议 |

标签 `<表情>` 与 `<情绪>` 共同属于表演轨，不是两条独立轨。时间轴、连续性状态和素材绑定也不计为六轨。

需要具体粒子、烟火或剑光时按[粒子行为](particle-vfx.md)设计触发、路径、交互和消散，写回特效与环境反馈；简单自然反馈不必展开完整菜单。

涉及快速挥刃、跟拍拖糊或残影要求时，按[运动成像](motion-blur.md)一起安排动作与机位。关键接触和恢复应能追踪，不以“每帧全锐利”代替可辨标准；用户明确要求低模糊或艺术残影时保留其选择。

每拍用“准备 → 发起 → 接触/避让 → 回应 → 终态”组织。两个角色都应有动作和表演；画外角色说明位置、反应和暂不可见的部分，不能凭空消失。每拍通常只有一个主要结果，密度过高时删减动作。

相邻拍可以共用一次格挡的回弹、卸力或落脚，避免每拍归零重摆起手。空中转地面、远处贴近、飞剑回握、受击恢复均要有可见桥接；弱点须先造成并保留，随后才能被发现和利用。详细方法见 [prompt-craft.md](prompt-craft.md)。

## 状态与能力

记录双方位置、朝向、支撑/重心、兵器和手、损伤、道具及环境、机位侧。下一拍起点等于上一拍终点。只有可见移动、转身、松手、撞击等才能解释改变。世界方向和画面左右分开；越轴需要可见过渡或中性机位交代。

能力卡包含：归属、触发、可见表现、范围上限、限制、代价和结束条件。效果从原角色产生；变形留可辨识的身体/核心连续过程，不能用爆闪换成另一角色。写实材质与超自然能力是两个维度，换渲染风格不自动改能力等级。

## 两层时间轴

导演层细分目的、因果和状态，投喂层合并相邻节拍为少量主要结果。30 秒通常可先试 4–6 个主段，允许依据密度调整。细节拍数量不是模型参数，也不自动等于镜头数量。

主段必须按原顺序、无遗漏无重复地覆盖导演拍。修改动作或终态后同步改主段摘要；程序检查引用、时间覆盖和复核记录是否过期，语义仍需实际审阅。

镜头与成像修订也要同时进入逐拍 `camera.path` 和适用主段的 `summary.camera`；粒子存续另入特效或环境。只改细拍不会自动改投喂文字，总设定或前段镜头说明也不能替代后段同步。

## 换兵器与局部修订

先列受影响的动作、接触、声音、握法和距离，再改词。金属剑改为木杖后，剑刃切割、剑格结构、火花和金属长鸣不能无条件保留；不必要的身份、结尾和能力改动应省去。

空间复核使用简短的世界方向草图或位置表，逐拍记录双方“从哪里，经哪里，到哪里”。例如 A 向西南退、B 追随同一路线，不能直接把结果写成 B 到了道路北缘；若要到北缘，必须有可见的北向位移或换位。检查主段合并是否省掉了这个必要过程。摄影机横移不会改变角色在场景中的位置。

复核时读完整的前后拍，不只读被替换的句子。发现路径含糊先简化交手，避免用更多方向词掩盖问题。此检查适用于改变距离和路线的修订；短提示词不必输出内部位置表。

工程模式可使用[动作契约](action-contract.md)，仍需对空间合理性做导演判断；结构完整不等于物理成立。

入点与出点包含在总时长内：30 秒含 0.3 秒入点和 0.8 秒出点时，目标结果最晚 29.2 秒完成，主要行动窗口为 28.9 秒。结尾按目标选择呼吸、沉降、威胁余势、明确时段的定格或命中前收黑；不额外延长，也不为悬念片段补造胜负。台词与准备动作可以并行，但要单独核对完整发音窗口。

一镜到底使用同一 shot_id 和连续相机路径；单次生成可以有切镜；一个文件不能证明单次生成。当前平台时长冲突时说明冲突，不擅自拼接。

完整交付可用 [制作包模板](../assets/sequence-template.md)，结构化方案见 [数据契约](contract.md)。

# 三种战斗母版

母版规定因果组织方式，不固定角色脸、服饰或渲染风格。改变武器长度、场地宽度、参与人数时重算距离与可行路径，不能只替换名词。

## 人物级攻防

目的受阻 → 对方前压 → 主角承受并观察 → 利用已有空间反制 → 目标完成后停手。力量由接触、身体支撑、步伐恢复和道具重量体现。未允许幻想能力时不添加剑气、护盾、飞行或巨型终结技。

例：[grounded-15.prompt.txt](../examples/grounded-15.prompt.txt)，[结构化计划](../examples/grounded-15.plan.json)。15 秒，六个细节拍、四个投喂段，同一连续镜头。短刀从持握、失衡松手到落地有过程，落刀位置和持械手状态持续保留。

## 升级式斗法

可采用十一拍：近身交锋 → 移动布置前两处印记 → 应对追击并完成第三处印记 → 收势引导 → 阵列围控与对方防御 → 分波消耗 → 屏障破裂 → 同一敌方转为风柱 → 利用转向迟滞接近 → 回收阵列完成引导 → 限定范围的终结压制。

升级依赖预先展示的资源和条件：三处印记不消失；巨剑消耗既有阵列而不无限复制；敌人转化有过程；主角付出体力与机动性代价；终局仍有警戒。

例：[epic-30.prompt.txt](../examples/epic-30.prompt.txt)，[结构化计划](../examples/epic-30.plan.json)。11 拍合并为 6 段。本项目依据附件重建细拍，不是原视频逐镜观察或遗失计划的原件。

## 巨型敌人反制

威胁挡路 → 躲避建立尺度 → 看见既有装置 → 诱导巨敌朝向 → 付出接近代价 → 操作装置 → 障碍形成 → 撤离完成但威胁尚存。

胜利可只是开路和撤离，不必击毁。机械尺度来自足部接地、惯性、转向时差与人物比例；道具要先出现再使用。巡检员右手终端时，用左手按按钮，避免道具突然消失。

例：[colossus-30.prompt.txt](../examples/colossus-30.prompt.txt)，[结构化计划](../examples/colossus-30.plan.json)。8 拍合并为 6 段，无超自然能力。货架沿既有轨道落位，保留可通行旁路。

## 用变量组合新案例

| 变量 | 可选方向 | 会改变什么 |
| --- | --- | --- |
| 目标 | 夺物、阻拦、护送、脱身 | 停手条件与结尾，不必击败对方 |
| 人数 | 双人、第三人支援/被保护 | 画外位置、注意目标与焦点 |
| 空间 | 宽道、窄巷、带装置场地 | 路径、握法与兵器作用距离 |
| 能力 | 无幻想、有限能力、场地级 | 触发、代价与终止条件 |
| 镜头 | 单镜或多镜 | 运动路径或切点，不决定生成次数 |
| 参考 | 纯文本、身份图、动作片段 | 绑定用途和排除范围 |
| 风格 | 真人、三维、水墨、漫画 | 材质和呈现，不改变能力尺度 |

新增[窄巷取函](../examples/alley-letter-15.prompt.txt)、[三人护送](../examples/three-person-exit-18.prompt.txt)、[反制失败后修订](../examples/failed-counter-repair-18.prompt.txt)，采用[动作契约](action-contract.md)，与原三例互补；没有平台出片验证。

15/18/30秒只是创作目标。先选目标和变量，再决定拍数与时长；平台未知时不宣称能单次生成。不要把固定故事改名当作所有场景的模板。

## 选择片段形式

三种母版之外，先判断这次是否只需要一个片段，而非完整胜负。来自新文字案例的补充形式：

| 形式 | 可复用结构 | 必须重新确定的变量 |
| --- | --- | --- |
| 双人御剑对决 | 接触试探 → 留下缺口 → 回握/恢复 → 诱导并回收弱点 | 谁控飞剑、谁控风场、实体与投影数量、具体伤处 |
| 单人群战升级 | 小敌施压 → 精英改变打法 → 既有损伤回收 → 更大威胁入场 | 敌人批次、恢复能力、场地破坏、目标是否必须击杀 |
| 多区域空战 | 开阔交锋 → 狭窄地形限制 → 向目标区域推进 | 空中支撑、区域连接口、世界锚点与视线 |
| 战斗登场预告 | 身份局部 → 尺度 → 准备/台词 → 接近 → 首次接触前收黑 | 原台词、切镜许可、动作负载、是否展示命中 |

这些是编排选择，不扩充人物默认能力，也不要求所有片段有22个细拍或三段大招。方法见 [prompt-craft.md](prompt-craft.md)，完整文字例见[回握与裂口](../examples/return-and-payoff-18.md)、[登场悬念](../examples/entrance-cliffhanger-15.md)。

# 按场面调整调度

三种母版负责主要叙事结构，本页处理人数、距离和空间条件；可以按需叠加，不必全部套用。每拍通常只有一个主要结果，但其余角色仍同时行动。

| 场面 | 开始前确定 | 每拍必须保留 | 常见失败与修正 |
| --- | --- | --- | --- |
| 多人/护送 | 全员目标、入口出口、前后遮挡和彼此路线 | 主接触外的人在绕位、封路、护送、恢复或处理障碍；暂不能接触的原因 | 敌人排队：给同时威胁和到达路径；过载时减少接触点，不让人消失 |
| 远程/近远转换 | 起点、射线或抛物线、射程、掩体、弹体归属 | 发动→途中→避开/命中→影响；靠近要有人的位移 | 相机一推就贴身：补路线与时间；不能穿过实心柱仍叫掩护 |
| 追逐/跨区 | 逃离目标、连接口、路线顺序、追者速度限制 | 谁先过门、何处减速、后者为何未追上；旧破坏留在原区 | 背景一换位置重置：展示经过门洞/桥端，并让追者继承距离 |
| 体型差/巨物 | 脚下尺度、可接近部件、落点、转向空间 | 同一敌人的部件运动和回收迟滞；小角色怎样到达而非镜头替其移动 | 临时出现弱点或道具：先建立条件；局部阻挡不等于巨物完全倒下 |
| 演武/试招 | 双方知情规则、停止信号、允许接触、展示目的 | 递招/承接关系、留手和收势；技术展示也须有受力与支撑 | 强制破防杀招：以完成演示、兵器停住或双方复位作为可见结果 |

## 多人状态表

按需要记录“时间 / 角色 / 位置与朝向 / 当前任务 / 暂不接触原因 / 下一动作条件”。画外不等于停机：C沿已建立出口撤离时可用脚步声或下一宽景确认；未实听参考音轨时声音只是拟议设计。

示意：A在回廊挡B，C从A身后撤向门；D在另一根柱后沿外圈封门。B和D的同时威胁迫使A移动，柱距让两人不能同时占用一条窄路。不能仅写“D等B打完”，也不能在同一瞬间让A以同一只手控制两件远隔兵器。

## 能力的成立与解除

布点、连接、激活、维持、释放和结束是不同状态。若阵法需要三个落点，先让三个实体标记都真实落到可连接的位置，再判断资源能否激活；画出光圈不能替代这一过程。对手可拔掉标记、遮断路径或迫使施术者移动，但只使用已允许的反制。

对每次能力记录当前阶段、拥有者、可用资源、维持条件、可见代价与解除结果。先在导演稿核对，工程模式再映射至既有 `abilities`、`ability_use` 和状态增量。当前CLI只检查它已支持的阶段和约束；它不自动模拟复杂布阵、资源算术或治疗恢复。超出契约的机制保留文字说明并明确未被程序验证，不能自造字段后称校验通过。

完整案例见 [回廊护送](../examples/corridor-escape-24.md)。

# 从打斗提示词提炼可执行编排

用于拆解、整理、改写已有文字方案，以及战斗登场、飞剑对决、移动空战。方法来自多份用户文本的比较，不是已验证的模型参数或成片制作流程。完整动作和结构化规则仍见 [choreography.md](choreography.md) 与 [action-contract.md](action-contract.md)。

## 先分版本和片段目的

一份文件可能含两套完整方案。先以标题、重新起算的时间轴、角色能力或结尾变化划分版本，记录每版的角色、能力、场地、镜头与结尾。除非用户要求合并，不把两版招式叠加到同一个人身上，也不以文件名、性别或头发颜色决定能力。

文字拆解分为“原文明确写出、编排判断、建议修订、缺失证据”。“图一/图二”“某模型生成”等文字只是素材声称；未读取图像、视频或账号能力时不写成已看过、已绑定或已经成功。

| 片段目的 | 因果重点 | 可用结尾 |
| --- | --- | --- |
| 完整交手 / 双人斗法 | 攻击、回应、夺取优势、代价 | 脱离、有限压制、分出胜负或仍在对抗 |
| 单人对多批敌人 | 每批威胁怎样改变路线、资源和场地 | 达成局部目标或新的威胁出现 |
| 登场 / 预告 | 身份、尺度、附魔或准备、接近目标 | 首次接触前收黑；不补造命中结果 |
| 穿越多区域的空战 | 每次交锋推动真实位移，转场保留对手 | 到达目标区域后的明确终态 |

## 把动作串成一条连续的交手

可拍动作单元：**谁以哪只手和哪件兵器，从哪里沿什么轨迹攻击什么 → 对方如何接触或避开 → 力量如何改变身体、刀剑和支撑 → 下一动作从此处开始**。刀背挡、剑格卡、刃面滑开等细节只有在形制允许时使用。

不要为每一击重新摆“起手式”。例如：右手斜剑接住下劈 → 膝盖屈曲卸力，剑尖被压到右侧 → 右脚外撤，利用回弹转腕挑向对手持械腕 → 对手撤腕并以护手接住。一次主结果可包含这样一组接触与回应，不能只写“连续三击”而省掉被挡住的过程。

重点补四类桥接：

- **空中到地面**：先着地、屈膝或翻滚，再滑退；不能悬在半空却双脚犁地。已允许飞行时说明踏空支点、反推或御剑转向，不用幻想标签取消路径。
- **远到近**：先利用压制、斜掠、蹬物或对手追近缩短距离；两岸对峙后不能直接贴脸。相机推近不改变人物距离。
- **受击到反攻**：先说明落脚、卸力、短暂失衡和如何恢复。跪倒或关节受损的敌人再次追击时必须继承伤处与恢复方式。
- **持物与双手操作**：飞剑离手 → 飞行/接触 → 召回路径 → 哪只手接柄 → 近战；掉落则另写落点和拾回。施法需要双手时先说明原兵器在哪里；“几乎脱手后攥稳”不是已经掉地后拾回。

回程必须从该兵器上一拍的实际终点出发。若前段只有剑影攻向护壁、实体剑仍在身旁，后段不能写实体剑“从护壁外折返”；让它在身旁转柄回握即可。确实需要前探时先补实体剑的去程，不用“召回”二字掩盖中间位置变化。

材质跟着对象走：金属护腕可有擦火，布袖应有纤维撕开；无金属的手腕不能无由生出金属撞击火花。换服装、兵器或角色后检查接触点、握法、声音与损伤，不只替换名字。

## 飞剑、剑影与弱点的因果

先用一句话区分 **实体主兵器、实体副兵器、能量投影**。写清最大同时存在数量、生成/回收条件、损毁去向与合招消耗。不要自行授予更多能力；数量未定时选择并标明测试假设，正式设定则继承原值。

“仅一把实体剑，最多六道能量剑影”允许六影围攻，不允许六把实体剑随后各自被握在手中。“禁止武器增殖”如果针对实体复制，应明确范围；不能一边泛禁增殖，一边无条件令百柄新武器出现。颜色要结合形状、运动、来源、材质反馈辨识角色，不能仅以红/蓝自动分人。

有效弱点回收要有四环：

1. 某次接触在明确对象和位置留下缺口、裂纹、嵌入物或能力标记。
2. 后续运动和镜头继续保留该处，未被治疗、转形或更换。
3. 角色视线、诱导动作或对方护住该处，说明其注意到了机会。
4. 后续攻击命中同一对象同一处，结果受已有条件限制。

若原文首次召出护盾就说“攻击先前裂口”，可提前补一次实际受击，或把当前攻击改为先打裂再追击。击中一柄飞剑的裂纹不能无解释让所有飞剑同时爆炸；要先建立共同阵列/传导条件，或仅保留这一柄损毁。每次补桥接都占时间，必要时删除重复招式。

可参照 [飞剑回握与旧裂口案例](../examples/return-and-payoff-18.md)。这是文字教学例，没有真实出片证据。

## 镜头连续性与空间锚点

一镜到底先画一条能走通的机位路径，再安排景别：侧后跟随 → 沿外侧绕到接触侧面 → 后撤升高看范围。不能用“切至远景/无人机”替代路径，不能用全白、全黑、尘幕偷偷重置位置。闪光或一帧反相本身不一定等于剪辑；要看前后机位、姿态、时间是否连续，以及是否保留关键接触可见性。

只要远景和特写的需求，可理解为不在中景停留；连续推近必然经过中间景别。若用户确实要求中间景别一帧都不能出现，同时又禁止剪辑，应明确这项冲突，不能假装两者同时满足。

空间锚点固定在世界里。绕拍时同一灰岩可以在画面中移动；不能写“绕角色一圈但灰岩始终固定同一像素”。多区域战斗先排出路线，例如桥端 → 残殿入口 → 殿外风眼；给越过门洞、边缘或缺口的可见过程。旧破坏仍在原地，进入新区域不等于旧桥复原。

“双方始终可读”与“每帧两张脸都清楚”不同。双人近战优先让接触点及双方持械臂在画内；短暂表情/手部特写可声明另一方的画外位置和下一次回到双人景别的时机。若用户要求双方每帧全身可见，就取消不兼容的单人微距，不悄悄放宽约束。

## 节奏、台词和结束方式

高强度不等于全片匀速摇晃、一直爆闪、每秒完整打一套。让短促交锋、承压恢复、观察和再爆发相互区别。眼神看向旧裂口、手指重新攥紧、呼吸转重都能承载转折，慢动作不是唯一强调方法。

先区分三种时间：故事里的动作先后、成片秒数、播放速度。按主段预算检验完整动作与台词是否放得下；朗读只能提供估计，准确口型和时长需要音轨实测。长台词可与附魔、视线或准备动作并行，缩短重复展示；用户要求保留原句时不擅自删改。15秒素材不能为了加尾帧变成16秒。

逐项写例外时段：正常速度覆盖哪里、哪段允许慢放、哪里允许定格；所有例外仍占总片长。若要29–29.5秒有余势、29.5–30秒完全冻结，就先写尘土与相机减速，29.5秒后两者都停止。姿势停住但呼吸、刀光、尘土继续，是动态停驻，不是全画面冻结。

结尾由目标决定：剑停在咽喉前是压制，双方仍持械是未决，斩击起势后收黑是悬念。最后一种必须停在接触前，不能额外写受伤、爆炸命中音或胜者姿势。参照 [登场预告案例](../examples/entrance-cliffhanger-15.md)。

## 压缩成可投喂文本

总设定放身份、实体兵器与能力预算、场地锚点、镜头模式及例外。各主段只写关键攻防、表演变化、镜头和结果；结尾用少量针对本方案的限制收束。需要时使用八标签，不为了标签重复完整总设定。

把抽象标签转为可见要求：皮肤明暗有柔和过渡，磨损剑脊反射环境，接触处只闪一下火花，飞剑保留剑尖与护手轮廓，风场有旋转方向和吸入碎屑。来源中的引擎名、分辨率、焦距、快门、震幅等可保留为用户指定风格/意图；未经工具证据不能宣称它们是有效生成参数或质量保证。

用户要求Niagara式粒子或细化特效时，按[粒子行为](particle-vfx.md)把来源、路径、交互与结束压缩成关键句；不把完整内部参数菜单塞入每个主段，不以尾迹暗中增加离体攻击或改变胜负。

涉及模糊时，按[运动成像](motion-blur.md)检查“动作、相机相对运动、模糊范围与方向、可辨事件、收束”，只保留当前镜头需要的句子。镜头意图同时写入细拍与分段摘要；不擅自用慢放、定格或逐帧曝光切换解决遮挡，也不抹去用户允许的动画残影。

最后做四次对读：总设定对时间轴；相邻两拍；正向要求对负向限制；角色/武器状态对结尾。优先级为用户当前明确选择、来源中的明确局部例外、一般默认；两条同等明确且互斥的用户要求需要澄清或标出待选，不能私自删去。来源草稿的内部冲突可以给出标明理由的最小修订。

限制按语义检查：旧血迹与新增血液、刀尖局部聚光与独立飞行光球、非发光空气压力壳与能量球、动作停驻与全场冻结并不相同。不要按单字命中机械删句；同一禁令只写一次，并写明针对的对象和时段。
