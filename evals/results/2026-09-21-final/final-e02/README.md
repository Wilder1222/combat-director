| 时间 | 主要动作与结果 |
| --- | --- |
| 0–2 秒 | B 先压迫，A 用木杖斜挡并轻退；木杖出现浅擦痕。 |
| 2–4.5 秒 | A 向西北退两步，B 沿同一路线追进，实际向北靠近碎石带。 |
| 4.5–7 秒 | A 向南侧移到 B 西南方，引开探刀后站稳；B 转向面对 A。 |
| 7–10 秒 | A 朝东北进逼，B 沿东北退两小步，后脚踏入北缘碎石带。 |
| 10–12.5 秒 | A 杖前段接触 B 持刀前臂近腕衣袖；B 脚下失稳，松指落刀、左膝触地。A 停手。 |
| 12.5–15 秒 | A 经 B 南侧空隙向东南通过，两步后转身，14.4 秒前在安全距离警戒；最后 0.6 秒保留呼吸。B 与落刀停在原处。 |

木杖约 1.4 米长、直径约 3 厘米、圆钝两端、无金属包头；A 全程右手握中段略靠后，左手空手。尺寸与世界方位的细化属于本次编排假设。接触表现使用木质短响、刮擦、衣袖压褶与浅木痕；原有金属火花和剑格拨刀不再用于实际动作。

本次仅离线编辑和导出文本，未生成视频、未上传或绑定素材。平台与模型未指定，单次 15 秒及其他入口能力尚未核验；声音为设计建议。`run.json` 记录读取范围、工具和限制，`work/` 保存迁移、语义比对与导出过程文件。
