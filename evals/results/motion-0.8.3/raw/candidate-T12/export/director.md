# 六轨导演稿

时间及状态独立于六轨；表情与情绪合为表演轨。

## B01 · 0–2 秒
目的：双方紧张，B暂时掌握主动

1. 人物攻防：A：向前一步接住对方挥来的短刀，接触后脚步轻退；B：向A逼近，短刀与剑发生一次清楚交接
2. 表演情绪：A：盯住短刀和持刀手，接触后短呼气；B：眉眼压低，注意A上半身。双方紧张，B暂时掌握主动
3. 摄影机：S01 / start / 南侧固定双人全身机位；机位、朝向、焦距和画框全片不变，不平移、不推进后退、不摇摄、不变焦。开拍前取景覆盖双方从开场至通过后的全部行走范围、头脚、完整兵器运动范围、北缘碎石带与落刀点；人物移动发生在同一画框内，远处石桥与静止地面保持稳定。B01中B起刀、A迎接、首次接触和接触后轻退都在画内；快移剑尖与刀尖允许沿挥动弧线少量自然模糊，右手握持、交刃和分离后的回收可追踪；背景不随挥刀横拖。
4. 特效：仅在兵器接触处有少量真实火花
5. 环境反馈：第一次交接带起少量浮尘，双方仍在官道
6. 声音：一次兵器碰撞、衣料与脚步声。无台词与背景音乐。

## B02 · 2–4.5 秒
目的：双方紧张，B暂时掌握主动

1. 人物攻防：A：边挡边沿道路后退两步，每次接触后收剑恢复重心；B：连续跟进，第二次动作让身体更靠近道路北侧
2. 表演情绪：A：退步时加快呼吸，眼睛不离对手；B：前压时呼吸逐渐加重，追随A肩部。双方紧张，B暂时掌握主动
3. 摄影机：S01 / continuous / 延续同一南侧固定双人全身画框，机位、朝向与焦距不动；A两次后退及B跟进均在画内，石桥与静止地面稳定。兵器快移端部可有顺实际短弧轨迹的少量自然模糊；两次接触各自分开可辨，收剑、恢复重心及B持刀回收可连续追踪，不靠跟拍维持构图。
4. 特效：小火花仅出现在接触时，不拖成光线
5. 环境反馈：A后退擦痕保留，B逐步靠近北缘碎石带
6. 声音：两次分开的短碰撞与摩擦声。无台词与背景音乐。

## B03 · 4.5–7 秒
目的：A从被动紧张转向集中判断

1. 人物攻防：A：双脚站稳，略侧身接住下一次压迫，把视线从刀尖转到对方重心；B：短刀被挡住，前进一步后需要收回身体
2. 表演情绪：A：抿唇后呼气，目光从刀尖转向对方重心；B：目光短追A侧移，收回身体时呼吸加重。A从被动紧张转向集中判断
3. 摄影机：S01 / continuous / 延续同一南侧固定双人全身画框，机位、朝向与焦距不动；双脚、双方持械手和交接区同时入画，背景稳定。迎挡时快移剑尖、刀尖可有局部短弧自然模糊，接触、侧身受力和B收回身体仍可追踪；运动减缓后模糊随之收束，不单独关闭某一帧模糊。
4. 特效：没有新增效果，重点是接触与身体停顿
5. 环境反馈：衣摆迟于身体回落，既有尘土继续飘动
6. 声音：接触声之后短暂露出呼吸声。无台词与背景音乐。

## B04 · 7–10 秒
目的：A夺回空间，B由压迫转为失位戒备

1. 人物攻防：A：迈一步主动交锋，逼出对方后退的空隙，不加额外空翻；B：接住来剑并实际后退，脚步进入碎石带
2. 表演情绪：A：迈步时锁定B支撑脚与道路空隙；B：退步时快速看向脚下碎石，身体努力恢复平衡。A夺回空间，B由压迫转为失位戒备
3. 摄影机：S01 / continuous / 延续同一南侧固定双人全身画框，机位、朝向与焦距不动；A前进一步、B实际后退到北缘碎石带及双方落脚全在预留画面内，石桥与静止地面稳定。快移兵器端部沿实际挥动方向保留少量短暂自然模糊，交接、回收及B踩入碎石的因果可追踪。
4. 特效：仅短小兵器火花，身体运动保持清楚
5. 环境反馈：B脚步进入碎石带，碎石因落脚滚动
6. 声音：短碰撞、脚步与碎石移动声。无台词与背景音乐。

## B05 · 10–12.5 秒
目的：A夺回空间，B由压迫转为失位戒备

1. 人物攻防：A：完成最后一次清楚交接，看见对方失位便停止继续攻击；B：脚下不稳退到边缘，持刀手在交接中被剑格带偏，失衡时手指松开，短刀脱手落在身侧，身体一膝触地
2. 表演情绪：A：目光从落刀回到B，呼气后停手警戒；B：短暂惊讶，眼睛追向落刀，手掌准备支撑。A夺回空间，B由压迫转为失位戒备

目的：目标完成后的克制停手

1. 人物攻防：A：从B空出的道路一侧通过，两步后转身，14.4秒前站到安全距离，剑尖略放低；B：留在道路边缘抬头看A，没有立即捡刀发动新回合
