# 审片与最小修复

区分文本预检、结构校验、实际视频验收。只有读取过的画面和实听音轨能形成媒体证据。未生成视频时给待填验收项，不声称已验证观感或成功率。

| 优先检查 | 证据 | 最小修复 |
| --- | --- | --- |
| 身份与持物 | 换脸、换手、兵器复制、终端消失 | 固定绑定、持物手和可见交接 |
| 空间与支撑 | 瞬移、越轴、漂浮、穿过场景 | 补路径、重心、机位过渡 |
| 攻防因果 | 对手不回应、未接触先飞出 | 拆开准备、接触、反应和恢复 |
| 双方表演 | 眼神失焦、无呼吸、敌方无状态 | 写清双方视线目标、张力和节奏 |
| 能力与代价 | 无条件开大、变形换人、无限复制 | 恢复触发、限制、结束与资源消耗 |
| 环境继承 | 落刀消失、印记重置、货架复位 | 继承上一拍状态 |
| 可读性 | 特效遮脸遮动作、镜头过密 | 减特效、放宽景别、合并主段 |
| 节奏与声音 | 动作塞满、结尾截断、音画错位 | 降低负载、保留余量、匹配事件 |
| 持续压力 | 防守后双方无故站定等候 | 让回收接反击，或交代受阻/蓄力；保留有目的的演武停顿 |
| 场地与战术 | 裂沟/断柱只作装饰，后续仍跑原路 | 回写可走路线、落点、遮挡和环境终态 |
| 运镜与尺度 | 近景巨剑失去参照、唯一接触在画外 | 按事件选景别，保留人物与建筑参照，验证连续机位路线 |
| 光线与空气 | 法术结束后仍发光、尘雾突然消失 | 稳定主光，继承局部照明和尘雾变化 |

报告：时间码或文本位置 → 证据 → 影响 → 修订 → 保持不变项 → 复测条件。优先改造成失败的最小部分，保留可比较的输入。结构检查不能做物理模拟，也不能证明主段摘要与细拍语义一致。

代码检查运行 [combat_tool.py](../scripts/combat_tool.py)；输出格式见 [契约](contract.md)。

## 修复示例：装置反制没有成立

[反制失败后修订](../examples/failed-counter-repair-18.plan.json) 是合成教学情境：货架导轨卡住，不能下一拍偷偷落地。修订使用已交代的隔离闸；屏障代价导致右手松杖，后续按钮改由左手操作。保留身份、机甲追踪、场景装置和有限撤离结尾。

复测三点：货架一直卡住；右手失握后不再握杖或按按钮；左手触钮在前、门体下降在后。没有真实视频记录，不能报告重拍成功。

局部修复先锁定事件与状态依赖。若终态改变，后续主段和总设定结尾也可能需要复核；“只修一段”不能忽略真实下游影响。

## 文字方案的专项预检

| 对读位置 | 常见问题 | 最小修订方向 |
| --- | --- | --- |
| 镜头总则 / 局部运镜 | 一镜到底却“切成无人机远景” | 改为有空间路径和时间的后撤升高，或由用户选择切镜模式 |
| 速度总则 / 重点段落 | 全片禁冻结却多处凝滞和终帧定格 | 写明保留的例外与起止；真正冻结时停止相机和粒子 |
| 武器前后状态 | 御剑在外却突然手持斩击；双手施法时原刀无处可去 | 补回程、回握与腾手，删减重复攻击给桥接留时 |
| 早期接触 / 后期反制 | 后来声称“旧裂口”但从未造成，或左右/肩袖位置不符 | 早段补同一处成因，或将后段改为首次形成弱点 |
| 正向能力 / 负向限制 | 禁止复制又无限生剑；绝对禁光球却写独立光球攻击 | 区分实体与投影、局部聚光与独立弹体，明确预算或删冲突能力 |
| 镜头 / 可见范围 | 每帧双方全身清楚却安排单人嘴部特写 | 保留严格可见性时改双人景别；允许暂出画时声明范围 |
| 片段目的 / 结尾 | 首斩前收黑却出现命中声、受伤或胜者姿势 | 截止于接触前，把未知结果留在画外时间之后 |
| 名招 / 身体路径 | 只有功法名就自动挡住攻击，或传统技法自动放出巨型法相 | 拆出可见动作，另核对幻想能力授权、资源与结束 |
| 破防 / 下一回应 | 兵器被压到身侧后立刻完整格挡 | 先避让、落脚、回收；没有恢复条件就继续承压 |
| 多人 / 空间任务 | 主角交手时其余人停住、画外瞬移、没有原因不能出手 | 逐人补路线、任务和受阻原因，减少同时接触点 |
| 机制候选 / 计划能力 | 搜索命中就默认拥有法器、预算或已激活能力 | 对读前提与现有设定；不适用就舍弃或明确改编 |
| 强度 / 摄影机 | 高燃自动变成定格、密集切镜和每拳气爆 | 分别选择密度、速度、镜头与特效，让接触与结果可读 |
| 粒子 / 触发与参照 | 挥空爆出命中火花，旧尾迹粘着兵器反转 | 绑定实际接触事件，分开新尾迹与旧尾迹的路径 |
| 粒子 / 材质与结束 | 木杖打出金属火星，停发时擦痕也复原 | 继承材质；区分停止新增、存量消散和环境留存 |
| 模糊 / 相对运动 | 固定背景因挥剑而全幅横拖，跟拍后所有肢体都像素锁定 | 分开相机、主体、兵器与背景的画面运动 |
| 可辨 / 时间风格 | 为看清接触偷偷慢放、定格或临时关闭一帧模糊 | 在原速度与镜头约束内调整构图和叠加效果；保留明确艺术选择 |
| 成像 / 粒子结束 | 自然拖糊像粒子一样在空中漂散，或把残影计为实体分身 | 分开曝光、效果寿命和艺术画法，保持实体与能力边界 |

这些是人工/模型文本复核项，当前 CLI 不自动判定它们。负向词不能按字面机械匹配，例如空气压力壳不必等于发光能量球。保留用户明确的形式选择和局部例外；细则见 [prompt-craft.md](prompt-craft.md)。

## 短镜爆剪专项验收

启用该模式时按[爆剪与相对关系](rapid-cut-continuity.md)逐镜对读；以下是文字或实际视频验收，不是CLI自动空间校验。

| 检查 | 失败信号 | 修订 |
| --- | --- | --- |
| 轴线与换边 | B左向右攻后无过渡变右向左；高位旋转180度 | 恢复同侧机位；实际换边先用双人/高位复位镜展示交错路径和新落点 |
| 三镜因果 | 只有眼神和震屏；同一击重复命中；挥空却有身体凹陷 | 对齐攻击ID的来路→命中点/避让点→反馈，Hit Stop只落在真实接触 |
| 冲量与滑退 | 向右受击却初始向左飞；未落地已有拖痕 | 沿冲量退移；改变方向先展示制动或主动反扑；接地后才有擦痕 |
| 复位间隔 | 超过5秒没有双方站位；高位只见风景 | 每3—5秒用有双方、地标与间距的镜头重建空间，必要时提前 |
| 遮挡与接续 | 袖子过镜后换手、反向、跳位，命中被完全遮掉 | 遮挡仅藏切点，保持主运动方向、速度量级与动作相位 |
| 力感触发 | 石板预裂、隔空凹衣、云层抢先翻滚、呼吸与接触脱节 | 从实际发力/接触处向身体与环境传递；裂纹和推云遵守能力预算 |
| 镜长与变速 | 44镜总长不符；所有0.9秒镜都慢放；每击子弹时间 | 快镜0.2—0.4秒、慢镜0.6—1.2秒；只保留开场与终局两处微慢镜，Hit Stop在镜内计时 |
| 模式替换与压缩 | 总则仍写一镜到底或禁切；主段丢失方向与复位时点 | 同步总则、局部运镜、负向限制和投喂正文，保留镜号范围与三镜顺序 |
| 节奏曲线 | 每击都蓄势—打击—停住；前中后同一强度；终局只扩大光效 | 前段提密、中段成簇、终局逐层兑现；反馈接下一击，保留必要恢复并区分轻重 |
| 硬切相位 | 切得早而漏接触，切回重播同一击，镜头更短但结果丢失 | 来路接触前切入命中点，短停释放后切反馈，受力结果可读后再接下一击 |
| 复位清晰度 | 虽按时切全景，却看不清谁在哪、地标被遮、下一击无方向 | 分开双方轮廓、露出支撑与地标，写清间距和下一击路线；复位中保留移动/压力 |
| 预算摘要 | 逐镜表正确但镜长数量/乘法错误，或把选择后的上限当数学极限 | 从最终表统计并复算；明确硬约束下界与额外创作条件，候选版不能冒充原规格完成 |
| 正文独立可用 | 可复制块写“按上表执行”，实际只复制摘要便丢失必要规则 | 将正文单独审阅；必要表格纳入同一复制块，保持场景、方向、动作和时间自含 |
| 跨层时点与锚点 | 六轨将接触镜入点当入慢点，身体中心终点被改叫门线 | 微慢绝对起止共用一份记录；坐标先定义参照点，门柱等固定锚点不漂移 |
| 破绽持续条件 | 跨过数镜移动仍“尚未收刀”，借普通恢复拖延对手 | 按累计时间检查恢复条件；有持续压制才留旧破绽，否则恢复后由新动作制造空隙 |
| 遮挡范围 | 全下半幅被遮却仍声称双脚始终清楚 | 明确局部遮挡与受保护区域，或从遮挡退出后才计有效读位窗口 |
| 接触位置与距离 | 用剑尖可达距离证明剑根可接，或局部间距与总则不符 | 拍清双手/兵器段的接点关系与真实接近，距离总则由逐镜状态归纳 |
| 一击多次接触 | 接触前切镜，下镜已沿刃滑离，首次格挡被省掉 | 依次展示首次接刃、偏转脱离、触地，指定主Hit Stop点；过载则简化动作 |
| 障碍作用范围 | 已在身后的柱子被描述成封住前方所有绕行 | 用当前站位和下一路线核对障碍范围；地形限制失效就更新，以真实威胁说明仍不能绕行的原因 |

特效故障的具体对读方法见[粒子行为](particle-vfx.md)。没有实际视频时，粒子数量、碰撞、时间精度与观感均不能由结构检查代为验收。

模糊与非预期重影按[运动成像](motion-blur.md)定位，分别观察正常播放时的攻防可辨性、前后帧持物连续性和用户风格。全片静止不能靠高锐度通过；单帧截图不能证明接触过程。先检查原图、原片和后期处理链，不凭外观断言TSR或插帧算法。
