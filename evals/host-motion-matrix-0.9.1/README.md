# Motion宿主请求矩阵

2026-09-29。补充深化计划R1建议的四类请求各长、短版本，共八次独立调用。此矩阵每格只运行一次，不替代原完善计划建议的多配置重复比较。

[请求权威](cases.json)在调用前写定；四类为显式motion blur、隐含高速交刃、拖影故障诊断、静态对峙。正常长度为200—360字符，短输出不超过160字符；计数包括标点，去除答复首尾空白。创作题只要提示词，诊断题允许简要分析；不把所有题都强制成同一种输出格式。

沿用此前实际宿主验证可用的条件：应用已有CLI、继承宿主模型配置、独立临时项目内冻结0.9.1技能、只读unelevated沙箱，单次调用关闭插件发现以隔离已安装旧版。其他宿主技能仍可用。不升级日常插件，不调用媒体服务。编码失败、错误和原始事件均保留，不以退出码为0推断读取成功。

每题通过`run.py`调用共用宿主执行器，保存完整请求、命令、事件、答复、退出码及哈希。`summarize.py`须等所有题终止后运行；它比较全部186个技能文件、原始产物哈希和可读参考全文。全文未匹配不必然等于未读取，可能仅有局部读取或编码损坏，需检查事件。长度统计和文件匹配不代替语义判断。

独立复核只接收原请求和完整最终答复，不接收父任务结论；按实际请求评价约束、因果、证据边界和输出范围，引用具体句子。父任务另核对读取路径与版本。真实媒体未提供，诊断结果只能是候选原因与核验建议。

旧三题及全部失败尝试保留在`evals/results/host-0.9.1/`，本矩阵另存`evals/results/host-motion-matrix-0.9.1/`。不得将本次结果合并成跨宿主成功率或视频效果结论。
