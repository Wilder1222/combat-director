# 审片与最小修复

区分文本预检、结构校验、实际视频验收。只有读取过的画面和实听音轨能形成媒体证据。未生成视频时给待填验收项，不声称已验证观感或成功率。

| 优先检查 | 证据 | 最小修复 |
| --- | --- | --- |
| 身份与持物 | 换脸、换手、兵器复制、终端消失 | 固定绑定、持物手和可见交接 |
| 空间与支撑 | 瞬移、越轴、漂浮、穿过场景 | 补路径、重心、机位过渡 |
| 攻防因果 | 对手不回应、未接触先飞出 | 拆开准备、接触、反应和恢复 |
| 双方表演 | 眼神失焦、无呼吸、敌方无状态 | 写清双方视线目标、张力和节奏 |
| 能力与代价 | 无条件开大、变形换人、无限复制 | 恢复触发、限制、结束与资源消耗 |
| 环境继承 | 落刀消失、印记重置、货架复位 | 继承上一拍状态 |
| 可读性 | 特效遮脸遮动作、镜头过密 | 减特效、放宽景别、合并主段 |
| 节奏与声音 | 动作塞满、结尾截断、音画错位 | 降低负载、保留余量、匹配事件 |

报告：时间码或文本位置 → 证据 → 影响 → 修订 → 保持不变项 → 复测条件。优先改造成失败的最小部分，保留可比较的输入。结构检查不能做物理模拟，也不能证明主段摘要与细拍语义一致。

代码检查运行 [combat_tool.py](../scripts/combat_tool.py)；输出格式见 [契约](contract.md)。
