# 分身与多人协同

需要分身、幻象、同貌身体、围攻或同步多接点时读取。接点与可用肢体见[战斗编排](choreography.md)，攻击发出后状态见[移动与在途攻击](movement-and-projectiles.md#发出后的维持与终止)。多个角色共用事件与状态，不另起分身流程。

## 分身、幻影与残影

按本次能力确定能做什么，再选称谓；半透明、同脸、同衣只是外观，不证明碰撞、持物或共享伤害。

| 用途 | 状态关系 |
| --- | --- |
| 运动残影 | 留在刚经过位置后淡去，默认不独立选目标、挡击或增加实体攻击 |
| 诱导幻象 | 出现处和误导明确；若不能碰撞，攻击穿过后继续有去处 |
| 可交互分身/召影 | 各有位置、动作、目标；持物、受击、持续与回传按本次术法 |

已设残影可攻、幻影阶段性凝实则保留起效条件，不把称谓当全作品统一能力表。出生前后总身体数、本体是否保留、退场对象明确：本体另放两分身且本体保留共三具，一分为二通常共两具，含糊时明确本次计数。身份资产条目和参考视角数都不是身体数，只在出生、退场、跨段等关键处更新，不逐句报数。

同脸同衣用本体、生成来源和稳定职责绑定，不擅改服装或发色。由北阵印生出的分身向南移动后仍是同一具，不按屏幕位置改名。建立时分清身体边界和空间，随后允许正常接触、遮挡；出画或遮住不等于融合、退场或丢失，也不要求所有肢体永远同框。

每具分身承担牵制、开路、持物、掩护等具体任务，可轮换，不都复制本体挥剑。兵器分别是原实体、术法投射或空手，复制外貌不自动复制原剑。影响结果时建立伤害是否回传、真实物品在退场后落地还是回收。回收先解除仍有效接触；推门分身消散后真实门保留终态，不能连同木门一起删除。

指定彻底消散时同时检查粒子出现和原身体是否还留着或再现，碎光覆盖不算退场完成。允许残骸、空甲、兵器遗留时保留，不为了清画面抹去指定物。该规则也适用于非分身角色消散。

## 多人持续施压

先选主攻防线，再给当前参与者目标、路线、职责与抵达条件，侧翼和支援可同时进行。画外角色仍有位置与任务，不排队待打；清晰度不足先调整允许的覆盖和旁支，用户指定围攻不能改成逐个单挑。

具名者是否计入群体要明确：四护卫含队长共四人，队长另带四护卫共五人。倒地、出画、进入背景不自动减人数；只更新影响交换、退场和接续的状态。

同时施压可以是近攻与侧翼逼位、远程截路与追击并发，不等于所有人同帧命中。未命中的对手仍迫近、调整射线、回收或维持封锁；主角借遮挡/逼位脱围时，对手有回应，空隙由动作产生，不靠他人消失。

## 同步接点与友军通路

明确要求同一时刻多处接触时，逐接点指定由哪件兵器、肢体或术法承接，并检查覆盖范围。双掌各维持一盾可承两路，与一柄短剑同时挡相隔很远两处不是同一条件；不能只写“同时格挡”跳过可用防守部位，也不能为聚焦把其中一击错后。

检查攻击线路、挥动范围和退路互占。发出前同伴挡射线可改角度/暂缓；发出后由同伴避让、有效拦截或已设转向/解除处理，停新发射不让在途攻击消失。穿透和友军识别另有依据，不能默许。

例：符修封退路、枪客正面刺入，剑修拨枪使枪尖扎入封路符支点，断纹后从缺口撤出；枪客拔枪的空隙迫使符修补位。主事件包含两路威胁与一次利用，侧线不被镜头焦点删掉。
