# 视频参考：从可见事件提取方法

用于研究现成战斗片段。目标是提取能迁移的动作与摄影方法；具体作品片源、截图和时间码留在研究记录，不把全部图片打进运行技能。

## 先定证据范围

记录作品、页面URL、上传者、实际观察版本及时间范围。正片、预告、官方精选、第三方混剪分开；无法确认是否重排或变速时，不把剪辑版的镜长当正片镜长。流媒体未取得原文件时写明无原片哈希，可对观察截图与时间记录留哈希。热门程度需另有当前证据，不由一个频道的标题推出排名。

播放器标题写4K不证明实际解码4K。时间跳转后须等目标画面完成解码，再配对时间码与截图；加载圈、前一帧滞留、进度条先走而画面未更新的记录排除。步进按键增加的时间不证明源素材真实帧率或没有插帧。截图缺音轨就不写实听反馈。

播放器报告已就绪也须检查实际图像；块状失真、局部撕裂等异常若在复查后仍存在，保留原记录并标为来源/播放链路未定位的异常，不当成原作剪辑技法。纯黑底上手势与器物连续变化则另作观察，不能仅凭背景黑色判为加载失败；仍需前后帧确认。

## 按完整交换观察，不只挑爆光帧

先找一段包含“威胁出现—回应—结果—下一状态”的交换，再按问题加密。逐项区分可见、推断、未知：

| 维度 | 观察内容 | 不可直接推断 |
| --- | --- | --- |
| 招式与战术 | 谁迫使谁改路线，手/武器/法术的起点、目标、回应和代价 | 招式正统名称、未见的能力机制、字幕所称技能已执行成功 |
| 动作连贯 | 同一主体的姿态、持械、支撑或飞行朝向怎样接续；防守后是否有恢复条件 | 两个姿势之间必有合理路径；避让即受击；有光即命中 |
| 特效 | 附体、飞行主形、尾迹、接触扰动和环境残留分别是什么，何时交接注意力 | 所有亮线都有碰撞能力；画面圆环必为护盾或传送门 |
| 机位 | 景别、俯仰、主体遮叠、固定地标与前中后景 | 仅凭透视猜精确镜头焦距或相机高度 |
| 运镜 | 共同背景如何移动，主体尺寸/视差如何变化，谁驱动视觉速度 | 主体变大就一定推镜；对象掠镜就一定切镜 |
| 切镜与节奏 | 确认的边界、运动相位与视线/地标的交接；长镜内部是否仍有爆点 | 稀疏抽帧数等于镜数；画面模糊等于转场；播放器停帧等于Hit Stop |
| 力感与声音 | 接触前后形变、位移、制动、环境结果；实际听到时再记声音起止 | 闪光本身证明冲量方向，或未听音轨却推定低频/断音设计 |

切点不确定时记录候选区间，再观察区间内相邻画面与固定参照。没有确认硬切就写“构图变化/可能连续运镜”；没有覆盖整段就不报全段镜数、平均镜长或越轴结论。

## 提炼时保留条件

一条方法写成“观察依据 → 作用解释 → 可替换变量 → 使用条件 → 待验证项”。跨作品复现后再提高置信度；单例只能支持候选方法。保留失败或反例，不用新增规则掩盖素材本身没交代的因果。

例如：一个前景飞行物迅速放大并掠过画面，后景台座仍可追踪。可尝试以近景高速运动制造冲击、以固定后景保住空间；须检查主角、接触与下一路线是否仍可辨。它不证明整段无剪辑，也不要求新项目改成一镜到底。用户指定多机位爆剪时，可将该方法放在一个既有短镜内部；若另有明确镜数或三镜链约定，也不能借参考擅改。

新编排应改换人物、场地与动作目的，只借已分析的构图/运动关系；不把原角色的招式名称、身份、能力或脸自动迁移。先用新案例做文本与可见性检查，实际视频另验。
