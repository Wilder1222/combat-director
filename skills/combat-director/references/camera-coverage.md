# 镜头服务于战斗事件

动作与场地先锁定，镜头负责选择可见范围、视角与节奏，不在镜头稿中新增攻击或改变胜负。对接其他导演技能时继承其已确认镜头约束；冲突回到对应动作或场景设定修订。

用户指定短镜爆剪、约44镜或以多机位替换一镜到底时，采用[爆剪与相对关系](rapid-cut-continuity.md)：B左向右攻、A右应对，同侧机位；每击来路/命中点/反馈三镜，每3—5秒空间复位，换边先拍路径。眼神、刀线、Hit Stop、遮挡转场、低位对冲与高位复位均服从这组方向约束。

## 按事件选镜头

| 要看清的事 | 取景与机位依据 |
| --- | --- |
| 持械接触与卸力 | 双人侧前三分之四、中全景等能分开双臂和刃口的视角；长袖不得遮住唯一因果点 |
| 追击、后退与跨区 | 保留落脚与路线，侧移或跟随后退交代实际位移与障碍 |
| 巨大攻击或场地毁坏 | 拉开景别，同时保留人物和建筑参照，展示攻击经过与结果 |
| 发现破绽、决定反击 | 表情镜头只有在节奏允许且信息必要时使用，不能让仍在攻击的对手凭空等待 |

每镜记录“事件目的、景别/侧位、主运动、起终点、保持可见的东西、切点或连续连接”。一个镜头先选一种主运动；复合运动有空间理由时可用，不机械禁止。删掉同时环绕、俯冲、推近、变焦的口号串。

多件离体武器或大范围法术已获设定支持时，可先用较高机位交代来路/落区布局，再以同一事件的低位视角显示临近尺度，最后拍局部交互与范围结果；每次变角承担不同信息，运动趋势与地标接得上。剑群空镜、单人表情或分屏并列面孔不能自动计为双人空间复位；复位须在同一物理空间内读清双方与下一路线。

需要突出招式机制、且形式允许时，可暂时弱化背景，让手势触发、器物成形/启用、出招路径依次成为注意中心。黑底或抽象背景属于展示手段，不证明人物进入另一空间、对手停止行动或时间冻结；回到实景须继承持物、姿态和正在发生的威胁。严格固定轴线、频繁复位的爆剪可改用保留地标的局部近景；单人俯拍即使重新看见地面，也不自动完成双人空间复位。

持续抵压或接触后才释放的招式，可先用双人镜确认接触关系，再以局部镜辨认手、器物和受力材质，释放后拍离开接点、接地制动与新的双方距离。局部镜是在解释同一次接触，不自动增加攻击次数；先分清首次触碰、持续施力和分离，别把持续抵住写成重复撞上。拳停在脸前只显示危险间隙，不能替代接触证据。迁移到三镜爆剪时，将必要接点细节放入同一命中镜，反馈镜承接释放；装不下就简化持续施力，不照搬参考中数秒的停留或偷偷增加微慢次数。

## 路径与覆盖

一镜到底从接触近景到巨型远景，需要相机沿可行路线后撤升高并留出时间；不能瞬切无人机视角或靠白闪重置。空间和时长不足时删减事件，或提出镜头模式冲突，不能擅改用户约束。多镜头可在运动接续、反击起势或尺度升级处切，继承方向、持物和环境。

逐段复核：攻击来源 → 接近/轨迹 → 防守回应 → 接触或避让 → 可见结果 → 下一步压力。一般模式这是覆盖检查，不要求六次切镜；爆剪模式按专项三镜链覆盖。镜头可省略不重要的准备，但不能把唯一接触和结果都藏到画外后宣称已展示攻防。

将动作密度、速度、镜头数、尺度与特效强度分开调整。15 秒可以紧凑，也可以保留蓄力；停顿应改变威胁、观察或资源。明确要求演武、慢动作、定格时保留其目的，不把所有静止自动判为错误。

## 修复归属

短镜选机位前先回答“此镜新增哪项信息”：眼神交代决断，刃线交代来路，接触近景交代材质与作用点，低位交代真实相向推进，高位交代双方新间距、地标与下一路线。反应特写不替代空间复位。特效先给唯一首触及双方轮廓让出窗口，再用外围扩散放大尺度；爆剪的读位计时与切点相位统一按[专项](rapid-cut-continuity.md)复核。

- 路线不通、支点被毁：先改场景/动作，随后重排机位。
- 双方有动作但互不影响：补回应、接触与身体结果，不能只加摇镜或震屏。
- 实际交手被袖子/尘雾遮住：先调整取景和效果遮挡，仍不可读再简化接触动作。
- 巨剑看不出大小：补人物与场地参照和更宽覆盖，不先堆更多特效。
- 新镜头改变了攻击方向或人物位置：回写动作并复核，禁止只在镜头层悄悄发明。
