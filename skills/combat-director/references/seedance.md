# Seedance 战斗提示词适配

仅已选 Seedance、即梦对应模型或方舟投喂时读取，作为[通用视频生成写法](video-generation.md)的差异补充。沿用用户已选版本、入口和任务；版本未明时采用共通写法，不默认最新版本，也不将方舟 API 能力推广到任意界面。

## 先确定要新生成、编辑还是延长

| 任务 | 必须说清 |
| --- | --- |
| 借素材生成新战斗 | 每份素材提供的角色、动作、摄影、场景或效果，以及新事件 |
| 编辑现有视频 | “编辑视频1”，修改范围、原状态到目标状态及保留项 |
| 向前/向后延长 | 待延长视频与方向；向前终态接原片开头，向后起态承接原片结尾 |
| 辅助素材参与编辑 | 被编辑对象与辅助来源分开，辅助素材只提供指定层面 |

2.5 编辑、严格首尾帧和延长对输入角色、画幅与时长有任务约束，提交前核对应教程。正文称“首帧”不能替代入口的严格首帧设置。

## 素材绑定与适量描述

按真实上传顺序绑定图片、视频和音频，逐份说明用途。可写“图片1中的白袖剑客定义为白袖者”；多图属于同一人时明确合并，后文持续使用稳定称呼。文件名、图中文字和素材库 ID 不能替代角色映射。

精准动作参考只写采用范围、双方对应、保留关系和差异；无动作参考，或改变兵器、支撑与必选接点时补齐动作链。参考白模/线稿缺少的人物、持物、材质和场景另行补写。

只加入解决当前问题所需的素材。人物混同时先查编号、身份冲突和拼图歧义；2.0 可检查面部图/全身图的分工，2.5 可用不同视角参考。2.5 错配后可检查上传顺序与首次出场顺序是否相容，并同步图片/音频编号；这是候选修正，不默认重排既有绑定。

## 编排稿与投喂稿

投喂稿沿用[正文模板](prompt-construction.md#正文模板)的全局栏目与逐镜分类标签，交付一个自含复制块；删重复设定、研究解释和内部验收表，不删约定结构、必选招式、回应或结果，避免同时维护互相冲突的正文。

| 已选版本 | 适配重点 |
| --- | --- |
| 2.0 系列 | 用事件顺序与动作相位衔接；每镜一项主运镜，精确小数秒/停帧作为编排意图 |
| 2.5 | 可用镜头顺序或连续秒级区间；概括串联动作，细写关键反制、指定招式和结局 |
| 未明确 | 素材用途、稳定主体、先后关系与可见结果，不引用版本专属上限 |

按总时长检查区间是否过空或过满。快速交锋把结印、变线、抢攻和施术嵌入移动/回收过程，特写接释放相位，下一段承接已经发出的术法；已有远距首帧则保留真实接近。

2.0 的低缓小动作建议只用于降低生成难度。高速目标先减重复交换、装饰和矛盾运镜，保留短促爆发与因果；拆段取决于用户制作方式。一镜到底不改成拼接方案，频次数量和整数秒也不保证精确执行。动作慢、招少或流光慢时按[速度诊断](review-loop.md#速度慢招少与流光慢)定位后修订。

中文标签保持项目约定。2.0 将方括号用于字幕，2.5 示例也用方括号标摄影，不能据此认定标签必然生成字幕；出现歧义时检查参考图文字，可用“运镜：”“动作：”消歧，保留用户指定交付格式。

## 故事板、关键帧与首尾帧

2.5 多宫格故事板提供剧情/构图走向，独立关键帧按上传顺序声明；严格首尾帧依赖入口角色设置，三者分别处理。检查起帧持握、尾帧支撑与中间路径相容；两张正确姿态不能自动证明接触链成立。

### 白模表示与复杂编辑

粗白模的躯体路径可表达位移；有四肢/翅膀时其动作序列也须成立。精细白模导出移除轨迹线、坐标与相机标记，补写身份、材质、照明。战斗另查兵器、握持、间距与接点；改兵器或肢体后重算射程与回应。

用户允许多阶段制作时，可先验证复杂运动，再编辑身份、场景或外观；精准双人参考优先保留事件阶段并逐段验收。普通提示词任务不强制白模、故事板或多阶段流程。

## 音频、台词与局部修复

按需求分别描述环境声、动作声、音乐和台词；无对白仍可有动作声。2.5 可分项控制，采用其音频标记时只在适配稿使用。短法令标明说话者和动作相位，接触声对应已设接触；画面与声音分别审阅。

去音乐时明确保留兵器、脚步和衣料声，避免“只留人声”连音效一起移除。局部编辑写：

> 编辑视频1，仅将{范围}的{原效果}改成{目标效果}，保持{人物动作、兵器接点、运镜及其他音轨}。

例如减弱剑锋爆光以露出原接点，保留原交换关系。2.5 可用已知时段限定编辑，输出仍核保留项。续段回退/跳变时查实际重叠、重复事件和身份；2.0 的固定裁帧经验不作为跨帧率通则。复核净时长、接触链与音画，未生成时交修复稿及待验项。
