# Seedance 战斗提示词适配

本页是[通用视频生成写法](video-generation.md)的条件补充。只处理已选Seedance入口的差异，不作为其他模型的默认模板；未指定模型时停留在通用方法。

用户指定 Seedance、即梦对应模型或方舟投喂时读取；一般战斗编排不必加载。本页依据2026-10-04核对的官方2.0、2.5指南独立转写。先采用用户已选版本、入口和任务；未给版本时使用共通写法，不默认为最新版本，不将方舟API能力当作任意界面都有。

## 先确定要新生成、编辑还是延长

| 任务 | 写法与保留项 |
| --- | --- |
| 借素材生成新战斗 | 说明参考哪个素材的角色、动作、摄影或效果，再交代新场景与事件；不同用途分别绑定 |
| 修改现有成片 | 明确“编辑视频1”，写修改对象、范围、原状态到目标状态，点明要保留的动作、机位和声音；不要仅写“参考视频1”让任务变成新生成 |
| 续接现有成片 | 明确向前或向后延长视频1，从已观察的衔接状态写新内容；向前延长的终态应接回原片开头，向后延长的起态继承原片结尾 |
| 用另一素材辅助编辑 | 先标待编辑视频，再说明辅助素材只提供什么，例如图片的衣装或视频的粒子形态；不混淆被修改对象和参考对象 |

2.5的编辑、严格首尾帧和延长会约束部分输出属性；参考生视频与上述任务不同。需要实际提交时核对当前教程的输入角色、画幅与时长设置；不要仅靠一句“首帧”就宣称已启用严格首帧接口。只写提示词时不自动生成API请求或启动生成。

## 素材绑定与适量描述

依据实际上传顺序绑定图片、视频、音频。用“图片1中的白袖短发剑客定义为白袖者”建立稳定称呼，后续持续使用；多图属于同一个人时明确合并为同一角色。图片中的姓名字样、文件名或素材库ID不能替代正文绑定。角色只借外观，动作、摄影、场景、音色各自说明来源；只取局部时标出范围和用途。

只用足以解决本场问题的素材，不为凑配置增加参考。2.0多人混同诊断可优先检查单人面部图与全身图的分工；2.5允许不同视角参考，不把2.0对人物多视图的谨慎建议写成永久禁令。先排查编号、身份冲突和拼图歧义，不把新增参考数量当作一致性保证。

精确且已观察的动作参考，可以用映射、采用范围、保留项和必要差异表达，不再逐帧复述同一动作。无动作参考、改变兵器/支撑或有必选接点时，仍补齐当前战斗的来路、回应和结果。白模、线稿等缺失视觉信息的素材也需要补写实际人物和场景；不能把“减少复述”理解成所有任务只写“激烈打斗”。

**本项目原创示例（假定三份素材已按描述绑定）：**

```text
素材对应：图片1为白袖剑客，图片2为深衣剑客。视频1开场近侧表演者对应白袖者，远侧表演者对应深衣者，换位后对应关系保持。采用视频1已选片段的双剑攻防顺序与横移摄影，两人均保留右手原剑。场景改为宽阔石院，地面保持平整，动作路径不增加障碍。画面为三维国风动画，保持两人外观差异。只生成兵器接触声、衣料声与脚步声，不加入对白、背景音乐或字幕。
```

此例依赖实际参考，不是无素材时可直接复用的独立动作脚本，也不保证参考动作全部兑现。

## 编排稿与投喂稿

详细编排仍沿用公共模块、逐镜按需中文标签和时间预算。用户只要模型投喂稿时，交付一个自含复制块，删除研究解释、重复设定与内部验收表；不能为压缩删掉必选招式或改变结果。不要同时交付两份互相冲突的正文。

| 版本 | 时间与动作表达 |
| --- | --- |
| 2.0系列 | 总时长遵守用户要求；各镜优先按事件顺序和动作相位衔接，精确小数秒/停帧只作编排意图。每镜选择一项主运镜，避免同时堆推拉摇移 |
| 2.5 | 可用镜头顺序或连续的秒级时间段；区间过空易被补剧情、过满易漏动作，不以“一秒三击”等频次数量保证精确执行。串联动作可以概括，关键反制、指定招式和结局写细 |
| 未指定版本 | 采用明确主体、素材用途、事件顺序与可观察结果，不承诺精确时间控制，不引用某版本专属上限 |

2.0指南的低缓小动作建议用于降低生成难度，不覆盖用户的快速战斗目标。先减少重复交换、装饰和矛盾运镜，保留爆发速度及因果；分段生成仅在制作方式允许时采用。一镜到底不能因官方推荐武戏拼接而被改成剪辑方案。

2.0指南将方括号列为字幕表达，2.5示例也用方括号标摄影；因此不能断言所有中文标签都会生成字幕。保持项目既有中文标签约定；无字幕投喂出现歧义时，可用“运镜：”“动作：”等中文冒号段落消歧，先检查参考图中的文字，不能擅自更改用户要求的交付格式。格式转换属于适配选择，不是已实测修复。

## 故事板、关键帧与首尾帧

2.5中，多宫格故事板主要给剧情与构图走向，不能承诺逐格严格对齐；独立关键帧按实际上传顺序声明。严格首尾帧任务依赖入口的首帧/尾帧角色设置，普通参考图被文字称作首帧不等于同一模式。

战斗接触不靠两张图自动补成：起帧持握、尾帧支撑和中间路径必须相容。线稿或白模缺少的武器形制、身份、握持、光影另行描述，并与已有运动一致。用户要求准确动作时优先核对真实可用的控制素材，不强制制作故事板或安装外部skill。

## 音频、台词与局部修复

无对白不等于静音。按用户需要分别描述环境声、动作声、音乐和台词；2.5明确支持分项控制。短法令标明说话者与动作相位，在已设接触发生时才配接触声；声音不能证明画面已经命中。只有实听才能判定同步，不能凭提示词认定声画成功。

**局部编辑句式：**“编辑视频1，仅将{已定位范围}的{原效果}改成{目标效果}，保持{人物动作、兵器接点、运镜及其他音轨}。”例如减弱已存在的剑锋爆光时，目标是露出原接点，不能新增受击或重排交换。2.5可按已知时段限定编辑；输出仍需核对保留项是否真的未变。

续段出现回退、跳变或画质下降时，检查原片与新片实际重叠、重复事件及身份细节。官方2.0的固定裁帧建议属于特定修复经验，不作为所有帧率、版本或片段的通用删帧规则。处理完重新核对净时长与接触链；未经新媒体验证只交付修复稿和待验项。
