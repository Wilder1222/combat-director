# 战斗设计：攻防、空间与摄影

用于复杂交锋、跨区调度或专项摄影设计。按问题选读：[交锋与覆盖](#交锋与覆盖)、[空间与场面](#空间与场面)、[节奏与剪辑](#节奏与剪辑)、[特效与成像](#特效与成像)。动作与摄影共同服务同一事件；只改摄影时锁定事件与结果，不增招式或能力。

## 交锋与覆盖

先找人物目标、优势距离、移动/支撑方式和遇袭回应，再决定怎样让变化可见。招名删去后，仍应知道使用哪件兵器，从哪里攻向哪里，对手怎样应对。传统技法保留可见运动原则；文学招式依用户选定版本；原创仙术补触发、范围与结束。需核实名称或版本时才读[资料检索](library-workflow.md)，补写动作不能冒充原文已有内容。

每次主要交换同时解决下表相关判断，不把表格作为必交表单，也不为每个细节单开镜头：

| 战术变化 | 动作与空间必须成立 | 摄影应让观众看见 |
| --- | --- | --- |
| 进入近战 | 跨过间距、踏入兵器作用范围，对手有回应 | 接近路线、双方关系和第一威胁；相机推进不代替接近 |
| 格挡、卸力、破防 | 来路与接触对象明确，偏转/承压改变下一动作 | 分开持械手与刃口的角度，保留从来势到反馈的联系 |
| 击退、失衡、落地 | 冲量、重心/支撑变化和制动相接 | 身体、支撑与位移结果；胸像配裂纹不证明滑退 |
| 远程破招 | 攻击经过共享路径，改变某处防线 | 发射端、受阻处与后续结果的空间联系；不只轮流施法特写 |
| 换区、追压 | 路线、障碍、速度差和到达条件成立 | 相对距离、地标与下一威胁；背景飞掠不证明追近 |
| 巨型攻击 | 范围、经过区域与尺度合理，局部/整体后果分清 | 人物或地标尺度参照、作用区域及可见结果 |
| 犹豫、留手、反制 | 选择改变先手、攻击落点或追击决定 | 看向的威胁和选择的代价；不让画外攻击随表情镜暂停 |

主要转折可内部比较同框连续覆盖、接点侧位、沿威胁跟随或拉开显示范围，选能揭示变化的方式，不凑备选数量。每镜明确观察目的、起始相位、跟随对象、可见范围和结束结果。复合运镜要有空间理由，不把所有片拍成侧面架剑中景，也不堆叠环绕、俯冲和震屏。

比较相邻交换的高度、轨迹、防守、重心和结果。同门或镜像对抗可以打法相似；重复接架有争夺目的才保留，下一次利用已形成条件，不靠换招名伪装升级。即时反应针对当前可见威胁，预判才依赖已知条件。失位后用避让、残余招架、回弹或换支撑恢复，不能切镜后重摆标准架势。

受力沿实际冲量开始，主动变向需要新的发力；空中按既有推进能力处理。贴身防护可以传力；分离屏障先破口或让路，余势才到后方目标。挥空、格挡、擦中与实击反馈不同。裂纹、衣料内凹、滑退、断息和推云按作用与力量尺度选择，不逐击套齐。

只追踪会影响后续的位置、朝向、支撑、持械手、损伤、道具、能力与地形。临时抓控不同于转移持物；手被占用不能同时执行另一动作。实体兵器与投影分开，离手有去回或留置。弱点可预存、暴露或新造，但要进入角色可知范围并作用于同一位置；新裂口有造成与留存。布阵依赖落点时，布点、连接、激活、解除各有条件；不为普通挥剑添加资源系统。

## 空间与场面

选择有用的近区接触、中区机动、远区尺度及高差，不必输出地图。跨区连接离开缘由、途中压力和到达条件。开放仙侠让封路迫使改高度、远程压制逼近身、落点被毁迫使换路线；花海、林冠、崖壁、山脊和云层是可选关系，不要求走遍。大背景、同步飞行和轮流光束不等于战术变化。窄场地利用门、柱、墙和出口，扩展须有通路。

蹬石、被浮石承载、御空不同：蹬离后跨越到新支撑；一块石托升不是连续踏石。空中反向启动要有制动或推力，损坏的桥与落点继续改变路线。相机换位不冒充人物换位，透视不改变真实射程。

| 场面 | 额外决策与覆盖重点 |
| --- | --- |
| 双人近战 | 长短兵器、中线与握法限制；接架为何保持、怎样分离 |
| 仙侠斗法 | 近身、御器、场域为何转换；控制范围、路径、实体回收与尺度切换 |
| 群战/护送 | 目标、入口出口、遮挡与到达时机；画外角色继续绕位、封路或处理障碍，不排队等打 |
| 追逐 | 谁先通过瓶颈，追者为何未追上；到达继承间距与主动权 |
| 巨敌 | 接近代价、部件运动、支点与回收迟滞；弱点如何可知，局部受阻不自动整体倒下 |
| 演武/登场 | 允许接触、留手与停止信号；按展示或首击前悬念收束，不补完整胜负 |

水下、真空、晃动甲板另核对介质、推进与支撑。多人过载时减少同时需要精读的接触点，其他人仍有合理去向。低位适合看脚下启动与迫近，高位适合看双方、范围与路线；纯风景或单人俯拍不算关系复位。用户要求全身同框时不强加单人特写。

## 节奏与剪辑

高能通过接续和升级形成反差：前一交换的结果逼出下一选择，压力可从先手转移到落点、空间或能力限制，不只把光球变大。开场快速进入当前威胁；中段有因果相连的爆点；高潮利用前段形成的条件兑现结果。按用户范围取舍，不把三段曲线变成固定段数或时间比例。角力、蓄势、佯退与情绪停顿有战术用途则保留。

人物出手、相机运动、播放倍率、切镜频率分别设计。连续运镜也可以高速，短镜也会拖慢动作。准备、接触、恢复和下一招可以叠接；眼神、呼吸与衣摆附着进行中的动作，较长停留才需要时间条件。旧识、犹豫和收手通过识别起手、失去先手、偏锋、卸械或放弃追击体现，不默认相爱相杀或喉前停剑。

按事件所需时间选覆盖，最后统计切点。关键变化难以同镜读清时拆，重复同一姿态或结果时合。时间段、招数、接点与镜数不同，连续机位移动不增加镜号；不预设镜数、区间或快慢配比，来路—接点—反馈不强制分成三镜。超载先删装饰与重复覆盖，再减可选交换，保留必选结果与桥接。

切点可落在刀线切入、接触、反制起势和反馈接续处，必须有新信息、空间交接或强调作用。同一次事件不因换角度重新发生，首触音不重复重放。Hit Stop或微慢只强调选定时刻，计入总长并恢复实速；不默认每击使用，不承诺模型逐帧执行小数时码。

同一交锋簇保持轴线，绕行、错身、升空和换区展示路径后建立新关系。固定左右、复位间隔及特殊微慢若为当前要求仍需保留；自适应只取消镜数配额。复位可以在追击中完成。衣袖、碎石和碎光藏切点时，前后承接动作相位、方向与速度趋势，不跳过唯一命中、回收或落地。一镜到底给连续可行路线与机位移动时间，不隐切或白闪重置。

结尾承接前段结果，保留动态余势、呼吸和场地残留，不统一站姿定格；是否分胜负、留悬念或继续追逐由目标决定。

## 特效与成像

仅在效果影响读图或战术时细化。区分装饰、材质反馈与实际能力；附刃亮带不自动成为斩波，寒雾不自动承重。写清来源/触发、路径、作用结果和结束，不要求每段粒子或一套渲染参数。

- 火星、木屑来自实际作用位置；挥空可以有尾迹，但没有命中爆点。主要形态说明方向与范围，细节说明余势，环境结果按状态留存，不必每次三层俱全。
- 新尾迹随当前剑路产生，旧尾迹留在经过的世界位置并衰减，不整体跟剑反转；停止新增不等于存量瞬间清空。
- 持续风场有范围、维持与变化，重复尘雾不是新攻击。能量消散不修复兵器与落点，不自动清空仍有效的飞行物。
- 花瓣、衣袖、石屑和碎光分别遵循风、身体、实体抛落和能量退场；推云需要作用范围与传播，不随近处普通碰撞同步翻动。
- 白闪、冲击帧和速度线可以强调，不能替代接触/身体结果，或自动新增爆炸、伤害和停时。

曝光模糊来自相对画面的运动，景深虚化来自距离平面，粒子尾迹留在场景中，艺术残影不新增实体分身。固定机位下挥剑不会令静止墙面整幅横拖；跟拍可减小躯干位移，摆臂、剑尖与背景仍各有相对运动。可辨不要求逐帧全锐利，明确的低模糊或拖影意图保留。

相对相机停住后，常规拖糊不在空中漂散数秒；粒子可停发后衰减。快门、帧率、插帧和播放速度不是同一设置，入口未支持时只能写观感意图。关键破防不能全被省略；若袖子、光团或模糊遮住关键结果，先调视点与非关键效果，再按任务授权简化交互。真实结果的诊断见[观察与修复](review-loop.md)，制作依据见[来源](sources.md)。
