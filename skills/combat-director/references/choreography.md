# 交锋、战术与连续状态

用于目标、近战交换、感知判断、受力恢复、持续接触、抓握和物件交接。正文组织见[提示词构建](prompt-construction.md)；以下例句用于说明不同机制，按本场能力与目标改写。

## 目标与战术选择

把目标转成可见终态：夺物看归属，护送看到达，拖延看等待事件，脱身看通路。个人下风也可守住目标，局部缴械、逼退或巨敌落空只改变相应条件。演武、登场和技能展示按其任务结束。

交换应改变后续选择，或让持续压力产生代价。本场突出一项已有且有用途的打法特点，把它写成目标与风险下的取舍：短幅拨刃后逼持手、守中线截近、绕侧取位或重击迫退，各按当前兵器、体型、修为与意图采用。写其偏好距离、来路和回收怎样服务目标，遇到什么威胁会改招或放弃窗口。连续占优、同门相似打法都可成立，不为辨识度硬造独门能力；多场战斗通过目标、阻碍和结果区分用途，继承招式回响、能力与损伤。

**选择例句：**守桥者短幅拨开来刺，沿对方尚未收肘的路线点向持剑腕，追者缩肘撤刃。追者再次探入时先收肘护腕，沿栏边挤向桥口；守桥者见身后同伴仍在过桥，收回前脚、横剑堵住侧路，舍弃追腕窗口。同一攻腕习惯被对方记住，护送目标使守桥者选择守口。

### 战术依赖与行动窗口

先串出本场目标面临的阻碍、实际改变阻碍的事件，以及下一行动凭什么成立，再安排镜头与占时。跨阶段承接距离与通路、攻防线、可用持手、损伤消耗和仍在推进的威胁；阶段由这些条件的变化划分，单次交换或短任务可直接成稿，不必填内部表格或凑固定阶段数。换区域、展开大招或切入特写本身不证明局势已变，持续占优也可沿同一目标推进。

关键变招核对前招实际开放的窗口，以及后招所需的距离、持手与回收进度。剑线偏开、失稳和让路分别判断；对方已经回封，刚才的空门就不再可用。窗口从条件成立到被回收、补位或来袭关闭，不因跨镜或跨阶段一直保留。修订前提时一起重算依赖它的后招与时间；后招先以当前状态起动，再落实新结果，不能让预定高潮倒推一个未发生的破防。

同向退追时，间距由双方实际推进量决定：拉开须退者先加速、更快，或追者因回收/让位延后；缩距须有相应追入。只写“双方继续移动”不能支持距离突增，特写也不代替这段行程。以米、臂距或刃程核终点，含混的“身位”只有方向与尺度已明确时采用。

例如刀客虚点守卫左肩，守卫仍守住门口枪线，原定侧穿就未成立。若终态指定夺路，应从当前刀位和距离补出真正改变封线的过程。内部可用“对手没有追挡，后招是否仍成立”检查转折；正文只写本次实际发生的选择及依据。

### 施术与变身的行动窗口

结印、蓄势、吟诵、变身和器物展开占用本场所需的手、支撑与时间，先看已有距离、遮挡、控制或同伴掩护能否供完这个窗口。对手在其间仍可逼近、改角、攻击或争取自己的目标；近景呈现准备过程时，画外推进也在同一时窗内计算。威胁先抵达就从当前准备姿态处理防守、缩短/改招或中断，边施术边承接须与当前持手、支撑和已有能力相容。完成后从此时距离、持物与追击接招；变身改变哪些能力、体量或部位按已设条件表现，未被改变的伤势、接点和原在途攻击继续有效。

**窗口例句：**院门西有石柱，剑修站在柱东侧，右手持剑；本场展开需站稳、左手连续结印。枪客在前方双手持枪，枪尖尚不及胸，见其左手起印便前踏直刺。剑修沿柱边后撤，以右剑斜拨枪杆向外，左手停印，未成术光退去；枪尖掠身扎向柱侧空处。枪客屈肘抽枪、踏向门线，剑修从偏外剑位回防。下一段先处理已经逼近的枪线，本次展开没有凭特写获得额外准备时间。

### 同招变化、诱招与感知

同招可首次迫退、再次被封线，或用相似起手诱出新回应。诱招给足威胁表象，写对手实际改变哪条防线，再利用开放路线；未上当就从原封线继续。两次实刺按实际线路写连刺或变线，具体成败继承用户要求。

回应依据角色可获得的起手、轨迹、声音、前次结果、接点力变或已设感知能力。观众先见的埋伏不是角色已知信息；仅补影响当前判断的范围、遮挡和时间。看到起手撤步可以先发生，本次碰撞造成的破损/位移则在作用之后；先到的气流、灵压或持续束缚按其来源处理。成片静音与剧情听觉判断分开。

### 变招、反转与代价

| 变化 | 执行与接续 |
| --- | --- |
| 临场变招 | 刺线被封后收肘，沿未覆盖侧线转挑，继承原剑位与追击 |
| 同体系升级 | 相似起手改短来路、集中接点或调整释放顺序，说明旧防守为何不够 |
| 底牌或突破 | 已埋备用符、能力条件或新领悟改变限制，触发、作用和代价可见 |
| 舍身反转 | 承接攻向同伴的一击，为其留路线；收益与伤势分别表现 |

反转可只抢回通路或护住目标。疲劳、伤势、已燃符箓、破盾和离手兵器分别限制后招；恢复机会来自距离、阻挡或对手意图，代价按世界设定接续。功法融合/境界差见[力量专题](powers-and-formations.md)，吟诵见[声音与表演](sound-and-performance.md)；指定慢镜、凝滞或停格计入当前时间。

## 交锋与覆盖

### 进入近战与偏转反击

在当前兵器射程内组织“目标/来路 → 对手处理 → 接触或让空 → 受力 → 回收与下一威胁”。实体与术法支撑按本场机制处理。发力或急转影响成败时，写当前支撑或御空驱动怎样承接髋肩转动、肢体/刃线的直进或弧路，以及收肘、转胯或术法制动怎样接下一招；不逐招填解剖清单。腾空余势可延续旋转，主动改变通行方向仍需已有推力或接点；转肩本身不自动提供御空推进。短镜覆盖当前相位，相连镜组补齐关系；只换媒介或摄影时保留原动作与支撑机制。

**交换例句：**青衫修士以后脚送髋、右肩前送，右手剑直刺胸前；刀客侧身，以右手刀的刀背将剑尖拨向外下侧，随转胯带刀横切腰侧。修士收腹撤胯，刀锋只断外层衣带；退脚踏住后方石阶承住退势，肩线回转、屈肘将偏下的剑尖挑向持刀腕，刀客收肘退步避开。擦衣、人体命中和屏障受击分别反馈，失位后的回应从当前残余架势开始；连招可逼防、变线或取位，不必全中。

易混术语按机制使用：击剑的“脱离换线”指刃尖绕过对方兵器换线，普通抽枪/松杆另按实际动作命名；枪法“拦、拿、扎”依据所用体系核枪尖弧线与前送线，手推杆或剑脊拨挡不借名。

### 紧凑交换中的招式变化

快速连招比较相邻交换的目标高度、刃线、进入角度、距离与结果，用已经发生的拨偏、让位或回收决定下一招。先减少完整复位、双方空等和无用途展示，再取舍可选交换；必要加速、接触/让空和回收仍要可读。试探、压抵、蓄势与演练按其实际用途保留。

最终正文在每个动作旁标具体耗时，以来袭、回应、接点和回收的用时锚定速度；移动、转向与对手受力反应同样写清。同步架挡与侧让可各标0.2秒并用“同时”连接，不因此拆成两个停顿；各关节随同一个身体动作配合。速度取值来自距离、动作幅度和本场能力，不能用同一个0.2秒套满所有动作。节点与动作预算按[正文时间规则](prompt-construction.md#每个战斗节点的秒数输出)内部核对。

**连续例句：**甲右剑斜劈乙右肩；乙右剑上迎、转腕引刃向自身右外侧。甲尚在收肘，乙已脱刃刺其左肩；甲侧身让尖掠过，右剑由低位上挑乙持剑腕。乙缩肘避腕，沿已偏开的剑位回切甲腰侧；甲收腹斜退，腰斩落空，乙随退势追近，甲从上挑后的高位回防。各次变化继承持手、余势与本场支撑。

### 瞬时打击与持续推压

混合打法按当前交换的功能选择：处理来势、改变角度、短促反击、腿法或脱离分别服务当前距离与目标。前一动作留下的接点、空隙、旋向或未完回收决定下一动作；流派名称附在可读动作上。已有参考仅给出招名或“拨挡/导向”时，不据此扩写正统套路或整套技法。连续换招不要求次次改流派，也不以完全复位分隔各体系。

瞬时拳、踹、斩写启动加速、可读接触、承力变化、回收/恢复支撑与分离；持续送力才写推压或控制及维持接点。换角仍覆盖同一次事件。

**单击例句：**白衣左脚踩实，侧转身体，收右膝后送髋踹出；脚跟触及黑衣胸前叠臂，护架压向胸口，肩背沿来力后移。白衣立即屈膝收腿落脚，覆盖保持到双方分离。退移或击飞幅度由本场设定决定。

局部光效、闪帧或微慢覆盖这次加速、唯一接点与受力，受击特写接其结果；出招前重音按[既定相位](camera-and-rhythm.md#视觉重音与触发相位)呈现。

本场若选接触型附加效果，先区分初始冲量与效果作用：已设身体命中导致承力变化，接点再触发光、细弧或残留；效果仅强调接触时不能提前推倒对手或补一次命中。效果另有传力能力时才按其条件计算额外作用，造型与范围见[接触型静电](style-and-materials.md#接触型静电与环境反馈)。

### 接触相位与双方承接

擦碰、贴刃滑动、压抵、推撞和束缚分别记录双方部位、接点移动、供力/供能者、受限动作及解除条件。必要握持占用的手，按当前结构与能力判断兼持、分指或自主施术是否相容。

压力沿兵器、肢体与支撑延续，双方可进退或沿接点转向；强弱位移可以不同，御空/阵法按其承载。有用途的僵持可为同伴争取时间。

持续压抵期间再用另一只手推肘、取物或操作时，写原持械手如何维持当前接点，对手的挣脱与补防同时继续；松开、滑脱或抽离之后才结束这项控制。由兵器尖端转用柄钩时补必要的收杆/转柄姿态，不让柄端跨过整段杆长凭空出现在对手腕边。细小接点的观看尺度由[摄影](camera-and-rhythm.md#观看关系与取景选择)处理。

**相抵例句：**两剑胸前斜交，青衣踏进压低刃线；红衣屈肘退步，转腕将接点导向身侧，青衣收住前倾。两刃滑至末端分开，红衣抽剑护胸，青衣顺空出的下路续攻。后续压力通过滑动、下沉或退路变化表现，不重复起始碰撞。

外来攻击先改变原接点或维持条件，再更新两方行动；主动脱开、被迫松手、断供分别交代。多个抓控/压刃接点逐项解除，剩余控制继续有效。

### 抓握、牵引与抛掷

写谁以哪只手抓对方何处，按姿势、距离和其他控制判断仍可用的肢体。抓腕限制该局部，抓衣料另看牵动、滑脱与破损；全身定身按已设能力处理。

牵引、托举或共同旋转保持相对位置、接点与承重，握手随被握部位移动；提离原支撑须有替代承载，首帧已腾空则续当前阶段。一手松开后，另一手、身体或绳索仍可牵连；真正脱手才沿原方向自由运动，再落地、碰撞或御空制动，施力者同时回收。隔空摄人与实体抓握分别写，指定吃力按相应法术表现。

普通软绳收去松弛形成张力后才牵动物件，松手端不等于物件端解绑。例如绳套剑鞘，收紧后鞘被牵近，鞘中剑按其当前握持/锁定决定是否随动；手端松开，鞘端须另解扣。剑与鞘分别追踪，硬化绳或隔空牵引按其机制另判。

### 受力后的恢复

接触结束后余势仍可继续，朝向与位移方向分别判断；止住位移、恢复姿态和兵器回防各需条件。

| 当前限制 | 解除与延续 |
| --- | --- |
| 支撑/移动失控 | 踏步承重、借已有支点或御空制动，碰地后还要承重 |
| 兵器偏离封线 | 回收、改封线或以当前姿态应对，身体站稳不使剑自动归位 |
| 伤势/装备/术法受损 | 代价继续限制后招，恢复机制先成立 |

未完全恢复时，按当前范围与姿态选择后退架挡、下落回剑或顺偏转接招，追者按行程抢攻。格挡、失衡、受伤与施术中断分别判断。横斩落空后的制动转挡继承余势；抢攻发生在对方回收未完的窗口，衣料/薄尘辅助发力而不代替它。

### 兵器差异与战术连招

比较长度、握法、结构、优势距离和挥动/回收空间，再选争位方式，每次变招继承原握法与落脚。

**例句：**重杖者分手持杖斜砸右肩；剑客让出砸线，杖头触阶后从杆侧削向前手。杖客后手仍握尾，前手松开避刃，退步抽杖横隔；剑客收肘止在隔挡外，改攻未覆盖的下路。

### 特殊兵器与持物交接

伞、钩、索、链和变形兵器按实际结构写接物部位、负载经过的握点/支撑，以及卸载、解钩或换手后的行动。

**换锚例句：**右手索钩挂梁下铁环，双脚落稳侧台后索身松弛；抖索脱钩收回，才将同一钩头掷向前栏柱。新钩挂牢、索绷紧后蹬离，旧铁环仍留，左手持刀。

**结构转招例句：**带锁扣金属骨伞撑开导刃，来刃离开后解扣收伞、回肘送伞尖直刺；荡越时以柄钩挂梁，双手承重。落上邻台卸载解钩，恢复右手持伞。

同一物件的交付、夺取、共握、抛接和拾回都有接触/释放；共握仍是一物，新增握点不等于原持有者失控。接收者原持物先有去处，持续手控的护盾先解除或采用相容接法，兼持/自主维持按机制处理。实体占有与遥控/使用资格分别判断，被缴械者仍可使用其已有空手、术法或撤离手段；丢落物保留位置，离手飞行/返程见[移动与在途攻击](movement-and-projectiles.md)。

### 机制反制与旧痕回收

先有角色可获知的线索、裂口或机构，再试探/逼出窗口并利用。旧痕随所属物件移动，局部失效按其范围反馈；对方可护住弱点，利用也可失败。前面强调的线索可兑现、失效或留下未解威胁。

**裂口例句：**弧盾右下缘首次被切出细缝，尚未闭合。攻者虚点左肩，守者转盾向左；攻者跨步沿露出的旧缝送剑光，右下盾片剥落，其余仍挡胸前，守者撤步补护。

**机构例句：**机械兽发射瓣张开才露聚光口；刀客避首射，下一轮张瓣时掷短刃卡铰缝。聚光外泄使兽停发、转身护胸；短刃留缝，刀客双手空出，沿侧逼近。

连锁有留置、维持与触发，如三枚贴盾光钉由细线连接，合指后亮纹依次传入节点；普通尾迹只有其成像用途。分层屏障、回收和破阵见[力量与法阵](powers-and-formations.md)。

### 单人连招与动作签名

动作签名取自已发生的距离、路线与收招习惯。后续复用可让对手预先封线，出招者缩短来路、改接点或舍弃机会；写出与前次的差别及当前代价，不靠重复招名认领回响。

演武按兵器接续重心和旋向：低扫末端收肘制住过大的刃弧，借当前支撑送髋转肩把剑提向斜上；躯干旋击由新支点、腾空余势或已设御空驱动承接，再循余势收转。练习物的接触与落空分别表现。身体、兵器和尾迹可共享或改变旋向，反向需支撑、回弹或能力推力；服装尾饰与攻击肢体分别判断。光尾留在已走过的世界路径再衰减，见[风格与材质](style-and-materials.md)。

### 情绪与选择

犹豫可偏要害，留手可收锋，愤怒可追入深处，信任可换位掩护，情绪通过事件及代价可见。关系、法宝共鸣和结局分别决定；共鸣按已设依据用于识别、干扰或增幅。既有“兵器共鸣—无情交锋—同归同伤”模式仅在本场关系、能力与结局相容时采用。

表演嵌入接架、回收或观察窗口，视线对象和微变化带出下一行动；远景用身体选择，近景读面部，威胁继续推进。具体表演/声音见[声音与表演](sound-and-performance.md)。
