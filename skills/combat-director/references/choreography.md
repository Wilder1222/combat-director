# 战斗提示词：交锋、空间、摄影与效果

按当前问题读取[交锋与覆盖](#交锋与覆盖)、[空间与场面](#空间与场面)、[节奏与剪辑](#节奏与剪辑)、[特效与成像](#特效与成像)。原稿中可迁移的方法已写成下文句式，无需打开原稿或外链。选择本场需要的项，替换人物、武器与路径后融入时间段，不整表拼接。

## 交锋与覆盖

先确定双方目标、优势距离与支撑，选兵器确实能完成的动作。命名技法仍需写发力、轨迹和回应；仅有名称的来源不足以证明具体技法。

### 进入近战与偏转反击

用于实体兵器交锋，先写实际接近，再写接点及下一威胁：

```text
{甲}借{地形/对手回收间隙}从{起点}逼近到{该兵器可及距离}，{支撑脚}蹬地、转髋，以{持械手与刃/杆部位}沿{斜劈/直刺/横扫轨迹}攻向{目标}。{乙}移到{方向}，以{兵器部位}接住并将来势导向{空处}；{甲的兵器与重心}顺势偏移，{乙}沿露出的{线路}接{反击}。镜头保留双方上身、持械手与脚下，接点分开两件兵器的轮廓，结束时看见{新的距离与主动权}。
```

失位者可以避让、残余招架或换支撑恢复，不能下一镜自动回到完整架势。比较相邻交换的轨迹、高度和结果；同门相似打法或角力可保留，但重复接架要有争位目的。

### 接触相位与双方承接

贴身缠斗、压刃、抓控或推撞时，区分接近、接触/维持、释放与恢复。它们是同一动作的相位，不强制分成四镜，也不要求每次轻碰都停住。持续施压时写清谁保持哪个接点、另一方如何承接；解除之前，被占用的手、武器或支撑不能同时自由执行下一招。

**句式：**“{双方部位}接触后，{施力方}沿{方向}继续{压/推/牵引}，自身{追步/屈肘/重心变化}承接阻力；{承力方}以{支撑或卸力}使{接点}移向{位置}。待{分离条件}出现，{可用肢体或武器}才转入{下一动作}。”

**例句：**“两剑在胸前斜交，青衣者踏进半步压低剑尖，红衣者屈肘退步、转腕将交点导向身侧；青衣者前脚落稳收住前倾。两刃滑离后，红衣者才抽剑护住胸前，青衣者顺空出的下路续攻。”双方都有承接，接触不靠火星代替；世界规则允许隔空作用时，另写清力量传递机制。

### 交叉遮挡与重新辨识

用于交错换位、绕背、群战或大面积遮挡；不要求所有动作都固定同框。先保留稳定称呼及少量外观/持物识别点，再给每人不同的可追踪路径。遮挡前看见进入方向，出遮挡后接上原人物的朝向、持物和余势；关键换手、夺物或唯一接点若被完全遮住，就调整覆盖或明确留为未知，不能由结果倒推已发生。

**句式：**“{甲}从{地标一侧}沿{路径}穿过，{乙}沿{另一条路径}回应；{遮挡物}短暂掠过后，{甲的识别点和原持物}从{出口}出现，仍处于{上一动作的余势}，{乙}在{承接位置}继续{对应动作}。”

**例句：**“白袖剑客右手收剑贴身，从石柱近侧绕过；深衣剑客追向柱后远侧。相机横移越过柱缘，先露出白袖与右手剑柄，再见白袖者在柱另一端转身迎敌；深衣者随后从远侧出柱，仍持原剑追近。”柱子用于视点交接，不承担凭空换人或重置姿态。

### 兵器差异与战术连招

用于快剑对重杖、短刃对长兵，或同一兵器的不同打法。先给双方不同的争位方法，再写连招；颜色区别不代替动作区别。三连击可分别承担逼防、改线、取位等任务，不必三击全中，也不把“刺、挑、抹、削”四个词当作已完成四次交换。

**组织顺序：** 双方兵器的长度/握法与优势→首招迫使对方怎样回应→回应暴露什么线路→变招如何利用→双方持物、支撑与主动权的新状态。

**句式：**“{甲}以{适合当前兵器的轨迹}封住{通路}；{乙}用{位移/兵器部位}让其{落空/偏转}，在{甲回收或改握的窗口}沿{空出的线路}进身。{甲}以{仍可用的手、杆部或支撑}应对，迫使{乙}把原本的{下一招}改为{新的选择}。”

**例句：**“重杖者双手分握铁杖，踏步把杖头斜砸向剑客的右肩；剑客向左侧移出砸线，杖头落在石阶上，碎屑从接点向外弹开。他趁杖头尚低，右手持剑贴着杆侧向前削向对方前手。重杖者右手仍握杖尾，前方左手松开躲过剑锋，后脚退半步将杖身抽回横隔；剑客收肘停在隔挡外，改攻杖身未覆盖的下路。”

同一连招的每步都继承上一握法和落脚。重兵器也可短打、快剑也需回收；不把兵器类别写成固定胜负或“重击必击飞”。

### 机制反制与旧痕回收

用于打断发射、破阵、重复利用护盾裂口，或收回前段留下的伏笔。先说明能被看见的机制或缺口，后手才有针对性；“精准命中核心”不能自行补出一个此前不存在的核心。

**组织顺序：** 机制/留痕的建立→人物察觉→对手保护或继续使用→逼出可达线路→作用在同一部位→局部失效与后续窗口。

**句式：**“前次{攻击}在{明确位置}留下{裂口/已设可维持的能量节点}；{甲}在{可见窗口}发现它，先以{另一动作}迫使{乙}改变{防线/朝向}，再沿{开放线路}作用于该处。{受影响部件}先{失去具体功能}，随后{甲/乙}利用或处理{新的局面}。”

**裂口例句：**“第一次剑光在弧盾右下缘切开一道细缝，细缝随盾面移动且尚未闭合。进攻者视线落向该处，先向守方左肩虚点，诱使其左掌把盾面向左转；进攻者趁侧缘露出，向自己的左前方跨步，沿重新可见的细缝送入第二道剑光。右下盾片先剥落，其余部分仍挡在胸前，守方撤步调整掌向补护，不因局部破口就全身爆炸。”

**机制反制例句：**“机械兽胸前发射瓣每次张开才露出聚光口；刀客躲过一轮直射，趁下一轮张瓣时将短刃尖朝前掷入铰缝。刀刃卡住闭合，下一次聚光在出口外泄，机械兽被迫停发并转身保护胸前；短刃留在铰缝，刀客双手空出，借停发窗口沿侧面逼近。”

需要多点联动时，将“留在空中的普通光轨”改写成已设技能：例如“贴在盾面上的三枚光钉由同一细线相连，施术者二指合拢，亮纹沿细线依次传到各钉，最后在接触的盾片上释放”。先交代留置、维持与触发，才写连锁；没有该机制时只回收实际裂口，不让尾迹自动引爆全场。

### 特殊兵器与持物交接

用于伞、钩、链、长短兵转换或离手攻击；兵器的具体结构由本场设定决定，不默认普通纸伞能承重/钩链。

```text
{人物}用{现有结构：钩端/杆身/刃背/伞骨}接住{作用对象}，将{实际负载}传到{握持与支撑}，借此完成{旋转/拉近/撑起}；先{解钩/卸载/换手}，再让{兵器部位}沿{新轨迹}接下一招。另一只手此时{持物或空出状态}保持明确。
```

```text
{离手兵器}由{持械手}沿{路径}袭向{目标}，{对手回应}使它{偏转/命中/落空}；它随后{沿既定控制范围内的路径返回原手/由另一只空手接住/留在明确位置}，主人以{可用手与剩余装备}承接下一动作。
```

临时抓控不等于物权转移，手被占用不能同时结印或再持另一物；投影不占实体手，但须有既定能力来源。

**结构转招例句：**“以有锁扣、能承重的金属骨伞为设定：持伞者右手握柄，左手推扣撑开伞骨，把来刃沿倾斜伞缘导向身侧；来刃离开后，左手解扣收伞，伞骨合拢，右肘回收再送出伞尖直刺。转入荡越时才用柄端钩挂住横梁，双手抓稳伞柄承重；双脚落上邻台、卸去负载后解钩，恢复右手持伞。”伞的撑、收、刺、钩各有结构与占手转换，不一拍中同时完成。

### 单人连招与动作签名

用于演武、角色技能展示；根据兵器选一条能接续的重心/旋向关系，不机械复制持伞、月夜或尾部装饰。

```text
{人物}压低重心，以{兵器及部位}沿{低位路径}完成{扫/拖/挑}，借后脚蹬地和转髋将兵器提向{斜上方}；躯干顺势转到{朝向}，{下一落脚或已设腾空方式}承接{旋击/下劈}，收势不停回标准站姿。{衣摆/装饰长形}跟随身体，{光尾}保留刚经过的弧路后衰减。{练习物接触结果，或无实际命中}。
```

身体、兵器与效果可共享旋向，但不强制整段始终同向。主动反转需要新支撑、回弹或能力推力。尾状长形若只是服装/残留，不自动变成可抓取或独立攻击的肢体。

### 情绪与选择

用于犹豫、识别、留手、佯退；将表演嵌入攻防，而非让对方暂停等待：

```text
{甲}在{正在发生的接架/回收}中看清{对方可识别的信号}，将原本攻向{部位}的{兵器}偏到{安全或次要线路}；{乙}利用这次偏锋{逼近/夺回先手}，迫使{甲}以{退步/卸力}继续应对。
```

表演要有可见触发与视线对象，近景可这样接入：

```text
在{接架/对手回收形成的窗口}，镜头以{能读清脸部且保留威胁方向的近景}跟随{人物}；其视线从{对手兵器/支撑脚}转到{暴露的退路/破绽}，{眼睑微收/眉间收紧/嘴角绷住/下颌放松}表现{警觉转为判断明确等变化}，随即{改变攻击线/撤步/逼进}。在{启动相位}切回{交代双方位置的中全景}接续这次动作；背景与武器可局部拖糊，眼部及关键接点保持可读。
```

一镜到底时将上述切回改为相机沿可达路线调整取景，并计入时间；不要为了微表情突然贴脸再瞬移拉远。远景不要求看清嘴角细颤，遮面不描写被遮住的表情。情绪由局势变化推动，不每招重复“愤怒眼神”。

只有场上确有时间窗口才另给凝视/台词停顿。人物关系由用户决定，不默认旧识或相爱相杀。

### 面部特写

用于看清来势、决定改招、受压后稳住或短暂迟疑的关键相位。先定这一张脸向观众提供什么判断，再决定截到整张脸还是眼部；不让战斗为了展示面容停住。

**组织顺序：** 进入特写的动作窗口→脸部角度与取景范围→视线对象→一两处微变化→来光与运动关系→离开特写时承接的动作。

**句式：**“在{正在发生的回收/接架/远处来势}中切到{人物侧前方的面部/眼部特写}；{视线}锁住{画外但已建立位置的威胁}，{眉眼/嘴角/下颌}出现{具体变化}，{已有光源或法术来光}从{方向}掠过脸侧；镜头随{头肩运动}小幅跟移，在{判断转成行动的相位}切回{下一景别}接续{动作}。”

**例句：**“对面金色来梭正越过石柱时，切入青衣人侧前方的面部特写，从眉骨收至下颌，右侧留出视线空间；他的目光盯住画外右侧来梭，眉间一紧、下唇短促抿住，金色反光从右颊向鼻梁扫过。相机随他沉肩向下跟移少许，在头部开始侧让时切回中全景，继续看清让位和持剑迎击，不重复一次起势。”

只在面部可见时使用对应细节；遮面改为露出的眼部特写。眼睛与面部轮廓保持可辨，背景可按运动方向拖糊；扫过脸的光来自已建立的效果，不是随机频闪。特写占时包含在总长内，远处攻击继续接近或对手继续回收；一镜到底需沿连续路线调整到近距离再退出，不能凭空变成贴脸机位。

## 空间与场面

地标用于定位、阻挡或支撑，不能只有背景装饰。近区接触、中区移动与远区尺度按场景展开；窄场地利用限制，开放仙侠可用纵深与高差。

| 需要的变化 | 可直接改写进正文的局部句式 | 成立条件 |
| --- | --- | --- |
| 远近斗法转换 | “{甲的定向攻击}沿{共享路径}逼近，{乙的防线}挡住{部位}；{甲}改用{已有范围能力}封住{退路}，{乙}从{仍可通行的缺口}移到{新高度/近身距离}反攻。” | 能力先有来源；由封路/压制导致换打法，不轮流无目标放光 |
| 跨区追击 | “{通道/落点}被{当前攻击}封住，{人物}沿{门、墙、屋檐、树干或山体通路}离开；追击者在途中从{位置}施压，人物借{支撑}到达{新区}，镜头拉开交代双方间距及下一来路。” | 给出可达路径；受损门墙/落点持续影响路线，相机移动不代替迁移 |
| 浮石与空中转向 | “{碎石}被{已设风场/力量}带起；{人物}先处理{飞来障碍}，落脚在{可承载石面}，蹬离后越向{下一落点}；{支撑破坏或推力变化}使其调整路线。” | 蹬离、被石托升、御空分清；不能用同一块托升的石头冒充连续踏石 |
| 群战与护送 | “{前方对手}从{入口}封住{护送/突围目标}；{人物}以{当前动作}打开{通路}。同时{侧方对手}绕向{落点}，{另一人}受{障碍/职责}限制尚未接近，下一威胁在人物{回收/移位}时进入。” | 画外角色有位置与到达条件，不排队等打；过载时减少同时需精读的接点 |
| 巨敌与阶段升级 | “先以{人物/建筑}衬出{巨敌局部}，镜头随{身体运动}揭示整体；{攻击}只改变{关节/支撑部件}，其失衡打开{接近路径}，人物到达后再作用于{已暴露弱点}。” | 局部受损不自动整体倒下；弱点可预存或新造，但必须可知可达 |
| 登场与首击前悬念 | “从{足部启动/兵器握持}进入{人物全身}，再揭示{对面威胁及尺度}；{附刃效果}从{来源}沿兵器推进，人物借{明确支撑/已设能力}起势，在{首次接触前的具体相位}结束。” | 不补完整胜负；短时长不塞长台词，不能把服装当作踏空能力证据 |

水下、真空、晃动甲板另确定推进、介质和支撑。环境改变若影响下一招，就写进下一单元；不靠一句“场地破坏严重”代替路径。

### 地形接力与尺度升级

用于楼层、庭院、回廊、屋顶、殿内等区域之间的追击。先把本场选用的支撑物排成可达路线，再让一次攻击改变其中一段；下一动作利用或绕开变化。没有必要在短片中塞入所有场地。

**句式：**“{上一击}使{护栏/落点/通道}发生{实际变化}，{人物}因此改走{仍成立的支撑链}；{对手}从{来路}追压，人物借{场景物的承重/摆动/遮挡}改变{高度/方向/间距}。进入{新区}时用{景别}同时交代双方和{保留的旧破坏}，下一招从{实际落点}开始。”

**例句：**“横扫击断回廊护栏，持伞者收起伞面，以承重伞钩挂住殿内横梁下的独立吊链，沿缺口荡入大殿；追击者踏过断栏落到石地，立刻抬剑逼近。持伞者借摆到高点的余势踹向旁侧铜钟下缘，铜钟绕自身完好的吊点摆向追击者；他下潜避开钟沿，钟体继续摆过，持伞者则回荡到侧台，双脚承重后卸力解钩。侧面全景保留铜钟摆向、双方落点与仍破开的栏口。”

破坏规模以结果递进：例如“脚下裂砖影响制动→护栏断裂迫使换路→梁体失效造成坠落→新区域暴露另一威胁”。每级先给支撑为何失效与人物如何应对；用近景读接点、较长全景读迁移、远景读破坏范围，不重复同一次命中。不把裂一块砖自动升级为整座山崩塌。

### 法相与威胁揭示

用于已设召唤、巨像或大范围术式。将显形过程和新增战术作用绑定；形体变大应改变遮挡、攻击范围或可达路线，不能只把同一光团放大。若本场是首登预告，停在约定起手相位即可。

**组织顺序：** 触发手印/器物→局部显形与环境尺度物→整体轮廓→施术者与法相的控制关系→具体攻击路线→对手的应对空间与结果。

**句式：**“{人物}在{支撑/既定悬浮状态}以{可用手或器物}触发{能力}；先让{局部}从{空间锚点}显出，与{建筑/人物}同框，再揭示{整体与尺度}。{操控动作}使法相{哪个部位}沿{路径}作用于{范围}，{对手}沿{未被覆盖的通路}应对，留下{实际结果}。”

**例句：**“禅杖已横放身侧石台，术者双脚仍踏台面，双手由胸前合掌转为右掌前推；身后先亮出高过殿门的金色指节，再由下向上接出肩部与上身，门柱衬出比例。半身法相同步前推右掌，掌面只沿正前方向推进，院内雨幕先被推开，剑客向北侧未覆盖的廊口疾走；巨掌抵住东墙后，墙砖从接点松裂，金纹沿掌缘破散。”

法相是投影、可传力能量体还是实体召唤物要在能力设定中明确；上例选用可传力能量体与动作同步控制，不强套给所有法术。脚踏石台不因显形自动升空，腾手过程不省略；近景的控制动作与远景的威胁属于同一时间链。

### 远景光梭对撞

用于开放空间中的远距高速交锋。先明确光梭是**包裹人物/兵器的流光**，还是**离体法术**，再分别写主体、来路和碰撞；不把尾迹在画面上的交叉当作实际命中。

**组织顺序：** 远景中的两端起点与尺度地标→光梭主体和色形区别→接近路线/高度→唯一真实交点→对撞瞬间的形变与受力→弹开、擦过或穿透后的去向→双方位置与下一威胁。

**句式：**“远景同时纳入{双方起点、地标与间距}；{甲及其光梭形态}沿{路线与高度}逼近，{乙及其形态}沿{相向路线}迎上，在{三维空间中的明确位置}以{兵器/能量主体}相撞。先看清{接点或接触轮廓}，再让{短促闪光、压缩光纹、扩散粒子}展开；{主体}随后沿{符合受力或已设控制的方向}分开，旧尾迹留在原路径变淡，镜头仍能读到{新位置与结果}。”

**人物包覆流光的例句：**“远景从峡谷南侧看见相隔三十米的东西岩台，青衣人在左，白衣人在右，谷底河流衬出纵深。两人借已设御空能力离台，在同一高度沿相向斜线掠向中央；青白与金色梭形流光包住身体外缘，靠前的剑锋和躯干轮廓仍可辨。两剑在谷口孤岩上方相抵，尖端先迸出短亮点，两道光梭前缘受压摊开；随后各自借御空调整姿态向来路侧退开，衣摆与持剑手跟随回撤。薄光环从剑刃接点向外扩散后消退，镜头保留双方分开的间距，不把相撞写成身体融为一团。”

**离体法术的例句：**“两人留在东西岩台，身前法阵各射出一枚细长光梭，青白梭自左下向右上，金梭自右上向左下，在孤岩上方同一高度迎头相抵；亮芯先压缩，再碎成两束向来路反散的短光丝，人物仍在原台，没有随弹体冲到谷中央。散光照亮岩壁近侧后迅速变暗，双方下一次施法从各自原站位接续。”

远景要在同一构图中读清两条来路、交点与主体去向；闪光不能长期吞没轮廓，背景地标保留尺度。人物间距大时给真实接近占时，离体法术相撞不自动让施术者倒飞；若要传力到本人，先有对应技能机制。只改摄影时只拍原稿已有交锋；原稿没有御空或光梭，不为套用例句新增能力。

**分波封路与逐层对撞：** 剑雨、刃群或连续弹体先写来源和各波任务，再写每波如何改变防线，不用“全部同时炸开”抹掉过程。可套：“{第一波}沿{线路}迫使{回应}，{第二波}封住{因此出现的退路}，{后续攻击}利用{未修复的局部变化}继续作用；结束时交代{剩余弹体、实体兵器与双方位置}。”

**例句：**“六枚由同一竖阵一次凝出的银白刃形投影分为前后三枚，术者右手实体剑仍垂在身侧。前三枚沿扇形袭向弧盾中央和左右边缘：中刃受阻碎散，侧刃被弧面导开，在盾外熄灭，左缘留下一道缺口。后三枚随后沿该侧收束：第一枚抵住缺口边缘，后两枚相继压入，使局部盾片向内折裂；守方在连续冲击中向未被封住的右侧撤步。阵中不再补生投影，六枚均在这轮碰撞中耗尽，盾上缺口保留。”数量只在影响连招或结果时明确；光刃投影、可回收飞剑与手中主剑分开命名，不能在下一镜无因恢复为满阵。

## 节奏与剪辑

先决定本段要让观众读到什么结果，再选择拍法。编排稿每镜写起止时间、镜长、观察目的、跟随对象、可见范围和结束变化，不堆运镜词；根据动作与信息量安排长短，不预设镜数或快慢比例。投喂稿按入口转换为支持的时间粒度或镜头顺序，见[编排时间与投喂时间](prompt-construction.md#编排时间与投喂时间)。

### 分清速度与局势推进

“不够快”先定位四件事：人物从发动到恢复用了多久；相机如何追随或转交主体；画面是否慢放或加速；切镜是否带来新的信息。相机绕得快、衣摆飞动、光环转得快，都不能替代人物完成攻防。也不把提高切镜频率当作唯一修复。

持续接架若承担角力或试探，应有防线下沉、脚下失位、刃线滑移或主动卸力等变化；若只是保持同一姿态供相机绕拍，先改接架后的选择。可写：“两刃相抵后，守方手腕随压力向外转，前脚被迫侧移；攻方趁刃线偏离中路收肘抽剑，守方追步封住直刺，攻方只得转向其外侧绕行。”变化由回应触发，不按计时器凭空换招；选择角力时也不强制快速分开。

高强度段保留关键的连续交换、距离或高度变化以及局势转折。为降低生成难度，先处理冗余效果、观看遮挡与无效重复；不能把用户要的追击、变招和反制统统削成一次挥剑。复杂度确需改变时，说明保住了哪些必选事件、调整了哪些可选覆盖，再按已授权的制作方式执行。

| 拍法目标 | 提示词写法 | 避免误用 |
| --- | --- | --- |
| 镜长变化与紧凑节奏 | “用{较长镜长}连续看清{接近/绕位/攻防链}；在{局势变化}后接{较短镜长}突出{单一威胁/反应}，再用{所需镜长}承接{受力、恢复及下一攻势}；结果可读即接下一动作。” | 每镜有明确时长和切点，合计准确；不均分、不机械交替、不重演命中。长镜持续推进，短镜不塞整串攻防；单镜改用镜内节拍，不加切镜 |
| 攻击交接视点 | “相机从{攻击者的起手相位}沿{威胁来路}跟到{接点}，保留{防守者的回应}，再随其{反击方向}转向，结束时看清{双方新关系}。” | 视点追到效果却丢掉回应时，改覆盖，不追加随机甩镜 |
| 同框接触与结果 | “相机位于{不遮挡两件兵器的侧前方}，将{持械手、目标部位和必要支撑}同框保留，从来势持续看到{偏转/失衡/落脚}。” | 不是每击强制三镜；胸像不能代替脚下滑退 |
| 快切与关系复位 | “在{真实动作相位}切到{新增信息的视点}，接续相同来势与结果；{绕位/换区}后用包含{双方、地标和距离}的移动全景建立新关系。” | 换角不重演同一次命中，首触音不重复；用户固定左右时保持，换边须有路径 |
| 一镜到底 | “相机从{起点}沿{可行通道}跟随{主体}，在{相位}绕到{侧位}，留出移动所需时间，再退到{能同时看见结果的位置}，全程连续。” | 不靠袖子、光团、白闪藏切或瞬间俯视/平视切换 |
| 微慢与爆发 | “常规动作保持{用户要求的速度}；仅在{选定接触}短促强调{接点与受力}，随后立即恢复，{回收/追压}接续进行。” | 计入总时长，不逐击套Hit Stop；慢镜、动作慢、镜头慢、剪得慢分别处理 |
| 小物件构图转场 | “{小物件}旋到{画面位置和大小}，在{相位}切到同位置的{月轮/阵环/钟面}，保留{轮廓或运动方向}；新镜随即展开{人物、地标和实际所在位置}。”例：“铜币亮面转正时切到画面中央同大小的满月，向下摇回仍在江面竹筏上的人物；后续另拍靠岸与跃上岸石。” | 仅用于允许切镜的段落；同一物件材质和名称保持一致，构图匹配不替人物完成迁移。一镜到底改写连续取景，不能藏切 |

升级来自防线改变、退路收窄、支撑失去或能力条件变化；眼神、呼吸和衣摆可附着正在进行的动作，不各占一次等待。结束保留本场需要的余势、身体状态或悬念，时间不够先删装饰与重复覆盖，再减可选交换。

### 蓄爆反差与延迟结果

用于有意蓄势、拔刃或终局收势。选一个真正改变观众预期的停顿，并写清停顿时仍在发生什么。动作幅度可小，信息仍推进；高速段只强调少数可辨的关键变招，不承诺一个瞬间完成数百次接触。

**句式：**“在{对手回收/双方暂被障碍隔开等实际窗口}，{人物}以{小幅但有目的的动作}完成{观察/准备}，{局部效果}沿{来源}逐渐变化；到{发力/触发相位}立即恢复实速，连续看到{离开支撑、攻击路径与结果}。随后{收势}与{已经发生的命中后果}在前后景中接续。”

**蓄势例句：**“双方被倒下的横梁暂时隔开，刀客把刀背横到胸前，空出的左手二指从护手上方引向刀尖；红纹跟着手指沿刃背逐节亮起，只照亮邻近指节和半侧脸。对手正从横梁另一端绕来，刀客看准空隙，左手撤离刃线，后脚蹬地冲向梁端；慢拍结束在蹬地之前，后续进身以实速看清。”只有既定附魔能力才加红纹；普通拔刀可用出鞘和金属反光完成张力。

**延迟结果例句：**“上一镜已看清剑刃切断机关傀儡膝部的外露拉索；剑客穿过其右侧后制动，右手剑身退向左手稳定的鞘口。前景看见半入鞘的剑与侧脸，焦点沿纵深转到仍因惯性前踏的傀儡；失去拉索牵引的膝节屈折，它向前跪落。雨水和散屑一直运动，后景结果只发生一次。”

区分“后果晚被看见”与“技能延迟触发”：前者不重演命中，后者需先设存留介质、触发和作用范围。入鞘声可与结果对点，但不能默认发声使未受击的敌人或建筑爆碎。局部短暂强调、人物主动急停、全画面定格分别描述；手、衣发、雨滴不能同时写全静止又持续微颤。

### 快速动态交错运镜

让相机依次接住进攻者、接点、防守者和反攻线路。写清**人物路线、兵器/光梭路线、相机路线**三者的不同起点与方向，再安排速度变化；“交错”来自真实运动关系，不是随机旋转和切镜。

**组织顺序：** 机位起点与初始跟随对象→加速跟入→经过哪个开放间隙或主体侧面→在什么攻防相位交接跟随对象→相机如何转向/减速→结束构图揭示的新位置。

**句式：**“相机从{甲的侧后/侧前位置}加速跟随{进攻路径}，沿{不穿过身体和实体障碍的路线}掠到{交锋侧位}；在{偏转、擦身或反击启动}时，{横摇/弧移/短促后撤}交接给{乙及反攻方向}，{前景与背景}产生{对应视差或短暂拖糊}，随后迅速稳住{接点/落脚/双方位置}。”

| 手法 | 可直接改写的局部句式 | 结束时要读到什么 |
| --- | --- | --- |
| 贴身侧跟与弧线交接 | “相机贴着{甲侧后方的开放通道}加速跟入；{乙}偏转来势时，相机沿两人外侧画短弧，转而跟住{乙的反击方向}，人物与兵器始终不穿过镜头。” | 主动权如何从甲转到乙，反击从哪来 |
| 擦肩穿行与前后景交换 | “{甲}从近处向{方向}掠过，{乙}在较远层反向移动；相机沿{明确空隙}侧向穿行，让两人前后景关系在可见路径中交换，再拉开少许保留双方。” | 谁经过谁的哪一侧，交换后各自站在哪里 |
| 甩镜接反击 | “相机先跟{被导开的兵器}，在{乙启动反击}时从同一机位快速横摇到{反击来路}；背景只在横摇期间短暂拖糊，镜头在{真实接触之前}收住，完整看到{回应与结果}。” | 甩向有来源的新威胁，不能甩完只剩爆光 |
| 低位掠行与抬镜接动作 | “相机在{人物侧方的开放路线}低位掠过，读清{踏地/滑步}，随{躯干起身或已设跃起}向上仰抬，并沿侧方后撤留出{武器/身体}运动空间。” | 落脚怎样带动上身攻防，运动终点与下一支撑 |

**例句：**“甲向东突刺，乙在同一攻防轴线南侧退半步，用剑身把来刃导向北侧；相机从甲南侧后方沿开放石面快速向东跟入，抵达两人南侧时减速，完整看见刃身偏转。乙趁势向西斜斩甲的持剑臂，相机从当前侧位短促横摇向西，在斜斩抵达前稳住；甲收肘撤臂，剑锋从臂外掠过。背景石柱在横摇中短糊，持剑手和让空关系恢复清楚，结束保留甲后撤、乙前压的全身位置。”

连续交错镜可在内部变速与交接对象，切镜版本则在明确动作相位另标下一镜；横摇本身不是切镜。虚拟相机可快速穿行开放空间，但仍写出连续起终点，不能穿身体、实体墙或用旋转把角色瞬移到另一侧。双方绕位后，先按新的对峙关系更新动作轴线，再说明机位处于哪一侧；开场的“同侧”不能证明后续接点仍无遮挡。过轴时以可见环绕/擦身路径或全景重建方位；有固定左右要求时，在同侧完成交接。速度最高的阶段容许局部拖糊，真正接点、关键表情与结果要能辨认，避免全程不停止的旋转。

把三种拍法串联时，可用“短面部特写读出判断→较长远景看清光梭来路、对撞与分开→跟入新一轮交锋并交接视点”，每镜按实际事件确定不等时长。面部特写里的判断要在后续动作兑现；远景的分开位置要成为交错跟拍起点，不把这个顺序当作每场必用模板。

## 特效与成像

选用法阵、法术或手印时，先读生成模板的[法阵](prompt-construction.md#法阵)、[法术效果](prompt-construction.md#法术效果)、[手印变化](prompt-construction.md#手印变化)，取得具体句式后接回本次交锋。局部联动可写：“{可用手}从{旧手型}经{实际过渡}变成{新手型}，{锚定位置的阵纹}由{前状态}转为{后状态}，{法术}沿{路线}作用于{目标}；对手在转印期间{逼近/绕位/受阻}，迫使施术者{继续、取消或改用已有能力}。”持械、旧术维持和在途攻击均继承上一状态。

先确定主光，再给每种效果分配来源、形态、作用与结束。选择本场需要的反馈，不逐击把所有层套齐。

| 要表达的内容 | 提示词写法 |
| --- | --- |
| 主光与能力照明 | “{环境光源}从{世界方向}投下{冷暖光}；{发光兵器/能力}靠近{人物/地面}时照亮相邻表面，移开或熄灭后附加亮度减弱，换机位不改变光源位置。” |
| 格挡、挥空、实击 | “兵器在{真实接点}相抵并偏向{方向}，{符合材质的火星/碎屑}从该处散开”；“来势从{身体外的路径}掠过，只留下{尾迹/被击中的背景结果}”；“{实际命中}使{身体/护具}先沿{冲量}响应，再借{支撑/主动发力}制动。” |
| 锐利攻击与面状防线 | “{来源}放出沿{明确线路}前进的{细束/刃形}，抵达{目标}后{穿入/受阻/偏转}”；“{防御者}在{范围}展开{屏障主形}，受到攻击时{局部形变/破口}，不无因传伤到屏障后。” |
| 环身弧与展示 | “{兵器部位}随{旋身/转腕}扫出{平面的月牙/圆弧}，弧线保留在经过的空间后衰减，细丝附着其后，不新增实体分身或传送能力。” |
| 拖尾与残留 | “新尾迹只从当前运动的{剑尖/伞沿}生成，旧尾迹留在原路径逐渐变淡；兵器反转后新弧改向，旧弧不整体跟转。能量散去，{裂口/倒木/落石}仍留在场地。” |
| 风场、碎片与尘雾 | “{持续场}在{作用范围}将{尘土/衣发/云层}沿{传播方向}带动，{人物/飞行物}按既定能力应对；{实体碎片}沿受力方向飞出再下落，{能量碎光}按设定消散。” |
| 透明气压冲击 | “{真实碰撞}后，一层近乎透明的弧形压缩前沿从{接点}向外推进；背景云纹在经过前沿时短暂折弯，{雨雾/尘粒}随后被推开，前沿离开后恢复清楚。”例：“谷中对撞后，云带先沿扩散圆面凹开，薄雾再被推成两侧翻卷的边缘；气压波自身不发光，人物借既定御空能力制动。” |
| 冲击帧与遮挡 | “先保留{来路、唯一接点与受力姿态}，再让{短闪/碎片/尘浪}扩散；光团退去时仍看见{新位置或破坏结果}。” |
| 运动模糊 | “跟拍让{躯干}相对画面较稳，{剑尖/摆臂}沿各自运动方向短暂拖糊，背景依相机运动产生视差；{静止地标}不随普通挥剑整幅横拖。” |

曝光模糊、景深虚化、场景粒子和艺术残影分开。相对相机停住后，常规拖糊不会漂散数秒；粒子可停发后衰减。快门/帧率是设置，慢放是时间处理，未支持精确控制的入口只写观感要求。圆环、寒雾和附刃亮带不自动变成传送门、承重平台与离体斩波。

### 贴附式水墨与分层反馈

用于三维人物叠手绘水墨、流体附刃或两方能力对照。先写效果贴在哪里和怎样随动作变化，再写飞白、烟丝、粒子；人物周围常驻一团浓雾会失去手部与武器轮廓。

**组织顺序：** 人物/兵器归属→贴附位置和主形→动作牵引方向→接触变化→少量离散层→局部照明与消退。

**句式：**“{效果}薄贴于{刃口/伞骨/衣甲的具体位置}，静时呈{收敛形态}；随{挥动}沿{轨迹}拉出{主色与形状}，外缘有{飞白/细丝/碎点}。{真实接触}使{局部}破开，{碎光或介质}沿{方向}散出；旧尾迹留在刚经过的空间变淡，主体和接点仍能看清。”

**例句：**“写实三维人物与雨夜石庭叠手绘水墨效果。剑客的青黑薄流贴住剑身，挥斩时青白细亮刃缘在前，后方拖出窄幅飞白墨痕；持伞者的紫灰雾沿伞骨分叉，收伞时向骨缝内聚拢。剑刃擦中伞骨后，接点先迸出短促火星，青黑墨屑顺被导开的剑路甩出，少量紫灰碎丝从受压伞骨脱落。色光只映亮近旁手指与湿袖，雨水沿各自受力方向飞散；两人的脸、握点和伞骨轮廓不被整片烟雾吞掉。”

吸收原稿的轻重差异，按**后果**选反馈，而不按固定闪帧套餐逐击套用：

| 实际结果 | 写进提示词的层次 |
| --- | --- |
| 轻擦、导偏 | 刃杆先改向，接点少量火星或短墨丝，动作立即续接；可不震屏 |
| 重压、失衡 | 护具/兵器先形变或传力，承重脚滑退/支撑破坏，再有水片、尘土或气场向受力方向散开；需要时镜头短促随冲量下沉后稳住 |
| 大范围技能命中 | 先读攻击主体和防线相撞、抵抗与胜负，再让冲击由接点扩向场地，最后远景看范围及留下的地形；闪光只占必要相位 |

主形、尾迹与粒子按可读性择用，不能用“全招叠满”盖住差异。非血腥写法可通过护甲、布料、护体光屑及身体失衡表达代价。无超自然能力时，接触结果遵循材质与受力；用户选用的水墨尾迹可作为艺术成像，不获得离体攻击或照明作用。特效色、形状、运动方式归属稳定，不把颜色混合误写成角色换技能。
