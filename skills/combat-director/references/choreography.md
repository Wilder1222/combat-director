# 交锋、战术与连续状态

用于战斗目标、近战交换、感知判断、受力恢复、持续接触、身体抓握和物件交接。详细正文由[生成模板](prompt-construction.md)组织；空间、摄影和效果的规则分别在下方专项读取中维护。按本场实际能力编排，例句是可改写方法，不是固定配方或成片成功记录。

## 目标与战术选择

先把目标转成可见终态：夺物看物件归属，护送看被保护者到达处，拖延看等待事件发生，脱身看实际通路。个人下风也可守住目标；缴械、逼退或巨敌一击落空不自动意味着整场获胜。纯演武或技能展示不补宿敌、反转或同伤结局。

主要交换改变后续选择，或使持续压力产生代价。连续占优可封掉退路、耗尽防具、逼近目标，不要求轮流翻盘。角色的距离偏好、发力/回收、可用防守和风险选择由当前兵器、体型、修为与意图决定；同门镜像可以相似，重兵也能短打，快剑也要回收。局部摄影或效果修改只呈现已有选择。

**选择例句：**“守桥者拨开来刃，追击者退开露出空隙；守桥者视线掠到身后仍过桥的同伴，收回前脚、横剑守住桥口。追击者沿栏边试探侧路，他侧踏堵口，放弃刚才的反击窗口。”护送目标须先成立，表情嵌入收步，不额外停打。

同一故事的多场战斗比较“目标、主要阻碍、结束后改变的条件”，再选打法与摄影。通过门洞、掩护撤离、切断威胁来源只是不同任务示例，不是固定顺序；保留招式回响、能力和损伤，不强制逐场升级敌人。只换场地、服色和粒子仍重复一套起手/接架/击飞时，重编缺少独特用途的一场。摄影版本保持同一事件。

### 同招变化、诱招与感知

同一招可以再次出现：首次迫退、再次被封线，或借相似起手诱出不同处理。回应依据本场可获得的起手、轨迹、声音、前次结果或已设感知能力调整，不靠“已经识破”替代过程，也不为了零重复删去指定招式。

诱招先给足以被当成威胁的表象，再写对手真实改变了什么。引走防守后利用已开放路线；对方未追挡时保留原封线，让试探者收招、改实攻或承受退让代价。两次真刺不是自动的佯攻，虚晃也不保证空门。用户已定成败时补足相应过程。

观众看到的埋伏、背后手印或画外攻势不是人物已知信息。角色可通过视线、声源、接点的力变或已设神识判断；看不见不等于完全无法感知，也不临时加透视、全知或预知。只补影响该回应的范围、遮挡和时间，不每招加内部信息表或眼神镜头。

提前防守与提前受击分开：看到起手撤步可先发生，某次碰撞造成的破损/抽动/位移发生在作用之后。先到的气流、灵压或持续束缚可以先产生结果，但来源要成立。全片静音是成片音响要求，不能自动删除已指定的剧情听觉判断。

### 变招、反转与代价

| 变化 | 执行与接续 |
| --- | --- |
| 临场变招 | 刺线被封后收肘，沿未覆盖侧线转挑；继承原剑位、距离和追击，不保证改招必达 |
| 同体系升级 | 相似起手改短来路、集中接点或调整释放顺序；说明旧防守为何不够 |
| 底牌或突破 | 已埋的备用符、能力条件或新领悟改变限制；触发、作用和代价可见 |
| 舍身反转 | 接下攻向同伴的一击，为同伴留下路线；收益与伤势分别表现，不自动受伤变强 |

反转可只抢回通路、护住目标或迫退强者。功法融合/境界差读[力量专题](powers-and-formations.md)，吟诵读[声音与表演](sound-and-performance.md)。正常速度可利用回收窗口变招；慢镜、凝滞与停格只在当前要求下使用并计时。

疲劳、伤势、已燃符箓、破盾和暂时离手兵器分别限制后招。已设疲劳应改变追距、掩护或回防，不能只喘息后完全复位；恢复机会由距离、阻挡或对手意图提供，不固定每几招同时休息，也不把人类疲劳强加给明确不疲劳的傀儡。各角色代价沿用世界设定，不擅改成另一种受限状态。

## 交锋与覆盖

### 进入近战与偏转反击

先进入当前兵器射程，再写“目标/轨迹 → 对方处理 → 接点或落空 → 受力 → 回收与下一威胁”。身体支撑和术法支撑按已设能力区分。短镜负责本相位，相连镜组交代完整关系，不要求每镜重做起收。

**句式：**“甲借地形或乙回收间隙从起点进入可及距离，支撑发力让兵器沿明确高度与路线攻向目标；乙离开来线或用具体部位接挡，把来势引向空处。甲的剑位与重心随之变化，乙沿露出线路反击；相机保留两件兵器轮廓、持手和受力位置，结尾形成新的距离或主动权。”

**交换例句：**“青衫修士踏近直刺胸口；刀客侧身用刀背拨开剑尖，顺势横切腰侧。修士收腹撤胯，刀锋仅断外层衣带；借后方石阶承住退势，回剑上挑持刀腕，刀客收肘退步避开。”实体、剑气和屏障的结果分别写，不能把擦衣转成身体受伤。

失位后可以残余招架、让空或换支撑，不能换镜就恢复完整架势。三连招可以逼防、变线、取位，不必全中；动作词的数量不等于完成交换数。

### 瞬时打击与持续推压

瞬时拳、踹、斩按“启动加速 → 可读接触 → 承力变化 → 回收/落脚与分离”组织。继续压住、持续送力属于推压或控制，只在需要维持接点时使用。换角是覆盖同一次事件，不再蓄力或释放；腿伸直顶住数秒再爆光击飞时，应核对是否误写成持续顶推。

**单击例句：**“白衣者左脚踩实、侧转身体，收右膝后送髋踹出；脚跟触及黑衣者胸前叠臂，护架压向胸口，肩背沿来力后移。白衣者立即屈膝收腿落脚，同侧全身覆盖保持到双方分离。”具体是否退飞由本场设定决定，不把重击必击飞、单镜或单招变成默认。

强调命中的局部光效、闪帧或微慢须让对应加速、唯一接点与受力可读；出招前的视觉重音仍可按[既定相位](camera-and-rhythm.md#视觉重音与触发相位)使用，不提前制造命中、伤势或破损。强效果的相位/覆盖可调整，不能跳掉整个伸展过程或用光点代替肢体作用；受击特写接已发生结果，不重演命中。诊断中暂去干扰效果不成为通用禁用规则。

### 接触相位与双方承接

擦碰、贴刃滑动、持续压抵、推撞和束缚是不同状态。成对记录双方部位、接点怎样移动、谁维持力/供能、哪些动作受限及怎样解除；不是把两人的独立姿势拼在一起。一只手在维持必要握持时不能同时做不相容动作，兼持、自主术法等明确例外按设定处理。

压力由兵器、肢体和当前支撑延续，双方可推进、后退、沿接点转向或守住通路。强弱双方不要求等幅后退，御空/阵法承载不强加地面支撑；有用途的僵持可以等待同伴完成任务，不强制每秒移动。

**持续相抵例句：**“两剑胸前斜交，青衣踏进压低刃线；红衣屈肘退步、转腕把接点导向身侧，青衣收住前倾。两刃滑到末端分开，红衣抽剑护胸，青衣顺空出的下路续攻。”后续压力可有滑动、手臂下沉或退路缩短，不反复叠起始撞击声、震屏或新爆点。

第三人或外来攻击先改变原接点/维持条件，再更新两方下一动作。主动脱开、被迫松手、供能中断各有原因；不能只释放受控者，让控制者仍保持旧力量和目标。抓控或压刃的多个接点逐项解除，结束一个不等于全局清场。

### 抓握、牵引与抛掷

抓握写谁的哪只手抓对方哪里。抓腕只限制已控制的局部，其余肢体按姿势、距离和其他控制保留可用回应；不保证任何姿势都能反击。抓衣料与抓肢体分别判断牵动、滑脱/破损，不为脱身临时让衣服断开；明确全身定身按该能力编排。

牵引、托举或共同旋转保留相对位置、接点和承重变化，抓握手随被握部位移动。提离地面要有替代支撑，首帧已托举/腾空时从当前阶段继续，不重演抓起；局部手特写不能独自证明整人已举起。

一手松开后，另一手、身体承托或绳索仍有效，剩余牵连继续。真正脱手后，被抛者沿已有方向运动再落地、碰撞或按御空制动；施力者也回收或转下一动作。仍连腕/绳的摆荡不是自由飞行。隔空摄人不补造实体抓握；指定吃力仍表现，不强迫所有法术有同样重量反作用。

普通软绳先收去松弛、形成张力才牵动物件，不能当刚性杆推移；松开手端不等于物件端解绑。例如绳只套剑鞘，收紧后鞘被牵近，鞘中剑是否随动由其当前握持/锁定决定；手端松开后鞘端连接仍留，另有解扣过程才脱离。剑与鞘分别追踪。明确硬化绳体或隔空牵引时按机制另判，不强加普通软绳前提。

### 受力后的恢复

接触结束不等于运动停止，面朝西仍可被逼向东。移镜、收剑、站直和衣摆余动分别是摄影、持物、姿态和材质现象，不能单独证明人物止住位移或恢复防守。

| 当前限制 | 解除与仍保留的状态 |
| --- | --- |
| 支撑/移动失控 | 踏步承重、借已有支点或既定御空制动；碰地不等于已承重，新踏板不凭空出现 |
| 兵器偏离封线 | 回收回防、改变封线或从当前姿态应对；身体站稳不使剑自动回胸前 |
| 伤势/装备/术法受损 | 当前代价继续限制下一招；举剑不治伤、不修兵器或补满护盾，恢复机制须已建立 |

未完全恢复仍能后退中架挡、下落中回剑或顺偏转接招，只要当前范围与姿态允许；追者不等待对方站稳。格挡、退移、失衡、受伤和施术中断分别判断，命中不自动取消一切能力。

临时改招继承兵器余势与对方行程。横斩落空后可以制动收肘转挡，也可来不及；“立即反击”不重置起手。回收窗口中的抢攻发生在回收未完时，不能先全复位再宣称利用空隙。衣料折皱、束带滞后和薄尘辅助真实发力，不逐动作凑身体部位配额。

### 兵器差异与战术连招

比较实际长度、握法、结构、优势距离、挥动/回收空间，再选争位方法。轻重、长短和服色不直接决定胜负；同门相似打法可保留。每次变招继承上一握法和落脚。

**例句：**“重杖者分手持杖斜砸右肩；剑客让出砸线，杖头触阶后从杆侧削向前手。杖客后手仍握尾，前手松开避刃，退步抽杖横隔；剑客收肘止在隔挡外，改攻未覆盖的下路。”落空、松手和横隔分别提供后招条件。

### 特殊兵器与持物交接

伞、钩、索、链及变形兵器按本场结构使用，普通纸伞不默认能承重。用哪一部位接住对象，负载怎样经过握点与支撑，卸载/解钩/换手后怎样转招都写清。

**换锚例句：**“右手索钩挂梁下铁环，双脚落稳侧台后索身松弛；抖索脱钩并收回，同一钩头才掷向前栏柱。新钩挂牢、索绷紧后蹬离，旧铁环仍在原处，左手持刀。”旧锚连接不因改招消失。

**结构转招例句：**“有锁扣的金属骨伞撑开导刃，来刃离开后解扣收伞，回肘送伞尖直刺；荡越时才以柄钩挂梁，双手承重。落上邻台、卸载后解钩，恢复右手持伞。”开、收、刺、钩有结构/占手转换，不在一瞬同时完成。

追踪同一物件，主动交付、夺取、双方共握、抛接、落地拾回各有接触/释放。共握仍是一件物品，另一手触到不等于原持有者失控；易手不必先落地，切前甲持切后乙持不能替代要求看清的过程。接收者原持物要有去处，必须连续手控的护盾先解除/转成已允许维持或另选接法；兼持、分指施术、自主护盾不套一手一用途硬规则。

实体占有与远程控制/使用资格分别判断：抓住剑柄不自动断契，被缴械者仍可能用已有空手、术法、遥控或撤离。丢落物保留位置，不下一镜复原。离手飞行与返回、指定分剑见[移动与在途攻击](movement-and-projectiles.md)。

### 机制反制与旧痕回收

先建立人物能获知的线索或裂口，再试探/逼出线路并利用。同部位留痕随所属物件移动，局部失效不自动全毁。对方可保护弱点，利用也可失败；前面强调的物件、裂口或出口可以发挥作用、失去作用或作为明确未解威胁保留，决胜时不突然添万能核心或道具。

**裂口例句：**“弧盾右下缘第一次被切出细缝，尚未闭合。攻者先虚点左肩，守者把盾转左；攻者跨步沿露出的旧缝送入剑光，右下盾片先剥落，其余仍挡胸前，守者撤步补护。”诱挡成立才利用，不把局部开口写成全身爆炸。

**机构反制例句：**“机械兽发射瓣张开才露聚光口；刀客避过首射，在下一轮张瓣时掷短刃卡铰缝。聚光外泄使机械兽停发、转身护胸；短刃留在缝中，刀客双手空出，沿侧逼近。”

连锁需已设留置、维持与触发，如三枚贴盾光钉由细线连接，合指后亮纹依次传入节点；普通尾迹不自动引爆。屏障分层、能量回收和破阵的具体条件见[力量与法阵](powers-and-formations.md)。

### 单人连招与动作签名

演武或技能展示按兵器选可接续的重心/旋向：低扫后借支撑提向斜上，转躯干由下一落脚/已设腾空承接旋击，再由余势收转，不每招返回标准站姿。练习物实际接触与没有命中分别表现，不虚构被击者。

身体、兵器与尾迹可共享旋向，不必始终同向；反转须有支撑、回弹或能力推力。服装的尾状装饰/残留不自动变为可抓取、独立攻击的肢体。光尾保持走过的世界路径再衰减，成像细则读[风格与材质](style-and-materials.md)。

### 情绪与选择

关系、法宝共鸣和结局分别决定。犹豫可偏开要害，留手可收锋，愤怒可追入深处，信任可换位掩护；事件与代价要可见，不用情感标签宣布力量升级。旧友可分胜负，立场冲突者可护第三人，敌转友无需兵器自动相生。共鸣可在已设依据下用于相互识别、互相干扰或联合增幅；“武器共鸣—无情交锋—同归同伤”只在用户关系/能力/结局适配时作为可选悲剧模式。

表演附在接架、回收或已有观察窗口中，视线有对象，微变化带出下一行动；不为面容让敌人等候，也不每招重复怒容。全景由身体选择表达，近景再读脸；具体微表情/声音见[可拍表演](sound-and-performance.md)。
