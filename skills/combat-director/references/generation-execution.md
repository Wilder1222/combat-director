# 实际生成与预算执行

仅用户要求实际制作视频、指定执行平台或任务需要真实素材接口时读取。仅写提示词不启动生成、不要求选平台或准备额外控制素材。表达适配由[视频生成适配](video-generation.md)维护，输入职责由[参考素材](reference-and-iteration.md)维护，审阅与接续由[复核流程](review-loop.md)维护；这里不绑定供应商和旧参数。

## 能力确认

从当前可调用工具说明、接口返回和官方文档核实影响本次任务的项目，不能依赖旧记忆或社区模板。已明确生成且已有授权时继续，不重复添加审批。

| 项目 | 本次需确认的关系 |
| --- | --- |
| 实际入口 | 工具存在、输入 schema、身份/连接可用；能力摘要不替代真实入口 |
| 时长、画面 | 单次范围/离散值、延长与裁切，画幅、分辨率、风格限制 |
| 镜头模式 | 单镜、多镜、自定义分镜开关实际含义；多轮攻防不自动启自动切镜 |
| 素材 | 身份、首尾帧、动作视频/音频支持、数量、标识和裁切/重构 |
| 迁移 | 当前模式传身体/表情/相机/场景，角色图与角色视频控制范围，交互是否被支持 |
| 声音 | 原生声音、对白/音效输入、关闭声音与参考音频各自支持；图片附件不推定音频能力 |
| 任务 | 编号、查询、成功/失败、结果有效期、已有任务与幂等 |
| 后期 | 拼接、裁切、变速、停格、转场、音轨；变帧率是否改时间，音频怎样处理 |
| 提示文本 | 自然顺序、粗窗、结构分镜、独立排除字段；数值是秒/帧/权重，控制边界不等于真实切镜 |
| 请求长度 | 模型与工具各自上限/单位，拒绝或截断；关键动作结局在实际发送范围 |
| 授权费用 | 本任务总额/币种、已确认花费、未结算占用、本次真实设置报价；账户余额不等于任务授权 |

视频上传不证明可复刻全身打斗，特效预设、身份、局部表情与动作迁移分别确认；动作输入支持也不证明输出接点正确。正向正文优先，独立排除字段只在当前模式支持且必要时用，官方模型建议也不能跨模式互相代替。

后期变速核播放时间与帧重采样，核最终时长；声音随画变速、保音高或另配音分别处理，只做画面变速不签音画同步。无原生音频时按已确认后期处理，不承诺原生声音；社区写后配不证明平台不能原生。口型、精确卡点、分轨编辑不凭提示保证，不自动创建/上传不需要的控制音轨。

## 提交、查询与停止

1. 将成片时间映射为平台支持的生成段，分别记生成长度、裁切/重叠与实际使用长度，不假设可延长或后期。
2. 核本次实际附件、顺序/标识和职责，重排/替换/移除后同步正文；提交真实输入，保存编号、接受状态和非敏感设置。
3. 按工具建议查询。观察超时不证明任务终止；继续核原编号，不因无新输出另开任务。明确失败读原因，确定参数错误在已有授权及余额内可修正重试一次；认证、余额、持续服务故障停止并报告准确处理项。
4. 提交超时、是否创建未知时先查已有任务或用接口支持的幂等；仍无法确认则停止，不盲目重投可能重复计费请求。
5. 成功后取得实际文件/可用链接，按已确认能力处理拼接、裁切、声音。缺对应能力则交已完成段和待完成项，不虚构 MP4 路径、成功或链接。
6. 有真实查看能力才审身份、兵器、来路、接点、法阵功能、地形、原速与音画，记录实际范围。文件取得但未看/未听分别说清，漏拍不反证文字规则有效。

进度百分比是任务状态，非成片观察。卡近完成不能归因动作缺终点，不能无证据改成停下/回起点再付费提交；先查原任务与服务错误。样片修正先具体症状、有界变量与必要依赖，用户只描述而无可看片时原因仍是假设。

## 累计预算与免费范围

每次付费提交前核当前设置报价和剩余授权。换模型、增声音、重试或新批次不重置总额，未确认退款不加回，未结算任务保留可能占用额度；上限不明不猜着提交。限定仅免费调研时，即使余额尚在也不付费，不反复请求追加。旧研究的实验额度与历史花费仅属于原实验，不继承新任务授权。

保存实际花费和任务状态时避开凭据、临时访问令牌和秘密 URL；能固定随机性、组件强度/版本/连接时记，托管未知留未知。费用记录是执行证据，不是质量证据。

## 交付状态

| 事实 | 可声明 | 仍未证明 |
| --- | --- | --- |
| 提示词、时间安排完成 | 文本完成 | 视频存在、模型兑现 |
| 返回任务编号并接受 | 已提交 | 已出片 |
| 工具成功且结果可取得 | 生成完成 | 动作、空间、声音、审美通过 |
| 实际看过并记录，声音另记听辨 | 本样片在列明范围已审阅 | 未看/未听项、其他条件稳定性 |

工具不可用或失败时交完整可复用提示词、分段、必要映射/接续与准确原因；用户仅要提示词无需环境说明。指定平台不可用不自行换平台，已有输出如实交付，不以元数据、播放回执或波形替代内容核验。
