# 战斗设置与详细正文

负责把已选动作写成自含的提交正文；任务流程与专题选择见[主入口](../SKILL.md)。用户指定格式优先；未指定时，采用独立全局栏目和逐镜中文分类标签。动作、摄影及效果描述同一条事件链，分类不增加攻击或占时。删重复内容，不删默认交付结构。

## 成稿结构

按“总长/目标与素材绑定 → 全局画面、画质与风格 → 其余稳定设定 → 分类分镜 → 目标终态与必要限制”组织：

- 默认独立列【全局画面】【画质】【风格】，把人物目标/打法、兵器、起态、能力、光照和摄影等稳定设定集中一次。身份图、首帧、动作和风格参考按实际用途绑定。
- 每镜写时间范围与镜长，每个战斗节点另有明确的起止秒数和占时；一镜内含多个节点时逐个标出，一镜一节点可共用同一时间标题。用【画面与动作】【摄影】区分事件与观看方式；从当前姿态写来路、回应、作用与变化，下一镜承接。外观、光色和规则不逐镜重抄。
- 终态由最后一个计时事件完成，保留实际余势。明确限制集中一次，并与局部慢镜、闪帧或定格等指定例外相容。

【人物与兵器】【场景与起态】【材质与光照】【摄影基调】用于有独立信息的稳定设定；【战斗特效】【声音】【衔接】按本镜需要增设，不输出空栏目。标签内可写连贯自然句，跨栏目引用当前事件，避免重复完整发动过程。用户明确要自然段、特定平台格式或其他标签时按其要求转换，同时保留所需信息。

### 任务专属的视觉与摄影设定

三个默认全局栏目各有职责，不能仅换标题后重复同一句：

| 栏目 | 具体内容 |
| --- | --- |
| 【全局画面】 | 整片的主体关系、环境层次、空间尺度、画幅及观看重点，如湖心双人御空、近水/中层人物/远阁的布局 |
| 【画质】 | 所选媒介的完成度与动态成像目标，如轮廓稳定、纹理层次、亮部细节、持手与接点清晰；分辨率等真实参数按已知入口另设 |
| 【风格】 | 基础媒介、美术语言与审美取向，如写实国漫CG、赛璐璐或水墨；保持题材与能力边界 |

全局选择要能区分这场片子的观感：按当前对象写具体表面/笔触、主光方位与明暗关系；所用术法区分作用机制和视觉主形。CG的织物、皮肤、金属分别受光，二维/水墨以线面、色阶或浓淡表达；用户选定的引擎/摄影质感词可保留，并补可见目标。

另有独立信息时写【材质与光照】【摄影基调】【特效体系】。这些是本场稳定选择，分镜展开转身、接触、释放或制动时的实际响应。效果、手印和法阵细则见[风格与材质](style-and-materials.md)、[力量与法阵](powers-and-formations.md)及[摄影选择](camera-and-rhythm.md#摄影风格与镜头形式)。

首帧已承担外观与光色时，在相应全局栏目简写继承范围，分镜集中写变化；只有身份参考时仍设计本场场景与呈现。质量标签和引擎名须有具体可见目标，不能代替画质说明；制作设置另见[渲染方案](rendering-and-quality.md)。

### 空间尺度与取景适配

【全局画面】选影响本场判断的体量、距离、高差或地标参照；各镜再按当前观看关系安排主体占比。实际尺寸、画内大小与攻击覆盖分别表达，细则见[尺度信息与取景回认](camera-and-rhythm.md#尺度信息与取景回认)。普通稿不要求把所有距离写成数字，刃长、臂距和共同地标已足够时直接采用。

占框比例说明对象与适用相位，例如开场两人全身、近战上身或盾缘局部；不把近身构图套到间距更大的远射。只有必要部位能同时入画时才采用该景别。后招依赖的小缺口或握点要在相关镜组中先看得见、再认得回；无法清楚覆盖时调整允许的取景或本场设计，不靠质量标签补可读性。

## 把交换写成动作

“拨开、闪避、反击”需要展开影响本招的关系：谁从哪条路线进入射程，以什么支撑和握法沿哪条兵器/肢体来路攻向何处，对方怎样处理，接触或让空后双方怎样受力、回收并续招。以[交锋与战术](choreography.md)维护机制细则，正文只写当前发生的事。

细节并行描述同一次动作，例如“右脚斜落同时沉髋，右肘贴肋，刀背从杆下抬起，转腕将枪尖引向北栏”。这不是四次停顿。御空换向按已设推力/控制写身体朝向、髋肩带刃和制动，不套地面踏步。专业称谓补具体执行；去掉招名仍能读懂来路与作用。演武接重心、旋向和兵器余势。

对抗按当前目标选择距离、线路与风险，必要时让一项打法在后招中产生回响。表演用“看见什么 → 怎样选择 → 身体/握持怎样变化”进入观察、接架、回收或释放窗口；所用景别须看得见。脸部特写期间来势继续，施法远景承接已发攻击。声音选择当前声源、阶段及前后景，细则见[声音与表演](sound-and-performance.md)。

### 将选定表现写进分镜

正文把“本场选择 → 已发生的动作/作用 → 可见或可听变化”编成句子。只展开当前观看任务有用的细节，分镜优先写变化而非重复“清晰、稳定、保持原样”。

资料的相容筛选、来源等级和类别转写见[资料改编](library-workflow.md)；这里核所选方案在相关全局栏目与事件中兑现，避免只有卡名或质量口号。

| 已选内容 | 同一次事件中的表达 |
| --- | --- |
| 材质与光色 | 转腕时剑面窄高光滑向刃缘，收肘挤皱袖口；已设侧光随转肩离开颊面，暗侧仍承湖面回光 |
| 术法造型 | 已选薄刃在指前形成窄亮前缘与内纹，释放后旧尾迹留路衰减；接触改变主形，局部色光随来源退出 |
| 摄影与表演 | 进身触发侧跟加速，导偏后沿外缘转跟反击；在原观察窗口由眼线转到空闲施术手，再接真正放出的攻击 |
| 环境与声层 | 已有气流压水、脚踩薄水或兵器擦栏分别产生对应反馈；关键接点居前，持续风雨居后，解除后余响与现场声接续 |

环境反应先有作用来源；战术地物若被选用，应改变通路、遮挡、支撑或选择。局部改摄影/风格沿原动作和环境条件，不为增表现临时添气流、灯光、机关或攻击。术法形态与光效不替代其来源、回应和结果。

【画面与动作】【摄影】保持默认；有独立信息时可用既有【战斗特效】【光影】【手印变化】【法阵】【眼神】【面部微表情】【空间环境交互】【声音】细项。它们解释同一事件，不要求逐镜填齐。

### 参考动作适配

按[参考适配](reference-and-iteration.md)选保留的关系与允许替换项。换兵器、体型、支撑或地形后双方一起重算射程和回应；精确复刻遵守所选范围。已有精准动作参考时写清映射和差异即可，没有动作参考时写完整动作链。

## 整场编排与生成片段

动作单元是一次改变局势的变化，镜头是切点间的视点，生成片段是一次请求的媒体。一个动作可跨镜，一个镜头可含多招；阶段、招数、镜数和请求数分别计算。

“一次连续生成”先约束生成请求数；是否允许切镜由镜头形式另定。参考含面部插入或多景别时，不直接推断为多次生成；指定一镜到底时，所有取景变化仍须沿连续可达路线完成。

先串必选事件的成立条件、实际变化与后续依赖，再安排占时和镜头，取舍可选旁支。阶段依条件变化产生，短任务可直接写一个依赖组，不必凑固定幕数。复杂度来自同窗要精确改变的关系，先删重复外观、无功能特效和冲突运镜；保留必要接近、回应、受力和回收。指定夹击或同步双挡仍同步，可通过取景和错开可选装饰降低负荷。

同窗退追、施术和旁线按共同时间推进；镜头先后展示不决定事件先后。生成、发出、抵达分开编排，按[投射时序](movement-and-projectiles.md#生成批次发出顺序与抵达顺序)核预设封路与结果驱动的后波。后招所用窗口在本次变招时仍须有效。

### 编排时间与投喂时间

默认分镜用起止时间和镜长预算，总和包含蓄势、表演、慢镜和结束余量。未知入口用总长、时间段和事件顺序表达意图；有时间控件时按其实际粒度设置。小数时码不承诺逐帧控制。

#### 每个战斗节点的秒数输出

最终复制块必须体现每个战斗节点的秒数参数，不能只在内部计划、导演稿或整镜标题中保存。节点是一次改变局势的连续交换或必要的表演、转换、收尾窗口；并行的落脚、转肩和衣料反馈可归于同一节点，不逐个拆成停顿。直接写“节点2：1.2–2.4秒（占时1.2秒）”，在其【画面与动作】【摄影】中落实发生的变化。未给分配时依事件依赖拟定；已有总长与节点时间先继承，再修具体矛盾。

同镜多节点分别列时间；动作跨镜时标明同一节点的接续区间，镜长与节点占时分别核算。同步攻防共用一个节点时间窗；确需标并行支线时写“与节点2并行”，重叠时间只计一次，不把同步关系拆成排队。秒数精度随任务，整数和小数均可，不为了形式编出逐帧承诺。

节点标题保留起止秒数与占时；战斗过程中每个有独立来路或结果的动作直接标明耗时，包括进身、闪避、格挡、反击、转向、回收和对手回应。秒数紧跟具体动作，例如“侧让0.15秒 → 拨挡0.2秒 → 进身0.25秒 → 出拳0.15秒 → 接触微慢镜0.25秒 → 收拳0.2秒”，用短促启动、接触与回收锚定速度。相互配合的髋肩、关节与衣料变化随对应动作写，不拆成额外停顿；持续控制与追逐按本场实际目的给耗时，不把所有动作统一压成0.2秒。

同时发生的攻防用“同时”或“并行”连接，并各写实际动作耗时；慢镜直接写“接触瞬间微慢镜0.2秒，随后恢复实速”。节点内不推算绝对起止时点，复制块不写“成片占时”“已含在节点内”等预算注释。串行动作总耗时、并行关系和慢镜预算在成稿前内部核对，摄影、声光与衣发反馈随同次动作推进。原动作时长、播放倍率和使用时长的计算见[时间计算](camera-and-rhythm.md#倍率停格与成片时间)。

节点、镜头和生成请求共用本段从0秒起的时间轴；所有串行节点连到总长，必读接点、恢复和终态各有窗口。独立分段另标整场对应。工程导出从既有beats的start/end生成节点起止与占时；一个section合并多个beat时仍逐一输出，作者在正文中逐动作写耗时，程序不猜分未给时长的复合动作。

总长相加正确后仍按每组依赖核准备、接近、飞行、作用、回收与终态的占时；可以并行的过程只计同一时窗，先决条件尚未成立的过程不能提前完成。短窗里需要串行完成多次换线或多项取景时，先压可选装饰、简化覆盖或重分配镜长。纯先后关系不另编无依据的精细间隔；指定精确时序则保留为意图并核实际入口。

终段从前一镜留下的距离、高度、剑位和动势继续，留出完成目标、分离、制动或落脚的必要窗口。已在前镜恢复的高度不再重复抬升；末尾结果不能只在全局设定中宣布。局部时间调整同步更新受影响的事件与切点。

独立片段从自身0秒起算，另标整场对应。共享转场只计一次，生成时长、裁切余量和成片净时长分开，计算见[成片时间](camera-and-rhythm.md#倍率停格与成片时间)。用户指定单次直出或一镜到底时保持该制作方式。

### 分镜与分段组织

阶段随局势变化产生：封线被破、能力受阻、目标转移或换区。多阶段升级应改变实际对抗条件，并继承资源、旧痕、在途攻击与未完控制；规模更大不单独等于战术升级。

多镜在动作相位切换，逐切口按[相邻镜接续](camera-and-rhythm.md#相邻镜接续)对读；只有易误接处补【衔接】或下一镜首句。指定一镜时改成镜内节拍，以连续路线交接取景。

独立分段各自带齐必要稳定设定、实际起态和开场机位，段尾交当前持物、动势与未完威胁，下一段从该相位继续。纯文字可一次写全；接已有视频时采用[实际终态](review-loop.md#实际终态与续作)。

### 视觉重音落到正文

按试探、受压、关键变招和恢复的实际用途选择观看强弱，将[相位](camera-and-rhythm.md#视觉重音与触发相位)及[临时图形和恢复](style-and-materials.md#冲击帧与闪帧)写进对应事件。摄影、效果或声音可分别承担重音，实速也能有层次；不按每击同一套餐或固定长短镜数编排。

## 正文模板

以下示范落实默认分类结构，使用具体场景而非待填字段。独立全局三项、逐镜双标签和每节点起止秒数/占时是默认交付约定；附加栏目、秒数取值、镜数和详细程度随任务变化。

### 整场多镜

~~~text
4秒，16:9，黑衣刀客穿过北侧门洞，灰衣守卫持枪拦路。
【全局画面】阴天湿石院中的双人争路，门框形成前景压迫，人物在门南空隙争位，门内石路逐渐显出可通过的纵深。
【画质】自然细节与柔和亮部，粗布纤维、刀面细拉丝与湿石反光分别有层次；快速接点阶段辨得出刀背、木杆和两方握点。
【风格】真人武侠动作电影，以实体兵器、步法与身体受力推进。
【人物与起态】刀客右手持刀、左手空闲，惯于收肘短线抢近，目标是穿门；守卫双手持木杆铁枪头长枪，依靠长线和枪尾堵口。枪头刚刺空、向门内回抽，刀客在杆南侧距门槛一步，石面覆薄水。
【材质与光照】西侧云光形成软边，门内较暗，湿石回光照到人物下侧；粗布袖口随屈肘挤皱，刀面亮边随转刃移动。
【摄影基调】在门南侧跟住争路，追近时加速，接杆时收稳，枪尾换线时转跟；切镜接当前相位。

节点1／镜1：0–1.2秒（节点占时1.2秒，镜长1.2秒）
【画面与动作】黑衣用0.2秒看向杆南侧门隙，蹬地逼近0.4秒，右肘贴肋送刀背至杆下0.4秒，沿当前来线续进0.2秒；灰衣同时屈肘抽枪1.2秒，仍以杆身隔住门口。黑衣袖口随收肘压出深褶，前脚在逼近中落下，薄水从鞋边短促甩开。
【摄影】门南中全景随进身横移加速，包含两人身体、握点与实际落脚；门柱掠后，接杆前减速收稳，沿送刀相位切同侧接点。

节点2／镜2：1.2–1.8秒（节点占时0.6秒，镜长0.6秒）
【画面与动作】刀背贴杆0.15秒，黑衣转腕向北送杆0.2秒，灰衣同时随杆偏北0.2秒；刀面亮边由刀背滑向刃缘。黑衣紧接收肘撤开刀背0.25秒，不重新摆架。
【摄影】接点近景稳住两方握点，随木杆短幅北移，沿脱开余势切回门洞。
【声音】唯一接点的短木质闷响居前，踏水与衣料声退到后层，不加巨响或金属火星。

镜3：1.8–4秒（镜长2.2秒）
节点3：1.8–2.8秒（占时1秒）；节点4：2.8–4秒（占时1.2秒）。
【画面与动作】节点3中黑衣收肘0.2秒，刀尖保持斜前下，跨槛0.4秒、落脚承重0.4秒；灰衣同时向北侧踏0.4秒、分脚稳住回拉0.6秒。节点4中灰衣转髋扫枪尾0.4秒；黑衣同时沉肩避线0.4秒，继而沿通路迈出0.5秒、随承重调整刀位0.3秒。灰衣在黑衣脱离的过程中回收枪尾并探近0.8秒；黑衣仍持原刀。
【摄影】从门南全景沿通路后退，先跟黑衣过槛；灰衣转髋扫枪尾时短幅横摇交给来势，再收稳双方位置，门内石路展宽。
~~~

### 一镜到底

保留全局分类栏目，稳定设定写相机连续起点、开放路线和终点，全镜只标一次镜长，内部标镜内节拍及每个节点的起止秒数和占时，每个节拍用【画面与动作】【摄影】。例如全镜0–4秒（镜长4秒），镜内节点沿用上例0–1.2、1.2–1.8、1.8–2.8、2.8–4秒及各自占时；这些时间不表示切镜。取景变化从上一实际机位接续；贴脸再退远有路径和占时。上述事件若改一镜，接点近景须由连续贴近取得，不能只删“切”字而保留机位跳变。

### 独立分段

每段一个自含复制块，写本段时长、整场对应、全局三项、素材职责、必要稳定设定与承接状态；每镜沿用分类标签，首段或续段均给实际开场机位。段尾状态是最后计时动作的结果，未发生的下一招留到后段。避免“同上”“接上段”代替独立请求所需信息。

## 对读与修正

| 检查 | 修正重点 |
| --- | --- |
| 交付格式 | 满足用户指定格式；未指定时全局三项独立、每镜时间/镜长与双标签齐全，无空附加栏目 |
| 全局视觉 | 全局画面、画质与风格各有本场具体内容；静态参考继承范围明确，不只写质量口号 |
| 尺度与取景 | 真实距离、占框对象和作用范围相容；高低来路、细小旧痕及相关持手能在所选镜组辨明 |
| 角色与动力 | 目标/风险是否影响打法、判断和选择；支撑或御空驱动是否进入躯干、兵器与制动，既定同门相似打法保留 |
| 视觉兑现 | 选定表面/笔触、光色及术法主形是否在实际事件中响应；阵面结构、接触变化与退出按采用范围写清 |
| 资料兑现 | 本次所选打法、摄影、场地或视觉方案具体改变哪条正文；不以卡名、检索命中或禁令代替内容，不强塞不适用类别 |
