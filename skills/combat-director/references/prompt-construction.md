# 战斗设置与详细正文

用于整场创作、正文组织、时间表达及压缩。先从[主入口](../SKILL.md)继承任务和约束，用下面的方法完成本场句子；示范变量在交付前全部替换。专项规则只在需要时读取，正文不暴露工程字段、工具名或检查日志。

## 使用方法

稳定设定写在开头，逐镜写当前变化。每镜常用【画面与动作】【摄影】【衔接】，声音、法阵、手印等有独立信息任务时再展开。栏目是同一事件的不同呈现，不是另一次攻击或新的占时；没有使用的模块直接省略，不写空标题或“无/不适用”占位。落空、失手、撤阵、消散等已发生的变化仍是有效内容，用户明确的禁止项集中保留。

### 详细动作与表演

默认交付详细可见动作，不能把“拨开、闪避、反击”的摘要当完整正文。一次交换或相连镜组落实以下关系，短镜只承担当前相位，不逐镜重复全部事实：

| 关系 | 写成具体动作 |
| --- | --- |
| 目标与招式 | 争线、逼防、取位或脱身的具体执行；招名去掉后仍能读懂 |
| 发力与持握 | 影响本招的支撑、重心、髋肩肘腕、持械手与兵器部位；术法发力按已设机制 |
| 两条轨迹 | 人沿哪条路线进退、转向和落位；兵器从何侧/高度走向哪部位、怎样偏转与回收 |
| 回应与受力 | 对手怎样接挡、卸力、避让或不及回应；哪个对象受力、何时分离、怎样影响下一招 |
| 判断与表演 | 可拍窗口内的视线对象、一两处眉眼/下颌变化以及行动选择 |
| 覆盖与响应 | 摄影实际容纳所写的部位与接点；衣发、尘水、声音和光效响应当前事件 |

细节并行解释同一动作。例如“右脚斜落同时沉髋，右肘贴肋，剑脊由杆下抬至南侧，转腕把枪尖引向北栏”，不排成四次停顿。短镜删重复外观和装饰，仍保留发力、来路及辨识接点。脚部特写不同时承诺嘴角，全景不承诺瞳孔微变；遮面用可见眼部或身体选择传达。[可拍表演](sound-and-performance.md)维护具体窗口与声音关系。

无对手的演武用重心、旋向和兵器余势接续，不强加受击者。复杂结印、变形、法阵或御空只在已有能力下写触发、轨迹、作用及结束，不能由模板栏目增加法术。

## 整场编排与生成片段

动作单元是一次改变局势的攻防变化；镜头是切点间的连续视点；生成片段是一次请求的媒体。一个镜头可含多招，一个动作可跨镜覆盖，一个片段可含多镜，不能互相直接计数。

先按用户总长与制作方式完成整场，未指定时按内容拟定；首帧已接架、腾空或带余势时从当前阶段续写。全局设定集中人物、兵器、能力、场景、素材职责与起态，图中没有的条件明确为创作设计。

### 参考动作适配

素材职责、换武器/角色/地形后的双方重算、硬约束冲突与真实控制输入在[参考素材与动作适配](reference-and-iteration.md)统一维护。文字借鉴与平台动作迁移分开；不要在正文宣称未实际绑定的姿态/轨迹控制。只把本次选中的关系落实为动作句，不让用户补内部映射表。

### 动作单元

内部逐交换明确“起态与距离、目标/判断、人物路线、身体/兵器来路、对手处理、接触/让空、受力/位移、回收与下一威胁”。同一窗内可以有侧翼支援或指定同步接点，区分先后与并发，不强制串行。持手、连接、在途攻击、伤势与地形沿同一状态链变化。

句式：“甲从起点经具体支撑/能力进入攻击范围，持械手送出明确轨迹；乙依当前姿势作出回应，在接点形成偏转/落空/承力。甲回收或继续维持，乙在新位置接下一招；环境保留作用后的实际变化。”这是一种表达骨架，不要求每招有反转或命中。

### 动作密度与取舍

先保留用户硬约束、身份空间、完整攻防、结果与必要摄影；术法反馈和情绪若承担线索、作用或选择，也属于因果。供能阵线、证明格挡的光纹、留手导致的偏锋不能因类别为“特效/表情”就删除。用户指定镜头、声音、人数、同步和接触不属于默认删减项。

| 冲突 | 调整顺序 |
| --- | --- |
| 先后与同时混杂 | 写清主语、依赖和并发；同一击的接触、受力与碎屑仍是同一事件 |
| 多路攻击相互遮挡 | 在允许范围调整站位、轨迹或覆盖，保留指定同步、人数和接点 |
| 同时争抢远景/局部/表情 | 按当前信息任务组织镜组或镜内取景；不默默牺牲指定细节 |
| 重复外观/氛围/无功能运镜过多 | 让有效素材承担已给静态信息，删重复修饰，留当前身份、空间和状态 |
| 仍超载 | 顺排或收束可选变化；制作方式允许时才分段，不删必选回应、改结局或强降速 |

不用统一字数、每秒招数或人数上限判断可执行性。核对同时变化的对象和状态：换区、变形、发射、反制、破坏、表演和摄影是否抢同一窗口。只列“高速激斗”也不说明连续交换，更多解剖名词不自动更详细。

同一份稿的公共设定只写一次；独立提交每段仍带齐必要信息，不能用“同上”或未绑定附件替代。已由正向动作表达的反向解释可删，硬限制与有歧义的约束仍保留。压缩后对照最终发送文本、附件与参数，不让关键事件只留在计划或评分说明里。

**改写示范：**“疾冲连斩、绕背结印、剑雨爆闪、旋转甩镜同时完成”可在当前破防目标下改为：“青衣踏入剑程，斜斩胸前；守卫横剑上迎，青衣顺相抵将刃线压向外侧，逼其侧踏。相机同侧跟住持手与落脚，短火星落在接点，下一击从露出的内侧来。”若结印/剑雨也是必选项，须留真实占时，不能用示范删去。

### 编排时间与投喂时间

编排稿的起止时间和镜长用于预算，小数切点表达剪辑意图。实际入口只支持事件顺序时写先后及切换相位；支持时间控件/帧条件时按已核实粒度表达和设置。未知模型直接投喂保留总长与事件顺序，不承诺逐秒/逐帧兑现。精确冻结、倍率或声画对点按[成片节奏](camera-and-rhythm.md)及实际后处理验收。

独立片段从自身0秒起算，另保留整场对应；共享衔接画面只计一次，生成时长、裁切余量和成片净时长分开。用户要求单次直出或一镜到底时，拆段拼接不能冒充满足。模型表达适配读[通用写法](video-generation.md)，真实能力/执行才读[生成执行](generation-execution.md)。

### 分镜与分段组织

先确定“本段人物要什么、阻碍是什么、结束后改变什么”，再选阶段；封线被破、能力失效、目标转移和换区是具体变化，不是固定开场/清兵/头目/大招流程。

一镜有明确观看任务，可覆盖某相位或连续多招。切点可突出抢攻、转交视线或揭示关系，不必等完整起收；前后镜接续来势、接点、受力与余势，不重演。标题写“拨枪进门”这类具体事件，不能代替正文。

逐切口使用[相邻镜接续](camera-and-rhythm.md#相邻镜接续)对读；只在容易误读处用【衔接】写“上一镜结束在什么阶段 → 本镜从该阶段继续 → 方向/空间怎样读通”。它说明已有动作，不增加停顿、重演或第二套状态账本。前后动作已自然连通时直接连写，不每镜重抄全局。

**跨侧局部例句：**“切前青衣右剑向东送出，红衣从其北侧让开，剑尖尚未触身；切后从北侧反拍，保留同一东门与双方原持剑手，画面投影随观察侧改变，青衣仍向东完成同一刺，红衣继续北移。”若用户锁定全程画面左右，就选相容机位，不能用这句许可反拍。换镜后青衣再次收剑起刺、红衣突然回原站位，是新的攻击或状态跳变，不是上述接续。

允许分段制作时选关键接点已读清、状态可承接且下一动作能起步的位置；持续追击可在运动中交接，不强停成站姿。下一段处理前段的新条件，不重做同一开场、蓄势或获胜循环。独立请求的首镜给自身起始机位，不依赖缺失前片来“切入”。

段尾的持物、动势、接点与未完威胁接入下段第一条动作；白闪/遮挡也不能掩盖身份重置或重发同一剑。纯文字多段可以一次写全并标计划接续；已有素材按[实际终态与续作](review-loop.md#实际终态与续作)处理，硬约束失败不自动接纳。

### 视觉重音落到正文

先按[视觉重音与触发相位](camera-and-rhythm.md#视觉重音与触发相位)选本段真正要读出的变化；需要效果时再用[冲击帧与闪帧](style-and-materials.md#冲击帧与闪帧)写法，不为补栏目给每击加闪光。

将“加入冲击帧”补成“当具体事件在所选相位发生时，画面暂时怎样变化，哪些轮廓/持手/接点必须可辨；随后恢复当前现场，双方按这次作用继续受力、收招或维持接点”。放进触发事件的【画面与动作】，不要另写一招；单独的【视觉重音】仅在确有独立信息时使用。指定组合则写先后与分工，指定无效果就省略。

例如强调挡住重击：“棍端压到剑身中段时，两件兵器与双方持手仍能分开辨认；暗蓝底上的浅色轮廓短促显出，短线从棍剑交点向外展开。回到院落夜色，剑客肘膝继续承力下沉，棍端随抽手离剑，双方仍握原兵器。”这是兵器格挡的呈现，不能写成剑客身体受击或另一次破防。具体用色、范围与恢复依本场设定替换。

## 全局设定与按需细项

下表合并原25项写法的实际信息任务，供作者选用；不是必填清单，不要求逐镜全部展开。稳定设定与本镜变化各写一次。

| 信息 | 写法与维护位置 |
| --- | --- |
| 整体风格、材质、光比 | 明确媒介和实际照明，继承素材；CGI/真人及效果分层读[风格](style-and-materials.md) |
| 人物、武器、能力 | 稳定称呼、实体形制/持手、身体实例与允许作用；服饰和颜色不证明能力 |
| 环境、空间、前中后景 | 共享地标、可用路径/支撑、远近层次及本镜遮挡；[移动专题](movement-and-projectiles.md)核对通行 |
| 景别、运镜、切镜 | 需要看清什么、起终机位、连续路线或切点、取景范围；[摄影专题](camera-and-rhythm.md)维护细则 |
| 行为、人物路线、身体/兵器轨迹 | 判断、目的、支撑/发力、来路、回应、作用对象、受力/回收，依[交锋](choreography.md) |
| 环境交互、命中效果 | 真实对象的接点、受力与后果；落空余势/格挡传力/破盾耗尽分别写 |
| 招式与能力边界 | 招名展开机制、轨迹、代价与结果；指定原典按[资料检索](library-workflow.md)核实 |
| 手印、法阵、法术效果 | 持物先处理，印诀/器物触发，阵面位置朝向、范围功能及解除；[力量专题](powers-and-formations.md) |
| 光影、战斗特效、动态模糊 | 来源、传播、附着与消退，保留人物/接点辨识；风格化例外有范围 |
| 时间、速度、微慢/冻结 | 镜头与动作时间分开预算，声明哪些阶段变化；[摄影与成片节奏](camera-and-rhythm.md) |
| 微表情、眼神、情绪 | 当前景别可见、视线有对象、变化有触发、随之行动；[声音与表演](sound-and-performance.md) |

### 战斗术语与动作对应

按实际机制使用中文“称谓＋执行”，不借名给不存在的动作。外文只用于查证或明确需要；流派与原著招名按[资料检索](library-workflow.md)，原创组合称谓不冒充传统秘传。

| 术语 | 必须已有的事实 |
| --- | --- |
| 进身、斜步让线、下潜闪避 | 实际进入射程、移出攻击线或从威胁下方通过 |
| 扎枪、斜撩、斜劈、横扫 | 枪尖前送线、由低斜上弧、由高斜下线或杆刃经过高度 |
| 架挡、拨挡、卸力 | 兵器角度承来势、引偏来线，或肘腕/重心承接压力，不默认持续角力 |
| 拍击对刃、压杆控制 | 前者短促作用于兵器；后者维持接点限制线路并有释放条件 |
| 防守还击 | 先化解来攻，再利用当下窗口还击，两阶段均可读 |
| 迎击/截击 | 对方仍进攻时直接攻击，处理同时到来的威胁；不借击剑比赛判罚 |
| 佯攻 | 威胁表象引出真实回应，未上当可失败；两次实刺是变线连刺 |
| 脱离换线 | 击剑语境中刃尖绕过对方兵器换线，普通抽枪/松杆不是自动同义 |
| 近身短打、剑格击腕、抢线进身 | 当前距离、兵器部位和战术目的，仍需具体路径与接点 |

拦、拿、扎的枪尖弧线按所用体系核对，不把手掌推杆叫拿枪、剑脊拨挡借名为拦枪。没有对应动作不为补术语加招。

### 摄影术语与空间对应

【摄影】写“景别/角度＋实际运镜＋路径/速度变化＋动作切点”。横移、摇摄、推拉、变焦、拉焦、眼位、过肩和动作匹配剪辑的区别在[摄影信息任务](camera-and-rhythm.md#摄影信息任务)及[摄影术语](camera-and-rhythm.md#摄影术语与空间对应)维护。参数只在有实际用途时保留，不因补称谓改变覆盖、镜数或相机路线。

## 正文模板

默认多镜整场一个完整复制块；一镜到底内部标节拍；独立片段各自自含。模板中的变量须转成本场完整句，不输出花括号、空栏目和“接上段”式缺项。

### 整场多镜

~~~text
【本段概述】目标、当前阻碍、结束后改变的条件与总时长。
【人物与兵器】稳定身份、形制、持手和必要能力。
【场景与起态】共享地标、距离、高度、支撑、动势及风格。
【素材说明】实际提供素材的职责与人物/场景对应；没有素材时省略。

具体事件｜起止时间（镜长）
【画面与动作】从当前状态发生的详细攻防、受力与新局势。
【摄影】实际景别、位置、路线和切点，覆盖所写接点与行动。
【衔接】上一动作余势怎样交给下一镜的真实起态；必要时补述。
【声音】只有独立信息时写该相位的声源及阶段。
~~~

复杂手印或法阵可另列细项；它们解释上述同一动作，不再释放一次。无对白默认不逐镜写“对白：无”。

**高速覆盖示范：**4秒三镜覆盖一次拨枪进门，也可在指定单镜中用相同节拍推进。

~~~text
追杆进身｜0—1.2秒（镜长1.2秒）
【画面与动作】黑衣刀客沿回抽枪杆南侧逼进，后脚蹬地、前膝屈曲，右肘贴肋将刀背从右胯斜送至杆下；灰衣守卫屈肘向门内抽枪。刀客视线找到门南空隙，肩线压低，不等枪尖回到双方之间。
【摄影】门南近中景横移跟拍，包含侧脸、双手和前膝，门柱快速掠后；将接杆时动作匹配切近。

一触拨开｜1.2—1.8秒（镜长0.6秒）
【画面与动作】刀背贴到杆南侧，右前臂随转腕短促向北送杆；守卫双手随杆偏北。刀客随即收肘撤开刀背，短声落在唯一接点。
【摄影】同侧接点近景保留持手和偏开的杆身，沿余势切回门洞。

越槛接追｜1.8—4秒（镜长2.2秒）
【画面与动作】守卫随偏杆向北踏，分脚承住回拉；刀客收肘、刀尖斜前下，从南侧空隙跨槛承重。守卫以新落脚转髋，枪尾沿腰高弧线带向后肩；刀客随落脚沉肩，让枪尾从肩后掠空，追击仍在继续。
【摄影】门南全景沿通路后退，门框两侧掠过，落脚与枪尾可辨，在沉肩相位接后镜。
~~~

### 一镜到底

开头写相机连续起点、路线和终点，全镜只标一次镜长；内部标签标镜内节拍，不能暗含硬切、接点插入镜头或机位瞬移。需要贴脸/拉远时沿可达路径改变取景并计时。

~~~text
本段自含设定与连续相机路线。
全镜0—总长秒（镜长总长秒）
事件｜起止时间（镜内节拍）
~~~

### 独立分段

只在制作方式允许时分段，每段自含目标、素材、人物/兵器、场景/起态，必要时写【承接状态】。独立首镜有实际开场机位和动作，不依赖未提供前片才能开始。段尾状态描述最后已发生的结果，不在末尾另加未计时动作。

~~~text
第N段｜任务｜本段时长，对应整场时间。
本段完整稳定设定与实际素材职责。
【承接状态】必要动势、接点、持物、损伤、术法、环境与未完事件。
首镜事件｜本段局部起止时间（镜长）
【画面与动作】从承接相位继续，不重发已经在途或已完成的攻击。
【摄影】给出本段起始机位，延续或明确改变观看关系。
其余事件逐镜写全，结束在本段目标时长。
【段尾状态】实际完成的局势变化和下一段起态所需事实。
~~~

## 生成顺序

锁定硬要求与全局设定，编排可达事件及状态链，按信息任务安排镜头/时间，写完整正文，再进行下列对读。既有任务只有局部变化时只改对应层，不重新发明人物、招式或结局。

## 对读与修正

- **需求与因果**：必选动作、回应、接点、结果和终态在最终正文中；招名/术语去掉后动作仍明确，实体和术法各自有去处。
- **详细与相位**：人的路线与兵器路线、支撑/发力、对手处理和回收完整；增加的是同一次动作细节，没有因分类多写一击或让全招逐关节停顿。
- **空间与覆盖**：景别看得见所写部位，摄影接回当前动作；眼神有对象，面部有拍摄窗口；阵面位置/朝向、在途攻击和未解除控制接续。
- **时间与节奏**：镜长总和正确，短镜不过载、长镜不空等，实速有加速/短促接触/抢攻而非标签；单镜没有隐藏切换，独立段自含且不重开旧局面。
- **相邻切口**：先辨接续、重看或省略，再核结束/开始相位、当前地标和方向、持物接点与余势；作用的后果不在切口提前发生或重复计算。衔接句有具体关系，不用“流畅衔接”替代。
- **范围与表达**：局部慢镜/二维等例外写回总规则，负向不否定指定局部；稳定设定不反复抄，栏目不编号、不重复、不留空。有实际用途的等时编排可保留，摄影版本不改事件。
- **重音与恢复**：触发事件及相位明确，临时效果有保留信息和退出；恢复接当前持物、受力与破损，不重置现场。出招重音不提前算命中，格挡重音不变成人体受击，图形变化不默认增加停格、切镜或场内爆炸。

硬约束真正互斥时指出具体选择，其余缺口直接修正文并重读相邻单元。对读是文字验收；时间戳、标签、结构和复核摘要不能保证模型已经实现动作。
