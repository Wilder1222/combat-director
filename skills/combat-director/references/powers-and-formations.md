# 力量、屏障与法阵

需要屏障、多层力量、功法融合、相克、境界差、巨敌或破阵时读取。发射/供能/操控中断的唯一规则在[移动与在途攻击](movement-and-projectiles.md#发出后的维持与终止)；接点、受力与目标完成见[战斗编排](choreography.md)，能量照明与残留见[风格、材质与术法照明](style-and-materials.md)。

## 屏障与碰撞结果

先明确中间物是守方防御、攻方囚阵、普通掩体还是仅遮视线的烟幕，不能凭光罩形状判为护盾。能力机制先定它阻什么、怎样传力、何时失效；再选择盾面轮廓、纹路、透明度和光色，让受压、导偏或局部失效可见。晶片、流体或网格是造型选择，作用按本场能力成立，具体呈现见[效果形态与传播](style-and-materials.md#效果形态与传播)。分别追踪来袭物、屏障、人物：开裂不等于全失效，破盾不等于攻击仍有余势或身体已被击中。

| 作用 | 必须接续的结果 |
| --- | --- |
| 阻停、吸收 | 攻击在哪里停住、消散或转化，防守余量怎样；挡住刃锋仍可向持盾者传力，后退或伤势须有对应来源 |
| 偏转、反射 | 来路、接点、新去向连续；导开不自动原路返回，返回原方向也不保证命中已移动的施术者 |
| 穿透、缺口 | 哪处失效、攻击是否仍能通过及随后去向；攻击与盾同时耗尽时，人物可无伤但失去遮护 |
| 绕行、范围传播 | 路线、覆盖区与阻挡按机制确定；范围攻击不自动穿透所有掩体，墙后受光不等于受击 |

多层防御按实际经过的层次检查，允许已设能力越过外层、透传力或只阻某类攻击，不强迫先碎最外层。需要读清胜负时安排可辨后续；用户允许在爆发中切出的结尾仍可保留，未可见的伤势和胜负不当成已验证结果。

利用旧破口时，沿所属盾面继承其移动、转向和剩余遮挡，再核破口大小、兵器穿入姿态与盾后目标的深度/高差。剑尖过孔不证明整段刚性剑身能继续转向目标；盾后目标可能仍被其他盾面或实体兵器隔住。需要威胁维持手时，在本场交代掌、盾缘与缺口的相对位置，以及通过后的可达剑线；不统一规定掌必须位于盾中心，也不让近景替攻击穿盾。

## 多重力、功法融合与蓄势

一招数重起效时，每重改变不同状态，按窗口选可辨层次，不默认九重全部展示。例如首股掌劲压弯盾缘、形成细裂；第二股震力沿裂纹扩散，使后脚滑退；末股短冲击穿过裂口，迫使弃盾侧滚。先辨接触，再看滑退与弃盾，不把同一次初触配成多个新命中。

组合功法说明各术职责、汇合点、兼容与代价：一术困住火线、另一术切断供能，形成先困后断；或已设相容的两股力量共同压同一盾。颜色混合只辨来源，不证明融合、增幅或相容。持手、媒介与维持条件要能并行，合流后继承原消耗和结束条件。

蓄势需掩体、同伴掩护、射程或先控制对方形成窗口。正面对轰服务指定较量，移动斗法可截路、绕盾、逼位、打断；强者更准、更快、更省力也能表现升级，不必扩大爆炸。主动停招、镜头慢与真正冻结分别见[动作阶段与切点](camera-and-rhythm.md#动作阶段与切点)。

## 境界压制与相克条件

境界差用投入与结果对照：全力剑气在护罩外散去，守方只转掌维持；或轻拨来刃便使攻方连退回防，守方原地守位。来源、作用点与人物结果清楚即可，不自动推导跪倒、地裂、双伤。优势只覆盖已展示能力；正面防住不证明背侧无弱点，击退不证明能阻止护送。越级脱身、夺物或护送可成功而不击败强者。

| 相克机制 | 成立线索与代价 |
| --- | --- |
| 偏转 | 正面厚、斜面可导开；转盾使剑气去空地，同时暴露侧翼 |
| 切断 | 多剑依同一连接悬停；佯攻主剑后切连接，剑失去悬停坠下并留下通路 |
| 过载 | 弱击分流让节点依次亮起；诱耗一侧后集中攻该侧，攻方也消耗储备 |
| 诱导 | 锁定追踪有已设转向边界；柱后换位引其撞障，角色承担换位风险 |

机制先在当前世界成立；允许原创时简短建立条件，不由属性名与颜色直接推出克制。

## 能量回收与转化

先明确能处理哪类来势、承接物、饱和或中断；只在影响结果时设容量。反射、吸收再释放、召唤能量回收与实体返回是不同过程。接收要有路径与可见变化，释放需真实窗口、控制动作、出口与可达目标；用尽后标记和下一招余量接续。

例：已设铜盾仅能收住正面一道雷束，雷光沿槽流入边缘，三槽依次亮满；守方侧转让后续雷流导入空地。对手收束时，盾转向已露出的门锁，扣机关让槽内电光汇成短束击断锁扣；槽暗下，人物借门通路离开。普通金属盾不会自动吸能。来源被封、储能耗尽或承接物破损的后果保留，切镜不重新满载，回收也不默认必胜或更大召唤。

## 法阵的来源、附着与范围

先确定触发/来源、当前位置与附着对象、主形与朝向、范围、攻防功能、维持和结束状态；本次涉及破阵时，再依据已设机制交代可破坏处与失效条件。遗留阵可由环境触发，无需强加现场阵主。来源、供能与位置分别判断：掌前盾可随掌或释放后定址，远方持续供能不等于追随供能者。转接附着或由随动改定址，要有动作和位置。

按本场功能选尺度参照：掌前盾可用手臂与胸腹，封路阵用出口和落脚区，巨型发射阵或法相再用楼层、山脊等共同地标交代体量与距离。外形尺寸、实际作用区和环境传播分别落句；高悬巨环可以只向桥中一道通路发束，桥旁地面只受照，阵纹很大不自动扩大伤害。画内占比与机距的观看证据见[尺度信息与取景回认](camera-and-rhythm.md#尺度信息与取景回认)。

| 常见设定 | 空间与功能 | 收束 |
| --- | --- | --- |
| 掌前盾阵 | 随掌位置/朝向，局部接挡或斜导，也会露侧翼 | 撤掌收拢或节点受击开裂 |
| 发射阵 | 定址或附武器，发射方向明确，截击/逼位 | 停新发射与已发攻击分别处理 |
| 地面封路阵 | 附固定区域，封出口/限落脚/断支援 | 节点破坏先产生局部缺口 |
| 大型剑阵 | 阵主、连接、攻击区可辨，分波逼位、主剑利用空隙 | 主剑失控、断连接或撤阵按机制收束 |

附舟阵随舟平移不自动同角转向；阵纹原地自旋不等于阵心移动或范围扩张；绕镜只换观察。目标进出范围后，按生效条件改变限制；离开减速阵解除阵法减速，伤势和地形破坏仍留。脚腕追踪环不自动定身；束缚须明确锁关节、牵制位移或已设直接定身，直接定身也不需要额外接地和实体链。

阵面或立体阵势先有用途、世界锚点、主形朝向及可辨尺度/厚度，再选少量结构：圆环、折线、扇片、网格或分立符柱各依本场造型；阵心、边缘和连接按功能采用。写明从哪里生成、哪些部分先后成形、发动时哪处响应、接触后怎样受压/导偏/破损、退出时何处收拢或熄灭。用来供能或传力的连接按机制承担作用，亮纹沿连接推进可显示对应过程；仅作装饰的纹路随主体形变即可。绕镜时阵面出现透视缩短，贴地阵顺地面高差，空中阵有高度，不能像HUD始终正对镜头；装饰自旋不是位置/范围变化，可读文字只在内容需要时写。

**发射阵例：**左手二指点东侧目标，在一臂远处出现直径一米的竖阵，阵面朝东；中心光扩内环、细线接六枚楔纹、外圈最后闭合，内环转而外圈定址。推掌使阵心发一道直线风刃，楔纹依次暗下、外圈收熄。尺寸和结构只属于这次设定，地面反馈由实际作用决定。

**盾阵例：**本次已设左掌维持正面矩形薄盾，受压传入左臂，右手剑斜护肋侧。“她展开左掌，掌前竖面先显角纹，横线连接成苍青薄盾；斜下风刃抵住上角，接点附近网线向后弯，青光沿横线压向掌根，她屈左肘、后脚滑退承力。风刃在盾上耗尽，上角留暗裂，下半盾面仍护胸腹。她侧转收掌，未损横线向掌前收拢熄灭，破角碎光在原处散去；左袖的青色受照退出，右手剑仍护肋侧。”受压、局部破损与撤阵对应不同阶段；撤阵前按余下覆盖防守，收掌后接回已有持剑状态。

人物施阵时让可用持械手、结印手与阵纹生成关系可读；双手结印前处理现有兵器，占手与自主维持见[战斗编排](choreography.md)。法令与吟诵只在需要时加入，见[声音与可拍表演](sound-and-performance.md#法令与完整吟诵)。

### 手印变化与术法联动

先确定可用手和原持物去向，再写旧手型、手指/腕/双掌位置的过渡、新手型及起阵、瞄准、释放、维持或取消的实际变化。少量关键动作串起一次施术，不逐帧罗列关节；原创指型不冒称传统正统手印，只有招名的来源不支持补造真实动作。

句式：“另一手与兵器保持现态，可用手以具体指型和掌向起印，经转腕/抬肘/分掌变为新手型，令旧阵纹或术法从原状态转为新状态；最后收印或维持，能力按已定条件停止、转交控制或继续。”

例：右手剑尖斜向右下让开胸前空间，左手在胸前并起食中指，其他指屈收；左肘前送、腕下压，二指由竖直转为平指东侧，竖阵随指向闭合。左手再展开为前推掌，阵心释放一道风刃；掌收回肋侧后阵纹熄灭，已发的自持风刃沿原线继续至碰撞消散。

双手印先收剑入鞘或置于明确位置，换到另一手只空出单手。持续手控的旧术改印时交代取消、转交或既定自持；兼持/分指例外按能力处理。中近景读脸、双手与必要兵器，指间空隙和关键手型可辨，流光不糊手；多次转印分配真实时间，对手在此期间继续追压、受阻或移动，不站等。

## 破阵的可见推理

破阵用线索、试探、窗口、利用形成因果，不用“识破”跳过依据。例：每次幻影重生前，北柱底环先亮；剑气掠环时幻影枪短暂散雾，柱基留下切口；剑修避开下一枪，趁重新凝聚沿柱外接近；剑尖沿旧切口断供能环，北侧幻影消散，剑修从缺口撤离，其余阵区仍运行。全阵崩溃另建立节点依赖，让失效沿连接传播，不统一一剑刺阵心。

旧痕回收可以是盾缘裂口、机关铰缝或实际能力节点。漂在空中的普通尾迹不自动成为连爆节点；使用光钉连锁时先建立留置、维持、连接与触发，才沿连接释放。

## 体型差、法相与异形对手

用同框或共同地标交代既有尺寸、肢体结构与移动方式。人兽、法相、机械造物按自身结构行动；局部放大不令巨爪缩小，变身或倍化写触发、前后尺寸与新攻击范围。体型、修为、力量、速度分别判断：巨兽可迅疾，小体型高修为者可正面承接，机制与反馈成立即可；已有御空不强加落地。

小者攻高处先登高、靠近降低后的部位或用已设远攻。落爪覆盖区、尾扫弧线、吐息通道明确，回应要真正离开覆盖。局部损伤只改变该部位功能，剩余肢体继续威胁；巨兽落空不等于落败。破坏只到设定会发生的范围，不每击自动全场崩塌。局部接触前让观众辨认哪只爪、哪段尾，关键变化后连回人物、巨体与可用路径，不要求每帧全身和微表情同现。

短示范：“机关巨像立在桥中，剑客只到它膝高；本例已设左腕外露细索只控制左掌开合。左掌下压封住桥中，剑客沿北缘避开掌面，趁左腕降到剑尖可及处，以右手剑削断索扣；细索脱开，左掌松开而整条左臂仍沿下压余势撞上桥面，只震松掌下桥砖。巨像右掌随即横扫桥中，剑客继续沿未覆盖的北缘退向东岸断柱；回看时左掌失去抓握、右臂仍在追扫，桥外地面与断柱未被这次局部作用摧毁。”先有本场弱点与接近窗口，局部成功再改变对应功能；同类关系也可用于普通身形对手的持械手、盾缘或机关关节，不默认增加巨大化、御空或全场毁坏。

法相的显形和新增作用绑定：可用手/器物触发，局部与尺度物同框，再揭示整体，说明投影、传力能量体还是实体召唤物及控制关系，具体部位沿可读路线起效。例如杖已放石台，双手由合掌转右掌推；门上先显巨指、再接半身，法相右掌同步前推，剑客走北侧未覆盖廊口；掌抵东墙才松裂墙砖，金纹在掌缘破散。显形不自动令脚下升空；首登预告可止于约定首击前。

## 光梭对撞与分波封路

先分包裹人物/兵器的流光与离体弹体。前者保留身体、刃锋、真实接点和御空制动，后者碰撞时人物可仍在原台；离体对撞不自动让施术者倒飞，传力需机制。投影尾迹交叉不等于三维接触。来路、同高度/空间交点、受压/碎散、主体去向与剩余状态连续；远景覆盖见[摄影信息任务](camera-and-rhythm.md#摄影信息任务)。

分波剑雨先明确来源、各波职责与怎样改变防线。例如一次凝六枚术刃，先发前三枚逼挡，侧刃导开留下左缘缺口，后三枚仍留施术者身侧；施术者看见真实缺口后，才沿该线释放余下三枚，逐次压裂局部，守方退到未封右侧；六枚耗尽、主剑仍在手、盾缺口保留。波次不自动再补满阵，也不以全部同爆抹掉作用链；生成、发出与抵达的关系见[移动与在途攻击](movement-and-projectiles.md)。
