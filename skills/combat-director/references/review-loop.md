# 观察、诊断、修复与实际续作

用于参考拆解、失败样片、有界修正和已有片段接续。观察事实先于原因判断；结构校验和创作计划不能代替视频或声音证据。素材职责与控制输入在[参考适配](reference-and-iteration.md)，实际生成操作在[生成执行](generation-execution.md)，本地帧证据在[抽帧工具](video-evidence-tool.md)。

## 素材与观察

先记录实际素材、版本/指纹、源文件时间零点、检查区间和方式，区分原片、预览、剪辑/变速/补帧结果及公开精选。只有标题、文件名、宣传或他人报告时注明来源，未实际观察的部分保持未知。

| 证据 | 支持范围 |
| --- | --- |
| 提示词/计划/工具配置 | 作者意图、实际提交及已知条件；不能证明媒体动作 |
| 静图/单帧 | 当前可见身份、姿势、形状和空间；不能证明速度、接触先后或音效 |
| 采样帧/连续帧 | 被覆盖的相位、兵器/接点及局部连续性；稀疏间隔仍可能漏瞬时接触 |
| 原速连续观看 | 在所看范围判断停顿、速度曲线、辨识负担和事件推进 |
| 实际听辨 | 所听范围的声源、内容、材质和同步；音轨/波形/转写不是听辨 |
| 工具回执/元数据 | 接受、成功、时长/规格和可取得位置；不自动获得画面或听感验收 |

全部源帧时间覆盖仍可能裁掉关键肢体、接点被遮挡或运动模糊；黑场源帧与帧表填充空格分开，帧号/PTS/图片可核对。编码像素、旋转/SAR和8位RGB转换不能单凭联系表判断原片构图、HDR高光或色彩。

按事件区分“可见、被遮挡、未覆盖、明确冲突”。观看后形成自己的观察记录；原速、连续帧、音频分别注明范围，不能由播放器状态、元数据或抽帧成功补签。

单人肢体结构、运动平滑与双人正确接点分别检查。低姿态检测置信度不直接等于身体畸变；按每人记录可见身体/肢体、漏检、跟踪身份交换和关键部位遮挡，再检查跨角色接点，不能只看较清楚一人便判双方都通过。通用运动评分不自动评价兵器与术法机制。

## 提炼参考

### 六项拆解模板

| 项目 | 提取与转写 |
| --- | --- |
| 整体风格 | 已见媒介/材质、颜色与光比、尺度和动作取向；未知渲染管线不反推 |
| 战斗人物 | 稳定身份、位置/支撑和可辨动作特点；动机未知不写成事实 |
| 武器 | 形制、握法、变形、离手/回收及交接；看不清不补新实体 |
| 技能招式 | 起点、发力、来路、回应与终态，转成本场具体关系 |
| 命中效果 | 身体/兵器/屏障/地面等实际对象、接点、受力与后果 |
| 特效光影 | 来源、主体/尾迹、路径、局部照明和消退，不从装饰环推导战斗功能 |

分析交付“观察范围、可见事件、呈现方式、可迁移关系、本场替换句、未证部分”。只拆解不编完整新故事；复刻保留用户选定身份/场景，借拍法迁移选择、姿态与视觉焦点，不复制原脸、固定镜数、帧率或整套结局。人物动作与摄影来自不同素材时重新核对距离、兵器与支撑。

多套修订时间轴不是连续分段；文字时间是计划，视频时码是观察。动画主创的意图/制作方法、实际看过画面和本项目推导分别标注，访谈或宣传图不替代拉片。幻想稿按明确御空/瞬移规则判断，不能把不需存在的中间飞行当错误；出现后持物/约束无因重置仍是问题。

## 诊断结果

逐个对应“用户请求/实际提交的事件 → 可见过程 → 结果”，标完成、未完成或未知。动作类别、结果相近和接触可读性分别判断：伸腿、屈膝过渡与膝部接触不同，对手弯身不单独证明膝撞；同一相似结果不能替两招。新启动是新攻击，换角重看同接触不重复计数；额外动作是否违规依限定次数/顺序判断。

关键词告警与文本工具输出先按主体、阶段和语境复核：某阶段静止不等于整片慢，描述接触后的力不等于提前受击；没有告警也可能遗漏不可达距离或指定接点。不按词数、查找命中或评分标签直接声明动作完成。

摄影借位与场内作用分开。用户接受影视借位时可用角度呈现剧情命中，明确落空仍不能配无来源受击；要求看清实体接触时，长焦压缩、震屏和反应不能代替接点。反应时机按本次机制，不统一延迟半拍。

输出“原时间码、观察、影响、原因假设及依据、替换正文、复测目标”。只有用户描述而无可观看素材时原因保持待验，不能把单条失败归为模型稳定能力边界。正文没回应先修编排；首帧/控制不符先查输入；实际发送不等于作者稿先查提交；这些成立后未兑现才记生成偏差。

| 症状 | 需先核对/有界修改 |
| --- | --- |
| 一脚久顶、闪帧直接伸直或接点后再爆发 | 原请求是单击还是推压；加速、唯一接点、受力与分离相位，后镜接结果 |
| 来势与火星存在、身体/兵器无变化 | 真实作用对象、握点/支撑及受力方向，不加亮光代替结果 |
| 反复接架、慢摆姿或空等挤掉后招 | 实际原速、回收中是否接招、指定交换对应、较长镜内推进；不只加高速词/镜数 |
| 脸/远景好看却路线和接点不可读 | 覆盖、距离、遮挡与相机路径；先分动作未发生还是没有拍清 |
| 结尾爆光直接宣告命中/阵毁/胜负 | 来袭物、屏障、人物各自结果；有意爆发切出的形式可保留，未见结果不验收 |
| 人物互换、持手跳变或单剑双持 | 输入/绑定/稳定称谓；追溯双手、腕臂及独立握柄，分辨鞘、尾迹、指定分化 |
| 刃长看似变化、疑似伸缩/断裂 | 邻帧朝向、握点、护手和刃尖区分透视/遮挡与真实变化；不可见端点保持未知，不能只数像素，也不能用透视掩盖明确断片/连接跳变，不强换用户锁定机位 |
| 易手复制、夺物后原术仍无因维持 | 原物共握与释放、接收手原占用、控制权和维持方式，不用结果跳变证明交接 |
| 抓腕全身僵住、松一手全部牵连消失 | 局部可动肢体、各对接点和先后释放；释放后双方继续实际运动 |
| 仍被牵住却自由移动/回收控制兵器 | 锚点、松紧、负载、可动范围与自持例外，处理实体去向和剩余连接 |
| 受力后瞬间站稳、回防或痊愈 | 移动、支撑、剑线、伤势分别恢复；允许未站稳的合法回应 |
| 裂痕保留却穿过仍堵住的通路 | 倒落阶段、剩余开口、体型/携物及既有能力；表面痕迹不强制封路 |
| 佯攻后无因空门、准确反制隐藏招 | 对手实际回应、角色可获线索/神识条件，保留未上当的封线 |
| 同脸身体增减或粒子覆盖后仍有原体 | 指定总数、来源与退场阶段，遮挡不等于消失，完整消散与遗留物分别检查 |
| 在途术法随停射或转身全部消失 | 发射、控制、供能、攻击本身结束条件分别处理 |
| 阵法随镜头漂移或自旋扩大范围 | 附着对象、地标、位置/朝向和转接；保留指定随动能力，未知不改成固定地阵 |
| 换兵器/地形后原动作接不上 | 当前长度、握法、身体、空间与用户固定范围，两方动作一起适配 |
| 首尾帧瞬移或隐含动势被反向启动 | 实际起末约束与缺过渡/互斥区别；修输入或可改过渡，不凭空加中间帧能力 |
| 控制参考像人体却不含兵刃接点 | 实际接入信号、预览、组件/连接；姿态关键点不自动包含剑刃与双人交互 |
| 动作参考末尾缺失或持续停留 | 真正送入区间、重采样/末帧延长、提交与返回时长、后处理；未知不从结果反推 |
| 声音巨响但画面轻碰/挥空 | 真正声源、阶段及有意画外/主观表达；有音轨不证明匹配，不用声音造接触 |
| 局部音频修改声称画面完全保持 | 实际是否有独立音轨处理；只能整段重生成时画面也可能变化 |
| 二维/水墨效果重演动作或重置状态 | 风格变化属于同一事件哪一相位，恢复后接持物、碎片与余势 |
| 前段已完成，后段再耗同符/发同剑 | 已完成/未完/回放的事件身份，原计划与实际采用终态 |
| 多条件一起改后归功于某个词 | 保留版本、输入、素材、可见参数、随机性、组件条件；只能比较整体方案 |

## 相邻镜切口诊断

先原速连看切点前后，定位观众在哪里失去事件或空间关系，再用切前连续帧与切后连续帧对照[相邻镜接续](camera-and-rhythm.md#相邻镜接续)。记录两侧实际可见相位与源时间，不只比较两个好看的端帧；两张姿态相似的图不能证明中间来势、接触或制动完整。

| 切口症状 | 核对与局部修正 |
| --- | --- |
| 切近后重复起手/碰撞，或动作尚未接触就跳到结果 | 对照原事件与两侧相位，先分接续、重看或省略；接续从实际阶段改写下一镜首句，指定必须可见的过程仍须覆盖。 |
| 人物突然反向或换边，难辨谁从哪侧来 | 对照人物世界路线、身体持手、当前机位与动态轴线，分真实转向和投影换边；只补缺失的观看关系，不用固定左右或镜像掩盖。 |
| 接点特写后距离/高度跳变、兵器认不回人物 | 查切前空间是否已建立、局部是否保留必要握点/轮廓、切后位置是否可达；修对应覆盖或缺失过渡，不统一给每切插全景。 |
| 切后无因换手/解除/站稳，追击或在途攻击停等 | 对照尚未完成的持物、接点与余势，核有无真实交接、释放或制动；续现有运动和威胁，修接续缺口而非重新开招。 |

遮挡、模糊或采样缺口造成的未知先记未知，不从方向相反就判违规，也不从端点相容就验收连续。区分原编排矛盾、实际覆盖不足和生成偏差，再改直接相关的动作/摄影句并复看切口；跨独立片段接续仍按下方[实际终态与续作](#实际终态与续作)采用观察状态。

## 冲击帧与闪帧的专项诊断

先原速查看重音能否被读成预期局势变化，再用连续帧核对“触发前 → 变化中 → 恢复后”。记录实际出现的事件/源时间、覆盖到的变化持续区间、前后持物与余势；未覆盖首次接触时记未知，不能凭亮帧或受击姿势推定接点。连续黑帧可能是设计黑场，也可能是片源/解码问题，先核真实源帧。

| 症状 | 核对与局部修正 |
| --- | --- |
| 闪在攻击半路、恢复后才接触 | 本来强调启动还是命中；仅后者需把触发改到具体接点，启动重音不提前验收伤害 |
| 双方剪影粘连、持手或交点消失 | 轮廓间空隙、局部明暗、兵器方向与取景；线条跟接点/来路，不用更多爆光补缺失 |
| 白闪变成额外光球、爆炸或击退 | 全屏曝光变化与场内光源是否混写；若只是画面处理，恢复时不新增传力或环境破坏 |
| 黑场吞掉必须看清的接触/解除 | 黑场前接点与动作相位是否已可读；必要时在允许的候选中撤效果查动作，不能用黑后倒退证明已展示 |
| 全段黑白、反相拖长或恢复即切走 | 局部起止、基础风格与恢复动作是否明确；回到原速核持续和反馈可读性，不只看最好的一帧 |
| 恢复后换持手、位置/损伤复位或再打一次 | 同一事件状态、破损、原运动方向及相机路径；不是仅补“恢复原色”就修好连续性 |
| 普通格挡与关键反击一样抢眼 | 本段强调层次与用户要求；按局势调整可选效果强度/位置，不删必选接触或回应 |

可比较同动作的无重音基线与单效果候选，动作已成立再按需要叠加。独立生成即使素材/参数相同，动作、机位和节奏仍可能变化；同时核这些条件，结果只支持所观察版本，不用一次更好看证明某效果普遍更强。用户指定效果组合或整场单次生成时保持要求，不为对照擅自生成、拆段或消费。

## 修复、压缩与复测

每轮优先改最有证据的变量组，固定其余可固定条件。接点需要同步改距离/取景、首帧改变需要改相应起态时联动直接依赖，不为“单变量”保留矛盾，也不改无关人物、招式和结局。联合修改不能归功于一个因素；相同种子仅在支持时用于对照，不保证确定性。

减少重复外观、无功能特效/运镜和可选旁支，保留用户指定人数、同步、接触、速度、镜头形式及终态；不能用对峙、白闪倒地或战后姿势冒充要求看清的动作。核心成立后可恢复装饰，不一律减招、降速或拆段。反复同类失败重新核查输入和归类，不原样无限重抽；要改变硬要求时给具体替代方案。

后期加速只在动作因果与连续性已经成立、仅节奏偏慢且制作方式允许时使用，并重算成片时间与声音。接点解除次序错、缺回应、兵器复制或终态未完成，不能仅靠变速修复或据加速后的观感判通过。

文字对读按[生成模板](prompt-construction.md#对读与修正)：完整动作、真实摄影、术语机制、状态、时间和授权范围。媒体审阅分别按原速节奏、连续帧接触/兵器、实际听辨验证；只看标签、分数或关键词不能验收。身份错乱、不可达作用、关键回应/终态缺失不由风格分抵消。

首次试做可验证最不确定的关键交锋，但用户要求整场单次生成时保持其方式。真实提交、轮询、重试、报价与累计预算由[生成执行](generation-execution.md)管理；不在诊断中凭任务进度猜缺动作终点或追加收费。

## 实际终态与续作

原计划、实际素材可见状态与本次采用起态分别保存。用户报告注明来源；只有文件名不算观察。纯文字多段可以按计划一次交付，不要求先生成；已有片段按下表处理。

| 素材情况 | 后段处理 |
| --- | --- |
| 结果在用户要求内 | 从实际起态补必要回收、制动或接近，更新剩余时间 |
| 结果违反身份、能力、数量、关键接触、时序或结局 | 不把偏差自动改成新设定；按授权修复或选合适素材，文字交付准确标待验 |
| 用户明确采用偏差并改变要求 | 更新后段起态与事件，保留原请求/计划和偏差，不能回写旧稿掩盖 |
| 部分看不清或未知 | 只承接有依据的事实，其他注明假设；不虚构已看过隐藏动作 |

已完成结果保留，未完攻击继续，提前发生事件仅在不违背时序或用户改要求时接纳。尾帧只能充分约束可见姿态，不能确定全部运动方向或节奏；原生延长/运动参考只有接口支持时才绑定相应上下文。

跨段仅传递当前有关项：

| 状态 | 必要内容 |
| --- | --- |
| 人物 | 身份、本体/分身及退场者、衣着损伤、伤势、意图 |
| 位置与动势 | 地标、朝向、距离、高度、移动方向及制动阶段 |
| 摄影 | 相机相对地标位置、观察方向、跟随对象，延续或明确换视点 |
| 动作阶段 | 发力、相抵、抓握、托举、回收、失衡与仍有效接点/支撑 |
| 兵器 | 实体数量、持有者/持手、离手位置、控制与返回状态 |
| 术法 | 尚存护盾/束缚、在途攻击与维持条件、阵法附着/朝向/范围及破节点 |
| 环境 | 损坏位置/阶段、通行/遮挡、水烟尘、仍在场光源与天气 |
| 声音 | 延续法令、声源/余响、配乐进退与静音范围，不重播上一击 |
| 事件进度 | 已完成结果、未完攻击/回应、后段必须保留的事件 |

## 对照记录与方法来源
