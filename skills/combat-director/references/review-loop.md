# 观察、诊断、修复与实际续作

用于参考拆解、失败样片、有界修正及已有片段接续。素材输入读[参考适配](reference-and-iteration.md)，生成操作读[生成执行](generation-execution.md)，本地帧证据读[抽帧工具](video-evidence-tool.md)。

## 素材与观察

记录素材、版本/指纹、源时间零点、检查区间及方式，区分原片、预览、变速/补帧结果和精选。只有标题、宣传或他人报告时注明来源，未观察范围保持未知。

| 证据 | 支持范围 |
| --- | --- |
| 提示词/计划/工具配置 | 意图、实际提交及条件，媒体动作另验 |
| 静图/单帧 | 当前身份、姿势、形状和空间 |
| 采样帧/连续帧 | 覆盖到的相位与局部连续性，稀疏采样可能漏瞬时接触 |
| 原速连续观看 | 所看区间的停顿、速度曲线、可读性及推进 |
| 实际听辨 | 所听区间的声源、内容、材质及同步 |
| 工具回执/元数据 | 任务状态、时长/规格与文件位置 |

按事件标“可见、被遮挡、未覆盖、明确冲突”，原速、连续帧与音频分别注明范围。即使全帧覆盖，裁切、模糊和遮挡仍可使接点未知；真实黑场与帧表填充空格用源帧/PTS核对。联系表及8位RGB转换不足以独立验收原构图、HDR高光和色彩。

分别检查各人的身体、肢体、身份跟踪与跨角色接点；低姿态检测置信度只提示需复核，兵器或术法机制需直接观察。

## 提炼参考

### 事件与镜头两遍解析

先确定借用战术、动作、摄影还是效果，选择与当前问题相对应的实际证据。

**第一遍恢复事件。** 用稳定称谓连回跨镜同一次攻击，记录起态、来袭、回应、作用与新局势，区分先后、并发、接续、重看和省略；新因果变化才记新事件，多角度展示同接点计为同一次。关键事件给源时间/帧与观察状态，结果镜保留缺失过程的未知。

**第二遍解释覆盖。** 看来路、接点、回应、恢复在哪个镜头或镜内阶段进入视野，机位揭示哪条关系；区分人物运动、相机运动与播放变速，检查切口继承或重演。关键姿态可作检索点，速度和声音分别依原速观看与听辨判断。

| 事件及源位置 | 观察 | 覆盖作用 | 本场迁移 |
| --- | --- | --- | --- |
| 一次攻击/回应/结果 | 可见与未知相位 | 视点揭示的关系、遮挡位置 | 采用的依赖/取景；换兵器、地形后重算项 |

创作者说明、当前媒体观察和本场设计推导分别表达。只有成片时提炼已见关系，只有文案时解析编排；原请求、生成次数、控制信号或成功率缺失则保持未知。

迁移时先选具体关系，如“拨偏打开内线，回收未完即抢入”，按当前身份、射程、支撑、控制与地形重写双方行动，再安排摄影。战术依赖读[交锋](choreography.md)，切口读[相邻镜接续](camera-and-rhythm.md#相邻镜接续)。单人素材支持所见身体运动；双人接点、多镜连续与局部编辑的保留项分别核查。

### 六项拆解模板

| 项目 | 提取与转写 |
| --- | --- |
| 整体风格 | 已见媒介、材质、光色、尺度与动作取向 |
| 战斗人物 | 身份、位置/支撑、可辨动作特点；未知动机留空 |
| 武器 | 形制、握法、变形、离手/回收与交接 |
| 技能招式 | 起点、发力、来路、回应及终态 |
| 命中效果 | 实际对象、接点、受力及后果 |
| 特效光影 | 主体/尾迹、来源、路径、照明及消退 |

按任务交付观察范围、可见事件、呈现方式、可迁移关系及未证部分；需要改稿时附本场替换句。复刻范围依用户选择，跨素材动作与摄影重新核距离、兵器和支撑。修订时间轴与连续分段分开，计划时间与源时码分开；幻想运动按已设御空/瞬移判断，出现后的持物与约束仍须接续。

## 诊断结果

对应“用户要求/实际提交 → 可见过程 → 结果”标完成、未完成或未知。动作类别、结果相近和接点可读性分别判断：伸腿、屈膝与膝部接触不同，弯身反应不足以证明膝撞。新起动计新攻击，重看同接点仍是原事件；额外动作依限定次数/顺序评判。

词语告警先按主体、阶段与语境复核，再看实际关系。影视借位按用户接受范围采用，指定实体接触需真正覆盖接点。交付源时间、观察、影响、原因假设与依据、替换正文及复测目标；仅用户描述时原因待验。先查作者稿与实际发送、输入/首帧、正文回应，再归类生成偏差。

| 症状 | 定位与专题 |
| --- | --- |
| 有来势/火星却无传力、接点后才爆发、受力后瞬间恢复 | 检查作用对象、唯一接点、支撑/回收；读[交锋](choreography.md) |
| 人物互换、持手跳变、易手复制、控制无因解除 | 核输入绑定及原物去向，分别追踪各握点、占手与释放；读[交锋](choreography.md)与[素材适配](reference-and-iteration.md) |
| 刃长疑似变化或断裂 | 连续帧核朝向、护手、握点与刃尖，区分透视/遮挡和真实连接变化；不可见端点保持未知 |
| 地形变后穿过堵口、牵住仍自由运动、在途术法随停射消失 | 核剩余通路、负载/连接及发射/维持/终止；读[移动专题](movement-and-projectiles.md) |
| 佯攻无因开门、隐藏招被准确反制 | 核实际回应、可获线索与后招窗口；读[交锋](choreography.md) |
| 占框比例容不下双人/高低来路，细小旧痕看不见 | 核画幅横纵范围、占框对象及细节覆盖；读[尺度与取景](camera-and-rhythm.md#尺度信息与取景回认) |
| 退追中间距突增、收尾重复抬升或瞬间停住 | 对读两侧距离/高度、真实推进量和制动来源；读[交锋](choreography.md#战术依赖与行动窗口)及[切口](#相邻镜切口诊断) |
| 剑尖穿缺口就直接抵达盾后手腕 | 核盾缘、缺口、持手深度及整段剑路的剩余阻挡；读[屏障](powers-and-formations.md#屏障与碰撞结果) |
| 总长正确却局部塞不下准备、飞行、反馈和结尾 | 按依赖组核串行与并行占时，重分配允许的镜长；读[编排时间](prompt-construction.md#编排时间与投喂时间) |
| 同脸身体增减、阵面漂移、爆光直接宣告阵毁 | 核总数/退场、阵法附着与各作用对象结果；读[分身协同](clones-and-multi-combat.md)、[力量专题](powers-and-formations.md) |
| 参考末尾停留/缺失、首尾冲突、姿态控制未含剑刃接点 | 查送入区间、重采样/末帧延长、组件连接与返回时长；读[素材适配](reference-and-iteration.md) |
| 巨响配轻碰/挥空，音频修改却改变画面 | 区分声源阶段、画外表达和实际独立音轨能力；读[声音](sound-and-performance.md) |
| 风格变化重演动作，后段再耗同符/发同剑 | 核事件身份与实际采用终态；按下方视觉、切口和续作诊断 |

### 速度慢、招少与流光慢

把反馈绑定实际覆盖位置。速度曲线依原速观看，稀疏帧只支持已见位置/姿态；实际提交未知时保留未知。

| 检查对象 | 有界修订与复测 |
| --- | --- |
| 接近、单招或招间占时 | 找进入射程、接点解除与回收遇追击的时间，减少无用途空等/完整复位，保留必要路程与反馈 |
| 相邻交换的实质变化 | 比较目标、刃线、进入角度、距离及回应后的路线，从当前姿态接变招；换镜/换招名/重看同接点不增招数，指定反复试探仍保留 |
| 流光本体与残留 | 区分人物、飞剑、剑气前端，定位越地标、缩距、接触/落空和制动，单独修慢的对象；尾迹衰减与粒子旋转另看 |
| 特写、蓄势与相抵 | 特写续判断/移动/释放，画外攻势继续；长相抵用推移、偏转、改线或脱离推进，指定蓄势/僵持按原意保留 |

按完整依赖组重排时间，再写摄影与效果；局部修复保留其他事件，整场重编标明范围。新文字仅说明修订关系可读，速度、招式和接点由新成片复测，声音另听。

### 画风画质与摄影增强复核

文字对读完整发送稿中的媒介、表面/笔触、光色、效果归属、镜头形式、路线与清晰范围，并核原身份、能力、事件及终态。风格版共享同一攻防，一镜到底核连续路线。

对照本场已经选定的表达，定位它在最终哪条事件句中兑现：角色目标如何影响取位，材料/笔触怎样随动作变化，主光与术法光何时响应，哪次攻击触发相机速度/方向或移焦，环境反馈由何作用产生，关键变化与恢复的声画主次是什么。只核适用选择，不按模板凑所有技巧。

| 文字症状 | 修复位置 |
| --- | --- |
| 全局写了精细材质，分镜只剩“清晰、稳定” | 在已有转身/屈肘/接触中补选定对象的表面或线面变化，沿实际光场受光 |
| 查到资料只列卡名/招名，或各风格仍是同一套泛句 | 按所选类别回读具体改编与必要来源，定位本场采用的动作/摄影/视觉句；读[资料改编](library-workflow.md#从候选变成此次交锋) |
| 为体现整库内容而新增能力、换场景或塞满栏目 | 对读当前用户条件与采用范围，去掉不适用候选；资料数量和引用覆盖率不是正文质量指标 |
| 两人仅服色不同，打法与表演没有目的 | 核当前目标、距离偏好、风险和判断；已设相似打法按本场保留 |
| 运镜只是跟拍/覆盖，关键判断与来势没有注意力转交 | 补已有动作触发的路径/速度/焦点关系，固定机位用镜内调度，单镜保持可达路线 |
| 术法只剩颜色与供能规则，主形/阵面变化不明确 | 展开本场采用的形态、生成、接触形变/局部失效和退出；作用机制继续接续 |
| 水纹、尘屑或环境损坏没有来源 | 回到对应接触/气流/支撑事件；缺失过程未授权时删无依据反馈，保留原场景条件 |
| 每击同样震屏/巨响，或全段没有观看主次 | 按已选关键变化调可选摄影/效果/声层，保留指定实速、静音、接点及终态 |

媒体看当前景别的材质/笔触、环境与术法光接续、关键接点遮挡、焦点和机位。锐利度、颗粒或低分辨率造型各按所选风格判断，动作正确性独立验收。观众知情与角色感知、朝向与焦点追踪、表演姿态与双人交互分别核查；原速/连续帧看剑缘、发丝、纹样及曝光闪动，色彩/HDR另核转换和显示条件，读[渲染与画质](rendering-and-quality.md)。

## 相邻镜切口诊断

原速连看切点前后，定位丢失关系，再用两侧连续帧对照[相邻镜接续](camera-and-rhythm.md#相邻镜接续)，记录源时间与实际相位。

| 切口症状 | 局部修正 |
| --- | --- |
| 切近重复起手/碰撞，或未触就跳结果 | 分接续、重看、省略；接续从当前阶段改下一镜首句，必读过程仍覆盖 |
| 反向/换边，来路难辨 | 核世界路线、持手、机位和动态轴线，区分真实转向与投影换边，补具体观看关系 |
| 特写后距离/高度跳变、兵器认不回人物 | 核空间建立、握点/轮廓与切后可达位置，修相关覆盖或缺失过渡 |
| 换手/解除/站稳无因，追击或在途攻击停等 | 核真实交接、释放、制动，接续原持物、接点、运动与威胁 |

遮挡/采样缺口保留未知，分别归类编排矛盾、覆盖不足和生成偏差，修改相关动作/摄影句后复看；跨独立片段按[实际终态](#实际终态与续作)承接。

## 冲击帧与闪帧的专项诊断

先原速判断重音，再连续核“触发前 → 变化中 → 恢复后”，记录源时间、持续区间、持物与余势。首次接触未覆盖则未知；连续黑帧先核是设计黑场还是片源/解码问题。

| 症状 | 核对与修正 |
| --- | --- |
| 闪在半路、恢复后才接触 | 区分启动与命中重音，后者移到具体接点，前者延续未触状态 |
| 剪影粘连、持手/交点消失 | 调轮廓空隙、明暗、方向和取景，线条沿真实来势/接点 |
| 白闪新增光球、爆炸或击退 | 分开全屏处理与场内光源，恢复接原作用后果 |
| 黑场吞必读接触/解除 | 查黑场前覆盖，必要时用允许的无效果候选复查动作 |
| 反相拖长、恢复即切走 | 明确局部起止与恢复动作，原速核持续及反馈 |
| 恢复后换手、复位或再打一次 | 修同一事件的状态、破损、方向和相机路线 |
| 普通格挡与关键反击同样抢眼 | 按局势和指定要求调整可选效果层次，保留必选回应 |

可比较同动作无重音基线和单效果候选；独立生成仍需核动作、机位和节奏差异，仅对所见版本归因。指定效果组合、整场生成与预算沿用户要求，操作读[生成执行](generation-execution.md)。

## 修复、压缩与复测

接触静电类场景逐节点对读：初始冲量与电弧触发是否先后成立，余电有无前次来源，衣发/尘纸/灯光各受什么作用，退光后身份、受力与道具位置是否延续。人数按既有人物及恢复状态回认，“最后一人”不能额外出生；摄影失焦或过冲不能吞去必读接点。最终复制块逐节点有起止秒数与占时，战斗动作与对手回应各有耗时，微慢镜直接标时长后续实速动作。串行、并行和变速预算在内部核对，正文无计时归属注释；被打断的动作不冒用原拟完整时长。文字通过只说明计划相容，实际媒体再核触发、连续性、速度与声画。

每轮改最有依据的变量组并固定其余可固定条件，直接依赖联动：改接点距离同时改覆盖，改首帧同时改起态。联合修改按整体方案比较，相同种子仅在支持时用于对照。

压缩重复外观、无功能效果/运镜和可选旁支，保留指定人数、同步、接触、速度、镜头形式和终态。反复失败重新查输入与归类；需改硬要求时给具体替代方案。后期加速仅用于因果连续成立后的节奏问题，并重算成片时间与声音；接点次序、缺回应、复制兵器和缺终态需修本身。

文字按[对读与修正](prompt-construction.md#对读与修正)，媒体分别验原速推进、连续帧接点/持物、实际听辨。首次试做可查最不确定交锋，整场单次生成按用户方式执行；任务、重试和累计预算由生成执行管理。

## 实际终态与续作

分别保留原计划、可见素材状态与采用起态，用户报告注明来源。纯文字多段按计划交付，已有素材按下表承接。

| 素材情况 | 后段处理 |
| --- | --- |
| 结果符合要求 | 从实际起态补回收、制动或接近，更新剩余时间 |
| 违反身份、能力、数量、关键接触、时序或结局 | 按授权修复/换素材；文字交付标待验，偏差待处理 |
| 用户明确采用偏差并改要求 | 更新后段起态与事件，保留原请求、计划及偏差记录 |
| 部分未知 | 只承接有依据的事实，其他标假设 |

保留已完成结果、继续未完攻击；提前事件按时序约束或用户新要求决定是否接纳。尾帧约束可见姿态，运动方向/节奏需过程证据；原生延长或运动参考依接口能力绑定。

| 跨段状态 | 必要内容 |
| --- | --- |
| 人物 | 身份、本体/分身/退场、衣着损伤、伤势及意图 |
| 空间与摄影 | 地标、朝向、距离、高度、动势/制动；相机位置、观察方向和跟随对象 |
| 动作与兵器 | 当前相位、接点/支撑、数量、持有者/持手、离手/控制/返回 |
| 术法与环境 | 在途作用、维持条件、阵面/破节点；损坏阶段、通路、介质与仍在场光源 |
| 声音与事件 | 延续声源/余响和静音范围；已完成结果、未完回应及后段必选事件 |

下一段首句续实际相位；拾回或再次用同招记新事件，明确回放重看旧事件则沿原消耗。分段可在运动中交接，遮挡前的必读接点仍覆盖；结构化观察与续作读[契约](contract.md)。
