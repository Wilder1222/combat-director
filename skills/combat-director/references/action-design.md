# 动作档案与名招转译

用于创建动作签名、吸收武学参考或诊断“双方像在套同一套动作”。保留用户动作顺序与能力边界；以下是虚构影视编排，不是武术谱系考证或现实教学。

## 先让人物有不同的行动习惯

每人用几句话记录：想达成的可见目标、优势距离、移动与支撑、常用起手、遇袭回应、失衡后的恢复、资源和弱点。选择一个主要动作签名，再给一项可改变的变体，不给每个角色塞满所有拳法。

例如甲习惯沿外侧小步绕位、右剑画短弧导开来刃，退路受阻时弧线被迫缩短；乙习惯直线前压、刀被带偏后踏进追回，连续追击使回收变迟。第二次相遇仍能辨认两人的习惯，第三次才利用已暴露的回收迟滞。情绪通过盯住手腕、呼吸变短、脚步犹豫表达，不要求每拍换一张夸张表情。

## 把名称拆成身体、作用与结果

转译顺序：**名称或意象 → 当前叙事用途 → 可见身体/兵器路径 → 对手回应 → 结果 → 恢复与下一条件**。招式名可保留在设计卡，最终提示词即使删去名字也应读得懂。

分别处理三个层次：

| 层次 | 处理方法 |
| --- | --- |
| 传统技法启发 | 用圆弧导引、贴身短桥、进退距离等可见原则；不把原创动作称作某流派标准套路 |
| 文学或影视名招 | 继承用户所选作品/版本的功能，缺少版本时标为创作转译；不默认拥有全套原著能力 |
| 原创仙侠能力 | 在动作之外补归属、触发、介质、范围、资源、反制和结束；外观像某名招不证明能力相同 |

以下只是本项目的创作解释，可用名称检索机制库：

| 用户提法 | 可保留的画面逻辑 | 必须核对 |
| --- | --- | --- |
| 太极剑 | 沿弧接引、顺势变线，剑和脚步共同让开攻击路径 | 剑仍在手、接触点可见、来力确实存在；不自动召出阴阳阵 |
| 少林龙爪手 | 张指前探、短暂控制衣袖或持械臂，随对手抽身改变控制 | 近身距离和空手成立；不能隔空多出巨爪或宣称历史招谱已证实 |
| 袈裟伏魔功 | 布面展开改变视线/来路，再随张力收回 | 身上确有布料且能腾手；若为结界，另立能力预算，不能无条件反弹一切 |
| 独孤九剑 | 先展示对手动作习惯，再识别空档、变线截住其兵器 | 这是文学名招意图的原创转译；看出破绽不等于必然成功，对手能变招 |
| 六脉神剑 | 指向、可辨的线状发射、避线、耗尽或收束 | 属幻想候选；先定射线数、遮挡和资源，不因名称自动无限齐射 |

详细候选见 [机制库流程](library-workflow.md)。不需要找库的短稿可以直接原创。

## 攻防链与防守恢复

每次主要交换写清发动部位/持械手、路径、接触或避让、受力方向、脚下支撑和下一起点。避免“连打六拳，对手全挡”这种无法逐项对应的概括。只保留改变局面的接触；对招数量服从总时长。

防守可分为完整架势、架势被打散、恢复中的临时回应。它们是判断视角，不是固定三拍模板。刀被压到外侧后，守方可以侧步让线、用尚可用的一臂短暂招架，等支撑脚落稳才重新组织；若没有落脚窗口，继续退让或失败。恢复用可见条件说明，不能把0.3秒或1秒写成适用于所有伤势的生理事实。

连击不强制左右交替、加入肘技或攻击多个区域。重复压同一柄兵器可以逼出脱手，数次佯攻也可以引出习惯，只要有目的、回应和变化。镜头切换不能把失衡和消耗清零。

## 镜头只突出本拍需要读懂的事

镜头描述优先说明景别、观察方向、运动路径、跟随对象及停止位置；需要精确角度时再补角度。短促接触可用中近景看持械臂，移动、腾空或落脚则保留支撑与落点。用户要求全身同框时，用构图和轨迹解决小动作可读性，不强塞特写。

建立关系 → 读清关键变化 → 看见结果，是可选的镜头目的顺序，可以在一镜内完成。它不意味着每招三次剪辑、固定机位角度或两秒换镜。正侧面、静机位和长镜头是否适用，取决于遮挡、空间和用户意图。

## 特效和强度分别设计

先写身体动作，再写额外能力。效果需要时说明来源、形状、路径、接触结果、残留与消散；布袖张力、尘土和水面反馈通常已足够表达力道。没有能量能力时不自动加气爆。

强度可来自目标紧迫、对手反应及时和恢复窗口缩短；动作密度是交换数量，速度是运动/播放快慢，剪辑是视点变化。四者不绑定。少量关键动作也能形成压迫感；快慢反差、短暂停驻、终结特效按片段目标选择，不把15秒短视频公式当成所有片段的法则。

视觉风格落实到轮廓、材质、光源、构图和运动；场景落实到地面、遮挡、支点与出口。用户说“你定”时给一个合适方案，只有要求比较或关键约束互斥时才提供选择。
