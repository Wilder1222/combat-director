# 声音与可拍表演

需要声音范围、法令、吟诵、声源/接触对应或情绪呈现时读取。人物目标、感知与情绪造成的选择由[战斗编排](choreography.md)维护；面部覆盖见[摄影专题](camera-and-rhythm.md#动态交接与局部拍法)。声音围绕已编排事件，不为普通提示词强加配乐与完整音轨表。

## 声音范围

| 要求 | 保留与限制 |
| --- | --- |
| 无配乐 | 只去掉配乐，按需求保留环境/兵器/对白 |
| 无对白 | 不自动删除环境、兵器声和喘息；法令/吟诵属于角色发声，本次另有明确要求才使用 |
| 指定角色无声 | 该角色不加台词、法令、喊叫、喘息；其他声源按原需求 |
| 全静音 | 不加任何可听声音，包括底噪；以轨迹、接触、受力和结果读攻防 |

成片静音不自动取消剧情听觉：铃槌碰铃触发转头可保留视觉顺序，成片无声音；角色感知范围仍按设定。声音要求不由通用默认覆盖，创作意图与接口原生/后期能力分开，见[实际生成](generation-execution.md#能力确认)。

## 声源与动作阶段

描述声源、材质/术法性质、阶段与远近即可，不每击堆满音层。

| 事件 | 声音关系 |
| --- | --- |
| 挥空、擦身 | 破风/衣料声；随后撞墙才是墙体撞声，不提前配成人体命中 |
| 短促接触 | 对应实际接点，剑杖、剑盾、肉身、术法盾各依材质，不全用金属巨响 |
| 滑刃、压抵、束缚 | 滑动可连续摩擦，维持术法可持续声；静止相抵不凭空刮擦，首帧已相抵不补起始撞击 |
| 分离、解除 | 相关持续声结束，已有余振自然衰减；撤盾不自动爆炸，阵法也可无声 |
| 蓄势、发射、消散 | 有用阶段绑定同一既定声源，不把一次持续压力配成多次新命中 |

画外预警、切镜后余响/声桥、主观失聪与刻意留白可有叙事用途，写清用途，不统一判错，也不替代指定可见接触。配乐强调威胁/局势/收势，不要求每次切镜卡重拍；需听清的法令与预警优先于装饰音层。声音可独立句附相应动作，最终仍完整提示词。

## 法令与完整吟诵

短法令只有本次需要时使用，明确谁说何词、伴哪次手印/出手，能在动作窗口内说完；步法、结印、短法令可并行，对手继续推进，不停战等待。手型仍可读；长句不够时调整非指定台词或编排，不吞指定招式/结果。无声施法也成立。

完整吟诵按机制绑定起颂、汇聚、释放：声起手印启动，推进中既定节点依次响应，指定末字对应放出/启动。三阶段不固定比例、不各占一镜，移动、掩护与蓄法并行。例：借柱侧移时左手结印低念“锁影成环”，末字落下，已围目标脚边的环纹收紧。是否必须念完、被打断后已发术法是否继续，按[维持与终止](movement-and-projectiles.md#发出后的维持与终止)判断，不能为念诵临时增弱点。

## 表演随攻防发生

可拍情绪以触发、视线对象、身体/握持变化与随后选择表达。受压时指节收紧、后脚找支撑；留手时剑尖偏离要害；决断时视线锁节点、主动让侧翼换窗口。已有创伤限制幅度与选择，不凭情绪新增伤势。关系由用户给定，不默认旧识、相爱相杀、共鸣或同伤结尾。

表情附正在进行的接架/回收/来势，不每个抬眼、沉肩、握紧单占节拍。当前景别看不见脸则用头转、握柄、身体响应，遮面只写露出部分；需要凝视/台词独立停顿时须已有掩护或间隔。情绪改变攻防条件的内容不按装饰删，正文压缩见[提示词构建](prompt-construction.md)。

## 制作与听辨边界

原生声音、音频参考、分轨编辑、口型和精确卡点分别核实，不能凭提示词保证。只修声音且工具有独立音轨能力时保留合格画面；若只能重生整段，说明画面可能变化，不称只改音频。听见击打而画面无触碰时先查画外声/遮挡/音效错配，不能统一补造命中。

观看与听辨范围分别记，定位声音在挥动、接触、相抵还是分离后。音轨存在、波形峰或转录不能证明听感、口型、接触与同步，未实际听辨不填音画通过。详细媒体观察与有界修正由[复核流程](review-loop.md)统一维护。
