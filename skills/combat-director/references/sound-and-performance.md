# 声音与可拍表演

用于声音范围、法令/吟诵、声源阶段和可拍表演；目标与感知读[战斗编排](choreography.md)，面部覆盖读[摄影专题](camera-and-rhythm.md#动态交接与局部拍法)。声音附着已有事件，按本次需要选用。

## 声音范围

| 要求 | 保留范围 |
| --- | --- |
| 无配乐 | 去掉配乐，环境、兵器、对白按需求保留 |
| 无对白 | 保留环境、兵器声和喘息；法令/吟诵属于角色发声，须本次明确需要 |
| 指定角色无声 | 该角色的台词、法令、喊叫和喘息均静音；其他声源沿原需求 |
| 全静音 | 所有可听声音含底噪均静音，攻防由视觉因果呈现 |

成片静音仍可保留剧情听觉：铃槌碰铃后角色转头，影片以视觉顺序表达这次感知。创作意图与接口原生/后期能力分别处理，见[能力确认](generation-execution.md#能力确认)。

## 声源与动作阶段

写声源、材质或术法性质、阶段及远近，按信息任务分前后景。先选本场哪次变化值得听见，再决定瞬态强弱、持续声和衰减；响度不增加冲量、伤势或额外命中。

| 事件 | 声音关系 |
| --- | --- |
| 挥空、擦身 | 破风/衣料声；随后撞墙时才出现墙体撞声 |
| 短促接触 | 声音落在实际接点，剑杖、剑盾、肉身和术法盾依各自材质 |
| 滑刃、压抵、束缚 | 滑动产生连续摩擦，术法依机制维持；静止相抵仅延续已设声源，首帧已相抵从持续阶段开始 |
| 分离、解除 | 对应持续声结束，余振衰减；撤盾、撤阵按本场可无声 |
| 蓄势、发射、消散 | 绑定同一声源的各阶段，持续压力保持其事件身份 |

试探与擦空可留较轻的破风、衣料和脚步，给后续关键变化留听觉余量；关键变线若伴已有兵器接触或术法释放，将对应声源的短促起音置前，脆响、闷响或持续摩擦依实际材质与动作产生。恢复时让原余振衰减，呼吸、承重脚步或下次预警重新可辨，威胁仍继续。并非每次交换都拉满，配乐卡点只落在本场选定且已发生的动作阶段，不把整场挥动排成固定节拍。

台词、预警或接点按观看任务居前，风雨、远处交锋和配乐居后；背景声成为判断线索时可转到前景。画外预警、余响/声桥、主观失聪和留白给明确叙事用途，必读接触仍由画面覆盖。声画重音可以共同落在关键变化，也可用轻声与近景突出判断；按[声音范围](#声音范围)删去不可听部分，静音版仍靠间隙、接点和恢复动作组织视觉轻重。

换镜延续原声源和时间，人物/相机移动改变远近。例：虚刺尚隔一掌时只听轻破风，画面留住尖端与防线间隙；两剑实际擦开时短金属声置前，镜内读清拨偏；分离后余振衰减，退步脚掌承重声与下一次来势重新浮出。没有触碰的试探不补金属撞声，恢复也不另加一次首触声。

## 法令与完整吟诵

短法令写谁说何词、伴哪次结印/出手及可用窗口；步法、结印与发声可并行，对手继续推进。长句按意图与语气试读，计入吸气、停连、接话和动作；未经试读标估计，窗口不足修可改台词或编排，保留指定内容。发声与身体动作共享呼吸，区分吐气发声、换气与憋气发力窗口；喘息和断句依当前受压、疲劳或掩饰意图选择。

完整吟诵绑定起颂、汇聚、释放，指定末字对应本次启动；三阶段可跨镜或与移动、掩护并行。例：借柱侧移时左手结印低念“锁影成环”，末字落下，目标脚边既有环纹收紧。是否须念完、打断后已发术法是否延续，读[维持与终止](movement-and-projectiles.md#发出后的维持与终止)；无声施法按本场机制成立。

## 表演随攻防发生

先确定人物想对谁或什么做什么：逼退、试探、隐藏意图、抢回通路。可拍表演由触发、视线对象、握持/身体变化和随后选择组成；看出口影响取路，指节收紧伴当前承压，留手让剑尖偏离要害，已有创伤限制动作幅度。

按景别选眼眉、头肩、呼吸、握柄或重心的可见项；遮面用露出部分，远景用转头和身体响应。它们随接架、回收与来势发生，独立凝视/台词窗口须有掩护或间隔。回应来自角色实际可察觉的来势、声源、力变或既定感知；多人各按观察条件行动，指定同步接点仍同步。

眼眉先动、头肩随后可表现某次判断；突袭受击也可先承力失衡，再显情绪。例：“青衣虚点赤衣肩线试探，见封门线未动，视线移向门南空隙；左脚承住退势、屈肘撤尖后换线进身。”表情和路线共同表达同一次选择。

### 身体先反应，意识后追上

本场已设反射、自主防御或觉醒机制时，分别安排身体反应、感知确认、情绪与主动选择的时间。身体可以先处理来袭并完成精准交换，人物随后才看向手或结果，出现指尖发抖、呼吸断续或肩线收紧；动作精准不自动把表情改成自信。该机制来自角色设定，普通人物仍按可获知线索和本场反应条件行动。

例如先有一次自动反击，退势与余电还在时角色低头确认手掌，惊惧由刚看见的结果触发；旁线敌人继续逼近，查看窗口随距离结束。后段主动收住动作、呼气和选定离开路线，才表达控制感变化。每个反应/确认/恢复节点写明[秒数窗口](prompt-construction.md#每个战斗节点的秒数输出)，表演可与回收并行，不把每次打击都拆成停战凝视。

接触静电的声音按同一事件分阶段：身体接点先有对应材质的短促闷响，已触发放电再有细噼啪或短嘶声，分离后余响衰减；持续细响只跟尚在的残留。无配乐仍保留本场允许的对白、呼吸、脚步和环境；强声不补未发生的第二次撞击。

## 制作与听辨边界

原生声音、参考音频、分轨、口型和精确卡点按真实入口核实。工具能独立改音轨时保留合格画面；只能重生整段时记录画面可能变化。听见击打而画面无触碰，先区分画外声、遮挡和音效错配。

观看与听辨分别记范围，把声音定位到挥动、接触、相抵或分离。音轨、波形和转写仅证明相应数据存在；材质、听感、口型及同步需实际听辨，观察细则见[复核流程](review-loop.md)。

最终正文和实际音轨各按上表声音范围检查：无对白核指定法令，角色无声核喘息/喊叫，全静音核底噪与配乐。文字检查只报告正文结果，媒体静音与音画匹配按实际听辨验收。
