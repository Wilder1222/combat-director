# 移动与在途攻击

需要轻功、御剑载人、御空、瞬移、换区追击、地形通行、飞剑返程或停射时读取。近身接点与持物交接由[战斗编排](choreography.md)维护；屏障和法阵作用见[力量、屏障与法阵](powers-and-formations.md)。移动、人物状态与兵器归属使用同一事件事实。

## 移动方式与持续追击

先按本场能力选择移动方式，再检查可达路径。仙侠身份不自动获得瞬移，现实落脚规则也不取消已设御空与空中变向。

| 方式 | 必须接续的关系 |
| --- | --- |
| 轻功借力 | 从哪个支点离开、越过什么、何处再次借力；树梢、水面或云阶是否承载由设定决定 |
| 御剑载人 | 人与承载剑一起移动；原剑离脚前，先有其他已有支撑、明确的腾空回落或已允许的御空切换 |
| 御空或悬浮 | 用身体朝向、术法响应交代高度、转向和制动；不强加踏板、地面落脚或足下法阵 |
| 瞬移或空间通道 | 原位置、触发、允许到达处、出现后的朝向、持物和威胁连续；共同地标交代换位，无需补造中途飞行 |

能力只放宽它实际控制的条件；瞬移不顺带解除锁链、治愈伤口或穿过未获允许的屏障。例如只能在两块已触亮的石印间换位时，人物由旧印消失、在新印朝桥口出现，右手原剑和肩部裂甲保持，追来的刃风继续撞向旧位置后的石栏。石印只是该例设定，不是瞬移通则。

追逐要有速度、路线、高度与制动变化。攻击迫使前者转向、降低高度、借物遮挡或反击，后者据此截近。由追逐转近战必须解释间距怎样缩短：加速、减速、折返、截路或已有攻击范围变化。同向同速、间距不变时，短兵器不能突然够到前者；可继续远程施压或保持未追上的结果。迎面接近后按路线处理错身、回转或并行，不自动变成持续贴身，也不为凑下一招无因悬停。

例：前者靠近桥墩时收小御空推进，绕墩内侧减速折返；墩体短暂挡住后者视线，后者仍沿墩外追入，间距缩至一剑可及。前者绕回墩边，见后者尚未回正右肩，便从已收住的剑位刺入；后者压剑拨开来刃，借相抵偏转飞行方向，双方从桥侧进入峡谷。桥墩在本次用于遮挡与迫使绕行，两人仍由御空承载。高速段可用头部转向、失衡与握柄表示判断，不必另停下来拍表情。

人物换位与相机造成的画面换边分别处理，见[方向参照](camera-and-rhythm.md#方向参照与换机位)。背景拖糊、衣袂飘动和镜头推近都不能独自证明缩距。空中急停须有本场移动方式允许的转向、制动或术法响应，不瞬间复位。

### 流光速度与追击本体

先辨认流光前端是谁：包裹人物的护体光梭、离手实体剑、脱离剑气或装饰残光，各自沿已有机制运动。速度写在本体短时越过地标、间距急缩、偏转后的去向与制动中；尾迹留在已经走过的世界路径上衰减，不能只让长光带、粒子或相机移动。本体不可辨或被爆光遮住时，接后续可见位置，不据尾迹推算实际速度或命中。

**御空例句：**“湖心上空，两人各被贴体光梭包裹，剑与持手仍在梭头内；白衣从近侧阁楼投影线疾冲向湖心，黑衣迎面截入，间距迅速缩到剑程。两剑相碰后，白衣右肩顺来力转开、屈肘收剑，两人分别沿错开的斜弧掠出；护体梭壳剥散，旧光轨仍留在来路淡去。白衣转髋带肩，以御空推力减缓外掠余势再折返，黑衣循原斜弧回正剑尖，追向她的新路线。”碰撞、错身、制动和再追分别成立，不把一段持续亮带当多次撞击，也不补地面落脚。

若只是离手飞剑慢，应修它的发出、飞行与偏转，不同时加快人物；若首帧锁定远距起态，接近须有真实占时。没有瞬移能力时保留可读的通行过程，不能为求快直接消失、换位或省掉用户要看清的回应。

## 地形变化与通行条件

从本场已有地物中选真正影响目标或路线的用途，如桥口限制并进、石柱遮身并迫使绕行、狭阶缩小长兵器回收空间；把位置与用途兑现为一次选择或路线变化，不给普通地物追加机关、能力或必然破坏。

自然反馈跟随实际来源与路线：剑尖擦水时，水线沿刃弧裂开后回落；脚底制动擦尘时，尘痕留在原支撑面。水纹/尘痕、真实承重、视线/攻击遮挡和控制连接分别判断：擦水不等于水面能承载，扬尘未必浓到遮身，遮视线未必挡刃；只有已设绳索、牵引或供能机制才形成相应连接，连成线的水花、飞尘或光尾不自动控制物件。石粉、浅痕也不自动等于塌陷、封路或滑倒。损坏保持，通行未改变时允许直接通过；雨雪与泥水不覆盖用户指定的稳定步法和已有能力。

**环境例句：**黑衣借已有石柱切断对方的胸前刺线，退脚踏住柱后石地转胯，从左侧绕出；制动擦起的薄尘沿旧退路散开，地面仍稳。白衣在柱右未见目标，待黑衣肩线从左侧露出才收剑改追；石柱继续挡住穿柱直线，薄尘未形成遮身烟墙。低空交锋中若剑尖擦出水线，人物仍由已设御空承载与制动，水线只反馈擦水路线。

影响后招的地物才交代位置、范围、倒落阶段与剩余开口。破裂、倒下、清空是不同状态；斜抵门框的碎门仍可能挡路。倒落方向与落定位置按共同地标延续，不随切镜消失。下坠物能否借力按既有承载与移动规则判断，不另造悬浮踏板。

通行须对照当前体型、携物、兵器姿态与缺口。剑尖穿缝不代表身体能过，空身侧过不代表背宽匣或横持长枪能过；需要时收拢兵器、走已有出口或用已设空间能力，不能暗中缩物、丢物或增门。遮视线、拦攻击、承重分别判断，烟墙和裂口不默认拥有三种功能。地面路径失效不自动封死仍可用的御空路线；只传递后续需要的变化，不给每片碎屑追加战术用途。

## 换区与支撑接力

在庭院、回廊、楼层、屋顶等区域间移动时，先把支撑物排成可达路线，让一次攻击改变其中一段，后招利用或绕开变化；短片不必塞满全部场地。水下、真空、晃动甲板另按设定确认推进、介质与支撑。

可写：横扫击断回廊护栏；持伞者用已设能承重的伞钩挂住独立吊链，沿缺口荡入大殿。追击者踏过断栏落到石地追近；持伞者在摆荡高点踹向铜钟下缘，钟体绕完好的吊点摆过，追者下潜避让。持伞者回荡到侧台，双脚承重、卸载后解钩。原栏口、铜钟摆向、双方落点都接续。

裂砖影响制动、断栏迫使换路、梁体失效造成坠落、新区暴露威胁，可以形成尺度递进；每级都有失效与回应，不由裂一砖自动升级为整山崩塌。摄影用近景读接点、全景读迁移、远景读范围，见[摄影与成片节奏](camera-and-rhythm.md)。

## 离手兵器与返回路径

浮石接力另分脚-石接触、石与人共同托升、人物蹬离和下一支点。仍站同一块上升石面是托升，不能称连续踏过多石；真正连续踏石要有每次离石及新的落点。已设御空、悬浮承载或术法改变推进时按其作用处理，不能为凑地形接力强补现实落脚。

分清实体飞剑、投射剑气和残影：实体占用已有物件，剑气飞出后原剑可仍在手或脚下；视觉残影不自动承载或伤害。在分化、发出、阻停、返程、再握持等关键处更新状态，不每个短镜都重复清单。

指定分剑时，写原件是否保留、另外形成几件以及承载、攻击、封锁职责。例如原剑留脚下、另化四柄术剑攻四节点，共五柄；五柄全飞走后补御空仍违反原剑承载要求。明确分化不能被全局防复制规则删去，数量正确也不代表职责正确。

离手攻击保留出发处、目标、偏转或落空后的去向、返程通路与再次握持/承载时机。被拨偏后从新方向继续，不无过程回手。直射、遥控转弯、自主追踪、空间召回分别按本场能力处理；控制距离、注意力和障碍限制只在实际冲突涉及它们时补足，不统一编数值。

主人绕柱或同伴进入返程路线后，飞剑须改道、受阻或使用已有空间能力，不能以亮轨掩盖穿体穿墙。链、绳兵器保持连接端、松紧和回收，不能按自由飞剑瞬时换向；换锚与卸载见[战斗编排](choreography.md)。出画不等于销毁、回手或失去控制，重新出现须与路径、占时及机制相容。

### 生成批次、发出顺序与抵达顺序

生成批次说明哪些投射在同一次形成及其总数，发出顺序说明谁先离开来源、发向哪里，抵达顺序说明谁先到接点；三者不必一致。同批生成不等于齐发，未发者留待后发须有已有发射器、容器或维持机制支持，不为分波补造悬停或自持。先发者也未必先抵达：不同速度、路程与可用路线会改变先后，按真实飞行接续，不以镜头呈现顺序代替。直射物不能为赶上后波临时绕障或转弯。

前波结果决定后波目标、方向或发出时机时，先有施术者看见或获知缺口、偏转、退路变化，再发尚未离源的后波；已设触发机制则按它能感知的条件启动。已经发出的后波若需改向，另依本场已有操控能力成立，不能用“随后追入缺口”暗添遥控。预先固定两侧封路时，保留原定发向与时序；目标恰好被逼进其中一路，不把先排好的攻击写成看到前波结果才临场改变。

高低封路以目标处的穿越高度核对，生成点的上下关系不单独证明会命中下沉后的胸位；一起核发向、目标原高度、避让量及飞行期间的移动。短距快袭时，回应可从可见起手提前启动，须在来袭抵达前完成相应避让/封挡；不靠“瞬间”省掉飞行与动作窗口，也不要求普通稿虚构精确速度或发射间隔。

**分批例句：**本场已设发射阵能同批凝六枚术刃、留阵分次直射，施术者右手原剑不离手。前三枚一起击中定址薄盾左缘，三处受压连成缺口，术刃都在接点耗尽；守方见开口向左撤。施术者看见裂口与撤步后，再将余下三枚沿三条穿口直线一起发出；守方收住左脚改退未封的右口，三刃越过左侧退路，先后撞在左廊后墙耗尽。阵中余刃清空，薄盾其余面与左缘缺口保留。分波作用见[光梭对撞与分波封路](powers-and-formations.md#光梭对撞与分波封路)，阵内留刃只属于本例已有机制。

同一投射换镜、慢放或回看仍接续同一次发出与飞行，不因多角度重看复制数量或重复扣除同一次生成、发射的消耗；持续维持若仍在进行，按已有机制计算。画外同波继续推进，不能把每枚投射都排成守方依次处理的单挑；确有逐枚发出、阻停或回收时，才分别交代对应过程。

## 发出后的维持与终止

施术者转身、改招、被打断或出画时，分别判断改变了发射、操控、供能还是攻击本体。

| 已建立机制 | 中断后的结果 |
| --- | --- |
| 脱离后自持投射 | 停射只停新攻击；已发剑气/符矢继续，直到受阻、到达去处、耗散或满足终止条件 |
| 持续供能的光束、盾或束缚 | 供能断后按设定衰减、解除或崩散；已脱离供能链的部分另判 |
| 遥控实体兵器 | 控制中断影响转向、推进、悬停的方式按机制决定；原物仍需有继续飞行、下坠、被截住等去处 |
| 自主追踪、印记或预置阵法 | 按既定锁定、触发与终止运作；换姿势或遮视线不自动失效，也不自动获得穿墙、绕障或友军识别 |

注视、手印、连续供能与自主维持均来自设定或明确采用的假设，不临时添加弱点。指定撤手后全部投射立刻散去时保留；只停新发射时不顺带清场。收束分别对应停射、断控制、在途攻击去向与真实地形残留；仍有效的投射可作为下一段威胁，淡去的装饰尾光与攻击本体分开。
