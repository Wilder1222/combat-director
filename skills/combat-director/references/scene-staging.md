# 场景先于交手

场景不是风景形容词。先决定人物能从哪里到哪里、有什么可挡可踩、环境改变后还有哪些选择，再排动作。可继承 CineWeave 的场景与视觉设定，但本技能独立完成同样工作，不要求另装技能。

## 最小场地卡（导演层）

- 区域与连接：起点、交锋区、出口或落点；相邻区域通过什么实际路径连接。
- 尺度：交锋距离、纵深、高差，以及人物与建筑或巨大攻击的比较物。
- 材质与状态：地面摩擦、承重、积水、裂口、可破坏物；哪些已经损坏。
- 视野：柱、墙、雾或悬崖如何遮挡；人物与摄影机各自能看见什么。
- 光线：稳定主光方向、环境亮度、空气状态；法术只在发生时局部照亮人物与材质。
- 可走路线与机位：人物路线和相机路线分别检查，不能穿墙或用相机运动代替奔跑。

不必把整张卡塞进提示词。只传入当前段影响动作、构图、光照与连续性的部分。已有 Combat Plan 可在 anchors、headers.scene、initial_state.environment、beat 环境和机位字段记录；不要增加未获 schema 支持的字段。

给出具体距离后，逐段核算它是否仍成立：双方后退/前进后的间距，刃长加身体位移是否够到目标，飞剑绕后或绕柱时距施术者是否越界，回程是否仍可控。相机靠近不缩短角色间距；六米外的一步挥刀不会因写了“巨刃”就自动命中。先移动到攻击距离，或让该击明确落空，不能悄悄放大武器与能力。没有必要时不用精确米数，但仍要解释跨距离的过程。

## 环境事件必须形成因果链

使用“原状态 → 攻击或移动造成变化 → 留存状态 → 下一步选择”：

| 环境 | 可见事件 | 战术后果与留存 |
| --- | --- | --- |
| 云海石台 | 刀芒劈开中央铺石，碎石坠向云海 | 对手沿完好的外缘绕行；裂沟后续仍存在 |
| 柱廊 | 飞剑削断既有石柱的上部 | 对手穿过相邻完整柱间躲避；断柱继续倒落，不自动复位 |
| 积水庭院 | 横斩逼出后撤，脚步搅起水纹 | 湿地制动距离影响落脚；水花方向来自脚步而非全场爆炸 |
| 风雾山道 | 剑风推开一条雾隙 | 原被遮挡的对手进入视野，反击有观察条件；风停后雾逐渐回填 |

环境不必每拍破坏。利用旧裂沟、柱后遮蔽、台阶高差同样构成参与。换场景时重排路线、接触、遮挡、材质反馈与机位，不能只换地名。

## 大场面与光线

用人物大小、石台宽度、山体纵深与运动视差建立尺度；选一个承担剧情的主升级，不要求漫天剑雨、巨剑、龙卷与法相同时发生。近身接触要看清兵器；巨大攻击要看见来源、路径、目标、回应和结果。广角不自动证明大场面。

光照跟随同一事件：刀芒经过时，黑金衣袖与石面短暂被暖光扫过；消散后恢复原主光。雾、尘、水与光改变可见性时，下一镜继承；不能靠白闪隐藏命中或突然换位。

复核：破坏了原落点后是否仍落在原处？断开的路径是否仍被直接跑过？光源是否无因换向？尘雾是否把需要验收的接触全部遮住？
