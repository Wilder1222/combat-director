# 参考素材与动作适配

需要多图、分镜拼图、首尾帧、动作/运镜借鉴或实际动作迁移时读取。本文维护素材职责与输入适配；样片观察、计划/实际/采用状态及修正变量统一在[复核流程](review-loop.md)，提交核验见[实际生成](generation-execution.md)。普通文本任务无需生成额外素材。

## 素材职责与互补

| 职责 | 采用信息 | 不自动继承 |
| --- | --- | --- |
| 身份、兵器 | 稳定外观、实体道具、持握特征 | 静态姿势成为全段起点 |
| 首帧 | 位置、朝向、支撑、接触、已发生动势 | 与图矛盾的默认站位 |
| 末帧 | 指定空间关系或姿态 | 自动换位、回剑、完成中间路径 |
| 场景 | 地形、支点、障碍、光线 | 不相关角色身份或遮挡后的新出口 |
| 动作 | 路线、发力起落、对方响应 | 外观、全套剧情、固定招数 |
| 材质、完成度 | 指定表面、细节、清晰程度 | 未指定配色/道具/能力；“质感”不自行决定信息范围 |
| 运镜 | 相机路线、景别变化、跟随关系 | 全部人物动作和故事 |
| 局部视觉效果 | 选定事件的触发相位、轮廓分离、明暗变化与恢复方式 | 整片换风格、固定帧数、额外命中或场内爆炸 |
| 分镜拼图 | 指定格序、事件、需保留构图 | 多格变同步多人，格数变成已实现镜数 |

同一素材可多职责，分别记控制范围；三视图通常一个身份，明确分身时剧情提供身体数，同图可约束多具同貌身体。未收到/未查看图，不把文字推测记为观察。身份图不是必然首帧，有首帧则由当前姿势进入动作，不重建已经确定的外观。

### 参考方法的保留与替换

用户要求借鉴、适配或复刻具体案例时，先按目标关系选本次主要依据：双人接招要能读双方作用，追逐要能读相对路径，群战要能读多人职责。相同题材/风格或“人物一致”的句子不能单独证明相应运动关系。需要多个来源时按动作、身份、摄影、风格各自职责采用，沿用用户优先级，不强制所有任务只用一个案例或把不同关系平均成新风格。

| 作者内部约定 | 写清什么 |
| --- | --- |
| 已读与已见 | 指定素材/版本/区间，原提示词、作者原片、平台复测及后处理分别标明；截断摘录不冒充全文 |
| 保留 | 具体路线、攻防依赖、切点、取景或效果恢复；每项有文字/画面依据，未观察过程保留未知 |
| 替换 | 当前人物、兵器、地形、时长与能力；牵动射程、支撑、对手回应的替换一起重算 |
| 避免与冲突 | 用户不采用的设定、未授权的能力、固定站位/结尾、无依据的模型或成功率；不自动照搬创作者身份或用户未选定的整套动作，明确选定的复刻范围仍按硬约束执行 |

约定只保留有证据且影响本次结果的项，不凑固定特征数。分析/适配报告可展示这份短约定与来源；只要提示词时把选中关系编进自含正文，来源记录留在内部或追溯文档，不强加案例名、方法表与素材清单打断复制块。原创且未给参考的任务直接创作，不为普通缺项索要锚定案例或先选模型。

对照检查“所选关系 → 本场具体句 → 下一镜的结果”，不能仅用风格词、标签齐全或相似姿态宣布迁移完成。参考的原成片和用同提示词另生成的复测是不同媒体，即使同页展示也分别记录；复测模型/分辨率、评分和作者评价不互相继承。[审阅流程](review-loop.md)维护实际观看范围与比较。

多图可互补同一维度，例如正面身份与背面服饰，指出各自采用的部位、属性和阶段，不机械一角一图。属性冲突用用户已定优先级；没有优先级且会改身份/关键动作时，指出具体冲突并准备选择，不折中造第三外观，不全丢仍有用素材。衣服、配饰、背负物不会因动作参考有挥砍就成为可用兵器。

换机位保持已知地标/通路。正面场景不证明背面有门、台阶或落脚处；允许补足时区分兼容新设计与已观察信息，禁止新增出口时不能补门脱身。只核查当前动作涉及的缺视角，不强制每次准备全景图库。

## 分镜拼图与逐格核对

先确认阅读顺序，以及格子属于连续事件、备选构图还是同时分屏，不能统一从左到右。格间接近、接触与状态仍能衔接，末格是计划终态，不是实际视频尾帧。普通边框、序号、箭头是说明；指定漫画分屏时才保留为画面元素。

逐格对照身份/兵器，核人数、肢体持物归属、接点和事件序，整板观感和分数不能代替。单格可含起止双画面或轨迹示意，先辨时间关系再判人数；无阶段标记且含糊则记录不明确，不因两处同貌就宣告分身，也不忽视单一时刻人数约束。修单格后重看前后衔接，分镜好看不证明成片遵循。

实际接口可能把整板当首帧、身份或分镜控制，核职责和入模处理；附件存在不保证逐格执行，纯提示词任务不强制创建角色/分镜图。实际镜头形式核查见[视点、镜头形式与竖屏](camera-and-rhythm.md#视点镜头形式与竖屏)。

## 稳定身份与攻守绑定

每人用对应素材的稳定称谓，必要时辅服饰/兵器识别点；同衣者以姓名/素材绑定，不擅改衣着。每次交换明确谁攻谁应，不以“进攻者”作永久身份、不连续用含混代词。称谓不随攻守和画面换边变化，持手按身体左右，参照见[方向规则](camera-and-rhythm.md#方向参照与换机位)。先说谁、删掉身份图均不保证模型不互换，需本次输出验证。

区分意外复制与指定同貌人物、分身、幻象。修意外复制查职责/人数，指定多身则保留独立动作、数量与外观，不全局禁同脸或换装规避；状态权威见[分身与多人协同](clones-and-multi-combat.md)。

## 动作借鉴与当前设定

明确保留具体动作、攻防关系、节奏还是运镜。允许借鉴时提炼如何接近、怎样改变防线、怎样结束这一拍，再按当前人/兵器/场地重写；精确复刻就是硬约束，不以适配自行换招。只有文字则按所述关系工作，不虚构看清握法与接点。

换长度/握法/身体结构/地形后，双方一同重算可达距离、挥动/回收空间、支撑与回应。双短刀近身旋扫换成长枪窄巷时，可在允许改编下改沿巷接招推进；不得原大圆横扫穿墙、缩枪或保留对不上路线的旧防守。推镜不缩攻击距离。

已有伸缩、御空、遥控、隔空作用按其机制保留，不统一落地，也不临时添加来掩盖冲突。固定原动作、原间距、兵器尺寸与场地互斥时，具体说明矛盾并准备保其余要求的方案；选择未明确前不声称精确实现。

借鉴冲击帧、闪白或反相时，把触发事件、画面保留部位、线条所指及恢复后的动作一起改到当前兵器/防线。拳套接腹部换成棍剑格挡时，强调的是两兵器交点、握点与承力，不继承原人体退步/伤势。背景简化是短暂呈现，真实遮挡、损坏、光源与未完攻击仍按当前状态存在；效果写法由[冲击帧与闪帧](style-and-materials.md#冲击帧与闪帧)维护。

## 动作迁移与实际控制信号

编排借鉴是写作，平台迁移还要真实媒体绑定，并核当前模式控制身体、表情、相机还是场景。仅表情驱动不能承诺全身剑斗；两条单人动作分别像参考不证明双人距离/接点/回应/共同终态。

修源动作错误时明确允许变化的部分，不能一面纠错一面要求错误控制逐帧保持。仅改文案未必覆盖强动作控制，应按实际接口调整必要控制部分并重看完整事件；文字任务不为此启动生成或补接口不需要的素材。

预处理时看实际接入通路和控制预览，不能只看原视频/节点名。人体与手部关键点不自动编码剑轮廓、长度、握持和交点；未进入表示的关系不称已锁定，也不推导模型必失败。工作流有姿态/边缘节点但仅深度连接时，实际只有那条接入信号；不默认三类同时生效，不默认换一种或叠全部必修好。控制预览未知时留未核验，返回后仍验双人关系。

参考时长和输出不符时，先查实际选段、重采样/末帧延长、提交长度、支持范围、返回文件与裁切记录，再定位丢失事件。只选原 10 秒中间 6 秒不属于自动漏拍；三秒控制末帧延到六秒不能把新增停留当原动作；处理未知不从停顿反推一定延帧。完整十秒只出六秒也不直接判动作复杂/太快，更不能据此减速、删招、换结局。

## 首尾状态与硬约束冲突

对照实际输入与要求的持手、朝向、离手状态、距离、运动方向。只缺过渡则在时间允许时补转身、回收、换位/制动并调整预算；图里已飞散碎屑、半空倾身暗示动势，相反运动须制动或允许修改输入，堆“更快/保持不变”不消冲突。

真正互斥时准备改素材/改要求的具体选项，必要选择未确定不覆盖人物设定，也不虚构平台中间帧接口、新瞬移或新伸缩解题。唯一剑既须始终载人又须离脚且禁止一切其他支撑，是机制冲突；原剑留脚下另化术剑则是合法不同设定。

素材和参数已明确承载的信息不机械重复正文，但指定接触、条件、人数和终态必须在实际提交文本/绑定输入里，不只存在内部规划或评分说明。提交序号按本次附件重排同步，稳定标识按实际标识核对；不存在的附件不写引用。模型中立的文本形式见[视频生成适配](video-generation.md)，压缩权威见[提示词构建](prompt-construction.md)。
