# 参考素材与动作适配

用于多图、分镜拼图、首尾帧、动作/运镜借鉴及实际迁移。本文维护素材职责和适配；样片观察、计划/实际/采用状态见[复核流程](review-loop.md)，提交核验见[实际生成](generation-execution.md)。

## 素材职责与互补

| 职责 | 采用信息 | 采用边界 |
| --- | --- | --- |
| 身份、兵器 | 外观、实体道具、握持特征 | 身份图不必是首帧 |
| 首帧 | 位置、朝向、支撑、接点与动势 | 从当前姿势续动作 |
| 末帧 | 指定空间关系或姿态 | 中间换位、回收和路径仍需成立 |
| 场景 | 地形、支点、障碍、光线 | 缺视角保持未知或注明兼容新设计 |
| 动作 | 路线、发力起落、对方响应 | 外观、剧情和招数按当前任务 |
| 表演 | 视线、反应时序、呼吸/台词、身体张弛 | 脸部驱动与全身/双人接点分开 |
| 材质、完成度 | 指定表面、细节与清晰程度 | 配色、道具和能力另按职责绑定 |
| 运镜 | 相机路线、景别变化、跟随关系 | 人物动作和故事另行采用 |
| 局部效果 | 触发相位、轮廓/明暗与恢复 | 不扩展为整片风格、追加命中或场内爆炸 |
| 分镜拼图 | 指定格序、事件与构图 | 先辨连续、备选或分屏 |

同一素材可有多职责，分别说明范围；三视图通常一个身份，分身身体数来自剧情。未收到或未查看的信息标为未观察。多图可互补同一维度，如正面身份与背面服饰，指出采用部位和阶段；冲突按用户优先级处理，身份/关键动作的未决冲突保留供选择，仍有用部分继续采用。

演员/数字人参考区分身份、脸部、身体与相机。只借表演时，将选定呼吸、视线、收肩嵌入本场攻防，重新核空手、握持、支撑与可拍窗口；半身驱动的覆盖不延伸到未控制的双人全身关系。实际模式见[视频适配](video-generation.md#对齐具体控制层)。

### 参考方法的保留与替换

吸收多份提示词时，盘点可访问原稿和版本：同文副本合并方法，同稿备选版本各留时间轴。按当前问题选动作、战术、表演、视觉、摄影或结构关系；已覆盖方法沿用现有权威，实质缺口补到对应专题。

用户认可按“具体关系、来源文字/媒体位置、适用条件”记录，问题另修；认可节奏只证明这项偏好。多来源按职责融入本场，如回收抢攻、术法反制、匹配转场和材质各有作用；互斥镜头形式、身份、能力与冻结范围按当前请求统合。复刻范围视为硬约束，普通新创作直接调用相关方法。

| 内部约定 | 记录内容 |
| --- | --- |
| 已读/已见 | 素材、版本、区间；原稿、作者原片、复测和后处理分别标明，摘录按实际范围记录 |
| 保留 | 有依据的路线、攻防依赖、切点、取景或效果恢复，未观察过程留未知 |
| 替换 | 当前人物、兵器、地形、时长与能力；牵动的射程、支撑和对手回应一起重算 |
| 避免/冲突 | 当前不采用的设定和互斥要求；明确选定的复刻项仍保留 |

只记录影响本次结果的项。分析/适配报告可展示约定；提示词把所选关系写进自含正文，追溯表留在维护资料。对照“所选关系 → 本场具体句 → 下一阶段结果”，相似风格或姿态不足以证明运动迁移。

原成片与另生成的复测分开记录，模型/分辨率、评分和作者评价不互相继承，观看范围见[审阅流程](review-loop.md)。换机位仅核当前动作涉及的缺视角；背面新门、台阶或支点若允许补足，注明创作设计，禁止新增出口的任务沿已知通路解题。服饰、配饰与背负物是否为兵器由本场设定决定。

## 分镜拼图与逐格核对

确认格序及连续事件、备选构图或同步分屏。说明用的边框、序号和箭头只有在指定漫画分屏时才成为画面元素；末格是计划终态，实际尾帧另看输出。

逐格核身份/兵器、人数、持物归属、接点和事件序。单格可含起止双画面或轨迹示意，先辨时间关系；无标记的同貌人物数量保持不明确。修单格后重看前后接续。

实际接口可能把整板当首帧、身份或分镜控制，核采用职责和入模处理；附件存在与逐格兑现分开验收。镜头形式见[视点、镜头形式与竖屏](camera-and-rhythm.md#视点镜头形式与竖屏)。

## 稳定身份与攻守绑定

用对应素材的稳定称谓，必要时辅以识别点，同衣者用姓名/素材绑定。每次写清谁攻谁应，攻守和画面换边不改身份，持手按身体左右，见[方向规则](camera-and-rhythm.md#方向参照与换机位)。称谓写法仍须用本次输出验证。

意外复制查素材职责与人数；指定同貌人物/分身保留独立动作、数量与外观，见[分身与多人协同](clones-and-multi-combat.md)。

## 动作借鉴与当前设定

先确定保留动作、攻防关系、节奏还是运镜。借鉴提炼接近、防线变化及结束条件，再按当前人/兵器/场地重写；精确复刻保留所选动作。只有文字时以其所述关系工作，未见握法/接点不记为观察。

改长度、握法、身体结构或地形，双方一起重算距离、挥动/回收空间、支撑与回应。例如双短刀旋扫换成长枪窄巷，在允许改编时改沿巷接招推进，回应也随新枪线调整。已有伸缩、御空、遥控或隔空作用按其机制保留；原动作、间距、兵器尺寸和场地互斥时，说明具体矛盾并准备可选方案。

效果适配连同触发事件、保留部位、线条指向与恢复动作重写。拳套接腹部换成棍剑格挡，重音改为两兵器交点、握点和承力，而非继承人体伤势。短暂简化背景仍接续真实遮挡、损坏、光源与在途攻击，见[冲击帧与闪帧](style-and-materials.md#冲击帧与闪帧)。

## 动作迁移与实际控制信号

写作借鉴与平台迁移分开：迁移核真实媒体绑定及模式控制身体、表情、相机或场景的范围；双人距离、接点、回应与共同终态需共同验收。

纠错时明确允许变化的源动作部分；文字未必覆盖强控制，应按接口调整必要控制并重看事件。看实际接入通路与预览：人体/手部关键点未必编码兵器轮廓、长度、握持和交点；只有深度连接就按深度信号验收，节点名称不代表全部生效。未知控制留未核验，不推导必失败或换控制必修好。

时长不符先查选段、重采样/末帧延长、提交长度、支持范围、返回和裁切记录。原10秒选中6秒与漏拍不同，3秒末帧延至6秒的新增停留也不属于原动作；处理未知时不凭停顿猜原因。定位丢失事件后再修，不仅凭短输出减速、删招或换结局。

## 首尾状态与硬约束冲突

对照输入的持手、朝向、离手状态、距离和动势。只缺过渡就在预算内补转身、回收、换位/制动；首帧已有飞散碎屑或倾身余势，相反运动先处理制动。

硬要求互斥时准备改素材/要求的具体选项，未选定前保留冲突。例如唯一剑始终载人、同时离脚且无其他支撑，三者无法并存；原剑留脚下另化术剑则是不同设定。

正文精简素材和参数已承载的静态信息，指定接触、条件、人数与终态仍进入实际文本/绑定输入。附件重排同步提交序号，稳定标识按实物核对，引用已提供的附件。文本适配见[视频生成适配](video-generation.md)，成稿压缩见[提示词构建](prompt-construction.md)。
