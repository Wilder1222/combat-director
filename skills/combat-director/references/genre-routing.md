# 题材、能力与呈现方式

整场创作、换题材或换画风时读取。题材决定内容侧重，具体设定决定能力上限，媒介与摄影决定呈现；三者组合。动作与状态由[交锋](choreography.md)和[正文组织](prompt-construction.md)维护。

## 先识别内容，再选择呈现

继承用户的世界规则、能力、动作与终态，补本场必要缺项。新创作可设计机制，局部改画风则保留原能力；服饰、动画、游戏CG或史诗感只提供视觉线索。

| 内容方向 | 正文重点与能力边界 |
| --- | --- |
| 仙侠 | 选定术法与实体攻防改变距离、攻守和目标，写触发/控制、来路、回应、作用、代价与残留。御剑、御空、阵法等按需设计；持剑、实体飞剑和剑气分别追踪，范围、供能与退出明确 |
| 武侠 | 展开兵器射程、攻守线路、步法身法、支撑发力、拆招与地形取位。既定轻功、内力、夸张腾挪或剑气写具体落点和作用，能力上限以本场设定为准 |
| 写实格斗 | 展开拳脚/摔控/持械的距离、护架、重心、接触传力、闪避、回收与下一威胁，动作由现实身体和物件支撑。疲劳/伤势、场地器具和血腥程度按任务及实际事件继承 |
| 其他或混合题材 | 按世界规则选改变局势的机制，如机甲关节、能源武器、怪物体型；明确实体、作用条件、回应和后果，读取命中的机制专题 |

“真人格斗”无超现实条件时采用写实内容，“真人仙侠”保留仙侠能力。动画可搭配任一题材；仅给“动画战斗”时直接拟相容的实体交换。严格写实与指定超现实能力互斥时，指出这个具体冲突。

真人觉醒或超常近战可以采用自然人体、现实支撑与电影摄影，同时保留明确授权的身体加速、自主防御或接触静电。分别锁定身体能力、效果是否额外传力及环境影响范围；真人质感不取消这些设定，也不自动授予其他术法。接触效果造型见[风格专题](style-and-materials.md#接触型静电与环境反馈)。

## 输出内容随组合变化

稳定设定只写影响本场的规则，动作体现题材差异：武侠以线路、拆招和借力展开，写实以身体/器具接触展开，仙侠先写所选术法的攻防作用，再写光轨、符纹及环境响应。

媒介明确为二维、风格化三维、水墨、像素或定格后，按[画风与材质](style-and-materials.md)处理表面与运动：动画用姿态、轮廓间距、弧线和线面变化强化已有事件，速度线/残影仍是呈现；真人或写实CG写身体、衣料、兵器与环境受光，反应由当前刺激触发。高画质沿已选媒介展开。

| 组合 | 应进入正文的差异 |
| --- | --- |
| 写实CG仙侠 | 选定术法与实体交锋相互作用，衣料、金属、术法光和空气层次分离 |
| 真人武侠 | 拆招、兵器与身法有来路/支撑，衣料受力和表演可拍；采用轻功/内力时写机制 |
| 真人写实格斗 | 距离、护架、击打/摔控、回收与自然声，质感落实到本场表面 |
| 二维武侠或二维写实格斗 | 对应题材的攻防继承，描线/色块、姿态及运动间距体现二维 |
| 真人仙侠或水墨仙侠 | 相同仙侠机制分别用真人受光/合成观感或墨面/飞白/留白呈现 |

称谓与稳定设定可合并，【人物与兵器】可改为【人物与打法】；只有独立效果设计才展开【特效体系】。自然尘水、接触和呼吸可直接进入动作/声音，参考中的荒野、纱罗、剑雨、龙卷或手持单镜仅属其采用范围。

## 改稿与对读

只改媒介、画质或摄影，保留能力、持物、射程、事件与结局；换题材才重算路线、攻防、反馈和时间，仍满足用户锁定内容。无法兼容时说明受影响的具体要求。

连读复制块：题材是否体现在行动？超现实作用有无本场依据？物理反馈、艺术尾迹和攻击是否分清？画风/表演是否对应媒介？省去未用模块，按具体世界规则核能力。
