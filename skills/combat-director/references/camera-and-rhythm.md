# 摄影与成片节奏

需要逐镜覆盖、快切、一镜到底、第一视角、竖屏、慢镜、冻结或视觉重音相位时读取。先有同一份动作事件，再用摄影传递它；动作目标与接点见[战斗编排](choreography.md)，时间组织与提交文本见[提示词构建](prompt-construction.md)。摄影不替人物完成移动、接触或判断。

## 摄影信息任务

编排稿每镜说明起止、镜长、观察目的、跟随对象、可见范围与结束变化；按事件选镜长，镜数随编排产生，不解释为少切优先。提交稿按实际入口转换时间粒度。先描述必须看清的部位、接点、前后层次，再选参数；焦距还受距离/画幅影响，光圈还受对焦/尺度影响，二者不能独自证明景别与景深。指定参数保留并查相容性，参数文字不等于实际清晰。

| 事件 | 画面承担的信息 |
| --- | --- |
| 接近、追逐、换区 | 中远景/跟拍保持共同地标、间距、路线与新落点；只拍脸不能证明迁移 |
| 格挡、命中、分离 | 中景保留持械手、目标与必要支撑，可短切接点；后退脚步需要取景覆盖 |
| 结印、显阵 | 人物动作与生成关系先可读，再看范围；纯阵全景不证明施术关系 |
| 破阵 | 阵纹亮灭与目标响应的先后可比较，不用“识破”代替线索 |
| 体型差、法相 | 同框/共地标交代比例，局部接触能追溯哪一肢体，变化后连回可用路线 |
| 情绪选择 | 留手、换目标与必要面部变化，远景不要求瞳孔细节；威胁在近景期间仍推进 |
| 光梭对撞 | 同构图读两端、来路、真实交点、主体分开与结果；亮尾交叉不证明命中 |
| 冲击、余波 | 先接触和受力，再看环境传播；白光遮住的结果不能靠文字升级为已观察 |

一个主事件可含夹击、同步双挡或近身牵制与侧翼封路，不限制同窗只有一人/一次接触；按距离、遮挡、景别判断能读哪些关系，指定同步不能改轮流。

## 摄影术语与空间对应

专业词必须对应本镜实际行为，可按“景别/角度、主运镜、路径与速度变化、动作切点”写，不为了列全技巧改变动作覆盖。

| 术语 | 非显然区别 |
| --- | --- |
| 横移、侧向跟拍 | 相机在人物侧方实体移动，说明哪侧/方向/相对速度，产生近远视差 |
| 纵向、后退跟拍 | 沿行进方向追随，或在人物前方后退看迎面动作；侧面平移不等于迎面后退 |
| 推拉、变焦、拉焦 | 推拉改变相机位置与透视；变焦改焦距与取景大小；拉焦改清晰距离，不能互换 |
| 摇摄、俯仰、甩摇 | 当前阶段原地转朝向，横向摇/上下俯仰/快速转向后收稳；不是横移或整机升降 |
| 弧线环绕、滚转 | 环绕沿开放弧线改观察位置，交代起终与过轴；原地滚转转画面倾角，不默认整圈 |
| 低位仰拍、中近景、过肩 | 是高度/朝向、入画范围、谁的肩占前景，不独自代表移动；过肩不等于眼位 |
| 纵深调度、前景视差 | 前后人沿真实路线交接；移动相机下近远物投影速度不同，不让所有层同速平移 |
| 动作匹配、轴线连续 | 同一动作相接阶段切视点，继承来势、持物、方位，不重演命中或冒称长镜 |
| 接点插入、反应镜头 | 放大既有接触或具体事件后果，占时计入原镜表，不加无用途特写 |

例：低位从桥南沿东向加速并行，近栏柱快速掠后、远阁门缓慢放大；右脚斜落相位动作匹配切同侧接点，续同次拨挡。倾斜构图用于指定失衡、滑动变焦用于主体/背景透视反差时才采用，不成为高速战斗套餐。

## 方向参照与换机位

| 参照 | 保持什么 |
| --- | --- |
| 场景方位 | 桥北柱、出口、崖上等不随机位变化；人物绕行才改变与地标关系 |
| 人物自身左右 | 持剑右手、左肩伤跟身体，投影换边不换手、不移伤 |
| 当前画面左右 | 当前机位下的投影可在绕到对侧后翻转，不说明人物换位或攻击折返 |

按当前攻防关系安排相机起点、可达路径/真实切点和终点。可见环绕、沿轴观察、地标或适量全景均可交代换边，不每次插入停顿。人物转身、彼此绕过与相机过轴分别判断，移动后更新当前轴线；初始同侧不证明后续接点仍无遮挡。自由走位不锁成全段左右站位；指定固定左右则保持同侧交接。固定站位、相机路径和全程左右若互斥，指出冲突，不靠镜像全幅、换身份或换兵器掩盖。

遮挡前有进入方向，重现后接原身份、持物、朝向与余势。出画仍在场，关键换手/夺物若全被遮住则覆盖不足或未知；需要有意隐身、省略赶路时按已设能力或时间省略处理，不一概判瞬移。

## 相邻镜接续

逐个切点对读上一镜最后的动作相位与下一镜最先发生的动作，再判断是接续、重看还是省略，具体时间语义见[动作阶段与切点](#动作阶段与切点)。跨镜覆盖同一事件时，换景别或观看主体可以改变信息重点；起手、接触、分离和受力仍属于原事件，不因切镜重新启动。

| 切点关系 | 对读与写法 |
| --- | --- |
| 事件身份与相位 | 明确谁的哪次攻击/回应停在哪个相位，下一镜从该阶段继续或接已发生结果；新攻击须从当下回收、持手与距离启动。只写“继续打斗”不能分辨接续还是重演。 |
| 方向与当前轴线 | 同时核人物自身左右、场景路线与当前画面投影。画面运动方向改变时，检查实际转向、彼此绕过或机位换侧；用已有可见运动/地标说明当前轴线怎样变化，不把投影翻转改成人物掉头。用户固定左右时仍保持其要求。 |
| 空间与覆盖 | 下一镜的距离、高度、落点与前镜通路相容，局部兵器/身体能认回所属人物和已建立接点。共同地标可由相连镜组交代，不要求每切全景；只在空间关系失去依据时补必要视野，脸部或爆光不能替代必须看清的迁移。 |
| 持物与接点 | 继承同一实体、持有者/身体持手、当前握法与接触/分离状态；切近接点要能追溯握点和作用对象。易手、解除或返回按实际过程变化，前镜遮住的关键交接不由后镜持物结果补签。 |
| 动势与下一威胁 | 前镜尚在进退、转体、回收、失衡或受力，后镜按当前支撑/能力承接余势；要停住或反向须有制动条件。未完追击、在途物与原接点期间的威胁继续推进，切反应镜不让它们等待。 |

正文只把容易误接的关系写进【衔接】或下一镜首句，其他已清楚的事实直接继承，不再复制完整状态清单。切点可落在动作中，相连镜组补齐必要因果，不要求每镜重做完整起收。一镜到底在景别或注意力交接处使用同样对读，但摄影须沿实际连续路线完成，不能由接续描述暗加硬切。

例：前镜末，青衣沿桥南向东进身，右手剑尖被灰衣刀背拨向北，青衣右脚尚未落稳。切到桥南同侧中全景，保留双方持手、刃线和青衣落脚；灰衣右手刀从拨刃末端继续压入，青衣右脚落在原石缝东侧承重，收右肘将剑尖从北侧带回防线，灰衣的刀已沿露出的内线逼近。切点交接的是拨偏后的余势与抢攻窗口。若下一镜直接让青衣在桥北站稳重刺，须修正遗漏的换位/恢复或重复发动；扩大景别本身不完成这些动作。成片切口的观察方法见[相邻镜切口诊断](review-loop.md#相邻镜切口诊断)。

## 视点、镜头形式与竖屏

眼位主观镜先明确谁看什么：可见自己的手、兵器和低头可见身体，完整正脸须反射等可见路径。过肩、外部机位不是眼位，已设离体神识按其范围处理。肉眼转向与当前头身姿态相容；全程第一视角不擅切外部表情，双方主观切换时持手和接点随人物，左右按新视点。

眼位盾挡若盾不透明，盾外中心被挡的接触不能宣称已可见；允许调整落点时可选视线下方的盾上沿，让来刀、接点、提离可读，自己的左盾右剑仍对应。这是该构图的一种解决方式，不是盾挡通则，也不靠透明化盾或外部补镜破坏要求。镜中自己的反射不计新增角色。

真实切镜、连续推近变景别与相机移动分开。编号多个镜头不证明输出切了，连续片拆多个文件不产生新角度。允许硬切时近景到全景可直接换观察位置，接同一事件状态，不需兵器/冲击波推相机。连续相机才需路径与占时，不能以“动作带出远景”隐藏切镜或瞬移。

9:16 要重新检查全段最外侧的身体、脚手、剑尖、接点、支撑与移动终点。头顶留白不能补两侧裁切，固定机位预留全段范围，允许跟拍时才随动。保留指定人数、兵器尺寸、横移、侧翼和镜头形式，不能为窄画幅删角色/短武器/添切镜。实际首尾帧需看接口裁切或重构后输入，原图完整不证明入模完整。

## 快速攻防的镜长与运动

速度感来自人物加速、抢时、攻防间隔、距离与视差、剪辑重音。先写出快在哪里：拨偏后趁对方回收未完追入，闪避余势转新线路，退步和架挡并行；反击仍有空手、射程与回收条件，不以“瞬间”抹掉路程。镜头慢不迫人物慢，相机快和衣摆飞不替攻防快。

高速多镜可试排 0.8–2 秒承担一次威胁/交接，0.3–0.8 秒强调已建立关系中的接点/脱手，2–3 秒看追身/变线/换区；这是编排起点，不是模型限制或强制区间。长距离、复杂支撑、蓄势与指定镜长按实际占时。更长镜要有内部节拍与持续移动，不用一次拨挡加四秒绕拍凑长。短镜突出一项变化，0.5 秒不同时塞起势、多招、环绕和特写；细写同次拨挡的接杆、转腕、离杆不等于另加三招。

开场从真实起态尽早入威胁，中段让未完回收遇到逼位/换线，短镜成组落在抢攻反制；换区用仍在移动的较长镜读通路，再接新波。分段只交状态，不每段重演蓄势、对招、摆姿。结尾按指定追击、分胜负或收势，不固定英雄定格。镜长不机械均分或长短交替，有用途的等长可保留；单镜改镜内节拍。

删掉“高速、激烈、爆燃”后仍能读出加速、抢时、接触分离、追击、反制才有动作依据。原速生成审阅另见[复核流程](review-loop.md)；平均镜长、切镜数和静帧姿态不证明节奏。慢的症状区分单招拖长、招间空等、交换太少、播放变速，不统一加高速词或删接近/回收/反馈。

## 动态交接与局部拍法

相机以起手到接点再到反击的注意力交接组织，而非整段无休旋转。主体由甲交乙、前后景换层时，写开放通道、运动相位与收稳处；虚拟相机可快穿开放空间，不能穿身穿墙。最高速段可局部拖糊，接点、关键判断与结果可辨。

| 拍法 | 路径与结束信息 |
| --- | --- |
| 贴身侧跟、弧线交接 | 从甲侧后开放通道跟入，乙导偏时沿两人外侧短弧转跟反击，读主动权变化 |
| 擦肩穿行、前后景交换 | 一人近层掠过、另一人远层反向，相机沿空隙侧穿再拉开，读谁过谁哪侧与新位置 |
| 甩镜接反击 | 从同机位跟被导开的兵器横摇向已启动的反攻，接触前收稳；不甩到只剩爆光 |
| 低位掠行、抬镜 | 从侧方开放路读踏地/滑步，随起身/已设跃起仰抬并后撤，读身体发力和下一支撑 |

例：甲向东刺，乙在轴线南侧退半步导刃向北；相机由甲南侧后方向东跟入，抵两人南侧时减速看刃偏转。乙向西斜斩甲持剑臂，相机从侧位短横摇向西、斜斩抵达前稳住；甲收肘让刃掠过臂外。石柱只在横摇时拖糊，结束见甲后撤乙前压。横摇不是切镜，连续版阶段相连、切镜版另标切点。

小物件匹配转场只在允许切镜时使用：铜币亮面转正，切画面同位置同大小满月，再下摇到仍在竹筏的人；后续仍需实际靠岸和登岸。构图相似不替人物迁移，物件材质/身份不改；一镜到底须用连续取景，不藏切。

面部特写有观察任务和动作窗口：从当前接架/回收/远来势进入，取脸部或眼部、明确视线对象、一两处微变化、已有来光，再在判断转行动的相位接回动作。遮面仅写露出的眼部，远景不用微表情；脸随头肩小幅跟移，背后威胁不暂停。例：金色来梭越石柱时，切青衣侧前方面部特写，从眉骨收至下颌、右侧留视线空间；目光锁画外右来路，眉间一紧、下唇短抿，金色反光由右颊扫至鼻梁。相机随沉肩向下少许，在头部侧让启动时回中全景，续让位与持剑迎击，不重复起势。一镜到底须有贴近退出路径与占时，不瞬时贴脸拉远。

## 关键姿态与视觉焦点

动画姿态是连续事件的辨识点：来势指向、防线改变、失衡/恢复，保持中间运动与双方回应，不每个造型停一次。侧位、肢体与躯干空隙、背景明暗可分轮廓，不必全涂剪影。姿态保持、运动间距、动画拍数和输出帧率分别处理；降低帧率不自动得到顿挫，流畅实速不新增定格，指定冲击帧则按相位强调。速度线/拉伸/残影不增加实体或命中数，成像规则见[风格专题](style-and-materials.md#效果形态与传播)。

这一刻要读什么，决定局部明暗、颜色、形状与运动。背景可丰富，只在关键轮廓后留可读区；焦点可由来势转防线再转结果，不强制整场灰暗。例：雨夜灯笼在门框、湿地暖倒影在门洞，两剑在暗墙前交会；守方撞开半门，暖光通路随门扇变宽，跟镜纳新出口和落脚。变化来自真实门扇，不用色变破防或移位。

### 视觉重音与触发相位

| 强调位置 | 观看任务与时间语义 |
| --- | --- |
| 出招前/来势中 | 读判断、威胁或加速准备，保留尚未接触的距离；变化结束后继续接近或出手，不提前给本次命中的伤势与位移 |
| 接触/作用时 | 读谁以什么作用于何处，覆盖攻击部位/兵器、接点和双方承接；效果对应同次作用，不凭图形线条宣布人体命中 |
| 后果出现时 | 读防线被改、支撑失稳、装备破损或通路打开，续原受力方向与回收；强调结果不补演已完成的接触 |

相位由本次观看任务决定，不要求所有效果都在接触后。视觉重音可以在原镜内发生，不自动新增切镜、慢镜或接触顿挫（Hit Stop）；指定这些时间处理时另写范围、恢复与占时。具体效果选择、信息保留、组合顺序与正常画面恢复在[冲击帧与闪帧](style-and-materials.md#冲击帧与闪帧)统一维护。

## 动作阶段与切点

慢镜辨动作，接触顿挫强调已发生接触；蓄力、主动停招、接触前冻结、整帧停格和人物冻结/相机环绕分别描述。指定接触前冻结/子弹时间时，保留尚未碰到的间隙、冻结范围、恢复时机，不提前命中，也不删风格要求。两刃投影重叠不证明真实接触，角度要能读前后层次/间隙。

整帧复制不产生新角度；人物冻结但相机环绕需取得相应视点，不能靠后期停格声称完成。表现停时不自动赋角色停时能力；局部冻结、身体主动急停、全帧静止范围一致，不能同一雨滴既静止又持续颤动。

跨镜先确定接续、重看还是省略。接续保留当前接触/分离；重看同瞬间不重复算伤害、破损、消耗与首触音；省略后姿态不证明省略过程完整展示。指定必须看清的接触、分离、换位不能仅靠结果镜补签。

蓄爆反差让停顿有用途且对手仍推进。例：倒梁暂隔双方，刀客空手从护手引向刀尖，既有附魔红纹逐节亮，对手绕梁逼近；看准窗口撤手蹬地，慢拍止在蹬地前、进身实速。普通拔刀用出鞘与反光，不自动附魔。

延迟看见后果与延迟触发分开：上一镜已切断傀儡膝部外露索，剑客穿其右侧后制动，右剑退向左手稳定的鞘口；前景看半入鞘剑和侧脸，焦点沿纵深移至仍惯性前踏的傀儡，失去拉索牵引的膝折、向前跪落。伤害只一次，雨与散屑继续。真正延迟术法先有存留介质、触发和范围，不能入鞘声无因炸敌。

## 倍率、停格与成片时间

区分原速动作时间、选中素材时长、播放倍率、成片使用窗口、生成时长和后期时间。恒定倍速时，使用时长 = 所选素材时长 ÷ 倍率；原速 0.2 秒按 1/4 播放占 0.8 秒，已给 0.8 秒成片窗口不再除一次。已有慢镜再变速按本次素材实际时长，不混剧情时间。

新增停格增加时长，窗口内已计的停格不重复加；渐变速度按分段实际使用时长或成片核查，不猜平均倍率。两段各 10 秒、重叠转场 1 秒使用 19 秒，裁切/重叠与生成长度分记。精确时长无法由接口和后处理满足时说明限制，不默改总长。

输出帧率、重采样/补帧和播放速度分别处理：可保时长增加帧数，不由高帧率宣布慢、快或接触更完整。精确倍率/停格要工具支持并看输出时间戳与动作，提示中的小数不保证逐帧兑现；无精确需求时以动作阶段和成片窗口表达。音轨变速/音高与实际执行见[生成执行](generation-execution.md#能力确认)。
