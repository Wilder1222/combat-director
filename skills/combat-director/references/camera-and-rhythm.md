# 摄影与成片节奏

负责取景、视点、镜头接续及时间处理；动作机制见[交锋](choreography.md)，正文时间组织见[提示词构建](prompt-construction.md)。先有事件，再决定观众何时看见来路、接点、选择与后果。

## 摄影信息任务

每镜或镜内节拍选当前需要看清的关系，再定位置、景别、运动和切点。局部可以只覆盖一个相位，相连镜组补齐完整事件；多线夹击或同步接点按同窗关系覆盖。

| 事件 | 必要观看关系 |
| --- | --- |
| 接近、追逐、换区 | 共同地标、间距、路线与新落点 |
| 格挡、命中、分离 | 持械手、作用对象、接点及影响受力的支撑 |
| 结印、显阵、破阵 | 人物触发、阵面范围、节点变化与对象响应的先后 |
| 体型差、法相、远程对撞 | 比例/来源、真实交点、作用主体与剩余通路 |
| 判断、情绪选择 | 视线对象或身体选择，所用景别实际可见的表情 |
| 冲击、余波 | 原作用与受力、环境传播及仍在的后果 |

### 尺度信息与取景回认

选本场会改变判断的尺度关系，再给观看证据。近身对决可用刃长、一步间隙或门槛，换区、远程对撞、巨敌再用共同地标比较体量、距离和高差；已有参照清楚时直接接当前动作，不每次重建大全景。

| 尺度 | 取景要让观众辨明什么 |
| --- | --- |
| 实际体量/距离 | 人物与对象处在什么位置，相对多大、相隔多远；同框或共同楼层、桥面等参照接通整体与局部，近景继承原尺寸、距离和高度 |
| 画内占比/机距 | 哪个主体或局部占据多少可见画面，相机实际从哪里看；局部占满画面可以强调迫近，但不能据此推断真实尺寸或人物已到目标前，推近/后撤仍走可达路径 |
| 攻击覆盖/环境影响 | 来势扫过或限制哪片区域，接点在哪里，哪些地方受损、仍能通行；取景容纳整片荒野时，攻击边界与未受击远处仍按本场机制保持 |

由整体进入局部交锋时，可依“尺度揭示 → 接近可达 → 局部作用 → 剩余威胁 → 回认”交接观看信息，在同镜或相连镜组中按实际事件完成，不规定镜数、占框比例或必须有巨敌。局部观看要认得到原部位，回认用共同地标接回人物、整体和退路；具体受损功能由[体型差专题](powers-and-formations.md#体型差法相与异形对手)确定。

按实际画幅检查所需关系的横向、纵向范围：头到腰的半身景可能容不下低于腰的待发术刃，近战的大人物占比也可能容不下数米间距及双方剑尖。扩大取景、改相容机位或用接续镜组覆盖；指定固定构图时先在其允许范围解决。细小旧痕要在下一次利用前有足够可辨的大小、对比与对应部位，高清标签不自动放大它。

连续景别变化写明来源：主体确实靠近相机、相机沿开放路径靠近/退远，或允许的变焦。双方只沿横向靠近彼此、相机仅平行侧跟时，不能把收紧的间距当作人物自动变大。切镜可直接换取景，但下一镜要继承当时距离与相位；宽阔环境不要求在每个局部镜完整入画。

短示范：“北侧宽景同时见只到巨像膝高的剑客、机关巨像与东岸断柱；沿北侧外缘跟剑客避掌接近，保留左腕降至剑程内的距离。削断索扣时沿同侧开放处靠近，收进剑客右手剑和巨像左腕；右臂的后续扫势继续，相机沿原侧退距，将右掌、受损左腕、仍可通行的桥北缘与断柱重新纳入画面。”本例的体型、弱点与路线均是已设条件，具体作用见[力量专题示范](powers-and-formations.md#体型差法相与异形对手)；放大索扣没有缩小巨像或延长剑程。

### 观看关系与取景选择

先选本场需要突出的一次关系变化：试探时保留剑尖与防线间隙，让观众读到对方是否上当；防线被拨开时收拢到持械手、两刃及打开的通路；受力后放回支撑、退路和追击者。必要关系已清楚时可继续当前取景，被遮挡、新威胁入场或注意力转交时才调整对应视野。摄影只改变同一事件的观看轻重，不增加一击、改能力或让双方停住。

细小接点先给可辨的轮廓空隙与朝向，再覆盖实际作用。固定全景用相容的交锋区和较大的侧向轮廓让钩口/手腕分开，不偷加特写；连续靠近必须在接触前到达能看清的位置，离开局部时继续原受力与解除。按钮或持手被柱、盾、挡板挡住时，选择本场可见且可达的操作面或允许的接续机位，不能仅写“同时清楚”。远距离供能手与目标侧接点可分配不同观看窗口，局部通过共同盾缘/地标回认，近景不替连接两端缩距。具体成稿核对见[空间与取景](prompt-construction.md#空间尺度与取景适配)。

### 观众知情与揭示时机

选择共同发现、观众先知或客观观察。观众提前看见侧翼，人物仍需实际声音、视线或已设感知才回应；共同发现也可用外部机位，不等于眼位主观镜。先定揭示关系，再定转向、退距或移焦，尊重指定镜头形式。

例如枪客正面逼近，取景提前纳入已沿栏推进的同伴，观众先读夹击；刀客到侧翼脚步可听时才转防。若要共同发现，相机在该声源/转头触发后揭示侧翼。两版只改揭示时机。

## 摄影风格与镜头形式

手持、稳定器、固定观察等运动质感，与单镜/多镜及动作速度分别选择。二维、CG或真人都可用这些观看关系；电影感不绑定焦段、微抖或环绕配方。

| 摄影选择 | 可见执行 |
| --- | --- |
| 固定/稳定观察 | 预留后续路径，人物在画内改变距离和攻守 |
| 纪实手持 | 低幅随步起伏、轻微跟随迟滞；关键接点仍可辨 |
| 贴身/力量牵引 | 随前冲起速侧跟加速，攻击被导偏时减速、沿外缘短弧转跟反击，随既有受力退路退距 |
| 稳定器/滑轨 | 连续平稳推移，速度跟随主体位移；平滑摄影不使攻防慢摆 |
| 御空/尺度揭示 | 随高度与纵深抬升、俯降或后撤，交代剑程与范围后接回主体 |
| 主观/过肩 | 明确观察者、遮挡、可见持手及视线范围 |

### 一镜到底的运动句法

用“触发动作 → 此刻机位 → 沿哪条开放路径移动 → 结束看见什么”接每个节拍。前冲从支撑足蹬出或身体起速触发跟拍加速；攻势被导偏后随路线变化减速、转跟已进入通路的反击；受力使身体沿原退路离开近景时，沿同侧开放通道退距，把失衡与支撑重新纳入画面。相机速度依人物位移和自身路径选择，不要求追上剑尖速度。起终位置相接，换向有弧线/制动，贴脸再退远计入占时；相机可以快速走开放通道，不能穿人穿墙或瞬移机位。

例：甲蹬足向东追刺，相机从两人南侧同向加速，保留剑尖与乙胸前的间隙；乙侧让拨偏时相机减速，反击进入已打开的通路时沿南侧外缘短弧转跟，东门地标仍在。甲以已设御空避刃，相机沿侧方抬升并后撤；甲下降时沿同一开放弧线俯降，接新支撑。力量牵引改变观看注意力，不替人物完成移动。

### 光学、微抖与成像规格

用户指定的数值保留为本场意图，实际设置按[入口控制层](video-generation.md#对齐具体控制层)核查；普通稿直接写可见结果。

- 焦段、有效画幅、机距共同影响取景；清晰纵深另受光圈和对焦距离等影响。必要持手与接点先纳入视野，再选参数。
- 焦点交接跟当前信息窗口走：判断尚在进行、眼部可见时读视线指向；握柄或结印显露出手选择时转到手；兵器进入作用窗口前转到刃线与接点。视线→手→兵器只有在现有占时、构图和清晰距离容得下时才连续完成；短促交锋直接守住必读作用，远景或遮面改用可见身体选择。跟随朝向不等于追焦，不要求无关远景与近脸同时锐利；多人同步接点不被逐个移焦拆成先后。
- 微抖/迟滞说明幅度、方向和触发；接触阶段减扰动。相机迟滞不同时延迟角色回应。
- 追赶型摄影可用“身体突然加速 → 跟拍短暂落后 → 转向略过冲 → 沿原路径重新捕获 → 必读接点前收稳”。落后和过冲显示实际加速，不能代替人物越过地标或掩去整段攻防；模糊期间身份、路线和余势继续，重新捕获不新增机位或攻击。碰撞造成的抖动绑定原作用，收稳后仍保留结果。
- 短曝光般清晰与明显背景拖影并用时，将后者限定为快速运镜阶段的艺术处理；实际尾迹和粒子另按自身机制退出。
- 擦镜失焦放在允许且不吞必读关系的窗口，离镜后追焦回来。浅景深、全程全清晰与整幅失焦的具体冲突须修可选呈现。

### 观看距离、透视与焦段选择

实际观察位置决定透视。近处伴随强调迫近与前后位移，远处观察便于比较双方路线；各自检查握点、遮挡、开放通路和景深。维持相近景别而改长焦通常需后退，透视变化来自机位变化，不缩短人物真实距离。用户已定焦段或构图时在其范围内组织覆盖。

## 摄影术语与空间对应

术语配“实际位置/路径＋速度变化＋可见范围”，不用词串代替执行。

| 术语 | 对应行为 |
| --- | --- |
| 横移/侧跟 | 相机沿主体侧方实体移动，有近远视差 |
| 纵向/后退跟拍 | 沿行进方向追随，或在主体前方后退 |
| 推拉 / 变焦 / 拉焦 | 分别改变机位 / 焦距与取景大小 / 清晰距离 |
| 摇摄/俯仰/甩摇 | 从当前机位转朝向，快速转向后收稳；不同于整机平移或升降 |
| 环绕 / 滚转 | 沿开放弧线换观察位置 / 转画面倾角；环绕交代过轴 |
| 低位/近景/过肩 | 分别指定高度朝向、入画范围、前景肩部；本身不是运动 |
| 动作匹配/接点插入 | 换视点接原相位，或放大已建立作用；占时仍在原镜表 |

## 方向参照与换机位

场景方位、人物自身左右和画面投影分开。桥北出口不随机位变；右手剑和左肩伤跟身体；绕到对侧后投影可翻转而人物未换位。

可见绕行、沿轴观察、地标或必要的更宽取景均能读通换边。人物转身、彼此绕过与相机过轴分别更新当前关系，初始同侧不保证后续无遮挡。固定画面左右按相容机位保持；不靠镜像或互换身份修冲突。

遮挡前有进入方向，重现后接原持物、朝向与余势。出画仍在场；必须看清的夺物/换手若全被遮住，需补覆盖或记未知。

## 相邻镜接续

逐切点比较上一镜末相位和下一镜首动作，先分[接续、重看或省略](#动作阶段与切点)，再核下面关系：

| 关系 | 核对 |
| --- | --- |
| 事件与相位 | 同一攻击从哪个阶段继续；新攻击从当前回收与射程启动 |
| 方向与轴线 | 实际转向、绕行和机位换侧分别有依据，身体持手与地标不翻转 |
| 空间与覆盖 | 距离、高度、落点可达，变化有真实运动来源；局部可认回握点、对象与原接点 |
| 持物与接点 | 同一实体/握法、接触或分离延续；易手、释放和返回有过程 |
| 余势与威胁 | 进退、转体、受力和回收续下去，在途攻击与追击不随反应镜等候 |

只在易误接处写具体衔接句，清楚的事实直接继承。例如切前右剑被拨向北、右脚尚未落稳；切后同侧中全景读右脚在原石缝东侧承重，收肘将剑带回防线，对方从拨刃末端续压。换景别没有替角色站稳或重发一刺。实际切口诊断见[审阅](review-loop.md#相邻镜切口诊断)。

按编号组织多镜时，一个切点只对应相邻两镜的交接，不在前镜的短窗里暗加另一机位及完整动作展示。内部对读可记“上一镜末已有何物、处于何相位、间距/高度怎样 → 下一镜首从哪里续”；正文仅保留易误接处的必要句，不输出状态表。飞行中、刚接触与已脱刃不能在切点互相替换。

最终镜头数从实际切点核回标题；镜内临时换角须重新登记，两端同属一个动作节点也不免除各镜预算。边界切至已编号下一镜只记一次；连贯横摇、移焦与可达推拉不误算成新镜。登记和跨镜节点的唯一正文规则见[分镜组织](prompt-construction.md#分镜与分段组织)。

## 视点、镜头形式与竖屏

眼位主观先明确谁看什么，可见自己的手、兵器及视线内身体；正脸需反射等路径，过肩不等于眼位。盾外接点被不透明盾挡住时，调整允许的构图或保留未知，不凭声音宣称已见。

硬切可直接换机位并接事件相位；连续推近、摇摄和移焦仍是同一视点运动。连续片拆文件不产生新镜头，编号多镜也不证明模型切了。

9:16重新检查两侧肢体、剑尖、接点、支撑及移动终点。固定机位预留全段范围，允许跟拍才随动；保持指定人数、兵器尺寸和侧翼路线。实际入模图的裁切/重构需另看，原图完整不证明输入完整。

## 快速攻防的镜长与运动

速度感落到加速、抢时、短促接触与连续变线：拨偏后对方回收未完已追入，让位余势接下一线路，退步和架挡并行。反击仍满足空手、射程和支撑；“瞬间”不抹掉路程。

短镜可强调接点/脱手，较长镜看追身/换区或连续交换；镜长依事件占时产生。试探可让间隙与防线留在稳定画面内，关键变线时才收紧观看范围或加快跟随，恢复阶段沿余势放回支撑和下一威胁；轻重来自本场局势变化，不要求每次接触都切镜、慢放或震屏。短窗不同时堆多招、环绕和特写，长窗有局势推进；有目的的试探、蓄势、僵持与慢速演练保留。

首帧已经接架或带动势就从该相位开始，中段利用已开放窗口，末段落到指定结果。镜数、平均镜长、震屏和尾迹不能单独证明实际速度；症状分辨见[速度诊断](review-loop.md#速度慢招少与流光慢)。

### 身体爆发与接触微慢镜

需要瞬时速度反差时，先让身体从当前支撑沿可辨路线加速，再选择关键接触短慢，随后恢复实速接同一次承力、分离和回收。慢镜集中读局部形变、接点和已设效果，恢复不重放首触、不让人物完整复位；下一威胁按共同时间继续。可用“实速逼近 → 短促身体爆发 → 接触微慢 → 实速续招”的曲线，常规交换保留实速，各阶段取值随本场预算。

每个节点在[最终正文](prompt-construction.md#每个战斗节点的秒数输出)写起止秒数与占时，动作正文逐一写具体耗时。例如“侧让0.15秒 → 拨挡0.2秒 → 进身0.25秒 → 出拳0.15秒 → 接触微慢0.25秒 → 收拳0.2秒”。相机跟住这条速度变化，慢镜结束后直接续原滑退；复制块不写计时归属注释或局部绝对时点。0.15–0.35秒可作为某场参考的微慢持续时长范围，不是所有战斗的固定参数；不以动作耗时倒推模型实际帧数。

## 动态交接与局部拍法

注意力从来势转接点再转反击；每次交接选择一项主要相机变化，并给收稳位置。人物直线追入时侧跟；反击改变行进方向时沿外缘短弧转跟；新威胁在当前机位可转向的范围内时才选摇摄，甩摇须在新接点前收稳；落脚或失衡决定局势时把支撑纳入低位取景。模糊退出后仍认得到持手与作用对象。一镜沿可达路径完成交接，固定机位用预留画幅、人物前后层次和允许的移焦交接，不强加运镜。

面部/施法特写进入正在发生的判断、移动、脱刃或释放窗口，写视线对象及景别可见的一两处变化。近景期间画外威胁继续，回动作时接已推进的相位；施法远景接已发术法，不重结印。单镜特写另需贴近/退出的可达路径。

小物件匹配转场只用于允许切镜的任务，例如转正的铜币亮面切同位置同大小的满月，再下摇到竹筏；同构图不替人物靠岸与登岸。声桥由原声源延续，见[声音](sound-and-performance.md#声源与动作阶段)。

## 关键姿态与视觉焦点

动画关键姿态辨认来势、防线改变和失衡/恢复。按视点、轮廓间距、局部明暗组织焦点，中间运动与回应持续；丰富背景可在关键轮廓后留可读区。姿态保持、运动间距、动画拍数与输出帧率分别选择；速度线、拉伸与残影解释已有运动，不增加实体。

### 从运动选关键姿态

解析参考按关系变化选必要证据帧，记源时间与可见部位，并连看前后区间。相似姿态和重复帧不补签中间路径。原创故事板的关键姿态是设计目标，需补运动过渡；帧数、镜数和平台控制能力分别判断，普通提示词不强制做关键帧。

### 视觉重音与触发相位

| 相位 | 此刻读什么 |
| --- | --- |
| 出招前/来势中 | 试探先读剑尖与防线间隙，判断/加速准备可突出本场视线或支撑变化，随后续接近/出手 |
| 接触/作用时 | 谁以什么作用于何处仍可辨；关键变化把接点、双方承接和打开的通路置于视觉中心，常规交换可保留原景别 |
| 后果出现时 | 随防线变化、失衡、损坏或通路打开延续原受力与回收，放回支撑及下一威胁，不重演接触来制造重音 |

视觉重音可在原镜发生，不默认添加切镜、慢放或Hit Stop。具体图形、效果组合和恢复由[风格专题](style-and-materials.md#冲击帧与闪帧)维护。

## 动作阶段与切点

跨镜时间语义：**接续**从原相位继续；**重看**再呈现同一瞬间，不叠加伤害、消耗或首触声；**省略**跳过过程，结果镜不证明被省过程已展示。必读接触、分离和换位保留覆盖。

区分慢镜、接触顿挫、主动急停、接触前冻结、整帧停格与人物冻结/相机环绕。接触前冻结保留间隙和恢复时机，表现停时不授予人物停时能力；整帧复制不产生环绕新角度。冻结范围一致，相关占时计入总长。

蓄势反差有真实窗口，如倒梁阻隔时附魔，对手绕梁仍推进；普通拔刀不自动附魔。延迟揭示则是稍后才看见已发生后果，例如断索后傀儡惯性前踏，相机从收剑前景移焦到失去拉索牵引的膝折。真正延迟触发另需已设介质和机制；入鞘不无因炸敌。

## 倍率、停格与成片时间

原速动作、素材时长、播放倍率、成片窗口及生成长度分别计算。恒定倍速时：使用时长＝所选素材时长÷倍率；原速0.2秒按1/4播放占0.8秒，已给0.8秒成片窗口不再除一次。

新增停格增加时长，窗口内已计的停格不重复加。两段各10秒、重叠转场1秒净用19秒；渐变速度以实际分段使用时间核查，不猜平均倍率。裁切余量与净时长分记。

输出帧率、重采样/补帧和播放速度分开；更多帧不自动证明接触完整。精确时间处理需入口或允许的后期支持，并核实际媒体。声音变速与执行见[生成执行](generation-execution.md#能力确认)。
