# 粒子行为：从动作触发到消散

用于用户要求粒子、烟火、剑光拖尾、碎屑、风场，或特效遮住动作的修订。这里借鉴 Niagara 的组织思路，输出仍是视频画面描述。用户明确要制作 Unreal Engine 资产时，再转入所用版本的引擎实现流程；不能把这份提示词当成可执行 Niagara 配置。

## 先锁定作用

先确定效果只是提示运动、表现材质，还是有实际攻击/阻挡能力。附刃亮带不自动产生离体斩波，寒雾不自动冻住人，卷尘不自动击退敌人。能力、范围、资源与代价继承当前设定；原地附魔、随剑尾迹、离体攻击分别处理。

粒子不是每段必需项。普通交手可以只有脚边扬尘、衣摆、接触处少量木屑；没有合理介质时省去颗粒。写实、动画或水墨描述不改变已授权能力。

## 按需描述菜单

| 维度 | 要回答的问题 | 写法例 |
| --- | --- | --- |
| 归属与触发 | 谁/何物在什么事件后产生效果 | 持剑者开始横切时，刃后出现细窄光带；两刃接触才出现火星 |
| 来源与分布 | 从哪部分产生，哪里密哪里疏 | 刃旁连续、外沿零散，手柄和脸部保持清楚 |
| 形态与介质 | 是光点、条带、液滴、烟还是实体碎片 | 短亮线、半透明薄带、棱角冰片、低矮灰尘分别描述 |
| 路径与参照 | 跟随物体，还是脱离后留在世界中 | 新尾迹接在当前剑路，旧尾迹停留在刚掠过的空气里并变暗 |
| 受力与变化 | 哪一层向何处加速、偏移、沉降 | 重砂很快落回地面，轻尘被廊外来风带向院内 |
| 接触与事件 | 撞到谁、什么位置、产生什么结果 | 碎冰撞阶沿后向侧下方弹开；未接触时没有命中爆点 |
| 停止与寿命 | 何时停止新增，已有部分如何退场 | 收剑即停止生光，旧尾端先暗，近刃一段随后熄灭 |
| 留存与可读性 | 下一拍还留什么，哪些动作必须看见 | 擦痕和碎片留在原地；最亮处局限于接触旁，持械手可辨 |

这是一份内部选择菜单，不要求把八项填成表再给用户。短稿先写“来源/触发 → 路径 → 接触结果 → 结束”，需要区分材质或修复失败时才加其他维度。密度和宽度可先以剑刃、手掌、人物轮廓为参照；精确粒子数、厘米和小数秒只是创作目标，不是已证实的通用模型控制。

技术词可帮助沟通，但要落到画面：Burst 是某次事件的短促散出，持续发射是动作期间不断有新粒子；Ribbon 对应连续尾迹形状，Drag 对应逐渐减速，Curl Noise 可转述为局部卷散。没有扰流需求就不加 Curl Noise。上述词不是本技能注册的字段或按钮。

## 三层只按需要使用

1. **主形**：读得出方向与能力边界的刃光、火舌、冰面或气流轮廓。
2. **辅助细节**：少量离散火星、冰粉或光点，说明运动余势，不盖过主形。
3. **环境结果**：被触动的灰尘、落叶、水面、碎片和擦痕，位置继承到下一拍。

没有必要就只选一层。特效写在 `<特效>`，场景介质和结果写在 `<环境反馈>`；同一事件不重复抄两遍。人物如何防守和恢复继续写 `<动作>`，用粒子制造视觉丰富度不能替代对手回应。

持续风场、火域或包围性法术与瞬间碰撞分开排。范围建立后，人物回应、防护承压、场域改变及后续威胁应有可见进展；重复尘雾不等于新攻击。大体积效果退去时，检查原有飞行物/余波是否仍有效，不能自动清空危险。只在已确认的交互处加局部顿挫，不让整片持续场域每秒都爆同一种闪光；局部亮光也不能独自证明命中人体。

攻击必须穿过彼此分离的多层防线时，按实际失效顺序接续：外层屏障破口或散开后，余势才到兵器架或身体；各层分别写仍有效的范围与下一接点，不能让完整屏障与人体同时承受同一条已被挡住的路径。贴身防护或相连的兵器架可直接传力给身体，须拍清传递关系，不误写为攻击已经穿透。兵器碎裂须从原持物位置产生可辨断裂与散片，握持状态随之改变；光屑退场不等于兵器自动复原。抽帧若只见爆光和散片，保留材质、首触和失效时点未知，不倒推已证实整条破防链。

## 六种可用行为

以下是原创编排建议，不是历史武学定式、引擎配方或已验证模型效果。按已有材质和能力选用。

| 情况 | 可见行为 | 需要避免的因果错误 |
| --- | --- | --- |
| 附刃剑光 | 沿实体剑实际经过的位置长出窄尾迹；挥动停止后旧尾端先暗 | 旧轨迹整体跟剑反转；凭空多出实体剑或远程刃波 |
| 金属擦碰 | 接触时少量火星沿刃面滑动方向散开，亮点迅速变暗下落 | 未接触先爆火；把所有材料换成同一种金属火花 |
| 木杖与足尘 | 支撑脚蹬地推开近地薄尘；若确有表层剥落，木屑从该接触处散出 | 木碰木自动打出高亮火星，衣袖磨擦就爆炸 |
| 获准的火焰 | 火源附近保持主体火舌，外缘翻卷；停止供给后主焰收缩、余烟稀释 | 火星当火焰全部主体；无设定地让衣服、场地同时着火 |
| 获准的硬冰 | 冰沿指定表面生长；碎片由明确破裂处脱落、弹落并留存 | 把软雾当可承重冰墙；碎片熄灭同时修复冰墙 |
| 风与落叶 | 先有可见落叶，被气流掀起、转向、越过障碍后失速下落 | 满屏凭空生叶；摄影机旋转被当成气流方向变化 |

水下和摇晃甲板需重选介质、支撑和参照。水下不能照搬干尘落地；甲板上的已有碎片跟随船体支撑，脱离的水滴或碎屑再有自己的运动。若涉及超自然运动，另写其来源和限制。

## 投喂压缩

将动作、对方回应与以下一句接在同一主段：

> 横切开始时，青白窄光带沿刃后实际剑路生长；旧尾迹留在掠过的空气里，末端逐渐断成暗点。对手让开后没有接触爆点，收剑时停止生出新光，握柄关系与回收过程仍能追踪。

只有用户允许附刃光效时才采用此例。去掉“Niagara-style”一词，画面行为仍应完整；用户指定该风格词时可保留一次。只要图生视频短稿时，以实际读过的输入图为基础描述运动变化，不重复倾倒静态外观。

平台限制另列。对推荐正向措辞的平台，可把“不要遮脸遮手”译为“主要光带避开表情与持械区域，回应和回收过程可辨”，内部能力禁令仍保留，不能因改写成正向句而放宽。没有平台证据时不编造负向参数或断言中文标签会被专门解析。

尾迹是场景效果，曝光模糊由画面相对运动产生，二者分别结束。剑停后存量光点可以继续衰减，不能据此让自然曝光拖糊在空气里漂散数秒；相机仍动时另判断相对运动。关键过程可辨不要求每帧像素全锐利，叠加规则见[运动成像](motion-blur.md)。

## 审片与最小修复

| 现象 | 对读什么 | 修复方向 |
| --- | --- | --- |
| 全屏光团盖过接触 | 原动作是否已给接触点与持械手 | 缩小主形，减少外层，保留接触窗口 |
| 拖尾粘在剑上转头 | 新粒子和旧粒子的参照是否分开 | 新尾迹跟当前路径，旧轨迹留在世界位置后消退 |
| 挥空却有命中爆点 | 特效触发是否绑定接触 | 让空只保留路径尾迹；真正接触再出接触效果 |
| 剑已收起仍无限冒光 | 停发与存量消散是否分别描述 | 给明确停发事件和存量退场顺序 |
| 换木杖后仍喷金属火花 | 介质是否随兵器一起改 | 改为材质允许的木屑、尘土或完全省略 |
| 效果结束让环境复原 | 消散的是能量还是实际损坏 | 能量可熄灭，擦痕、碎片与损坏按状态保留 |

先看原始输入、生成输出的时间码和前后帧，再提出最小修改。没有输出时只能做文本预检；不能把关键词命中、Schema通过或作者自查称为粒子模拟成功。

完整文字例：[附刃光迹12秒](../examples/particle-blade-12.md)、[木杖尘土12秒](../examples/particle-staff-12.md)。工程稿继续用 Combat Plan 1.2 的 `vfx` 和 `environment` 文本，修改后走现有表达复核，不添加未知字段。
