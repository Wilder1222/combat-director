# 风格、材质与术法照明

需要 CGI/真人质感转换、材质细节、术法照明、水墨贴附、跨媒介、冲击帧/闪帧或效果可读性时读取。事件事实保持，效果围绕现有来路、接点、反馈与结果；镜头与冻结见[摄影与成片节奏](camera-and-rhythm.md)，能力机制见[力量、屏障与法阵](powers-and-formations.md)。

## 风格转换与景别细节

3D 国漫 CGI 与真人质感共享人物身份、能力、动作、空间、节奏与结局。已有素材优先，明确转风格才改呈现；“电影感”只指摄影时，不自动改真人。CGI 可有真实材质，真人仙侠可保留粒子、发光瞳孔、能量屏障，不用风格表删能力。

| 对象 | CGI 可选呈现 | 真人质感可选呈现 |
| --- | --- | --- |
| 人物 | 造型轮廓和材质层次，比例服从美术 | 自然比例、当前景别可见的皮纹汗光，身份特征保持 |
| 布料、金属、皮革 | 折面、护甲高光、刃线辨识 | 丝绸垂坠、厚布挤皱、皮革磨痕、局部金属反光随动作 |
| 光照、术法 | 主光与能量色明确，接点不被吞没 | 环境光与术法光共同影响皮肤、布料、地面，能量可做主光 |
| 环境反馈 | 风格裂纹/尘浪仍有来源和方向 | 材质断裂、落尘、擦痕对应受力，程度仍服从术法 |

只写景别可读的细节：双人全景不强求毛孔、微血管和瞳孔倒影。手持、浅景深、颗粒、光晕均可选，不为真人感改固定机位或模糊接点。材质附动作，不另停展示：转腕拨剑时袖口挤皱、刃转带冷光，两版仍是同次拨挡和下一动作。更多短语见[材质与动作细节](xianxia-vocabulary.md#材质与动作细节)。

## 术法照明与身份颜色

先确定环境主光，再为发光能力指定来源位置、受照对象、明灭阶段与残留。光源相对场景保持，绕镜可改变屏幕方位与受照可见范围；不每镜从画面同一侧重布光。掌中蓝光染白袖是受照颜色，不变蓝衣身份；熄光后回到仍在的月光，不能白昼复位。

瞬时爆光与持续火焰/光束分别延续：碰撞闪光退后，地上火仍照近处人地；主光、短爆光、持续残留分别结束。可用剪影、曝光变化和风格闪色，不统一加固定光比、全场强补光。指定微光剪影而接点须可读时，在允许范围用轮廓分离和覆盖，不能全黑掩动作，也不擅自改变剪影风格。

## 效果形态与传播

分清攻击主体、辅助尾迹、粒子、曝光模糊、景深虚化和艺术残影；效果色/形/运动归属稳定，颜色混合不让角色换技能。按结果选反馈，不逐击叠满套餐。

| 功能 | 可写的可见变化 |
| --- | --- |
| 细束/刃形攻击 | 从来源沿实际线路推进，在目标受阻/偏转/穿入；面状防线按覆盖形变/开口 |
| 环身弧、附刃亮带 | 随旋身/转腕扫出平面弧，留在经过空间再衰减；不自动变传送门、平台或离体斩波 |
| 尾迹与残留 | 新迹从当前剑尖/伞沿生成，旧迹留原路淡去；反转仅新迹改向，真实裂口/倒木保持 |
| 风场、碎片、尘雾 | 持续场在范围内带动尘衣云，实体碎片沿受力飞出再下落，能量碎光按设定消散 |
| 透明气压波 | 真实碰撞后由接点推进压缩前沿，背景云短折、尘雨随后推开；前沿可不发光，不等于全场同震 |
| 接触光效强调 | 来路/唯一接点/受力可读，接点短闪扩散，退光后新位置和破坏保持；画面闪帧另按下节选择相位 |
| 运动模糊 | 跟镜躯干较稳，刃尖随自身方向拖糊、背景依相机视差；静止地标不因挥剑整幅横拖 |

相对相机停住后常规曝光拖糊不漂散数秒，粒子可停发后衰减。快门/帧率是设置，慢放是时间处理；入口不支持精确设置时写观感，见[倍率与成片时间](camera-and-rhythm.md#倍率停格与成片时间)。材质碰撞不强制火星，非血腥代价可用护甲、布料、护体光屑和失衡。

## 冲击帧与闪帧

先选本次要强调的局势变化，再选画面变化。破开既有防线、夺回通路、暴露代价或完成关键反制都可成为视觉重音；大招、巨响与击飞不自动成为唯一重点。未指定时让一般试探与关键转折形成层次，不给每次轻碰叠同一套效果；已指定的强调、攻防、人数和同步接点仍须保留，不能借简化删掉。

把效果绑定到已有事件与相位：谁的哪次出手、当前尚未接触/正在作用/已产生何种后果、观众此刻要读什么。出招前、接触时和后果出现时的时间语义见[相位选择](camera-and-rhythm.md#视觉重音与触发相位)。冲击帧强调形状与力的关系，闪帧强调短暂的亮暗或色彩变化；名称本身不替代具体画面。

| 手法 | 画面职责与必须保留的关系 |
| --- | --- |
| 冲击帧 | 临时简化背景纹理或提高图形对比，保留双方可辨轮廓、攻击肢体/兵器、作用对象和对应接点；出招前强调则保留未接触间隙。放射线从实际接点展开，运动线沿真实来势，轮廓线突出参与本次作用的形状，按观看任务选用；这些线不新增斩波、实体或命中 |
| 全屏闪白 | 整幅画面短暂提亮、泛白或过曝，形成视觉脉冲；它是画面处理时不自动成为场内爆炸或持续光源。要求看清接触时须在相邻相位实际读到该接点，不能只给白光前的来势和白光后的倒地 |
| 局部接点光 | 来自实际碰撞或既定术法，只在相应位置亮起、扩散和退去，照亮附近对象；其来源、传播及受照按上节处理，与全屏曝光分别描述，不能用全屏泛白代替局部接点 |
| 短暂反相 | 指定局部或整幅的明暗/色彩反转，仍保留同一人物、持物、姿态和攻击方向；反相退去恢复基础色彩及照明，不把暂时变色写成换衣、换身份或换能力 |
| 闪黑/压暗 | 明确整幅黑场还是仍有轮廓的局部压暗。接触后的整幅黑场须在接点已可读后发生，恢复时续同次受力与分离；出招前压暗则保留尚未接触的事件状态。黑画面不证明停时、人物消失、已完成命中或真实熄灯 |

正文按“正常画面与已有动作 → 指定相位的短暂变化及保留信息 → 恢复基础画面并续受力、回收或下一威胁”写全。恢复的是呈现方式，不是回到起手或初始站位；持手、兵器数量、位移、已发生破损、在途攻击与未解除连接继续。效果持续或退去时双方仍按当前动作推进，除非本次另有明确冻结；不靠闪帧把伸展、回应或分离全部略掉。

组合效果分别分配职责并写顺序。例如冲击帧让接点与形变可读，随后短暂反相放大同次接触的重音，恢复正常画面展示退步与回收；只有本次需要闪黑时才插入它。也可在同一相位叠局部接点光和图形线条，但区分场内光源与画面处理，不把所有词并列成同时爆发的套餐。一次作用只有原来的后果与声源，组合不再加一击、一次破盾或新的撞击声。

**改写示范：**“灰衣杖客双手斜压杖头，青衣将右剑斜架在肩前；杖头抵上剑脊时，青衣右肘屈曲、后脚滑向阶下，剑身随压力下沉。接触相位短暂提高黑白对比，淡去背后墙纹，仍能辨认两人轮廓、双手、杖头与剑脊交点，少量放射线从该交点向外展开。画面恢复原来的月光与衣色时，青衣继续后撤承重、转腕把杖头导向身侧，灰衣随偏转收杖；两件原兵器分开，阶上擦痕保留。”这是同次格挡的表现选择，不新增人体命中或强制停格，也不是已生成成功记录。

选中冲击帧或闪帧不自动要求切镜、慢放或 Hit Stop；精确帧数、保持时间与播放倍率分别按[时间与实际控制](camera-and-rhythm.md#倍率停格与成片时间)处理，不把输出帧率或文案中的帧数当模型已兑现的控制。观察与对照仍按[审阅流程](review-loop.md)，效果好看不能替动作通过。

## 跨媒介强调

只在选择三维/二维切换、撞色剪影或手绘终结时使用；三维叠二维与整幅切二维分开。指定基础媒介、切换相位、占时和返回结果，以原人物轮廓、攻击方向、持物对应同一事件，不新增命中。

例：三维侧拍中斧抵石甲、压出裂口；裂纹扩展相位转赭红底黑剪影，亮线沿原裂口分叉。回三维时甲片已向外飞出，持斧者收肘、守方沿原受力退步，胸前破甲保持。主风格及排除范围按段限定，不能全片禁二维/停帧否定选定强调段。

一镜到底的媒介切换仍同一视点/连续路径，不新增角度或蒙太奇。设计画面数、动画拍数、输出帧率与剪辑停格独立；精确帧数仅有实际控制时承诺，固定撞色数量和秒数不作默认。

## 贴附式水墨与分层反馈

三维叠手绘水墨、流体附刃或双方效果对照时，先定归属、贴附部位、主形、随动作牵引、接触变化，再选飞白/细丝/粒子与局部照明消退。常驻浓雾不能淹手部和兵器；艺术尾迹无超自然设定时不获得独立攻击或照明能力。

例：青黑薄流贴剑身，挥斩时青白细刃缘在前、后方窄飞白；伞骨紫灰雾分叉，收伞时聚回缝内。刃擦伞骨先有材质允许的短火星，再沿导开的剑路甩墨屑，少量雾丝从受压骨脱落。已设色光只照近旁手指湿袖，雨水沿受力飞散，脸、握点和伞骨轮廓可读。

轻擦导偏可少量火星/短墨丝、立即续招、不震屏；重压失衡先形变/传力、承重脚滑或支撑破坏，再水片尘气向受力散开；大范围技能先读主体与防线、抵抗与结果，再扩到场地，远景看实际残留。主形、尾迹、粒子按可读性取用，不因技能升级机械扩大闪光。
