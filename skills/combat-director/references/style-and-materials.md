# 风格、材质与术法照明

用于选择画风、转换媒介、细化材质光照及视觉重音。题材与能力由[题材路由](genre-routing.md)确定，镜头与时间处理读[摄影专题](camera-and-rhythm.md)，术法作用读[力量专题](powers-and-formations.md)。

## 视觉方案与开放风格族

继承用户风格与素材，分别选择基础媒介、表面表现、光色和摄影气质。未指定时直接选相容方案；用户需要选项时再列比较。CG可以写实或绘画化，电影摄影也可用于二维；气质标签落实到轮廓、表面与光色，能力沿用本场设定。

| 风格族 | 可见表达起点 |
| --- | --- |
| 真人动作电影 | 自然人体比例，景别内可见的皮肤与衣料；袖口有重量，剑面转动带动反光，环境受光与受力可信 |
| 写实国漫/游戏电影CG | 保留选定造型，皮肤、发束、布料与金属分别响应；薄衣透光、金线局部闪亮、剑脊反射移动，空间有体积和空气层次 |
| 风格化3D | 清楚的大形和面部轮廓，概括材质、雕塑明暗或手绘纹理，衣发弧线强化姿态 |
| 2D赛璐璐 | 干净描线、阴影色块与受控高光；袖褶随屈肘弯折，刃缘亮线随转腕移动，烟尘分层成形 |
| 2.5D厚涂/绘画动画 | 立体空间结合笔触与块面，软硬边缘分层；不同笔触辨识皮肤、布料与金属，纹理随对象稳定运动 |
| 水墨动画 | 浓淡墨面、飞白、留白与晕染构成空间；墨迹沿动作路线牵引，人物、持手与兵器仍可辨 |
| 纸偶/定格质感 | 纸纤维、折痕、分层剪纸或偶体手工表面；侧光表现厚度和投影，关节与姿态间距依动画方式选择 |
| 像素动画 | 稳定像素尺度、有限色阶和清楚剪影；兵器、接点分配足够像素，推拉时保持栅格语言 |
| 版画/木刻动画 | 刻线、黑白块面与有限套色；线密度和留白区分材质，细纹让出握点与接触 |

### 风格转换与景别细节

统一人物、道具和环境的大形、边缘、色阶、强调色与纹理尺度。材质按形体、颜色/纹理、粗糙度/反射、薄透/散射和毛发衣料逐层选择，再放回实际光场与动作校准；优先保留身份、服饰形制和兵器，只写当前景别可见的细节。

混合风格说明基础媒介、叠加层的部位及退出，例如“绘画化三维场景，剑路局部叠水墨飞白”。只换媒介时共用原形体、能力、动作和结局；纸偶姿态间距、像素变化及冲击帧的时间处理另按摄影专题。

## 画质、材质与光照

把画质写成所选媒介的完成度：二维看线面与色块，版画看刻线与留白，写实看表面和成像。全局选择本场表面/笔触、光色关系和动态清晰范围；逐镜把这些选择放进已有动作的起势、接触或回收，写出对象怎样变化。优先选会改变读法的细节：袖料的重量区分甩出与回落，刃面反光显示转腕角度，暗侧回光显出人物离墙。局部改稿继承已有基调，只补本次事件涉及的响应。

- **材质响应**：给当前衣料、甲片或兵器选表面，再写同一次形变的前后。薄纱张开时显透光，屈肘时袖料挤皱、回收后随重量落回；原已湿透的袖摆贴臂，甩动带出较重下垂弧；金属转面让窄高光移过剑脊与刃缘。绘画方案用线形、笔触和色阶表现对应变化。
- **空间层次**：给主光实际位置、冷暖/明暗关系及介质，再写人物或术法改变了哪处受光。经过梁下时额头直射收窄，尘气被斜光照亮而远处仍暗；平涂用遮挡色块与前后色阶完成同一层次。体积光、颗粒或光晕按本场选择。
- **动态清晰**：在相应阶段让脸、持手、攻击主体与接点可辨；把最亮刃线放在当前进攻轮廓，尾迹、尘雾、反光和虚化给出范围。细节随动作出现与退出，常规交换可只留材质变化，关键反制再突出选定接点。

成像可选通透表面、粗粝纪实、胶片颗粒与柔和亮部、梦境轻晕或平面高对比，组合时给范围。用户的“8K、电影级”等定位须转成这些可见目标。UE、Path Tracing、PBR、ACES及镜头型号涉及真实制作时按[控制层](video-generation.md#对齐具体控制层)核实；引擎与交付方案另读[渲染与画质](rendering-and-quality.md)。

## 参考视觉包的选择性编译

把用户选定的参数包转成本场画面：基础媒介与造型、当前衣料/兵器的表面响应、主光与近远介质、必选效果的主体与归属、摄影的连续路线。源角色、地点、招式与结局仅按用户指定范围迁移，实际设置与质感目标分开。

例如写实国漫CG包中的皮肤透光、发束分离、纱罗叠层、锦缎金线和剑身反射，只映射到本场已有对象；白金剑雨或苍青龙卷作为必选能力时，按[力量专题](powers-and-formations.md)建立来源、范围和攻防作用。摄影参数交给摄影专题，水墨与尘草按下方分层反馈。完整发送正文将画面布局、成像目标与媒介分别写入[默认全局栏目](prompt-construction.md#任务专属的视觉与摄影设定)，材质/光照按需要另列，不以去重省去必要标签。

**从选择到成稿：**共用“青衣转腕拨开来剑，双方短触后分开，灰衣顺势收肘，青衣继续进身”这次交换，按已选媒介兑现表面与光色。

| 本场选择 | 同次动作中的可见变化 | 成稿短句 |
| --- | --- | --- |
| 写实CG，厚布袖与银白剑面，西侧软光 | 屈肘挤皱袖口，转腕改变刃面朝向，分剑后袖料回落 | “青衣屈肘转腕拨开来剑，袖口在腕侧挤出深褶，银白窄高光由剑脊移到刃缘；双剑分开，她进身时袖料随臂回落，灰衣顺偏转收肘。” |
| 赛璐璐，概括衣褶与冷色刃线 | 袖褶描线随屈肘折转，亮线沿实际拨剑弧移动，分剑后接回基本色块 | “青衣转腕拨剑，袖褶描线向肘内折紧，冷色亮线贴着刃缘扫过短弧；剑刃分开后亮线随转面缩短，她跨步进身，灰衣顺势收肘。” |
| 水墨，深浅剑线与窄飞白 | 衣袖墨面随肘收紧，飞白沿导偏路线甩出，旧迹淡去后轮廓接续 | “青衣收肘转腕拨剑，袖口墨面收紧，深色剑线贴住来刃再导向外侧，窄飞白沿偏转路线甩出；双剑分开，飞白在原路淡去，她继续进身，灰衣顺势收肘。” |

句中保留实际转腕、短触、分离与下一步；换媒介时替换对应的线面、表面和受光表达，原招式能力与结果接续。

## 光场、反射与移动中的塑形

分别选择主光位置、软硬、主补关系、反差、色温与环境回光。柔光控制阴影边缘，暗侧亮度由补光/回光决定；负补光通过深墙或遮光区削弱回光。三点布光、冷暖互补与逆光轮廓按本场采用，必读刃线与持手保持分离。

人物和相机穿过光场时保持实际光源位置：进廊后直射退出，已有灯光或地面回光接续；离开深墙后暗侧回光增加。剑面、衣褶与观察角度分别改变高光，换机位延续同一光场。

发光体主形、环境照明和镜头/后期泛光分别描述。Bloom扩大亮部观感，场内照明范围和作用仍由光源决定；强色光退出后回到仍在场的基础光。关门缩窄暖光、破阵退出色光、扬尘改变远近对比、湿衣改变重量都可成为已有行动的阶段印记。

例：“西侧薄云日光形成软边，北面深墙压低青衣暗侧回光；她随拨剑侧踏离墙，下颌与袖口重新收到地面反射，右剑窄高光由剑脊移至刃缘。”光与材质随同一次移动变化。

## 术法照明与身份颜色

发光能力写来源位置、受照对象、明灭阶段与残留。身份色先分归属，再随距离、朝向和遮挡写受光：掌中蓝光染近处白袖，翻掌时亮区随掌向移到袖内侧，熄灭后恢复原衣色与月光。绕镜改变屏幕投影，光源在场景中的位置延续。

短爆光与持续火焰/光束分别结束：碰撞闪光退去后，地上余火仍照近处人物和地面。微光剪影用轮廓分离保留必要接点，曝光与闪色处理遵循选定风格。

## 效果形态与传播

能力机制决定来源、路线、覆盖和攻防结果；视觉造型决定主形、边缘、内部流动、光色与尾迹怎样让这些作用可见。先选本次已用术法的主形，再分攻击主体、尾迹、粒子、曝光模糊、景深虚化与艺术残影；生成、接触和退出各写当前发生的变化。苍青色薄刃可呈层叠气流或水墨飞白，是否切割、偏转或消散仍按已设机制。

| 功能 | 可见变化 |
| --- | --- |
| 细束/刃形攻击 | 从来源沿来线推进，受阻、偏转或穿入；面状防线按覆盖形变、开口 |
| 环身弧、附刃亮带 | 随旋身/转腕扫出弧面，经过空间的旧迹逐渐衰减；离体作用须另有能力设定 |
| 尾迹与残留 | 新迹从当前剑尖/伞沿生成，旧迹留原路淡去；反转只改变新迹，裂口和倒木继续存在 |
| 风场、碎片、尘雾 | 风场按范围带动尘衣，实体碎片受力飞出后下落，能量碎光按设定消散 |
| 透明气压波 | 碰撞后压缩前沿从接点传播，背景短折，尘雨随后推开，可使用非发光前沿 |
| 接触强调 | 保留唯一接点和传力，局部短闪扩散；退光后接新的位移与破损 |
| 运动模糊 | 跟镜躯干较稳，刃尖依自身方向拖糊，背景依相机视差变化 |

常规曝光拖糊随相对运动停止而结束，粒子可停发后衰减；火星按碰撞材质选择。快门、帧率与慢放分工见[时间处理](camera-and-rhythm.md#倍率停格与成片时间)。

例：本场已设苍青风刃可被飞剑导偏、落地后散尽，造型选薄弧前沿与细丝尾流。“男剑修横扫长剑，苍青薄弧从刃缘脱出，内侧气流沿弧面向前收束；飞剑斜抵薄弧右端，将前沿导向空地，尾流沿新去向被拉长。被导开的风刃落地散尽，细丝随后淡去，飞剑沿原回收路线退回守方身侧。”这次接触的反馈由导偏和既定终止条件决定，造型与颜色承担辨识。

### 接触型静电与环境反馈

本场允许接触型静电时，先锁定来源、触发条件、附着部位、主形/色光、作用范围和消退。可采用“身体高速运动并形成可见接触 → 初始冲量与局部形变 → 接点触发分叉细弧 → 衣发与环境响应 → 余电衰减”的顺序。前次接触留下的细电可沿手指、发丝或衣缝短暂延续，明确其来源与结束；强放电仍由本次接触触发。速度本身不自动赋予传送、离体射束或远程命中。

白蓝细弧、局部接点闪光、指间短丝与衣缝残留是可选造型。分开皮肤/衣发附着电、真实受力、场内照明和镜头泛光；最亮处让出必读轮廓与接点，退出后恢复同一身份、基础衣色和动作相位。仅作反馈的静电不能先于身体命中把人击退；允许额外作用时按本场机制说明条件和结果。

环境按已有对象与来源分层：身体位移气流带尘纸沿经过路线移动；接触冲击使衣料形变并带出近处尘气；已设静电使局部发丝/纤维抬起；灯具或记分牌闪烁需有本场放电影响的范围与条件。尘纸向内聚拢、地面环传播或整场电器失灵各需独立依据，不由颜色或强度词自动推出。反馈不新增攻击，远处仅受照不算受击。

本场可由首次短闪、连续交锋中的局部残留到终结的较密分叉逐步变化；升级须改变已设接触强度、积累或释放条件，不每击固定加大。全场范围效果只有在能力允许时使用。道具起态先存在，散落、滚动、灯光状态与尘量在后节点继续；纸张不能每击重新回到原处。示范见[觉醒型接触静电近战](../library/abilities/static-contact-awakening.md)。

## 冲击帧与闪帧

选择需要读出的局势变化及其触发相位：尚未接触、正在作用或已产生后果。一般试探与关键反制可有不同强调层次，用户指定的接点与效果仍保留；相位选择见[摄影专题](camera-and-rhythm.md#视觉重音与触发相位)。

| 手法 | 画面职责与保留信息 |
| --- | --- |
| 冲击帧 | 暂时简化背景、提高图形对比，保留双方轮廓、持手、作用对象及接点；出招前保留未触间隙。放射线来自实际交点，运动线沿来势，图形线条只解释同次作用 |
| 全屏闪白 | 短暂提亮、泛白或过曝的画面脉冲；必读接触须在覆盖中实际出现。画面处理与场内光源分开 |
| 局部接点光 | 从真实碰撞或既定术法的对应位置亮起、扩散、退去，照近旁对象 |
| 短暂反相 | 局部或整幅明暗/色彩反转，保留身份、持物、姿态与方向，结束后恢复基础色彩和照明 |
| 闪黑/压暗 | 区分整幅黑场和有轮廓的压暗。接触后黑场先展示必读接点；出招前压暗延续尚未接触状态，恢复接同次动作 |

按“已有动作 → 指定相位的临时变化及保留信息 → 恢复基础画面并续受力/回收”写全。临时图形退去时，原持手、兵器数量、位移、破损、在途攻击和未解除连接接续；效果和动作共同推进，冻结另按本次时间设计。

组合效果说明顺序与分工：冲击帧读接点和形变，短暂反相加强同次重音，恢复后展示退步回收；局部接点光可与图形线同相位叠加。仍只有原作用的一次后果与声源。

**改写示范：**“杖头抵上青衣右剑剑脊，青衣屈肘、后脚滑向阶下承力。接触相位短暂压低墙纹、提高黑白对比，两人轮廓、双手和交点仍可辨，少量放射线从交点展开。恢复月光与衣色时，青衣继续后撤、转腕导开杖头，灰衣顺偏转收杖，两件原兵器分开，阶上擦痕保留。”

切镜、慢放和Hit Stop按独立需要选择，精确帧数按[实际时间控制](camera-and-rhythm.md#倍率停格与成片时间)核实；新媒体的触发、持续与恢复按[审阅流程](review-loop.md)观察。

## 跨媒介强调

三维叠二维与整幅切二维分别给基础媒介、作用范围、切换相位、占时与返回结果，以原人物、方向和持物对应同一事件。局部二维/停帧的允许范围写回整体风格约束。

例：斧抵石甲压出裂口，裂纹扩展时转赭红底黑剪影，亮线沿原裂口分叉；回三维时甲片继续外飞，持斧者收肘、守方沿原受力退步，破甲保持。一镜到底仍沿原视点和连续路线；动画拍数、输出帧率与剪辑停格分别处理。

## 贴附式水墨与分层反馈

先定归属、贴附部位、主形及牵引路线，再选飞白、细丝、粒子和照明。艺术尾迹的战斗与照明作用由本场能力授权，墨雾让出脸、握点与兵器轮廓。

例：青黑薄流贴剑身，挥斩时前沿青白、后方窄飞白；伞骨紫灰雾在收伞时聚回缝内。剑刃擦骨先有材质允许的短火星，墨屑顺导偏剑路甩出，雾丝从受压骨脱落；已设色光照近旁手指与湿袖，雨水沿受力散开。

轻擦用短火星/墨丝立即续招；重压先形变、传力和失衡，再散水片尘气；范围技能先读主体、防线与结果，再扩到场地残留。按作用层次选择主形、尾迹和粒子。
