# 仙侠可见表达词表

需要补充仙侠形态或短语时按类别选，不要求凑术语数量。词表提供表达选择，机制权威在[移动](movement-and-projectiles.md)、[力量与法阵](powers-and-formations.md)、[分身](clones-and-multi-combat.md)等专题，避免用名称替代条件。原创优先通用称谓和原创机制。

## 武器与行为

| 对象 | 可见行为与关注点 |
| --- | --- |
| 长剑 | 刺、挑、斩、挂、压、拨、抹；明确剑尖目标、持手、收势 |
| 长刀 | 劈切、横扫、刀背拨挡、借势回斩；惯性影响后招，改向有原因 |
| 飞剑 | 离手、绕行、截击、折返、归鞘；实体与剑影分开，回程可接续 |
| 长枪 | 直刺、拦拿、回抽、横扫；优势距离与近身受限均可变攻防条件 |
| 符箓 | 贴附、投出、定点触发、燃尽；附着位置先于触发 |
| 阵盘 | 指阵纹、改节点、撤供能；器物变化对应阵中实际功能 |
| 琴、铃、扇 | 拨弦气刃、铃波推物、扇面导流；传播与作用明确，不只发光 |

## 能量形态与作用

| 名称 | 可见形态 → 作用 |
| --- | --- |
| 剑气 | 脱锋薄弧、贴地刃线、凝聚剑影 → 延斩、封路、断连接 |
| 灵压 | 衣摆贴身、脚边石震、对手膝沉 → 限起步、迫改姿势 |
| 雷法 | 电弧沿既定导体跳、雷束击节点 → 打断供能/短压，先有传播条件 |
| 冰术 | 接触面冰蔓、裂隙顶冰棱 → 锁落脚、改摩擦/通路 |
| 火法 | 火线沿攻轨卷、火环收拢 → 逼位/遮视线，范围服从设定 |
| 护盾 | 半透明弧受压凹、边裂扩大 → 阻挡/偏转，耗尽露缺口 |
| 魔气 | 贴地雾绕、凝爪抓兵器 → 遮挡/牵引/束缚，有维持条件 |
| 符文 | 节点依次亮、连接断、局部暗 → 供能次序和失效范围 |
| 残影、幻象 | 旧路轮廓淡去、来刃穿诱导形象 → 身法/误导，碰撞按能力 |
| 分身 | 由已有影印生成独立身体，分路后散/回收 → 攻防/开路/持物，数量归属与退场接续 |

颜色辨来源，形状与运动表达作用；属性名不直接证明相克。

## 打击层次

| 结果 | 可改写句式 |
| --- | --- |
| 接触 | 刀背顶剑脊、腕下压，响声与真实接点对应 |
| 格挡 | 来刃停盾前，持盾者承压退，身体未碰刃 |
| 破盾未中人 | 盾纹与符矢同散，衣物完好，失遮护移向掩体 |
| 落空 | 刃擦肩外，余力击后壁，身体未受此击 |
| 多重力 | 首重弯防具，次重展裂，末重过缺口 |
| 逐层破防 | 外网被拨、内盾裂，守方改防守姿态 |
| 以力破法 | 指明破坏的术法结构与形成空隙 |
| 法宝共鸣 | 已设关联法器同步颤，改变轨迹或供能；不自动双伤 |

## 材质与动作细节

依造型和景别选词，不为展示改衣、改机位或拖慢整段，详见[风格与材质](style-and-materials.md#风格转换与景别细节)。

| 对象 | 短语与动作联系 |
| --- | --- |
| 皮肤、汗 | 额头薄汗反光、下颌绷紧、眉心松开；在可见景别呈现当下压力，不凭空加伤 |
| 布、束带 | 厚袖挤皱、丝摆随转甩、束带稍后回摆；跟接触/加减速，不另占停顿 |
| 金属、皮革 | 剑脊冷光随腕、握柄磨痕、护甲局部反光；保原形，不强制镜面/火星 |
| 来光 | 火光掠侧脸、蓝阵光染近袖；方向/明灭对应施术，不永久改衣色 |
| 受力、落地 | 肩背后移、脚拖短痕、薄尘；说明方向/制动/材质，不每次地裂 |

## 指定作品与来源判断

明确指定《牧神记》《诛仙》等可保留角色、武器和招名，再展开本镜动作、形态、机制与结果；原创不额外套原著阵营/地点。原典事实区分小说、动画、游戏、用户自定义改编；忠实复现缺依据时查用户材料或可追溯来源，未经核验的连击数、属性克制、游戏效果不称原著定论。

可选择吸收逐层破防、剑阵逼位、法宝干扰、牵绊改变落点等方法，不整段搬人物/场景/结局。来源说明留创作依据，不挤进用户要求的纯提示词；追溯见[来源记录](sources.md)。
