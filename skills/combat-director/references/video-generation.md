# 通用视频生成写法与按能力适配

用于指定模型投喂、图生/参考生成、编辑或诊断。普通创作采用共通写法；选定模型、版本和入口后再核必要差异，不设默认厂商或要求用户填写能力表。

## 通用正文先成立

保留人物与兵器归属、起态、必选动作、回应、接触或让空、结果和下一状态。用具体动词写可见变化，相机、音效与粒子呈现事件。正文栏目和时长沿用[正文模板](prompt-construction.md#正文模板)，换模型时保留用户的招式、速度、结局和制作方式。

**详细程度由输入承担的信息决定。** 文生补齐可见起点；首帧图生重点写变化；精准动作参考写映射、采用范围和差异。没有动作参考，或改变兵器、支撑、地形与指定招式时，补齐动作链。删重复外观和装饰，保留区分双方、交点和状态变化所需的信息；素材承担静态内容时简写继承关系，不据此取消约定的全局与逐镜标签。

多人交叉换位或外观相似时，用稳定称呼与素材绑定；单人用足以辨认的简称。公共模块集中稳定设定，独立生成的每段带齐自身身份与起态。镜内节拍和叙事阶段不直接拆成新的生成请求。

短暂图形变化沿用[冲击帧与闪帧](style-and-materials.md#冲击帧与闪帧)。写清触发事件、保留的轮廓/持物/接点及恢复状态；具体帧数属于设计意图，精确控制由实际入口或允许的后期实现。

## 按输入与任务选择写法

| 输入或任务 | 正文重点 |
| --- | --- |
| 文字生成 | 场地、人物、持物和可见开场，再写动作、回应与结果 |
| 首帧图生 | 从已有姿态续写运动；先检查错手、错刃、接触、离地及模糊暗示的来势，避免与正文相反 |
| 身份/场景参考 | 说明素材对应谁、提供什么；身份参考与首帧构图分别处理，多图属于同一人时明确合并 |
| 动作/摄影/效果参考 | 标明采用范围、映射和修改差异；换兵器、体型或地形后重查可达性 |
| 故事板/关键帧 | 区分叙事参考和接口帧约束，补齐运动过渡；起尾姿态之间的路径也须成立 |
| 编辑视频 | 明确被编辑对象、范围、原状态到目标状态及保留项 |
| 延长/续段 | 先分清原生延长、末帧再图生或后期拼接；向前延长接回原片开头，向后延长继承原片结尾 |

首帧的脸、手、兵器与支撑有明显错误时，优先修起点。素材文字只说明意图；真正上传、编号和输入角色由实际入口确认。

## 只在落到具体入口时核对能力

沿用已选模型与入口，仅核本次硬要求涉及的能力。通用稿可先完成；只有提交所需条件缺失或与要求冲突时澄清。能力未知时注明影响生成的未核项，不杜撰语法、素材 ID 或参数。

### 对齐具体控制层

- **输入角色**：核首帧/尾帧、身份元素、普通参考与动作视频的真实绑定，以及截取范围、数量和互斥关系。
- **真实设置**：同步时长、画幅、分辨率、单镜/多镜控件；正文写“4K”“一镜到底”不替代设置。一个请求或输出文件也不证明只有一镜。
- **声音与排除**：核原生音轨、分项声音控制和负向字段；按入口转换用户的禁止项。
- **编辑范围**：核当前模式实际控制身体、表情、相机或场景中的哪一项；局部编辑与重新生成分别处理。

具体官方资料与核查记录见[来源](sources.md#主流模型官方文档与案例解析)；真实提交、预算和任务状态见[实际生成与预算执行](generation-execution.md)。官方教学案例可能属于旧版或其他模式，使用前核当前入口。

## 处理官方建议的分歧

| 建议或目标 | 本项目取舍 |
| --- | --- |
| 简短提示与详细导演稿 | 删素材已承载的静态复述和重复设定；关键反制、指定招式、接点与结局写细 |
| 每镜一个动作与连续多招 | 每镜保持明确的主要变化，可含相连攻防；按时长检查负荷，不设固定动作配额 |
| 单镜与多镜 | 内容决定编排，入口决定表达方式；连续镜头的相机路线可分相位，避免同时固定与环绕 |
| 正向描述与负向字段 | 优先写目标状态，如“剑始终握在右手”；保留用户禁止项，再按所选入口转为支持的写法 |
| 自然顺序与时间戳 | 用动作相位或粗时码说明先后；精确秒/帧和频次是意图，只有实际控制与媒体才能证明兑现 |
| 短片更稳与高速长镜 | 先减重复交换、可选装饰和矛盾运镜，保留速度与因果；仅在制作方式允许时拆段 |
| 同一请求与独立续段 | 同一请求集中稳定设定；独立段自含并承接实际状态，避免重演同一次接触 |

主体、环境与相机的运动分别交代。动作之间要有可实现的时间和路程；“快速”结合短促发力、迅速接近、收势中抢攻等可见变化，不能仅靠高频次数或快速剪辑代替。

## 共通的局部改写示范

首帧为双剑刚接架，目标为卸力后反击：

> 白袖者右手转腕把相抵剑锋引向身侧，侧踏卸力；深衣者收肘抽剑，两刃滑离。白袖者沿空出的下路斜挑，深衣者退步压剑挡开，接点迸出短火星，两剑随来力偏移；双方恢复支撑，仍握原剑相对。同侧中全景横移跟住卸力与反击，持剑手、交点和落脚可辨。

此例说明“已有起态 → 运动变化”，并非完整新场景或已验证的生成结果。

## 诊断与复测

排查实际输入与控件、真实提交内容、首帧矛盾，再检查动作/相机负荷和生成偏差。模型自动扩写、模式切换或附件变更后核实际请求，避免继续向错误起点堆词。

先定位控制对象：身体、持物、双方接点、相机、身份、场景或声音。单人动作迁移、面部一致和首尾构图各自只能提供对应证据；两人交互与中间路径仍须看输出。

保存基线与候选的素材、设置、正文和输出关联，优先修改最有证据的一层；同时更换模型、素材和正文时只评价整体方案。实际媒体按[事件与镜头两遍解析](review-loop.md#事件与镜头两遍解析)审阅，并核修改项和声明保留项。精选案例与程序检查不能证明稳定出片质量。
