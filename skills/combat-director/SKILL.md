# 战斗导演

把战斗想法写成可拍、可读、独立可复制的中文视频提示词。用同一条人物、兵器、事件和状态链组织近战、御剑、术法、法阵、分身及群战。先让观众看懂发生了什么、怎样看清、如何接续，再按需要补风格、表演、光影和声音。

## 判断任务与输入

- **创作或重编整场**：使用下方工作顺序和[正文模板](references/prompt-construction.md#正文模板)，读取该文档的详细动作、分镜/分段与对读方法；机制复杂时只补读命中专题。
- **局部改动作、摄影、节奏、声音或风格**：保留未授权改动的人物、能力、事件、时长和结局。只改摄影时不新增攻击、判断或受伤；转真人质感时保持原动作与术法。
- **参考适配或分析/诊断成片**：素材分工与保留/替换范围读[参考素材与动作适配](references/reference-and-iteration.md)，观察与修复读[审阅流程](references/review-loop.md)。按本次关系选来源，不按标题套整场；只写可见事实，标题、原稿、音轨存在和静帧不证明未观察过程。
- **实际制作或工程导出**：明确需要制作时读[生成执行](references/generation-execution.md)；需要 JSON、编译与可追溯审片时读[工程契约](references/contract.md)。普通提示词任务不要求选择平台、填 JSON 或启动生成。

继承用户已经给出的场景、人物、招式、素材职责与终态。普通缺项可拟定并简短注明关键假设；会改变身份、硬结局或制作方式的冲突才询问。先区分对抗、演武、登场和技能展示，不强补敌人、胜负、情感关系或新能力。

用户时长优先；未指定时按动作、目标与节奏拟定合理总长，不设固定秒数。其他未指定项采用16:9、快速实速为主、允许切镜、无对白、非血腥；明确的慢镜、蓄势、单镜、法令与无声范围优先。仙侠未指定风格且无素材风格约束时可采用3D国漫CGI；“15秒CGI横屏短片”是可明确选用的预设。电影感不自动把CGI改成真人。

身份图约束被指定的身份/兵器，首帧约束开场姿势和动势，动作参考约束选中的关系；同一图可有多种明确用途。三视图不是三人，同貌分身数量来自剧情。服装不证明能力，参考中未见的武器、场景和术法属于创作设定。

## 工作顺序

**本段目标与局势变化 → 全局设定 → 动作与状态链 → 时间及摄影覆盖 → 自含正文。**

1. 锁定人物身份、实际在场身体数、兵器数量/持有者/持手、起始距离与地标、允许能力、总长和目标终态。夺路、护送和拖延的结果分别落实，不默认击倒才算成功。
2. 对抗写“起态与距离 → 攻击来路 → 对手回应 → 接触/让空 → 受力与位置变化 → 回收与下一威胁”；演武用重心、旋向与兵器余势承接。详细写影响本招的支撑、髋肩肘腕发力、人物路线与兵器轨迹。各细节描述同一次动作，不排成额外停顿。
3. 区分瞬时打击、持续压抵与束缚。一次拳脚/斩击不因换镜再次蓄力或释放；维持接点时写双方承接、可用肢体、作用条件和解除。格挡、擦中、落空、破盾与人体命中分别反馈；停射不自动消除已发攻击。
4. 按动作相位安排短促交换、回收中的抢攻和连续追击。短镜可覆盖局部相位，相连镜组补齐因果；按[相邻镜接续](references/camera-and-rhythm.md#相邻镜接续)核对每个切口的事件相位、方向/地标、持物接点与动势，不重做起手。较长镜内持续变线、换区或推进目标。关键视线与表情嵌入可拍窗口，不能让来袭攻击等待。阶段、镜头和生成片段分别计数。
5. 按本段局势选视觉重音：出招、挡住、破防或脱身各有不同意义；需要冲击帧/闪帧时写具体触发、临时变化、保留信息与恢复后的动作，普通交换按其职责呈现。效果解释同一事件，不自动增加命中、停格或切镜。
6. 集中写稳定设定；逐镜常用【画面与动作】【摄影】【衔接】，按实际需要补声音、手印、法阵等细项。正文自然用“专业称谓＋具体执行”，不靠招名、术语串或特效代替动作。无关模块省略，同一事件只完整描述一次。

## 必须保持的关系

- 相机推进不等于人物接近。连续移动有路线、间距与落点；御空、瞬移、隔空作用按已设能力触发与限制处理，不强改成现实步法，也不借能力恢复伤口、持物或未解除的控制。
- 身份不随攻守或画面换边改变；人物自身左右、场景方位、画面左右分开。实体、剑气、残影与可交互分身分别追踪；易手、拾取、复制和退场有过程及结果。
- 原有损伤、术法消耗、连接、在途攻击、地形和光源影响后续。表面裂纹不自动封路，镜头暂时看不见不等于状态消失；复述同一击不叠加伤害或消耗。
- 同一时间窗可以有相连攻防、侧翼支援或指定同步接点。先理清来路、覆盖与并发，不能为简化把围攻改成排队单挑、删掉必选回应或改变结局。
- 多镜编排写每镜起止时间与镜长；一镜到底只标整镜长度和镜内节拍，需要连续可行的相机路线。单次输出不等于单镜，小数时码不承诺模型逐帧控制。
- 跨段继承必要身份、动势、接点、兵器、术法、环境、声音与事件进度。文字多段可按计划一次写全；接已有成片时区分原计划、实际观察及采用起态，不接受违背硬约束的偏差来完成续作。

## 交付与对读

只要提示词时给一个完整复制块，不附内部表格或日志；独立提交的多段各自给自含复制块及准确时长。先核对硬要求是否进入最终正文，再连读每次交换、镜头覆盖、状态与时间，修正矛盾、重复发动、空等和无效装饰。局部改稿保持授权范围。

生成任务接受、取得视频、静帧观察、原速观看和实际听辨各有证据。文字、结构、哈希和打包通过不等于媒体通过；没有相应观察就保留未验证项。运行包自含，普通写作不依赖来源仓库、外网或生成插件。
