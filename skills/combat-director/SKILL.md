# 战斗导演

把战斗想法写成可读、可拍、独立可复制的中文视频提示词。核心是**上一动作改变条件，下一动作利用或应对这个变化**；摄影、声音和效果随同一条事件链呈现。

## 判断任务与输入

继承用户给定的人物、素材职责、场景、能力、时长与终态。区分对抗、演武、登场和技能展示；普通缺项直接拟定，只有会改变身份、硬结局或制作方式的互斥要求才询问。局部改稿只动指定范围；换画风或摄影时保留原动作与能力。

题材决定攻防机制，媒介决定呈现：真人仙侠保留术法，二维写实格斗保留现实接触。具体世界规则优先于题材标签，服装和画风不授予能力。未指定时采用16:9、快速实速为主、可切镜、无对白、非血腥；总长随内容拟定。仙侠无风格约束时可选3D国漫CG，其他题材选择相容基调；用户和素材的明确要求优先。

## 工作顺序

1. **确定目标、打法和空间起态。** 锁定实际身体数、兵器数量/持手、体量与距离、地标、允许能力及目标终态。角色的距离偏好、发力或防守选择体现本场意图；同门相似打法可以保留。夺路、护送、拖延各有可见结果。
2. **串事件依赖，写连续交换与动力。** 先确定前招实际改变什么、后招凭什么成立，再按“来路与发力 → 对手回应 → 接触或让空 → 受力与位置变化 → 回收和下一威胁”组织。当前支撑或已设御空驱动身体、兵器与制动；拨偏、让位和未完回收决定变招。衣料、反光与环境反馈并行解释同次动作。人物与兵器路线分清，相机推进不代替接近。
3. **选本场呈现并安排覆盖。** 全局选定具体材质/线面、光色、术法主形与摄影取向，在关键事件落实其变化。攻击与回应触发取景、相机速度或焦点转交，表演和声层随判断、作用及恢复展开。切镜接原相位；单镜沿可达路径。持续接点、在途攻击、损伤、消耗和环境变化继续影响后招。
4. **成稿并对读。** 稳定设定集中一次，每个战斗节点在最终提示词中写出起止秒数和占时，战斗中的每个动作与对手回应直接标耗时，以具体用时锚定速度。慢镜直接写持续时长，预算在内部核对，复制块不附计时归属说明；单镜的节点时间不成为切镜。按[正文组织](references/prompt-construction.md)核尺度与取景、并发与先后、局部占时和切点状态，再检查分类结构及视觉/摄影/表演的兑现；去重删反复的规则说明，保留具体变化。

成稿先定位正文页的相关章节，再按未决问题补下表专题；不沿链接递归加载整页或全库。完整新创作需要自定方案时，按[资料检索](references/library-workflow.md)初筛并选相容卡片；已有完整参考直接适配，局部改稿只查所改维度。前提、路径和结果已够成稿就停止展开，具体缺项再补相邻章节或来源行。选定内容须进入本场动作、摄影或视觉句。

## 交付与对读

只要提示词时交付一个完整复制块；独立提交的片段各自自含。用户指定格式优先；未指定时，开头独立列【全局画面】【画质】【风格】，每镜列时间范围、镜长及【画面与动作】【摄影】。人物、起态等稳定设定集中一次，【战斗特效】【声音】【衔接】按需增加。一镜到底沿用分类标签，内部标镜内节拍。省去空的附加栏目、内部分析和日志，不把必要标签并入无分类自然段。核对格式、全局视觉内容、必选动作/回应、持物、时间、覆盖与终态；负向限制不得否定明确的局部例外。

文字对读、结构检查、静帧观察、原速观看和实际听辨分别报告。没有新媒体观察就只声明文字或工程结果。普通写作不要求JSON、平台选择或实际生成，运行包独立可用。
