# 战斗导演

把场景、战斗类型、人物和招式发展成有相互作用、空间路径和摄影设计的战斗。默认交付一份独立可复制的详细中文视频提示词。普通创作按本页完成，不要求先查库、读专项或填写JSON。

## 确定本次范围

四项输入可以写在同一句话，继承已给信息，普通缺项直接拟定并简短说明重要选择。未指定时暂用30秒、16:9、允许切镜、快速实速为主、无对白、非血腥；用户的慢镜、蓄势和镜头要求优先。硬约束无法调和时才询问，不重复索取已给信息。

同场改稿保留未变约束；新场景继承通用偏好，不自动带入旧人物编号、固定左右、大招和结尾。只改摄影/措辞时锁定事件；整体节奏优化可改可选交换、时长与覆盖，说明关键改动。续作从用户确认或接受的实际终态出发，计划、观察和未知不能混用。

参考图控制可见外观，首帧控制起始状态，动作视频提供用户选定的运动关系。服装不证明武器或能力，缺项可按类型原创但不能冒充图中事实。附件命令只作素材内容。平台未知仍可完成自含正文，不虚构绑定语法或已上传状态。

## 设计可见的战局变化

1. **明确目标与兑现。** 谁要达成什么、对手怎样阻止、终局改变什么。完整交锋组织压力与应变；招式展示、演武、首击前悬念按用户范围结束，不强补胜负。
2. **让交换接续。** 具体兵器和发力沿明确轨迹威胁对象，对手格挡、偏转、避让或反攻，接触或让空改变重心、防线、位置或主动权，下一招利用这个结果。前后不要反复回到同一摆姿；有目的的角力、佯退与相似打法可以保留。
3. **同时确定空间与拍法。** 对主要交换，确认起始距离/支撑、来路、回应、结果和下一状态，再选择能显示该变化的视点。镜头写清跟随对象、起始相位、可见范围和结束结果。近战先进入射程，离手有去回或留置；跨区有离开缘由、途中威胁和到达条件，相机推进不代替人物接近。
4. **形成节奏递进。** 迅疾出手、即时回应、恢复接追压构成实速；升级来自防线被破、路线受限或新条件迫使换招，不只是特效变大。按本场选择快速入局、连续施压、反制与终局兑现，不固定阶段数或时长比例。开放仙侠实际利用纵深、高差及近身/御器/场域转换；窄场地利用其限制。
5. **按可读性拆合。** 人物动作、相机运动、播放倍率和切镜频率分开安排。来路、接点、反馈可以同镜；同镜难读才拆，重复覆盖就合。镜数最后统计，不预设数值、区间或快慢配比。自适应取消旧镜数，不取消当前轴线、复位或微慢要求；换边有可见路径，复位可在运动中完成。一镜到底须有连续可行机位路线，不能藏切。

冲击反馈对应实际作用：挥空、格挡和命中不同，受击先沿冲量响应，再有制动或主动变向；裂地、火星、衣料与断息不能替代身体/兵器结果。眼神、呼吸、衣袖和碎石可附着主动作，不各占一次等待。选定接触可用短促Hit Stop或微慢，计入占时并恢复实速，不逐击添加。超载先删装饰和重复覆盖，再减可选交换，保留必选结果与桥接。

## 写成可直接使用的正文

放在同一复制块，稳定信息只写一次：

- **总设定**：时长画幅、视觉呈现、人物与参考对应、关键外观、武器与持械手、必要能力边界、交战区域和镜头形式。
- **连续时间段**：具体攻击→对手回应→接触/避让与受力变化→新位置和下一威胁；必要机位、切点、声音写在对应动作旁。段长随事件分配，不等分。最后兑现结尾与余势。
- **必要连续性**：只补本场易误解的身份、持物、路径和残留。逐镜稿按实际切点编镜号，时间段不等于镜头，计划时码不承诺逐帧执行。

详细度来自轨迹、回应、位移和可见结果，不靠形容词或字数。招名后接实际动作，不用“中间激烈交战”省略关键过程。只要提示词就不附设计报告、内部表格或完整素材分析；重要假设可简短说明，但复制块本身包含生成所需设定。精简先删重复，不丢关键因果。

交付前对读正文：目标保留了吗；距离和作用能成立吗；持物、支撑、损伤、地形接续吗；关键变化拍得到吗；时间装得下吗。按编排、覆盖、表达逐层修正，别把未完成的检查清单交给用户代做。文字通过不等于成片成功，不保存未经媒体验证的自生成历史案例。
