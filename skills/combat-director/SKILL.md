# 战斗导演

将用户的战斗想法发展成可拍、可读、独立可复制的中文视频提示词。完整正文写明**整体风格、战斗人物、武器、技能招式、命中效果、特效光影**，并在连续时间段中落实动作与结果。正文按生成模板的逐项写法具体交代环境与人物空间关系、远近景与景别、行为逻辑、人物行动路线和身体/武器动作轨迹、环境交互、运镜与切镜、动态模糊、时间，以及面部微表情、眼神和情绪变化；选用法术时写明手印转换、法阵构成与空间锚点、法术传播和中断结果；按生成模板组织，不只罗列标签。

## 先判断本次任务

- **生成或重编整场**：读取[战斗设置与生成模板](references/prompt-construction.md)，按其中各项的组织顺序、句式与例句把本场信息写成具体句子，再完成动作单元、状态衔接与正文。不要只引用文件名或让用户自行套模板。
- **仅改动作、摄影、节奏或特效**：读取[局部提示词写法](references/choreography.md)的相关小节；保留未授权改动的角色、事件、结尾与时长。
- **分析视频/图片/原提示词或诊断成片**：读取[观察与转写模板](references/review-loop.md)。先记录可见证据，再提炼可用句式；用户要改写/复刻时接入生成模板。
- **点名查库、平台生成或JSON工程**：仅按下表进入对应资源。普通写作不要求查库、联网、填JSON或调用生成平台。

## 输入与继承

场景、战斗类型、人物、招式可在一句话给出。继承已给约束，普通缺项由Agent拟定，重要选择简短说明；硬约束冲突才询问。不要求用户先提供完整导演方案。

未指定时采用30秒、16:9、允许切镜、快速实速为主、无对白、非血腥；用户明确的慢镜、蓄势、时长和镜头要求优先。先区分对抗、演武、登场和技能展示，不强补敌人或胜负。同场修改保留未变设定；新场景不自动继承旧人物、左右站位、招式和结尾。

参考图约束可见外观，首帧约束开场状态，动作视频提供被选用的运动关系。服装不证明能力；缺项可原创但不能冒充参考事实。未观察的音效、命中、材质或动作记未知，不能由标题、宣传或亮光补出。

## 工作顺序

**战斗设置 → 动作单元 → 状态链 → 时间与镜头覆盖 → 命中及光影 → 自含正文。**

对抗写“攻击—回应—接触/让空—受力变化—下一威胁”；演武写“起手—轨迹—重心/兵器余势—下一动作”。招名、风格标签和“无限连”不能替代这些过程。稳定设定只写一次，变化写在触发它的动作旁。

交付前按生成模板对读并修正正文；只要提示词时只给一个完整复制块，不附内部表格。拆解报告按观察模板交付；局部改稿只交付所改层。文字通过与工程通过都不代表成片成功。

## 必须保住的关系

- 相机推进不等于人物接近；近战进入射程，离手有去回/留置，跨区有真实路径与落点。空中反向有已设推进，不能由切镜重置支撑。
- 挥空、格挡、擦中与实击各写实际结果；光效、震屏和尘土不能替代身体/兵器反馈。实体、能量投影与尾迹分开，损伤和地形持续。
- 多镜战斗逐镜写起止时间和镜长，按动作与信息量编排长短变化，保持紧凑，不等分或机械长短交替；较长镜也要持续推进，短镜不能省略必要动作。镜数按编排与可读性确定，不预设通用配额；保留用户当前轴线、复位或微慢要求。一镜到底以镜内节拍形成变化，需要连续可行的相机路线，不能藏切；单次直出不等于没有切镜。
- 只改摄影时不新增攻击或能力；整体节奏重编可调整可选交换，但保留必选结果。续作从已接受的实际终态起步，不拿计划代替观察。
