# 战斗导演

将用户的战斗想法发展成可拍、可读、独立可复制的中文视频提示词。公共模块独立于分镜，集中写全场共用的风格、人物外观、场景、兵器与能力规则；各段分镜内部按需求选择不编号的中文类型标签，详细描述与本镜有关的空间、人物、动作、能力、摄影、时间与表演；25项是写作参考，不是必填清单。摄影、表演和效果服务同一条动作因果；公共模块和分镜都只写实际涉及的内容；不存在、未使用或不可呈现的模块直接省略，不保留空标题，不写“无”“未使用”“不适用”等占位说明。已发生的撤阵、消退、失手或落空属于有效事件，写在相关动作或状态变化中；用户明确的禁止条件保留在公共规则中，不逐镜扩成不存在的模块。不为填项增加情节。

## 先判断本次任务

- **生成或重编整场**：读取[战斗设置与生成模板](references/prompt-construction.md)的使用方法、动作单元、生成顺序与交付部分，再选本场需要的写法；将句式转成本场具体动作，不让用户自行套模板。
- **仅改动作、摄影、节奏或特效**：读取[局部提示词写法](references/choreography.md)的相关小节；保留未授权改动的角色、事件、结尾与时长。
- **分析视频/图片/原提示词或诊断成片**：读取[观察与转写模板](references/review-loop.md)。先记录可见证据，再提炼可用句式；用户要改写/复刻时接入生成模板。
- **JSON工程或编译导出**：按下表读取工程契约；普通提示词创作不要求查库、联网或填写JSON。

## 输入与继承

场景、战斗类型、人物、招式可在一句话给出。继承已给约束，普通缺项由Agent拟定，重要选择简短说明；硬约束冲突才询问。不要求用户先提供完整导演方案。

视频时长按用户需求确定，不设固定默认秒数。用户给出总长或范围时据此分配动作与镜头；未给出时，按动作内容、叙事目标与节奏拟定合理时长，并简短注明。不得为凑时长增加重复交锋，也不得为压时长省略必要因果。不擅改用户时长。

其他未指定项采用16:9、允许切镜、快速实速为主、无对白、非血腥。用户明确的慢镜、蓄势和镜头要求优先。先区分对抗、演武、登场和技能展示，不强补敌人或胜负。同场修改保留未变设定；新场景不自动继承旧人物、左右站位、招式和结尾。

参考图约束可见外观，首帧约束开场状态，动作视频提供被选用的运动关系。服装不证明能力；缺项可原创但不能冒充参考事实。未观察的音效、命中、材质或动作记未知，不能由标题、宣传或亮光补出。

## 工作顺序

**战斗设置 → 动作单元 → 状态链 → 时间与镜头覆盖 → 命中及光影 → 自含正文。**

对抗写“攻击—回应—接触/让空—受力变化—下一威胁”；演武写“起手—轨迹—重心/兵器余势—下一动作”。招名、风格标签和“无限连”不能替代这些过程。稳定设定只在独立公共模块写一次，分镜直接继承；当前站位、持物变化、攻防与摄影等本镜信息写在对应分镜中。变化写在触发它的动作旁，不重复公共外观与规则，也不以公共模块省略动作因果。

交付前按生成模板逐镜对读并修正正文。每段分镜先标起止时间和镜长，再按本镜需求选择【中文类型标签】，每项写具体内容。标签数量与顺序按表达需要安排，各镜可以不同；不相关项省略，不能留空或只写“同上”，公共模块与分镜分别组织；镜内只补必要起态、事件与变化，不重复公共内容。只要整场提示词时给一个完整复制块，不附内部审阅表。局部修改保留未授权层；一镜到底的各时间节拍同样按需选择标签。文字与工程验证不代表成片效果。

## 必须保住的关系

- 相机推进不等于人物接近；近战进入射程，离手有去回/留置，跨区有真实路径与落点。空中反向有已设推进，不能由切镜重置支撑。
- 挥空、格挡、擦中与实击各写实际结果；光效、震屏和尘土不能替代身体/兵器反馈。实体、能量投影与尾迹分开，损伤和地形持续。
- 多镜编排稿逐镜写起止时间和镜长，按动作与信息量编排长短变化，保持紧凑，不等分或机械长短交替；较长镜也要持续推进，短镜不能省略必要动作。镜数按编排与可读性确定，不预设通用配额；保留用户当前轴线、复位或微慢要求。一镜到底以镜内节拍形成变化，需要连续可行的相机路线，不能藏切；单次直出不等于没有切镜。
- 只改摄影时不新增攻击或能力；整体节奏重编可调整可选交换，但保留必选结果。续作从已接受的实际终态起步，不拿计划代替观察。
- 镜头、动作单元和生成片段不是同一单位。时间戳表达编排意图，不承诺逐帧控制；输入图、主动作、摄影与效果互相争夺注意时，先保留完整因果和用户硬约束，再删重复装饰或调整制作路径。
