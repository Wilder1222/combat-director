下表用于摘要初筛；相容性、来源等级与选读方法见页首检索规则。

| [武学节拍与连招](arvin-choreography-school-chain.md) | detailed | 77 | 每段选一条主运动线；下一招必须继承上一招的距离、手占用和落脚，允许被对手打断。 |
| [手部动作与攻击部位](arvin-choreography-hands.md) | detailed | 116 | 变换手部形状必须有空间和回收；用少数可辨动作表达区别，避免把全表写成一次连打。 |
| [踢击高度与身体路径](arvin-choreography-kicks.md) | detailed | 88 | 高度变化需要收腿、转髋和支撑交换；命中效果是候选，最终由双方位置决定。 |
| [压制与逆转拐点](arvin-choreography-turning.md) | detailed | 18 | 拐点来自已展示的习惯、资源或地形；对手改变习惯时允许反转失败。 |
| [终结前的呼吸与停顿](arvin-choreography-breath.md) | detailed | 0 | 停顿由收势、观察或重新支撑产生，时长随动作变化；不照搬固定生理秒数。 |
| [空间维度变化](arvin-choreography-space.md) | detailed | 67 | 只在场地提供高低与移动路径时换层；保持出口与落点，不为凑次数瞬移。 |
| [终结第一段：改变平衡](arvin-choreography-break.md) | detailed | 18 | 用一次可见改线或失衡创造窗口；对手站稳后窗口关闭，不自动进入终结。 |
| [终结第二段：集中输出](arvin-choreography-payoff.md) | detailed | 44 | 只兑现此前建立的能力和空间；终结动作可被挡住或让开，效果强度不得替代因果。 |

| [化劲与攻防转换](arvin-choreography-redirection.md) | detailed | 39 | 接触、改向、失衡、接续依次可见；对方抽手或变向时重新判断，不用化劲二字代替过程。 |
| [上下肢配合](arvin-choreography-upper-lower.md) | detailed | 38 | 手负责护线或牵制时不能同时做另一项抓握；腿的支撑和下一拍可用肢体持续继承。 |
| [抓控、投摔与脱离后的衔接](arvin-choreography-control-followup.md) | detailed | 23 | 控制成功与失败各留一条出口；对手起身后重新定距，不把锁控和反击当作必然连续事件。 |
| [八极两组短打连段](arvin-choreography-baji-pairs.md) | detailed | 6 | 选一组并明确对手如何回应；近身肘与肩的空间不能重叠，停顿由回收重立产生。 |
| [混合二十手：拆段使用](arvin-choreography-mixed20.md) | detailed | 20 | 这是分阶段参考，不要求在短片里打满二十手。每次最多抽一阶段，门派切换需由接触与重心解释。 |
| [连续轻击与重音节拍](arvin-choreography-rhythm.md) | detailed | 0 | 轻重对比服务动作可读性；只在重击因果节点做顿挫，不把每次接触都慢放。 |
| [攻守表情与身体反馈](arvin-choreography-reaction.md) | detailed | 0 | 先有明确受力方向，再有肩背、衣料和脚步反应；对手保持主动判断，反馈不能证明受伤程度。 |
| [中段递进与攻守三态](arvin-choreography-escalation.md) | detailed | 5 | 递进可选速度、空间、资源之一；防守、失衡和重建是状态变化，固定比例和恢复秒数不是生理事实。 |
