# 有限布幕结界

ID：`cloth-field`。袈裟意象的原创幻想能力，需人物设定允许。

**成立条件**：既有布料可被双手展开，双手没有同时持械；人物获准使用有限结界。先声明方向、可承受类型和次数，不能把“伏魔”理解为全能力免疫。

**阶段**：展开布面只是准备；张紧且纹路沿布边连通后才激活。一次已声明方向的能量冲击压弯布面，施术者向后落脚、双臂下沉，边缘纹路熄灭；此次预算消耗。松手、布面破损或连通中断均解除，解除后不再反弹下一击。

**对手反制**：可绕到未覆盖侧、等待消耗或以已获准方式迫使其松手。能否挡实体兵器是独立设定，不从能量防御自动推得。

**可见代价与结束**：承受后手臂暂不能再次撑起完整布幕，只能抱住下垂布料退让；本片不自动恢复预算。若后续必须用剑，先收布腾手再持剑。

**摄影与反馈**：画清布的两端、冲击方向和落脚，纹路贴在布面，不另生遮满人物的巨型球罩。布折痕与脚下尘痕保留。结构化阶段可映射现有能力事件，承受次数与布边连通仍须人工核对。
