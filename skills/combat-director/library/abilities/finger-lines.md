# 有限指向射线

ID：`finger-lines`。六脉神剑意象的原创影视转译；数量按用户设定，不从名称推断必须六线齐发。

**成立条件**：人物获准远程能量能力，有可用发射手、已声明射程与次数，发射点到终点路径清楚。普通动作足够时不采用本卡。

**阶段**：先显露手指朝向；细线沿所指方向发射。对手见指向后侧移，线从其原站位经过，撞到设定允许阻挡它的石柱后消散，柱面留下一道浅痕。下一次发射必须从当前手部朝向重新开始，不从空中旧轨迹凭空续射。

**预算与代价**：测试例可自定“两次单线、人物级范围”，明确是创作假设。第二次后手指颤动、腕部下垂，不能立刻加出第三次。若用户选定其它上限，改预算及后续状态，不强套两次。

**对手反制与失败**：提前改线、进入有效掩体或迫使施术手失去指向；自动追踪、穿墙、折返都需额外设定。被打断的蓄势不能在下一镜无由变成已释放。

**镜头与结束**：以包含双方和掩体的视角读清起点、路径、落点，再收近疲劳的手；严格全身同框则保留宽景。指尖熄灭和最后一道线消散说明结束，浅痕不消失。无实测音轨时尖啸、碎屑落声只是声音设计。
