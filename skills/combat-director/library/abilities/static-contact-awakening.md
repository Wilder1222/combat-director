# 觉醒型接触静电近战

ID：`static-contact-awakening`。按2026-10-13用户提供的SO-YEON文字参考独立改编的影视机制候选；未取得对应视频，不作为出片成功案例。角色姓名、身高、校园、白蓝色和30秒均是参考参数，采用时依本场改写。

**成立条件**：本场允许超常身体加速、自主防御与接触型静电；人物仍沿真实身体路线移动，有支撑、接触、受力和回收。静电是否额外传力、作用范围和残留时间分别锁定，真人质感与能力授权分开。

**动作与效果链**：来袭触发已设自主防御，身体先让线、处理接触并反击；初始冲量与局部形变可辨，接点再短暂亮起分叉细弧。局部微慢读同次作用，恢复实速继续原受力、分离和下一威胁。身体、光、摄影和声音共用这一事件，不因效果重放而新增命中。

**表演变化**：第一次反击后，人物才看见手掌残电与对手退势，指尖发抖、呼吸断续。身体精准与意识惊惧可以并存；确认结果的窗口内其他人继续逼近。结尾主动收住动作、呼气和选择离开路线，体现控制感变化。设定机制见[身体与意识的时间](../../references/sound-and-performance.md#身体先反应意识后追上)。

**摄影**：随可见身体起速追赶，允许短暂落后与方向过冲；沿原通路重新捕获，在必读接点前收稳。甩摇、模糊和闪光不替代接触覆盖；单镜取景变化沿连续可达路径，多镜接同一相位。

**环境**：尘纸沿位移气流与接触作用的方向移动，衣料先形变再回落；已设静电使近处发丝或纤维抬起，细弧沿来源部位衰减。电器闪烁、地面传播环或向内吸尘各需本场额外依据。散落物和受损状态在后节点保留，后续敌人用既有身份与路线接回。细则见[接触型静电](../../references/style-and-materials.md#接触型静电与环境反馈)。

**节点时间示范**：一个节点为2–3.2秒（占时1.2秒），侧让0.15秒、拨挡0.2秒、进身0.25秒、出拳0.15秒、接触微慢镜0.25秒，随后恢复实速收拳0.2秒。其他攻击在同窗继续，回应动作另写自己的耗时；具体速度曲线依本场动作与预算。[最终提示词](../../references/prompt-construction.md#每个战斗节点的秒数输出)逐动作保留耗时，复制块不附预算归属说明。

**限制与终态**：没有新接触时仅保留前次残电的明确衰减；光亮不能先推倒对手。被击退者再次入场需有恢复和抵达；首领加四人共五名敌人，后段“最后一人”应回认既有人物。终段为放电、承力、制动、确认和离开留实际窗口，只有已设能力才影响更远处对象。
