# 短弧接引

ID：`round-sword`。太极剑意象的原创影视编排，不是标准套路讲解。

**成立条件**：剑仍在可用手中，来刃正在进入可接触范围；身侧有落脚空间。目的可以是让路、脱离或试招，不预设伤害。

**动作链**：甲右手剑在身前形成短弧，接触乙的来刃；甲沿外侧让步，剑尖随接触移向身侧。乙察觉偏移后收回兵器并向前补步，甲不追砍身体，而把剑收在两人之间，保住下一次避让空间。

**回应与失败**：乙提前收招时没有可借的来力，甲的弧线只成为护持动作；外侧退路封住时缩短弧线并撤步，不绕到不存在的位置。

**恢复与代价**：接触后甲前臂下沉、呼吸加重，落脚稳住才再次变线；剑未脱手，不新增召回。

**镜头与终态**：斜侧双人景别读清两柄兵器、两人脚步与地面锚点；接触未被特效盖住。结束时相对位置确实改变，剑仍各归原持有者。无能量能力时只保留材质和衣摆反馈。
