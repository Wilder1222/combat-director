# 观察后截线

ID：`opening-counter`。独孤九剑意象的原创创作解释，不是原著招式或流派考证。

**成立条件**：此前确实展示对手的出手与回收习惯；观察者有可用兵器、合适距离及反应窗口。看穿招式不取消身体条件。

**动作链**：前一次交锋中，乙前压后惯于把刀收回右侧；甲目光追过刀尖而没有贸然追击。再次前压时，甲先让开来路，随后向已暴露的回收路线探出剑尖，截住乙的兵器。双方兵器碰触后分开，优势来自先前观察而非“招式无敌”。

**回应与失败**：乙改变回收方向，甲的预判落空，就保留落空并安排护持/撤离；不能事后补一句“早已看穿”让任何结果都成功。

**恢复与代价**：观察和等待占时间，也可能让出空间。甲剑尖前探后必须回收；没有机会追击时以守住出口作为结果。

**镜头与终态**：首次交锋看清刀的回收侧，后次保留同侧空间锚点。视线特写仅在可见性约束允许时使用；全身同框也可通过头部转向表达观察。终态为一次局部路线受阻，不默认死亡或缴械。
