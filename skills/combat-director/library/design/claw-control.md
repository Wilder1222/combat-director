# 抓袖与脱离

ID：`claw-control`。龙爪手形态的原创影视转译，不是现实擒拿教程。

**成立条件**：空手已腾出，双方已近身，衣袖或护臂可见。远处人物必须先经过接近过程；不对不可见身体部位编造精确控制。

**动作链**：甲张指前探扣住乙的宽袖，袖面拉出褶皱；乙随牵引侧移并收臂，布料绷紧后从甲指间抽出。甲手指合拢落空，乙趁这一拍恢复距离。抓住布料不代表已经控制骨骼或使人失能。

**回应与失败**：乙提前收臂时抓取落空；衣料滑脱或撕裂时按材料表现，不能继续写甲稳稳抓着同一块完整袖口。

**恢复与代价**：甲前探的身体需要回收与落脚；手掌保持空手，乙破损衣袖持续存在。后续可因抓取习惯被识破而改变攻防。

**镜头与终态**：保留双方手臂及袖面张力，必要时在同一机位后撤交代分离距离。普通抓袖不附加隔空巨爪；如用户选择法术，应另建能力而非改一个形容词。
