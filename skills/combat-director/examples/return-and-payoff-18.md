# 飞剑回握与旧裂口 · 18秒文字教学例

原创改编，展示武器归属、受击回弹和弱点回收；没有配套 JSON 或视频验证。仅在用户允许有限御剑与护幕能力时采用，人物脸和服装可替换。时长是创作目标，不是平台支持声明。

## 可投喂提示词

18秒，16:9，两名成年剑客在石桥东端交手。A穿暗红短袍，右手持一把有黄铜圆护手的钢剑；B穿灰白窄袖衣，右手持一把直刃钢剑，左手可维持一面贴近身体的半透明风幕。A最多同时生成两道红色能量剑影，实体钢剑始终只有一把；左手剑指可引导离手主剑，回握后剑指解除。风幕破裂后本片内不能再开，剑影各攻击一次即消散。两人的体能有限，受力后的步伐、呼吸与破损持续保留。

开场A在西、B在东，相距两步；桥北侧缺角石栏是固定锚点。B最多退到东端平台，不退出镜头。一镜到底，摄影机在桥南侧侧后跟随A，沿南侧平移至双人侧面，末段后撤扩大景别，保持交手轴线和连续时间。没有切镜、慢放或全场定格。只用环境和动作声音。

**0–4秒：接力反击，留下缺口。** A右手由外向内斜劈，B以剑身倾斜接住，右膝屈曲卸力；B顺着刃面滑开的方向转腕刺向A右肩。A右脚向西南撤半步，肩膀让开，左手剑指抬起；右手把同一把钢剑送出，柄先离掌后剑尖沿B外侧绕向其左肩。B左手抬起风幕，飞剑触幕被弹向北侧。风幕左肩高度留下两指宽的缺口，B左手压近该处维持幕面，呼吸骤紧。镜头在南侧双人景别看清接触和风幕缺口，火花仅出现在实体钢剑相擦处；剑碰风幕是短促气流撕裂声。

**4–8秒：召回、握住，再接近。** A左手剑指向自己右侧回勾，实体剑从B北侧绕过两人之间的空处，减速、转为剑柄朝A。A右手清楚接住黄铜护手后的剑柄，左手随后解除剑指；回握完成前不写实体剑近战。B趁回程向西跨半步刺来，A接剑后抬腕以剑身挡开，左脚接着前踏稳住。A视线短暂越过B剑尖，落在仍未愈合的左肩风幕缺口上。摄影机保持连续横移，双方持械臂和回握位置清晰。

**8–13秒：诱导防御，命中同一处。** A从实体剑上分出两道红色能量剑影，实体剑仍握在右手。第一影横向压向B右侧，B移剑拦截并将风幕右转；A本人向前斜跨一步，以实体剑压住B剑身，第二影沿风幕原有左肩缺口穿入，只击散维持风幕的气流节点，不击穿身体。两影分别完成一次攻击后消散，风幕由旧缺口向外裂开并散尽。B左手被回流震开，退向东端平台，两脚先后落稳；A没有多出实体剑。

**13–18秒：有限压制，保留余势。** B收回左手护住胸前，右手剑仍在；A继续压剑，将对方剑尖引向桥外的南下方，随后收半步，剑尖停在B肩前的空处。A目标是迫使B让出通道，B侧身向平台北边让开，双方均未再攻击。A吐出长气、手腕轻颤，B肩膀起伏，两人保持警戒。相机沿南侧后撤，显示让出的东行通路、仍缺角的北侧石栏和地面新擦痕。片尾呼吸、衣角与尘土继续微动，不宣称已经杀伤或获得永久胜利。

## 文本复核点

实体剑的离手、回程、回握、下一次实体接触顺序完整；两道剑影不混为两把可拾取的钢剑；缺口先在左肩高度出现，后来仍在同一处；风幕破裂与B让路是两个连续结果。若改成无幻想武侠，不能仅删除“能量”两个字，必须重编围攻与破幕动作。
