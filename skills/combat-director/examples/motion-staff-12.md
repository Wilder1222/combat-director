# 战斗设计卡

12秒、16:9、单次生成、一镜到底、正常速度。两名成年练习者完成斜劈、招架与前探试防，双方无伤脱离。

灰衣A在西朝东，褐衣B在东朝西；各双手握自己的同一根木杖，全程共两杖。

规则：
石院，北侧石墙与院中浅色石缝固定；南侧固定双人全身机位，日间柔和侧光。无幻想能力。杖端快移处少量自然弧形模糊，关键接触和恢复可追踪，静止石墙保持稳定。

时间预算：
0–0.2秒准备、11.4–12秒呼吸余量均包含在总长；11.4秒前双方完成退开和收杖。

来源：本项目2026-09-23原创运动成像教学方案；不是外部招谱、摄影机配置或视频观测。


# 六轨导演稿

时间及状态独立于六轨；表情与情绪合为表演轨。

## B01 · 0–2 秒
目的：互相观察并准备

1. 人物攻防：A：A轻探前脚，双手仍把木杖斜置右肩前，前0.2秒保留站稳与呼吸。；B：B调整两手间距，把木杖斜举胸前准备接开来杖。
2. 表演情绪：A：A看B前肩与杖身，呼吸平稳；B：B看A杖端，肩部微收。双方谨慎
3. 摄影机：S01 / start / 南侧固定双人全身，石墙不动；尚无快速挥动，不额外添加拖糊。
4. 特效：普通木杖与衣料自然外观。
5. 环境反馈：脚底轻擦只移动近处薄尘，石面完整。
6. 声音：轻呼吸与鞋底摩擦，无台词与配乐。

## B02 · 2–5 秒
目的：斜劈被接开

1. 人物攻防：A：A双手把木杖从右肩斜落向B左肩前；接触B斜架的杖身后屈肘随杖端向自己右下方滑开。；B：B向东南撤半步，双手斜举木杖接住来杖，将A杖端导向A右下方，左肩避开攻击线。
2. 表演情绪：A：A盯着接杖处，接触时短呼气；B：B收下颌看A杖端，双手握紧。接触时短促绷紧
3. 摄影机：S01 / continuous / 保持南侧固定双人全身，两根杖的接触和滑开在画内；快移杖端形成短弧形模糊，背景石墙稳定。
4. 特效：木杖接触处保留材质，不加火星或光带。
5. 环境反馈：B东南撤步留下浅鞋印，少量近地尘沿落脚处散开。
6. 声音：一次短木碰声跟随实际接触，随后木面摩擦。

## B03 · 5–8 秒
目的：收杖恢复后回应前探

1. 人物攻防：A：A先屈肘把低处木杖收回胸前，向西退半步落稳，随后以杖中段斜拨B前探的杖端到身外。；B：B在A收杖时向西北回进半步，双手推杖前探A胸前；被拨开后屈肘收回，不继续顶进。
2. 表演情绪：A：A视线从自己的回收路径转到B杖端；B：B看A胸线，被拨开时呼气并松开肩部张力。主动试防后恢复克制
3. 摄影机：S01 / continuous / 相机保持固定，能追踪A从低位回收再接开前探；杖端快移处轻微方向性模糊，双手持物关系可辨。
4. 特效：仍为两根实体木杖，无独立残影或发光尾迹。
5. 环境反馈：既有浅印仍在，A西退与B西北回进形成各自脚边少量浮尘。
6. 声音：前探破风、木面短接触与落脚声按动作顺序出现。

## B04 · 8–12 秒
目的：双方退开并收势

1. 人物攻防：A：A向西退一步，与B拉开距离，11.4秒前双手降低木杖并站稳，余下时间平稳呼吸。；B：B向东退一步，双手降低木杖，11.4秒前完成落脚，继续注视A。
2. 表演情绪：A：A肩部放松，仍看B；B：B松下颌，呼吸回稳。对练结束但仍留意对手
3. 摄影机：S01 / continuous / 同一固定全身机位到结束；杖与相机相对止势后不再产生快移拖糊，余量是呼吸而非定格。
4. 特效：木杖完整，无粒子光迹；自然材质细节在止势后更易辨认。
5. 环境反馈：停止踏步就不再扬新尘，已有细尘沉降，所有浅印保留。
6. 声音：两次落脚后只留平稳呼吸与微风。
