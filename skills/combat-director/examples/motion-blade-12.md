# 战斗设计卡

12秒、16:9、单次生成、正常速度、一镜到底。一次横切让空、一次回刺被拨开后双方无伤脱离。

灰衣A在西朝东，褐衣B在东朝西，各右手始终握同一把钢剑；全片仅两把实体剑。A获准有仅显示剑路的窄青光，B无此能力。

规则：
直线石廊，北侧石墙与东端方石柱固定。相机在两人南侧随交手向东平移，叙事中心跟住A躯干并留出B退进范围；不越轴、不切镜。自然短运动模糊与A的附刃尾迹分开处理，B与四肢相对运动仍可见。

时间预算：
0–0.2秒准备与11.4–12秒余量已含在12秒内；11.4秒前双方止势、相机平稳停下，尾迹在12秒前退净。

时间及状态独立于六轨；表情与情绪合为表演轨。

## B01 · 0–2 秒
目的：建立移动方向

1. 人物攻防：A：A向东进小半步，右手剑守胸前，不挥刃。；B：B面向A向东退小半步，守住原来的两步间距。
2. 表演情绪：A：A看B前肩，握柄不过度绷紧；B：B看A剑尖，后脚先探稳。谨慎试探
3. 摄影机：S01 / start / 相机从南侧双人全身平稳向东跟随A躯干起步，留出B东退空间；石墙在画面缓慢向左移动，起步缓慢不强加长拖影。
4. 特效：尚未挥刃，没有新青光尾迹。
5. 环境反馈：衣摆随步幅摆动，地面完整。
6. 声音：轻脚步与呼吸，无台词或配乐。

## B03 · 5–8 秒
目的：回刺与斜拨

1. 人物攻防：A：A先回剑至胸前；B前刺时向西退半步，右手斜立钢剑把来剑拨向自己左外侧，两刃短暂滑擦后分别回收。；B：B趁A回剑向西进半步，右手钢剑直刺A胸前；被斜拨后屈肘收剑并落稳。
2. 表演情绪：A：A看B剑尖，接触时握紧右手；B：B盯A胸线，被拨后收肘短呼气。短促接触后准备脱离
3. 摄影机：S01 / continuous / 相机保持南侧双人构图，连续减小向东平移速度，不急甩也不切换曝光；两只持械手、拨开方向和回收可辨，快移剑尖仍有短暂方向性模糊。
4. 特效：A回剑仅产生短新青光，前段旧尾迹留在原处继续暗下；窄光带避开两只持械手与交刃区域。B剑不发光。
5. 环境反馈：鞋底擦动留下浅擦痕，廊地没有爆裂或无由飞石。
6. 声音：一次短金属滑擦紧随实际交刃，再有各自落脚声。

目的：相机与人物收势

1. 人物攻防：A：A向西退一步，右手降低剑尖，11.4秒前站稳并停止挥剑。；B：B向东退一步拉开距离，右手剑尖降低，11.4秒前站稳，继续注视A。
2. 表演情绪：A：A肩部松开，呼吸放稳；B：B下颌放松，仍看A。主动脱离，双方未决
3. 摄影机：S01 / continuous / 相机连续减速并在11.4秒前停在南侧双人全身机位。停止平移后石墙不再横向拖糊；人物止势后的余量仍有呼吸，没有全场冻结。

5. 环境反馈：鞋底浅擦痕仍在，衣摆逐渐落稳，石廊完整。
