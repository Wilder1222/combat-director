## 1. 总体判断

这些提示词的价值主要在具体的攻防链和视觉事件：脚踩什么、哪一剑打向哪里、格挡怎样让身体失衡、风场怎样带动砂石、细小损伤如何成为后段机会。相比“史诗感、极致燃、电影级”等抽象词，这些信息更适合提炼成技能知识。

风险也很集中：大量动作、机位与表演挤入1秒；局部镜头违背总则；主兵器、飞剑、剑影没有明确区分；临时出现“先前裂口”；角色从远处到近处、从悬空到滑地缺少过渡。需要补的是可见桥接和约束范围，而不是继续叠加形容词或更长的负向词清单。

P2A和P2B不是同一套能力的措辞优化：飞剑从A转到了B，A改用剑气。P1A的骨神与P1B的傀儡骑乘组合也不是同一敌人的两个称呼。不能把两个版本合并后让同一角色无代价获得所有技能。

P3、P4以及P2/P6的若干段落共享骨架：前10秒高速试探，10–20秒控场、受挫和反击，20秒后终结碰撞，再留末段姿态。相似文本不能计为互相独立的效果验证，更不能把这条骨架当所有战斗的唯一正确结构。

## 2. 《最新打斗提示词》：群战升级与环境破坏

### 2.1 P1A：从杂兵到百米巨敌

| 时段 | 原文主要事件 | 编排作用 |
| --- | --- | --- |
| 0–3秒 | 出剑清杂兵、借岩起跃、落地疾行再刺 | 快速建立剑术、身体机动和敌人密度 |
| 3–7秒 | 精英巨斧压迫、滑退、攻击膝腕、应对骨刺 | 把横扫杂兵转为有反击的近身压力 |
| 7–10秒 | 低位滑行、反握挑斩、插地冲起、聚光 | 从地面交锋过渡为空中释放 |
| 10–15.5秒 | 多点落剑、奔行剑痕、夹击、背后重击、落剑翻滚 | 扩大场地破坏，再以失械制造低点 |
| 15.5–20秒 | 翻滚拾剑、突刺核心、引爆旧剑痕、骨神入场 | 反制并回收前段布置，开启新尺度威胁 |
| 20–28秒 | 避掌、斩腕、沿巨敌攀升、巨型剑光终结 | 对手尺度放大，攻击路径随之改变 |
| 28–30秒 | 落地喘息、尘烬、新威胁方向 | 让巨招有余势，保留续接可能 |

**可复用内容。** 近身剑术负责建立力量，受挫迫使重新争取武器，前段剑痕成为反制条件；巨敌不是放大版杂兵，而是改变接近路线、打击位置和机位尺度。地面裂痕、断柱和坍塌可以让场景记住先前攻击。

**需要修订的地方。**

- L13–14先令精英膝部受创跪倒，L23又从背后高速挥斧。需要给它以斧撑地、拖着受伤腿转身等恢复过程，或明确后者是另一名精英；不能无声复位。
- L16反握挑斩与此前握法之间缺换握；空中攻击后的滑地也要先给落脚或翻滚承力。每个桥接占用实际片长。
- L24小标题写“召剑”，正文却是滚地拾回；应按正文选地面拾取，并保留落剑位置。该行“镜头切至”直接违背一镜到底总则，可改连续贴地跟进到拾剑侧面。
- L33同时要求所有物体“精准定格”和剑锋震颤。若想动态英雄姿态，就不要叫全场冻结；若要尾帧冻结，明确最后0.5秒连相机、剑身和粒子一起停。
- L8/L35–40堆叠高速、全清晰、景深、动态模糊等要求。宜优先保证脸、握柄和接触点可读，让背景与拖尾承担速度感；无需假定快门、震频等数值会被视频工具作为真实参数执行。

### 2.2 P1B：同构故事中的实际改进和新变量

此版从双手叠握、剑身垂地起势；早期攻击膝部、腰侧和面甲裂隙，后段再次刺入裂隙。环境破坏依次扩大到柱体、阶梯、侧殿、屋顶与雕像，更适合做持续损伤记录。E3由百米骨神改成骑乘机械傀儡的指挥者，终结目标包含骑乘者和傀儡核心两层，必须分别追踪。

| 文本位置 | 价值 / 问题 | 建议 |
| --- | --- | --- |
| L57–58 | 开场长剑垂地，下一拍“拔剑般”容易暗示从不存在的鞘中拔剑 | 写“抬剑翻腕”，保持双手握持与剑尖抬起过程 |
| L62、L72 | 面甲缺口先出现，后被突刺命中 | 保留该因果，把角色看向缺口的注意变化写出来 |

| L64 | “推近红瞳再切光球”与单镜目标可能冲突 | 若是焦点变化写“移焦”，若是机位变化给连续推拉路径 |
| L73、L76–79 | 傀儡带来膝关节、肘关节、肩部踏点 | 踏点须在打击后仍可承力；骑乘者不能在击中傀儡时自动消失 |

| L81 | 定格、剑身震颤、镜头推进和最后半秒静止混写 | 划成动态余势段与全场冻结段，动作不互相否定 |

**提炼范围。** 适用于“敌群逐级改变打法”的片段。不能要求所有30秒故事必须经历杂兵、精英、巨神三次升级；人物级夺物或护送并不需要把场地毁尽。

## 3. 《双女》：能力辨识、回应链与终结碰撞

### 3.1 P2A：红色飞剑对蓝白风场

0–3秒以踢击、抓踝、挣脱和翻身开局，比双人隔空蓄力更早建立身体接触。3–10秒把飞剑轨迹、风刃高低、低位闪避和弹剑回击交织起来，9–10秒以安静的目光切换注意焦点。10–20秒通过围控、低位剑网、近身掌击、失械与拾回形成一次优势反转。20–28秒剑雨与龙卷按外围偏转、前列突破、核心接触、压力释放逐层碰撞；28–30秒双方落地再备战，保持未决。

**值得保留。**

1. 每次攻击给明确回应，例如肩颈避开第一刃、剑背挡住第二刃，格挡震动传到手腕。防守产生下一动作的起点，不是静止护盾挡住一切。
2. 红剑仍有剑尖、剑脊和剑柄轮廓，风场有旋转方向与吸入砂石；两种能力通过形态和运动辨识，而非只看红蓝颜色。
3. 固定灰岩帮助观众理解双方分处河床两侧；终结技之后重新露出灰岩，可以确认空间连续，而不是另换战场。
4. 碰撞不是直接白屏爆炸，而是先分层接触再释放压力。这是可迁移的呈现方法，仍要给层次足够时长。

**需补的因果。** L53从两岸直接进入贴脸近战，补一方借压制前掠或另一方追近的路线；L62第五、第六剑击中“先前划开”的风盾薄弱处，但该处缺少此前形成过程，应提前让一次飞剑留下缺口，或者当前先打裂再追击。L76的几十柄剑与L100附近的禁止武器增殖需要区分实体兵器与有上限的能量投影，不能两条泛写并存。L87灰岩“位置不变”宜理解为世界位置固定，相机绕行时它在画面里的位置仍可变化。

镜头总则只要远景和特写、不停中景，可用持续推拉过渡；若按“一帧中景也不能有”的字面要求则与一镜到底冲突。先核对含义，不能靠快速变焦掩饰一次剪辑。两位角色同时清楚也不等于两张脸在每个微距镜头中都清楚。

### 3.2 P2B：赤红剑气对银蓝飞剑

外观近似，但能力职责改变：A使用贴近主剑产生的剑气，B负责飞剑、围攻和剑雨。开场以飞剑擦面和一次0.2秒子弹时间强调危险，后续恢复快速交锋；此前版本的风场不能顺手继承给B。

| 时段 / 文本位置 | 原文的结构价值 | 复核重点 |
| --- | --- | --- |
| 0–4秒，L133–142 | 近面威胁、肩甲被擦、背后飞剑、接触后的滑退 | 飞剑绕后有路径；空中受击后先落地再犁出痕迹 |
| 4–10秒，L145–157 | 格挡让飞剑出现赤红裂纹，随后目光识别裂纹 | 这是完整弱点铺垫的好例；记录受损的是哪一柄、哪一处 |
| 10–15.5秒，L162–171 | 剑气阵与飞剑拆节点，近身压腕后失械 | 掉落的是实体主剑，不与飞剑群混同；落点与拾回关联 |
| 15.5–18.5秒，L174–177 | 拾剑后用细剑气击中旧裂纹 | 若其他飞剑连锁碎裂，须提前建立共同阵列/传导；一柄裂纹不足以解释全部爆炸 |
| 18.5–28秒，L180–200 | 剑雨封前路与两翼，巨刃与剑群逐层碰撞 | 交代从哪一组现存剑影汇聚、消耗哪些资源；不要无限增殖 |
| 28–30秒，L203–208 | 双方回到河床两岸，两柄残存飞剑参与末段 | 大碰撞后仍可用的数量与主剑持握要闭合，未决结尾不强加胜者 |

此版把“只有开场子弹时间，最后允许定格”的例外写得较清楚，优于全面禁慢动作后局部再写慢放。应吸收的是按时段控制节奏的方法，不是把所有片段统一为0.2秒慢动作。

**P2A与P2B的共同编排资产。** 角色能力辨识卡、飞剑回程、接触回弹、局部弱点、逐层碰撞、动态余势。**不应继承为默认规则。** 全女角色、固定红白服装、固定河床、全部远景加微距、固定终结大招以及所有生成任务都无对白。

## 4. 《双人打斗第二弹》与《双人打斗》：近似模板中的改装风险

### 4.1 共用骨架

| 时段 | 两份文本共有的功能 |
| --- | --- |
| 0–3秒 | 远距离御剑试探 → 风刃回应 → 攻击持械腕 → 强格挡后退 |
| 3–10秒 | 连击、密集拦截、滑行挑斩、借浮石上升、目光锁定 |
| 10–14秒 | 剑雨刺入风壁与地面、剑网持续施压、裂口扩大 |
| 14–18.5秒 | 男方贴背反击使女方失械 → 女方取回 → 攻击旧风壁裂口 |
| 18.5–24秒 | 风场扩大成龙卷，角色仍位于风眼；女方沿碎石接近 |
| 24–30秒 | 剑群合为巨剑、击散风场、男方跪地撑剑、女方收势止剑咽喉 |

P3/P4的风壁旧裂口有较清楚的前段成因，比P2A临时声明旧伤更完整。敌人位于风场中心，也提供了维持角色身份的写法，不必把人形敌人偷偷换成风暴怪。

### 4.2 P4：白发金甲版本

原文人物锚定为女方白金衣、黑金剑，男方白发金甲、金蓝剑；金色飞剑与青色风场归属不同。L16飞剑撞男方护腕的金属火花成立于金甲设定，L33斩肩甲也有明确材料反馈。

风险主要在动作过渡：L14距离约十丈却要在1秒完成放剑、接近、格挡和召回，连带镜头转换，负载过高；应减少一次交换或延长这一主段。L19–20飞剑刚处于御使状态，女方随即握剑滑斩，缺召回与接柄。L26男方双手操作风场时，原剑位置不明。L27以“瞬身到背后”跳过路线，原文未给瞬移规则；修订可选择已有风场加速绕行，而非凭空增加能力。L34双手结印之后，L36实体剑再次在手，也需回握。

L12绝对禁止冻结和定格，L37却以定格结尾。若保留用户要的剑指咽喉压制，可以写双方姿势停驻、呼吸和衣角仍动；若用户明确要全场定格，则将末段列为总则例外。保持压制结尾并不要求强行决定必须定格。

### 4.3 P3：双黑发、袍服版本

P3保留了大部分动作和秒点，但改成双方黑发；女方服装、耳饰、腰带和蓝银剑，男方米白绣袍、蓝色内层、红金腰带和金柄冷蓝剑。此时应靠衣服轮廓、兵器形制、能力形态、位置与表演辨识双方，不能继续依赖“黑发对白发”的旧区分。

L13飞剑击在男方手腕外侧仍写火花；既然没有明确金属护腕，需改为擦过金属剑格，或以风场裂纹和布料纤维反馈表现，不能把旧版金甲材质带过来。L30男方肩部变成袍肩被割，与P4的肩甲不同；之后依赖该损伤的姿态和声音也应跟着改变。L14空中受击后双脚滑地、L17握剑前缺召回、L23双手施法时丢失主剑、L24突然贴背，与P4的过渡缺口相同。L9禁止冻结、L34结束定格也重复同一冲突。

**可复用的方法。** 换角色不只换面孔与名字。对照身份、材料、持物、支撑、能力、损伤和结尾七项，逐一检查前后依赖。用旧方案制作新角色版本时，这比继续增加“禁止换脸”的次数更有效。

## 5. 《小师妹首登》：必须独立保留的预告语法

这份并不是缩短到15秒的完整对战。它先展示人物局部和体量关系，再以附魔、台词、起跳与连续踏空制造接近威胁的过程，最后把命中结果留空。巨兽转瞳已经是对主角行动的回应；不需要为了“双方必须交手”强塞格挡或受伤。

| 原秒点 / 行号 | 视觉与叙事用途 | 保留或改进 |
| --- | --- | --- |
| 0–3秒，L2–4 | 脚尖压裂屋檐、绑带漆皮耳坠，再切巨兽尺度 | 材质和体量具体；明确允许硬切，不套用其他文本的一镜到底 |
| 3–6秒，L5–7 | 冷眸和刀身建立目标；左指引导红色附魔 | 光沿手指经过的刀身依次出现，局部照亮脸，优于无源泛光 |
| 6–7秒，L8 | 说完整一句“大小姐今天脾气不好，看我怎么收拾你” | 1秒承载完整表演明显紧张；把台词移到附魔/目光段并行，给约4秒估计窗口，实际仍需配音测时 |
| 7–10秒，L9–11 | 蓄力、屋顶爆裂、硬切到城市间蹬墙 | 先蹬离再坍塌，先接触墙面再变向；不能只靠黑红残影说明位移 |
| 10–13秒，L12–13 | 三次踏空气爆、巨兽转瞳 | 明确三次能力事件与逐次上升，保持巨兽方向和城市尺度 |
| 13–15秒，L14–15 | 眼神、双手握刀、起斩短暂停顿、白闪收黑 | 左手从平衡位到握柄有过渡；停止于接触前，不加命中声、受伤或胜利画面 |

本例允许漫画速度线、台词、硬切、蓄力和收黑，这些均与若干30秒提示词的负向要求相反。它们属于不同片段形式，没有必要统一为一套禁令。默认成年角色是本项目测试假设，不因“小师妹”称呼推定未成年，也不能从未读取的图片补造身份。

完整修订例见 [15秒登场与悬念](../../skills/combat-director/examples/entrance-cliffhanger-15.md)。重点改变时间预算与路线交代，保留原句和悬念目的。此例为文字规划，尚未实测配音、口型或生成效果。

## 6. 《双男》：移动场地、连续近战与规则作用域

此份的突出优点是战场本身参与节奏：悬空桥的开放空间，残殿的狭窄通道，外侧旋风眼的终结尺度。天空裂隙作为持续锚点；攻击使桥、殿、浮石发生不可逆破坏，人物不能回到完整的旧区域重新打一次。

### 6.1 时间层次与角色功能

| 时段 | 主要功能 | 应保留的可见内容 |
| --- | --- | --- |
| 0–3秒 | 双剑已经咬合，从接触中进入战斗 | 钢剑刃面、握柄张力、手腕转向、对方后撤或回弹 |
| 3–10秒 | 近身连击、撞桥、低位反击、短暂观察 | 每击对应对手回应；破桥改变支点；9–10秒降低镜头扰动有助阅读注意变化 |
| 10–14秒 | 从桥推进残殿，剑气限制路线 | 入殿路径、门口/断墙位置、剑笼为何限制某一方 |
| 14–20秒 | 白发方受挫、稳住几乎脱手的剑、反击旧伤、场地再变 | “几乎脱手”不等于已经落地；伤处需先建立；两人进入风眼有可见位移 |
| 20–28秒 | 浮石交错、逐次挥击、终结碰撞 | 每次借力点与能力支撑、主剑实体连续、碰撞分层和代价 |
| 28–30秒 | 相撞余势与末段冻结 | 明确微动段和冻结段边界，区分谁仍持剑、世界破坏保留在哪里 |

### 6.2 原文内部的作用域冲突

| 位置 | 判断 | 最小改法 |
| --- | --- | --- |
| L5–6 | “每帧双人清晰”与允许短时出画、后续微距互相竞争 | 选双方持续全身可见则删单人微距；选关键交手双方可读则明确短时画外位置与回到双人景别的时间 |
| L11、L14、L19、L27 | 只允许最后冻结，开场和多次碰撞又凝滞1–2帧 | 将命中强调改为短闪/声峰且动作不停，或显式列出新增停顿例外；不能同时绝对禁止 |
| L16的9–10秒 | “镜头稳稳停”与禁止固定机位有歧义 | 写“降低抖动、仍缓慢横移”；稳定镜头不等于时间冻结 |
| L22的17–18.5秒 | 打中“先前擦破袍肩”，此前明确损伤更接近袖部 | 前段建立同一侧同一处肩口，或让反击命中已经出现的袖口；不能把不同部位混成旧伤 |
| 同一段 | 一处击中让多个青色痕迹连爆，缺共同触发条件 | 事先明确痕迹来自同一场域且会连通，或收窄为局部反应 |
| L22的18.5–20秒 | 天空锚点“突然压近”未交代是相机、人物还是裂隙自身运动 | 选一种并写路径；若只是视觉尺度变化，用镜头与人物接近解释，不能暗中搬动世界锚点 |
| L27的26–28秒 | “切成无人机超广角”违背一镜到底 | 让相机从交手外侧连续后撤升高，并保留相对站位和真实时间 |
| L27、L29 | 正文后段再次蓄力冲锋，负向却禁蓄力和对冲 | 若禁令只针对开场，写“开场直接接触，不再单独起跑”；若全片禁，则重编后段 |
| L4、L29 | 旧血迹衣服与绝对“无血液”字面冲突 | 保留旧痕但不出现新增出血，或按用户选择改成灰尘/焦痕；不能静默改角色信息 |

能量光球与透明压力球壳也不能只按“球”字判定。漂浮在刀尖的聚光、独立发射的能量弹、空气被挤压成弧形壳层是不同事件，应明确意图。裂隙合拢若是能力状态变化，不自动等于断桥与碎甲物理复原；必须分别记录。

### 6.3 应提炼的独特方法

- 区域之间存在单向推进路线，交手结果推动过门、离桥和入风眼，不靠相机瞬移换景。
- 双方能力既用于打击，也用于限位、牵引、借力和缓冲，让场地不是纯背景。
- 强碰撞与观察窗口交替。一直震动、每帧都有巨大拖尾，会吞掉原本很具体的持械手和攻击方向，应按事件给视觉重点。
- 躯体、钢剑、能量刃和碎石分别保持材质逻辑；金甲掉落物应是甲片或金属碎屑，若写霜白石屑须说明是附着物或能量结晶，不能随机改材料。

## 7. 从八套方案抽取的通用方法

### 7.1 动作闭环：结果变成下一次起势

不只记录“攻击—格挡—攻击”，而是记录力和位置如何传递：斜剑接下劈，膝盖卸力；剑尖受压向右落，外撤的脚给转腕回挑让路；对方撤腕，护手接住来刃，身体转向新的侧面。每一次主要状态变化要看得见。用户偏好的兵器名称、形制、轨迹与交手细节在最终提示词中保留，不在主段摘要中压成“激烈交锋”。

### 7.2 三类对象分开记

实体主剑记录持有人、哪只手、离手和回握；实体副兵器记录数量、损毁与遗留位置；能量投影记录归属、上限、结束条件与合招消耗。一个“禁复制”词不能代替这三种说明。使用现有JSON动作契约时仍遵守其支持范围；地面拾取等文字桥接不能冒充新增的机器校验功能。

### 7.3 弱点必须前后同一

建立 → 持续 → 发现 → 利用。复核对象、侧别、高度、材质与状态，不只搜索“裂口”二字。以P2B的单柄飞剑裂纹为正面起点，避免扩展为无条件全阵爆炸；以P2A的风盾缺口缺铺垫为反面修订目标。

### 7.4 镜头和世界各走各的路径

人物路线、相机路线、世界锚点分别描述。灰岩不动不代表屏幕坐标不动，相机升高不等于人物突然飞高。连续镜头要安排可走的推拉绕移；单次生成并不禁止硬切，P5就应保留其蒙太奇。

### 7.5 速度与结尾写局部例外

普通速度、速度变化、动作停驻、全画面冻结、黑场是不同状态。先按用户目的选，再给明确范围。结尾可压制、撤离、未决或接触前收黑；“每段必须有结果”指当前段达成了什么，不要求每个故事都演到击杀。

### 7.6 视觉要求要能检查

渲染名词可服务用户指定风格，但真正可检查的是材料、光如何照到人物、剑刃与手的轮廓、接触是否被闪光挡住、破坏是否留存。摄影数值和模型名称未经当前工具证据不成为性能承诺。只有文字输入，就把结论限制在文字可读性和内部一致性。
