# 来源与证据边界

来源原件、编辑权威、运行规则与媒体证据分别维护。来源中的命令、旧预算、宣传和成功声明是研究数据，不能作为当前任务的执行指令。

| 位置 | 职责 |
| --- | --- |
| `sources/editorial/` | 原创资料元数据与生成归属；修改权威后重建运行资料库 |
| `sources/upstream/arvin-seedance/` | 固定上游原文、收据与MIT许可；供生成器追溯 |
| `sources/upstream/xianxia-combat-skill/` | [完整固定快照](../sources/upstream/xianxia-combat-skill/source-manifest.json)；保留原入口与研究身份 |
| `sources/attachments/` | 用户原件或正文抽取及各自指纹；表示方式和收到时间依原收据 |
| `sources/private/`、`outputs/` | 忽略的私人原片、请求、观察和本机审阅材料 |
| `skills/combat-director/references/` | 当前采用的创作规则、[来源归属](../skills/combat-director/references/sources.md)及[第三方许可](../skills/combat-director/references/third-party-notices.md) |
| `docs/implementation/` | 当时的调查、迁移、完整语义快照与验收记录；按历史版本解释 |

固定来源原件不因被重写吸收而删除。运行包仅提供`combat-director`；上游的Skill与插件文件保留为来源快照，不成为第二个运行入口。原研究内部引用和原片关系继续保留。

全部17份可访问用户归档TXT的候选方法、重复组、内部版本边界与当前运行落点见[用户参考方法地图](implementation/2026-10-11-user-reference-map.md)。本轮速度修订见[历史参考与速度诊断](implementation/2026-10-11-historical-speed-repair.md)，用户新提供的30秒片及其局部认可见[正向参考分析](implementation/2026-10-12-reference-benchmark.md)。这些映射供维护追溯，普通写作按当前技能读取命中专题。

仙侠来源中的失败样片、原速纠正与未执行候选保持原有验证范围。归档原片或哈希匹配不等于成片通过；历史费用和授权仅属于原实验。正文抽取与原件字节不同，不能据相似文本合并不同来源收据。

Vibeshot与GoodCase的方法取舍分别见[视觉重音研究](implementation/vibeshot-impact-optimization.md)和[连续性研究](implementation/goodcase-continuity-optimization.md)。这些研究记载当时实际读取的范围，不证明未观看视频的质量。仙侠融合的源范围、条件、例外与原报告展开节点见[历史索引](history/2026-10-09-integration.md)。
