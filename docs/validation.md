## 复现命令

先在独立开发环境安装requirements-dev.txt，然后从项目根运行：

```powershell
python -m pip install -r requirements-dev.txt
python scripts/validate_release.py
```

运行时不需要这些开发依赖；解压后的combat_tool.py只依赖Python标准库。打包允许清单排除sources、tests、evals、docs、虚拟环境和临时输出。各次模型行为结果冻结保存，执行单元测试不会重跑或改写它们。
