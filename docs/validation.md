## 验证职责

| 检查 | 能证明的范围 |
| --- | --- |
| 来源指纹与迁移清单 | 固定原文、定位、目标版本和处置；归档不能证明能力已可用 |
| 文档/案例结构 | 本地文件及章节、公开/私有边界、28时间轴案例/30片段；不能证明语义或视频 |
| 工程与状态回归 | schema/引用、事实回放、并发/占用、复核失效、真实观察续作和导出兼容 |
| 抽帧真实工具测试 | PTS、像素/元数据、指纹和异常/文件保护；合成测试片不等于创作视频 |
| 独立语义审阅 | 所读源条件/例外与具体目标正文的对应，绑定版本和实际复读 |
| 冷启动完整创作 | 唯一入口在真实请求下的读取、完整提示词、需求与动作关系；文字产物不证明模型执行 |
| 包与安装 | 可复现ZIP、自含运行、单入口、当前宿主发现；当前对话缓存另有生命周期 |
