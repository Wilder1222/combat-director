## 文字行为检查

以两道真实素材改编请求分别运行0.5.0与0.6.0，每题每版一次，初轮4次独立执行后作匿名复核。复核发现新版一处实体剑去程遗漏，保留原稿、收窄修订并追加1次独立复测，主任务确认该缺口在复测文本中已修正。合计5次任务执行和1次匿名复核，输出、输入摘要和局限见[文字评估](implementation/prompt-evaluation-0.6.0.md)。旧版已经能完成两题的主要目标；新版对实体/投影、旧裂口与速度例外的表达更明确，但不据此宣称普适提升。

两题都来自本轮用于改进Skill的素材，登场题还有同源教学例，因此属于回归与知识检索检查，不能作为未见素材的泛化成绩。没有图像/视频观察、配音实测或平台出片，文字通过不代表生成效果通过。此前的12次独立任务记录见[原行为报告](implementation/behavior-evaluation.md)，与本轮5次分开计数。

## 本地插件更新

通过已存在的个人市场 `combat-director@personal` 更新，CLI确认 `installed=true`、`enabled=true`。安装版本为 `0.6.0+codex.20260922053502`；版本后缀只用于本地缓存刷新，仓库发布版仍为0.6.0。

检查了原本地源34个技能文件与0.5.0提交一致后，备份本地源，复制验证过的ZIP内容，用plugin-creator本地辅助脚本刷新后缀，再执行 `codex plugin add combat-director@personal --json`。38个发布文件在安装缓存中逐项核对；插件清单仅版本后缀和JSON序列化不同，其余内容相等。个人市场文件未改变。详细状态和哈希见[安装记录](implementation/local-plugin-0.6.0.json)。

原本地源留有12个Python字节码缓存文件；可选清理命令被执行策略拒绝，未重试删除，升级使用保留文件的复制方式完成。它们不在38文件发布ZIP中。新任务才会拾取新版技能；未执行新会话隐式路由、完整卸载/重装或跨宿主测试。
