# 当前设计

Combat Director以场景、战斗类型、人物与招式为输入，生成中文战斗视频提示词。源码基版0.10.0，采用详细编排与模型投喂共用事件事实的设计。

## 创作流程

默认创作不绑定厂商。模型投喂按[通用视频生成写法](../skills/combat-director/references/video-generation.md)区分输入、任务和实际入口能力；Seedance等版本规则仅在用户选用后读取。普通编排保持中文标签和完整动作因果；只有投喂表达与设置随模型适配，不新增生成接口或自动调用。对照官方文档的共通原则与分歧列在该reference，不能把某一版本经验写成通用硬限制。

**战斗设置 → 动作单元 → 状态链 → 时间与镜头覆盖 → 命中及光影 → 正文与对读。**

公共模块独立于分镜，集中写共用风格、人物外观、场景、兵器和规则；每段分镜内部按需求选择中文类型标签，从整体风格、人物与空间，到行为、轨迹、招式、能力、摄影、时间和表演逐项详细展开。25项是写作参考而非必填表；选中栏目描述同一区间，不存在或未涉及的模块直接省略，不写否定占位，不凭空增加情节。

对抗通过攻击、回应、接触或让空、受力和下一威胁接续；演武通过重心、旋向和兵器余势接续。近战先进入射程，换区展示路径，持物、支撑、损伤和地形跨镜持续。相机运动不能替代人物接近，光效不能替代命中反馈。瞬时打击保持启动、接触、受力与分离为同一事件，换镜不再次释放；持续推压则明确接点维持与解除条件。

动作参考迁移先绑定人物与采用范围，再按兵器、体型和地形重算接点与支撑。持续接触交代双方承接及释放条件，交叉遮挡后接回原身份、持物与余势。实际姿态/遮罩/轨迹控制和纯文字编排分别判断；本轮来源、缺口及实施映射见[研究优化方案](combat-research-plan.md)。

整场提示词默认在同一复制块中交付；编排稿每镜写时间/镜长，直接投喂稿按模型改用事件顺序或支持的时间粒度，再在该镜内部用按需选择的不编号【中文标签】展开，公共模块独立写稳定设定，镜内继承并描述变化；一镜到底用镜内节拍。镜长由动作和信息量决定，保留用户明确的轴线、速度和结局。局部改稿仅调整授权层。

## 生成与复测

动作单元、镜头和生成片段分别规划；成片时长按用户指定的总长或范围确定，未指定时按内容与节奏拟定，不设固定默认秒数。编排时间戳用于时间预算，精确切点另作剪辑验收。

图生正文集中描述运动、回应及必要变化；文生补全视觉起点。检查首帧持握、支撑、隐含方向和活动空间，已接架就从接架后续写。首尾帧正确不代表中间路径成立。

分段稿各自带齐必要身份、起态、目标与终态，从已接受的实际画面继续；共享画面不重复计入总时长。用户要求单次直出时，不能以拼接代替。动作密度按同时要兑现的变化判断，先减装饰和重复覆盖，再在授权范围内调整可选动作或片段边界。

生成前声明可观察的通过条件。身份/兵器错乱、不可达接触和终态断裂不能被特效分数抵消；一次修最有证据的一层，保留失败结果并遵守预算。没有新视频，只报告文本结果和待验目标。

## 当前优化与验收计划

目标是达到用户参考的战斗编排与表达水准；时长始终按任务确定。用户已明确本轮最终验收采用“完整提示词、独立创作审阅和技能验证”，不要求实际生成视频。优秀作品片段观察、外部skill源码、文字审阅和实际视频结果分开作为证据；不把视频生成另设为提示词交付门槛，也不由文字或工程通过推断成片效果。

| 工作 | 当前结论与下一验收 |
| --- | --- |
| 官方方法与公开skill | 已核对图生动作优先、输入角色分工和事件/摄影分离；只迁移决策方法，不继承外部固定秒数、动作配额或作者评分 |
| 公开生成案例 | 已取得官方R2V绿幕对照与I2V雪地近战展示，记录源文件、帧序号和局部观察；前者可见输入/结果组合，后者独立首帧仍缺失。针对案例补强指定招式与作用结果分别验收，未将展示当作独立复现 |
| 参考作品 | 诛仙花海段已有局部暂停观察，牧神记已有姿态相位研究；完整实时节奏和音轨仍待核验，不能称全场拉片完成 |
| 当前结果差距 | 本地参考接架序列与旧生成接架序列复查显示，后者多个采样保持近似横剑与竖械关系；优先检查接架后的回应和争位，不能仅增加绕拍或粒子。抽帧不证明完整速度曲线 |
| 写法落地 | 保留连续攻防和局势转折，分别诊断人物速度、摄影速度、播放速度与切镜信息；当前完整候选放在outputs/current，注明设计时长和未生成状态；保留12秒桥上剑枪试用；徒手试写经独立审阅修正身体方位、新轴线与脚部覆盖，当前候选按动作密度调整为13秒 |
| 提示词交付 | 移除平台交接规则；当前花海、林间与徒手三稿统一使用中文类型标签。图中没有的剑、花海和御空明确为创作设定，正文不以平台选择或预检作为写作前置条件 |
| 最终验收 | 以完整中文提示词、独立创作审阅与技能验证为准；三个当前案例分别覆盖实体剑与斗法、长短兵器争位、徒手肘膝开路，此前的动作链均已完成独立审阅和必要修订复核；此前逐镜完整展开已完成独立交叉审阅；现按最新要求改为逐镜按需选项，删减无关栏目并保留动作因果。记录见outputs/current/shot-detail-review.md。实际视频可作为后续任务，不作为本轮完成条件 |

## 维护边界

资料权威在sources/editorial与固定sources/upstream中，先改权威、重建再验证。sources/attachments保存来源原件或明确标注的正文抽取，不作为旧版技能加载。兼容Schema和tests/fixtures用于当前接口回归，不是待清理的旧发布版本。

项目仅保留当前设计、来源说明和最新验证；旧报告、截帧、安装快照及过期产物已清理。当前文字试用与本地检查保留在outputs/current，发布候选在dist，均不进入运行包。验证方法和证据边界见[当前验证](validation.md)。
