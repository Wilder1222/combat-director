# 当前设计

Combat Director 0.11.0提供一个Skill入口，整合通用战斗编排、仙侠机制、素材适配、生成执行与审阅；工程契约为Combat Plan 1.3。普通创作从自然语言输入完成，不先要求平台、JSON或额外素材。

## 一份事实与按需专题

主流程使用“目标与局势变化 → 全局设定 → 动作与状态 → 摄影及时间 → 正文”。人物、身体实例、兵器和事件沿同一状态链变化；正文的发力、摄影、效果、声音解释同一事件，不再发动一次攻击。

入口直接路由交锋、移动、力量/阵法、分身/协同、摄影、风格、声音、素材、模型表达、执行、审阅及证据工具。没有第二仙侠主流程，复杂机制组合共享目标和终态。词库、资料、来源与执行资料仅在对应任务读取；具体权威见[主入口](../skills/combat-director/SKILL.md)。

稳定设定集中，逐镜使用合并栏目，按需展开细项。镜头、动作单元和一次生成请求分开；多镜编排与一镜到底节拍分别表示，独立分段各自自含。时长按内容与用户指定决定，15秒CGI横屏保留为可明确选用的仙侠短片预设。

## 工程与证据

[Combat Plan 1.3](../skills/combat-director/references/contract.md)可选跟踪身体实例、同物件共持/拾取/遥控、成对接点、在途攻击、维持效应、阵法及未完事件。操作从同一初态回放，状态文本由投影生成；旧计划不被补造未知事实，新增事实进入原复核失效传播。

原计划、实际观察和采用续作起态分开。结构化实际状态未知时保持未知，不能从理想计划补填。抽帧工具依据真实PTS定位，保留原片/图像指纹、采样范围和像素转换限制；静帧、原速和音频分别记录。

执行仅在明确制作任务下核对真实入口、素材、镜头模式、声音、报价和累计授权，处理任务未知、幂等、重试与停止。历史源实验不是新任务预算。
