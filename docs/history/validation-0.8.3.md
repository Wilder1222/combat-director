## 工程与创作证据的边界

新例的来源权威位于sources/editorial/0.8.3，作者按每段实际对读身份动作、镜头时间、能力代价和连续性后形成复核凭证。生成器只应用已有凭证，不自动生成或刷新通过结论。八标签由分段摘要输出，镜头文字的语义质量仍需审阅。

[调研与计划](../plans/2026-09-23-motion-blur-integration-plan.md)把文字行为与媒体验证分开。工程通过不说明快门数字在视频平台生效，也不说明动作、粒子或模糊质量已经提升。建议27条媒体试点尚未提交，没有花费视频积分。

独立文字任务与匿名复核的原始结果均已保留。T07指出同一区域“每帧无模糊”与“强长曝光拖糊”的冲突，尚未形成可执行提示词；不计为全部满足，也不为凑满分删改条件。三个旧版对照均满足，现有样本不能证明新规则整体优于旧版。T12两层镜头同步、实际复核与七份导出得到文字和文件证据；完整边界见行为报告。

整体优化计划的WP04逐招详情、WP05紧凑读取、WP06全库独立创作比较仍未完成，motion blur专项不替代它们。
