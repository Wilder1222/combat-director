## 条件对读与验证边界

32 组映射分别列两项或以上条件/例外并保留源案例定位，允许重复机制共享同一章。重点对读互相相反条件：自持符矢停射继续 / 指定撤手立即散；不可碰残影 / 已设凝实；原剑一直载人 / 原剑获允许离脚切支撑；局部破阵 / 有依赖全崩；同时围攻 / 指定单击；全静音 / 剧情人物仍听见预警；精准复刻 / 关系借鉴；源动作错控 / 错误片段不能又要求原样保持。
