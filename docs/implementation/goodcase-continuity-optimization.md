## 二、这个 Skill 真正提供了什么

它主要提供以案例为依据的参考选择：明确保留、替换、避免的范围，将产物对应到选中来源，并区分观察与建议。原流程还要求每次读案例、一个主案例、至少三项映射、三段组织、一次修订及多项交付。[技能正文](https://github.com/LearnPrompt/goodcase-lite/blob/e7dab6009a861dc054cca9a724bca4dbf755d88b/skills/generated/action-continuity-choreography/SKILL.md)

对于当前项目，最值得吸收的是“为什么选这个参考、具体哪条关系迁移成功”的可追溯性。它没有给出双人接点、受力恢复、连续抓握、在途兵器或相邻镜相位的详细实现；这些由当前项目已有动作与状态体系处理。本次不把来源中的宽泛连续性要求包装成新的动力学能力。

## 三、逐项融合决策

以下“采用后写法”是本项目的适配决策，不是源文件原话。

| 来源组织方式 | 本项目采用后写法 | 条件与取舍 |
| --- | --- | --- |
| 输入缺项识别 | 沿用当前人物、目标、时长、素材职责与硬约束 | 普通创作不先索要模型、平台或案例许可 |
| 案例依据 | 按需要的运动关系找证据，记实际读取范围 | 双人接触、追逐、单人演武分别判断；不只匹配标题 |
| 单主案例 | 同一维度优先采用明确主依据，减少无解释混合 | 用户多参考可按动作/摄影/身份/风格互补，不硬限一个 |
| 保留/替换/避免 | 内部说明具体关系、改动边界及不采用项 | 不凑特征数；更换兵器要同步重算双方 |
| 起因/冲突/结果 | 沿用本段目标与局势变化 | 首帧已接架、追逐未完、演武均不强补三段故事 |
| 逐镜连续性 | 增加逐切口组合检查与必要衔接句 | 短镜只承当前相位，不强求每镜完整起收 |
| 对照与修订 | 对照被选关系在当前正文中的位置及后果 | 不设只修一次上限，也不把对照声明当成通过 |
| 多项输出 | 报告按需展示方法约定，提示词保持自含复制块 | 不给仅要正文的用户强塞素材/特殊步骤表 |
| 媒体不足标注 | 文字、静帧、原速、听辨与复测分别记录 | 来源自评、热度和单次评分不证明本项目效果 |

## 六、逐切口方法怎样改善提示词

对每个切口先问它属于接续、重看还是省略。接续再把上一镜结束相位与下一镜起始相位对齐：谁仍在出手、接点是否维持、兵器在哪、运动往哪里去、下一个威胁已经到哪。仅写“流畅衔接”没有提供这些答案。

| 对读点 | 可落到正文的关系 | 需要修正的跳变 |
| --- | --- | --- |
| 事件身份/相位 | 切前正在送剑，切后继续这一次送剑 | 换角又收剑起手、重复命中 |
| 方向与地标 | 同一东门；新视点下投影变化仍通向原门 | 镜像换持手、人物无转向反冲 |
| 射程与覆盖 | 切前已近身；切后取景仍容纳接点 | 推镜后就算远处兵器已触身 |
| 持物和接点 | 原右手、原兵器；相抵则承接原压力 | 切后道具易手、仍抓腕却变自由行动 |
| 动势与威胁 | 落空余势转回防；对方追击继续 | 未制动就站稳、近景期间攻击等待 |

例如：上一镜右剑刺向东侧，守方绕其北侧让空；下一镜从北侧反拍，门洞仍是同一东门，持剑手仍是自身右手。当前画面投影可以改变，世界中的人物路线继续。用户若锁定全程画面左右，则必须选相容机位，不能拿这一例子解除硬要求。

也不要为每个切口加全景、停顿或复位。可读地标、已建立的来路、运动相位与持物对应已足以说明时，下一镜直接继续；覆盖确有缺口再调整相关机位。桥接语句只解释已有事件，不能添加攻击来填空。

## 七、与视觉重音优化的结合

上一轮[冲击帧与闪帧优化](vibeshot-impact-optimization.md)负责同一事件的图形变化与恢复，本次负责它在相邻镜间如何接住。

一次格挡可以在原镜里出现反相，不需要新增shot_id；若随后切到更宽机位，必须继续此前受力、原握点及后撤。闪黑或遮挡不能变成补造接触、镜头形式或身份复位的理由。反相、闪黑、切镜即使都发生在同一接点附近，也分别说明呈现、信息覆盖与事件阶段，不再发动三次攻击。

这两轮共同形成：**本段目标 → 动作与状态 → 镜头覆盖及相邻交接 → 重音及恢复 → 最终正文对读**。素材参考始终限定采用关系，来源解释不挤进只要提示词的复制块。

## 九、验收范围

保留上一轮所有未提交内容，在当前权威上增量修改。独立文字前向试用分别检查无参考的跨镜接触连续、多个文字参考分工与换兵器后的双方适配；读取当前唯一入口，不预先提供本报告结论。真实产物、读取记录、时间检查和语义审阅保存于本机任务目录。

可重复请求及关系验收保存在[回归输入](../../tests/fixtures/continuity-reference-regression.md)。整合审阅曾发现“不抄整套动作”可能误禁用户明确要求的精确复刻，已改为不自动照搬未选定范围；另将摄影教学例句取景扩大到同时能看见持手、刃线与关键落脚的构图。这两项修正保持原动作与镜头数量。

当前内容检查、全量回归、自含候选包及可复现构建由已有项目脚本验证，实际结果见[验证记录](../validation.md)。本轮没有生成打斗媒体或观看外部视频，文字与程序验收不能证明成片动作、接点、方向或音响已经实现。固定源码只作为调研依据，运行技能不增加在线案例依赖或新的收费步骤。

最终结果：697个本地引用与既有28案例/30片段结构通过；204项单元回归中192项通过、12项条件跳过，补充媒体工具22项通过。发布记录40项通过、1个可选校验器未安装；候选包167文件、重复构建字节一致，并核对全部当前运行文件指纹无漂移。两个独立文字试用时间均连续，正文在已读范围保住指定关系；剩余媒体风险包括接点近景辨识、跨侧地标、持握和实际长窗口节奏，均待成片观察。
