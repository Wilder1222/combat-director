## 保留的交接注意项

M01 在八个常用标签外添加 `<局部运动模糊>`，M03 将曝光观感写在 `<特效>` 下。独立评审将两者列为工程映射待定，未判为用户任务失败：本批用户要纯文本，技能入口也仅要求“主要使用”八标签，没有请求或运行解析器。

项目的正式工程契约仍是六轨、八标签，曝光成像进入 `camera`，粒子留存在 `vfx` / `environment`。上述自由文本不能直接视为已通过工程字段映射；后续若转为结构化交付，应归入现有字段并检查细拍与分段摘要。此次未因这两个信息项增加标签语法、改动 Schema 或扩大主技能规则。

M02 评审独立查看了测试图。父任务另核对执行前冻结哈希与当前图片一致；这补充了评审只凭允许输入无法确认的历史快照信息，但不修改其原始未知判断。图像是明确标记的本地几何测试夹具，没有音轨或实际运动。
