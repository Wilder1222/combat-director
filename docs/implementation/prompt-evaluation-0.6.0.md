## 初轮设计

两题各用固定0.5.0和初版0.6.0独立执行一次，共4次。每个执行者只拿到对应Skill及必要引用、原始素材和实际请求。初版0.6.0的提示词参考在后续小修订前另存[输入快照](../../evals/results/prompt-0.6.0/inputs/prompt-craft.initial.md)，对应执行记录中的SHA-256；其他实际读取资源可按run.json核对。

| 题目 | 完整请求 | 原素材 |
| --- | --- | --- |
| intro | 请把这份素材整理成可直接投喂的15秒成年女刀客登场片段，允许切镜，保留原台词和第一斩即将落下时收黑的悬念结尾。只给中文提示词，不实际生成。 | 《小师妹首登》 |
| duel | 请把这份30秒双人斗法提示词修订成六段，保留一镜到底、人物设定、双方招式归属和末段剑指咽喉的压制结尾。只输出完整中文提示词，不实际生成。 | 《双人打斗第二弹》 |

输入与输出清单、哈希见[experiment.json](../../evals/results/prompt-0.6.0/experiment.json)。intro基线的执行记录只有文件路径，没有当时逐文件哈希；所用0.5.0快照已冻结，不能把事后计算冒充执行时采集。

两题都来自本次已分析素材，intro还有同源教学例。这是回归、路由与知识检索检查，不是未见素材测试，也不是普适提升的统计证据。此前项目的12次任务和本轮结果分开记录。

四份均未出现核心要求明确失败或角色技能互换，不能把所有删去的原稿微动作都算作缺陷：请求是压缩修订为六段。也不能将旧版已能完成的结果归因于新文档。

双方intro均未保留“图1人物/图2巨兽”的显式待绑定对应。此次没有取得参考图，所以不判已发生外观错误；若实际投喂包含原配图，应补回各图的用途和对应角色，仍不能声明已经上传绑定。该项作为条件性提醒，不强制所有纯文字提示词带不存在的参考图。

## 针对性修订与复测范围

初版duel第二段的实体剑去程遗漏是此次实际发现的问题，原答案和评语保持原样。只在[prompt-craft.md](../../skills/combat-director/references/prompt-craft.md)增加一个局部检查：回程须从该兵器上一拍实际终点出发；只有剑影攻击、实体剑仍伴飞时，就从身旁转柄回握，不虚构它已抵达远处。

为检验这个修改，以同一个duel请求、同一原素材启动额外一次独立执行，未提供缺陷、修订句或原答案。最终结果另行保存和复核，不覆盖初轮输出。工程发布检查在修订后重新通过。

本轮合计5次任务执行和1次独立匿名复核；最终复测由主任务作内容对读，没有第二轮匿名评分。复测将开场距离由原稿十丈改为六米以降低接近负载，执行记录明确列为创作修订；它不是原素材观察事实。仍有攀石合剑及末段落地的密度风险，结论限于指定兵器路径缺口在本次文本中已修正，不宣称其他语义风险被全面排除。

## 可据此判断与不能判断的内容

本轮证明新增参考能被路由读取，保留来源形式的能力可在具体文字输出中检查，也发现并修订了一项“返回之前未曾到达”的语义缺口。它不能证明任何平台在15/30秒里生成这些内容，也不能证明长镜头、台词口型或巨型剑术的实际效果。

intro最后不足两秒与duel攀石合剑段仍然密集；盲审将其标为媒体预演风险，没有据此捏造成片失败。后续有实际平台与媒体授权时，应先测这些局部时间窗口。未见素材、多次运行、跨模型和隐式触发仍属于待验证范围。
