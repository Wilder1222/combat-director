# 0.9.2：中文参考乱码后的恢复

日期：2026-09-29。0.9.1[宿主长短矩阵](host-motion-matrix-0.9.1.md)中MXH04、MXH06选中正确参考路径，但未从乱码中恢复。0.9.2在技能入口增加一段ASCII英文指引，让宿主即使损坏中文输出仍能读到恢复方法：乱码不算成功读取，重新按UTF-8读取入口与所需参考，Python可用时用`json.dumps(text, ensure_ascii=True)`传递内容，再解读转义；无可读方法则说明限制。

该指引不改变用户创作约束或运动成像规则，也不强制无Python的普通文本任务安装依赖。它针对观察到的失败，不要求每次加载全部资料。没有修改宿主全局编码、升级CLI或日常插件。

## 变化与工程结果

插件版本与入口升至0.9.2。对比两份ZIP，只有`.codex-plugin/plugin.json`及`skills/combat-director/SKILL.md`变化，其他185个运行文件相同，没有新增或删除文件。[包与请求比较](../../evals/results/host-encoding-0.9.2/comparison.json)保存哈希与范围。

正式命令`.venv/Scripts/python.exe -B -X utf8 scripts/validate_release.py`完成41项检查；95项单测中93通过、2项Windows符号链接条件跳过。新包仍为187文件，重复构建字节一致，见[工程记录](validation-0.9.2.json)。旧0.9.1 ZIP保持原哈希，失败事件和评审未覆盖。

## 实际宿主复测
