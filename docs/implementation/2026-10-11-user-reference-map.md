现有运行正文已覆盖上述主要方法，未发现必须新增独立运行文件的功能空白。若强化用户指定多阶段升级，可在[分镜与分段组织](../../skills/combat-director/references/prompt-construction.md#分镜与分段组织)增补一个正向例句：新段改变覆盖、通路或回收条件，继承资源和损坏；仍不固定清兵、头目、大招顺序。

旧文的精确秒数/帧数、固定三级碰撞套餐、每帧双人可见、一镜禁切与内部切镜、变化后直接复位、无机制入鞘迟爆、变身/断首/毁城及固定角色场地不自动成为全局规则。明确复刻项按当前授权保留；有因果冲突时重算关联动作，不能因“参考优秀”直接验收。
