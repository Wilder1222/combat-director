# 0.8.3运动成像：独立文字行为评估

日期：2026-09-23。范围为文字创作、修订和文件导出，没有视频生成、观看或引擎运行。本文与[36项工程发布检查](../validation.md)分别记证据。

## 执行方式

先冻结0.8.2的168个运行文件和0.8.3的175个运行文件，再执行[12题请求](../../evals/motion-blur-0.8.3/cases.json)。每题由独立上下文执行，T02、T08、T11另在旧版各运行一次，共15次执行。执行者只获得对应技能快照、请求和必要素材，不获得研究、改动理由、预期答案或其他回答；产物写在隔离临时目录，完成后原样归档。

T06、T09为未用于修改规则的留出措辞，主题仍在计划范围内，不代表跨领域泛化。各条件只运行一次，使用同一宿主的继承设置，精确服务端模型标识未知；不报告速度、费用或token效率。

独立复核者只收到用户原文、匿名回答和T12的必要输入/产物，没有技能版本、身份映射或设计结论。三组双回答随机排列。T12复核副本只替换输出路径前缀以隐藏条件名，原始回答保留；其他文字仅作编码规范化。复核以用户要求及实际内容为依据，凭证存在和关键词出现均不自动计为满足。

证据入口：[实验条件](../../evals/results/motion-0.8.3/experiment.json)、[全部原始执行](../../evals/results/motion-0.8.3/raw)、[匿名输入](../../evals/results/motion-0.8.3/anonymous-input)、[身份映射](../../evals/results/motion-0.8.3/blind-mapping.json)、[父任务工程核对](../../evals/results/motion-0.8.3/parent-audit.json)。读取清单来自执行者自记，不是系统级访问追踪。

## 已完成的机械核对

- 15次执行均留下回答和记录；101条读取记录的哈希与允许范围一致。
- 两套冻结资源没有内容漂移或新增文件；当前175个运行文件与候选快照一致。
- T01短提示词为96字符，符合其不超过120字的请求。此长度检查不代替内容评价。
- T12保留六拍除`camera.path`以外的全部内容，四段除`summary.camera`以外的全部摘要内容；人物、15秒、时序和结尾不变。总设定中的镜头说明随之同步，另有新ID、来源记录和复核凭证。
- T12实际复核五个scope、通过结构校验并导出七份文件。重算导出文本与全部产物一致，父任务检查不重新签发复核结论。

最初按字节比较T12导出与内存中的LF文本时，七份文件均不同；进一步核对确定差异只有Windows CLI写出的CRLF换行，规范化读取后七份文本完全一致。保留[首次探针](../../evals/results/motion-0.8.3/parent-audit-attempt1.json)和后续诊断，没有把首次字节比较改写成通过，也没有为此修改运行代码。

T07的“部分”表示用户最终想要的可执行提示词尚不存在，原因是题目条件互斥。评价者明确认可指出冲突的处理，不认为这是错误拒绝。该题没有被补写成伪满足，也不把候选结果汇总成12题全部满足；它不构成需要修改运行规则的失败。

三个配对题都不足以判定整体高下。T02两版各自给出连贯的三段木杖交接；T08两版均保留指定画法；T11候选版对曝光数字与工具控制的区别解释更充分，旧版也明确没有执行。旧版T11的“点头即停止”与开场点头确认存在轻微歧义，原样记录；这是单次回答的措辞问题，不能据此推断新版平台适配更好，也不据此增加全局规则。

T12评价者只核对了输入与产物内容，未收到执行者完整命令日志，也没有重跑专用校验器。执行者的[实际记录](../../evals/results/motion-0.8.3/raw/candidate-T12/run.json)和父任务的重算另行支持工程结论；不将这些材料冒充评价者亲自运行的证据。

本轮没有发现候选版暗改速度、镜头、能力或伪称执行平台参数的实质违约，因此保留已冻结的运行版本，不做无证据支持的规则扩张。MB05文字评估完成，MB07可以交付本地文字功能与已验证的ZIP；视频效果仍需MB06。

## 适用范围

这组样本检验显式使用技能时的文字行为，不检验Codex自动选技能、跨会话调用、实际平台参数或视频效果。同一宿主设置下的单次执行和一次复核不能给出通用成功率，也不能独立识别规则本身的因果贡献。

完整运行快照与两个ZIP保留在本地工作区；仓库证据目录保存文件清单和哈希，没有再复制全部运行文件作为独立重放包。原始结果中的临时绝对路径保留，当前归档可按实验目录定位。

工程检查、作者教学案例、执行者语义复核与本次匿名评价分别记录；它们都不是媒体观测。27条A/B/C视频试点仍为计划，WP04逐招详情、WP05读取精简及WP06全库行为验证仍需各自完成。

当前研究、实施文档及证据目录的交付哈希见[完整性记录](motion-blur-delivery-0.8.3.json)。此前研究阶段的校核仍作为历史保留，不拿其旧哈希代表当前修订。
