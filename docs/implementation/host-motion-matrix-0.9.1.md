## 条件和完整性

沿用此前验证可运行的条件：应用已有CLI0.154.0-alpha.6.2，继承宿主模型设置，无模型或推理强度覆盖；独立临时项目、只读unelevated沙箱、仅本次调用关闭插件发现以隔离日常旧版。每题为新的ephemeral会话。未升级日常插件、修改全局配置或生成媒体。

[请求与协议](../../evals/host-motion-matrix-0.9.1/README.md)在调用前准备；[机器审计](../../evals/results/host-motion-matrix-0.9.1/audit.json)保留八次命令、答复、耗时、可取得的usage与哈希。每个临时项目的186个技能文件均与0.9.1 ZIP相同，所有执行器声明的产物哈希均通过核对。CLI退出码均为0，但未用它替代加载或语义判断。

八次事件都有宿主提示：技能描述因上下文预算被缩短，仍保留全部技能入口。此项是实际宿主条件，不能声称完整描述始终全部进入上下文。完整错误项及其他启动信息留在各题events和stderr，未据此改动全局技能配置。

两个独立评审分别只收到四份原请求及完整最终答复，未收到父任务判断或读取结果。八题均为`satisfied`，未报告硬失败或具体小问题；评审明确不从文本确认工具调用或媒体效果。[前四题复核](../../evals/results/host-motion-matrix-0.9.1/reviews/MXH01-MXH04/review.json)覆盖动作、接触因果与输出限制；[后四题复核](../../evals/results/host-motion-matrix-0.9.1/reviews/MXH05-MXH08/review.json)覆盖诊断证据边界、最小修复及静态结尾。
