## 二、与当前项目的真实差距

当前工作树已有仙侠整合与工程升级。本次沿用其 0.11.0 权威，不回滚到旧版，也不把现有方法当成新增成果。

| 能力层 | 项目已经做到 | 本次补足 |
| --- | --- | --- |
| 战术与剧情 | 目标、阻碍、选择和终态分别编排 | 将视觉重音接入目标推进，格挡、取路也可以成为重点 |
| 动作 | 人物路线、发力、兵器轨迹、回应、传力与分离 | 效果明确绑定当前事件相位，防止图形变化偷换作用对象 |
| 摄影 | 信息任务、接点覆盖、自由/固定轴线、单镜路径 | 呈现重音不自动新增机位、切镜、冻结或慢镜 |
| 状态 | 持物、在途攻击、连接、伤势、环境持续 | 画面恢复只恢复呈现，不能恢复旧盾、无伤身体和旧站位 |
| 风格 | 材质、术法光、尾迹、二维/三维转换分层 | 区分整幅画面处理与场内光源，细化具体闪帧任务 |
| 生成适配 | 素材职责、接口粒度、自然语言/真实参数分开 | 几帧的设计要求继续按实际接口或后期能力核验 |
| 审阅 | 原速、连续帧、听辨分别取证 | 给出效果提前、拖长、吞接点、复位和归因的专项诊断 |

保留工程契约：这些变化主要属于编排与呈现，不是新增兵器、能力或伤害事件，无需为闪帧另建一套状态 schema。原有事实回放继续负责事件与状态，新增文字审阅负责图形信息和效果范围；二者的证据不能互相代替。

## 三、优化后的整场组织

主流程仍由动作和状态驱动，视觉重音在动作及覆盖成立后选择：

**人物目标与局势 → 稳定身份/能力/起态 → 双方动作与状态 → 摄影及时间覆盖 → 视觉重音及恢复 → 最终正文对读。**

例如“要穿过石门”的战斗，最有信息的事件可能是挡住封路重击并取得侧翼通道。把重音放在这一挡上，观众就能理解脱身为何成立。若给每次试探、擦碰和收剑同样强的变化，主事件缺少层次；应调整可选呈现，不能因此删掉指定攻防。

没有要求效果的任务仍可写清普通交锋；要求多个重音或复杂组合的任务按本段职责安排。示例中只用一种主效果是本例的选择，不是所有战斗的上限。高潮也不强制击飞、破甲或大招收尾。

## 四、相位、图形和状态怎样一起写

### 相位决定观众读到什么

| 本项目判断 | 必须有的事实 | 常见误写 |
| --- | --- | --- |
| 启动重音 | 尚未接触的间隙、发力或实际来势 | 一压暗就让对手受伤后退 |
| 接触重音 | 作用对象、接点、防守及双方承力 | 格挡爆光被写成人体实击 |
| 后果重音 | 已发生作用造成的失衡、破损或通路变化 | 恢复后重发攻击才出现结果 |

已修正交锋文档中可能被理解为“所有闪帧必须在接触后”的句子。命中效果要让对应来路、接点和受力可读；启动重音仍允许，只是不提前制造本次命中的结果。

### 图形保留针对当前交锋

本项目把画面信息分成三类：需要读出的主关系、可以临时简化的纹理、必须持续的场内状态。前两类用于构图，第三类用于连续性。

例如棍剑相撞，应能区分棍端、剑身中段、持手和两人承力轮廓。背景砖纹可以短暂淡去，门洞仍是同一位置；雨水、擦痕和正在偏转的兵器不会因纹理简化自动消失。反相后的蓝袖仍是原蓝袖，屏障破口仍是既定破口。

速度线承担图形引导，不是离体斩波。放射线应指向这次作用的接点；已经设定的实体碎片另走受力路径。把线条、碎片、尾迹和光源写成不同对象，能减少提示词把“效果”生成成第二次攻击的歧义。

### 各效果对应不同制作判断

- 冲击帧主要改变图形组织。它可以出现在原镜内，不自动变成定格或新机位。
- 全屏提亮作为画面处理时，不新增一个击退人物的光球。场内碰撞光则要有真实来源、照射对象和退光过程。
- 反相结束恢复当前照明和身份颜色，不能恢复破损或重新长出旧盾。
- 整幅黑场拿走可见信息。要求看清的接触要在相邻实际画面成立；黑后反应不能证明黑中已展示接点。
- 效果叠加需写顺序与分工；声源仍对应原事件，不为每一层处理增加一次撞击。

上述是项目的写作与审阅决策；具体维护权威在[风格与材质](../../skills/combat-director/references/style-and-materials.md#冲击帧与闪帧)。

## 五、正文、素材与模型投喂的整体一致性

正文只增加有用信息，不再要求逐镜填写效果表。一个可用句式是：

**具体事件/相位 → 暂时的画面变化 → 当前必须保留的信息 → 恢复后的受力、回收和新状态。**

这四部分落在同次事件的【画面与动作】中；摄影写怎样看清，衔接写怎样续上。它们不分别发动攻击或增加占时。稳定身份、材质和总时长仍集中在公共设置中。

视觉参考增加明确职责：可采用短暂明暗、轮廓分离或恢复方式，不能顺便继承参考全部动作和全片风格。换兵器时要同时重算双方距离、防线、握法、接点和后果。图生已提供静态设定时集中写变化；关键关系仍须进入最终提交文本或真实绑定输入。

指定“2帧反相”可以作为制作要求，但自然语言直出是否兑现要观察输出。接口没有精确帧控制时不虚构参数；需要后期才能实现且用户要求单次直出时，说明具体冲突，不能暗中以拼接或后期替代。这里未重新选择模型或启动生成。

## 六、完整原创改写示例：棍剑取路

这是一份 12 秒、四镜的文字设计，用格挡取得通路，展示效果恢复后的连续行动。12 秒和四镜只属于这个示例；它没有生成视频，文中时间是导演预算。

```text
【本段概述】12秒，16:9横屏，雨夜石院的棍剑交锋。青衣剑客要越过守路棍客进入东侧石门；末尾她通过石门，棍客仍在院内，胜负未分。快速实速，无对白，非血腥。整体为有清楚布料、湿石和金属材质的3D国漫CGI；一次短促的图形化重音只强调关键格挡，无慢镜、无停格。
【人物与兵器】青衣剑客只有一柄约八十厘米的直剑，起始握在右手，左手空着；棍客灰衣，双手握一根约一米八的木棍。实体数量与持有者保持，双方无御空、瞬移或离体攻击。
【场景与起态】青衣在院西，面向东；灰衣在她东侧约一米九，面向西。石门位于灰衣身后两米的东墙，门前北侧通路可行。月光是环境主光，门内暖光照出门槛；地面薄积水。相机在双方南侧，所有切镜保持同侧观察。

让开棍路｜0—3秒（镜长3秒）
【画面与动作】灰衣前脚向西短进，后手送棍，棍前端沿胸高直线戳向青衣。青衣目光跟住棍端，左脚向北斜落、后脚跟入，将胸线移出戳击线路；右肘收在身侧，剑尖斜指前下，棍端从她右侧掠空。灰衣双肘屈曲回抽木棍，同时转脚跟住她的新位置；双方没有身体接触。青衣借侧移向门前北侧逼近，视线从回抽棍端转向灰衣肩线。
【摄影】南侧中全景横移跟住，容纳双方全身、棍端和北侧落脚；戳棍与让线保持月夜正常曝光，雨与积水按身体移动反馈。

封住落棍｜3—5秒（镜长2秒）
【画面与动作】灰衣随转髋把棍前端抬过外侧肩线，双手下带，将木棍斜落向青衣上肩。青衣前膝屈曲、后脚撑地，右手抬剑在额前斜架，左手合握剑柄尾端辅助承力，剑身与落棍呈可读夹角，剑锋避开头脸。棍端压到剑身中段，青衣双肘随来力下沉、后脚在湿石上向西滑出短痕；这一挡阻止木棍落到肩部。
【视觉重音】只在木棍与剑身实际相抵时，墙面纹理短暂淡去，画面显为暗蓝底的浅色轮廓。保留两人分开的身体轮廓、双手握点、棍端与剑身方向和唯一交点，少量短线从棍剑交点散开。该图形变化短促退去，恢复当前月光、暖门光和原衣色；双方继续同次承力，剑没有重新抬起，木棍没有再落第二遍。
【摄影】切同侧稍低机位的中全景，纳入两人持手、兵器交点及青衣屈膝和后脚，提前留出下沉与后滑空间；接点、屈肘承力和脚滑连续可辨，不靠闪光证明格挡。

导棍取侧｜5—8秒（镜长3秒）
【画面与动作】从刚才相抵状态继续。青衣前脚向北外侧换支撑，右腕转剑面、双肘斜向南送，将棍端从头肩线路导向她右侧的低处。灰衣随棍前端偏南屈肘压住余势，前脚斜踏南侧承重；棍端落到南侧湿石，溅起短水花，剑棍随即分开。青衣左手从剑柄放开，右肘收剑靠近腰侧、剑尖斜向前下，沿灰衣北侧空出的通路向东穿过，不追加斩击。灰衣低棍仍由原双手持着，正在回收，不瞬间复位封路。
【摄影】切回南侧全景，沿院落向东横移，清楚交代剑棍分开、灰衣承重脚与青衣从其北侧经过；保持正常色彩，让水花和偏出的棍端响应原作用。

越槛回守｜8—12秒（镜长4秒）
【画面与动作】青衣承前面的向东动势跨过门槛，后脚跟入，在门内屈膝减速，再转身面向院内。她仍以右手握原剑，收肘将剑尖指向门外，左手抬到身前保持平衡。灰衣先从偏南的落棍位置抽起木棍，转脚与肩线朝东追视青衣，双手把棍端带回身前；双方已拉开到木棍不能直接触及的距离。青衣通过石门，灰衣留在院中，门仍开着，后脚滑痕与地面水波继续，双方都未受伤。
【摄影】南侧后退到能纳入石门和两人位置的全景，看到青衣入门、制动转身和灰衣回收。曝光与月夜风格持续，不再增加闪帧或英雄定格。
```

这个例子重点核对三件事：格挡是兵器作用而非人体命中；恢复接下沉与导棍，而非重新落棍；取路结果来自真实偏线与移动，而非画面一闪就进门。若真实视频做不到其中任一关系，应先定位动作或覆盖，再修呈现。
